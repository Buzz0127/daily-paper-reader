## 摘要
LLM智能体在数字环境中遵循一个实用的执行循环：它们在结构化状态上进行推理、调用工具、检查反馈并修正动作。将这个循环扩展到物理机器人是困难的，因为物理执行是连续的、依赖于具体具身、具有不确定性，并受到安全约束。现有的具身AI系统在操作、空间理解、导航和人形控制方面取得了进展，但这些能力通常仍然是专门的模块或松耦合的决策循环。在这项工作中，我们引入了HoloAgent-0，一个用于真实世界机器人部署的统一具身智能体框架。Embodied AgentOS将语言指令转换为可执行的技能图，调度机器人资源，监控执行，并根据运行时反馈触发澄清或重新规划。HoloAgent-0通过三个耦合层组织异构的机器人模型和控制器：用于闭环执行的Embodied AgentOS、用于物理世界扎根的3D空间记忆，以及用于机器人动作的具身技能。我们在真实硬件上部署了HoloAgent-0，并评估了其空间记忆、长程导航以及跨运动生成、物体搜索、跨机器人协调和移动操作的闭环执行能力。

## Abstract
LLM agents follow a practical execution loop in digital environments: they reason over structured states, invoke tools, inspect feedback, and revise actions. Extending this loop to physical robots is difficult because physical execution is continuous, embodiment-dependent, uncertain, and constrained by safety. Existing embodied-AI systems have advanced manipulation, spatial understanding, navigation, and humanoid control, but these capabilities often remain specialized modules or loosely coupled decision loops. In this work, we introduce HoloAgent-0, a unified embodied agent framework for real-world robot deployment. Embodied AgentOS converts language instructions into executable skill graphs, schedules robot resources, monitors execution, and triggers clarification or re-planning from runtime feedback. HoloAgent-0 organizes heterogeneous robot models and controllers through three coupled layers: Embodied AgentOS for closed-loop execution, 3D spatial memory for physical world grounding, and embodied skills for robot action. We deploy HoloAgent-0 on real hardware and evaluate its spatial memory, long-horizon navigation, and closed-loop execution across motion generation, object search, cross-robot coordination, and mobile manipulation.

- **整体含义**：HoloAgent-0提出一个**系统级组织方案**，将语言层面的推理与物理世界执行通过持久记忆、类型化技能接口和运行时监控连接起来，实现面向真实机器人的统一具身智能体框架。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- **闭环优先（Closed-loop first）**：将规划视为重复的观察-检索-行动-监控循环，而非一次性文本生成。
- **记忆中心（Memory-centric）**：持久空间记忆（几何、语义、层次化场景图）和时间记忆（任务状态、执行轨迹）作为规划的主要上下文。
- **类型化技能接口（Typed skill interface）**：机器人能力以类型化、可监控的技能调用形式暴露，包含命令参数、前提条件、预期效果和运行时状态事件。
- **默认可观测（Observable by default）**：记录所有命令、状态、记忆检索、转换和结果，支持调试和重规划。

### 关键技术细节
- **三层架构**：
  - **Embodied AgentOS层**：将自然语言指令转换为可执行技能图（skill graph），调度机器人资源，监控执行，基于反馈进行澄清或重规划。
  - **记忆层（Memory Layer）**：
    - **空间记忆**：包括几何/拓扑/占据网格、机器人位姿、开放词汇3D语义地图、层次化多模态场景图（HMSG：楼层-房间-视角-物体层级）。支持基于LiDAR或纯视觉（GeoFlow-SLAM++）的后端。
    - **时间记忆**：记录目标与计划状态、执行与恢复轨迹、结果摘要。
    - **记忆更新**：根据新观测、技能结果、用户反馈增量更新几何、语义和场景图。
  - **技能层（Skill Layer）**：将机器人能力封装为类型化技能调用，包含交互（语音）、感知（开放词汇检测）、导航（HoloNavi）、操作（HoloBrain）、全身运动（HoloMotion）等。每个技能发布状态事件（进度、成功、失败模式、置信度、可恢复性等）。
- **闭环执行流程**：用户指令 → 解析 → 从记忆检索上下文 → 分解为技能图 → 调度执行 → 监控验证 → 成功或触发重规划/澄清。
- **跨具身协调**：异构机器人共享同一记忆、技能调用和状态事件，AgentOS根据能力、位置、可用性分配任务。

## 7. 优点：方法或实验设计上的亮点
- **系统级创新**：将数字LLM智能体的闭环循环成功迁移到物理机器人，提出类型化技能接口，使物理技能像API一样可组合和监控。
- **记忆中心设计**：持久3D空间记忆（HMSG）支持粗到细的空间检索，并与时间记忆结合，避免仅依赖当前视觉输入。
- **实时内存更新**：支持增量更新几何、语义实例和场景图，适应动态环境变化。
- **实验设计亮点**：
  - 模拟和真实机器人导航评估采用了相同的协议（FSR-VLN基准），便于分离模型能力与硬件噪声。
  - 真实导航评估采用多距离阈值，揭示了失败本质（恢复问题而非定位）。
  - 语义映射对比包括在线方法，强调可部署性。
- **跨具身协调**：通过共享记忆和类型化技能接口实现异构机器人协作，无需额外协调器。
- **开放性与可扩展性**：基于ROS2命令/状态总线，开发者可替换独立模型或控制器。
