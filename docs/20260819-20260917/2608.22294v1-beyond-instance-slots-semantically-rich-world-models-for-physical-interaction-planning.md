## 摘要
用于物理交互的世界模型通常被训练来预测未来观测或潜在特征；然而，面向规划的模型必须回答一个根本不同的问题：候选动作是否能在保持关键关系的同时产生任务一致的未来。单体式状态表示会掩盖底层实体，而标准的实例级对象槽位仅能识别存在什么，而无法指明每个实体在任务情境中扮演什么角色。为弥合这一差距，我们提出语义丰富世界模型（SR-WM），这是一种以五个功能角色为中心构建的任务条件世界模型：夹爪、目标物、目标、关系和阶段。在 SR-WM 中，视觉实体编码器从预训练图像块特征中提取软实体假设，使分割掩码可作为可选的提议先验，而不强制其作为必需的状态表示或推理输入。随后，角色绑定器将这些假设映射到任务特定的角色，而动作条件动力学模型则预测角色转移以及细粒度语义，包括抓取/接触、谓词建立、关系保持、固定装置状态和阶段变化。至关重要的是，这种统一的角色状态为下游的多候选动作生成、阶段感知重排序和违规感知后缀重采样提供基础。我们全面的评估协议涵盖全部四个 LIBERO 模拟套件、跨套件迁移、感知诊断和动作敏感性分析。最终，这一表述将对象中心预测转变为连接视觉动力学与面向规划决策的语义接口。

## Abstract
World models for physical interaction are typically trained to predict future observations or latent features; however, a planning-oriented model must answer a fundamentally different question: whether a candidate action produces a task-consistent future while preserving essential relations.Monolithic state representations obscure the underlying entities, while standard instance-level object slots merely identify \emph{what} is present without specifying \emph{what role} each entity plays in the task context. To bridge this gap, we present the Semantically Rich World Model (SR-WM), a task-conditioned world model structured around five functional roles: gripper, target, goal, relation, and phase.Within SR-WM, a visual entity encoder extracts soft entity hypotheses from pretrained patch features, allowing segmentation masks to serve as optional proposal priors without mandating them as required state representations or inference inputs.A role binder subsequently maps these hypotheses to task-specific roles, while an action-conditioned dynamics model predicts role transitions alongside fine-grained semantics, including grasp/contact, predicate establishment, relation preservation, fixture state, and phase change.Crucially, this unified role state grounds downstream multi-candidate action generation, stage-aware reranking, and violation-aware suffix resampling.Our comprehensive evaluation protocol spans all four LIBERO simulation suites, cross-suite transfer, perception diagnostics, and action-sensitivity analysis.Ultimately, this formulation transforms object-centric prediction into a semantic interface linking visual dynamics with planning-oriented decision making.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：物理交互世界模型通常以"预测未来观测或潜特征"为目标，但低预测误差并不等于有用的决策——一个看似合理的未来可能抓错物体、丢失抓取、破坏已打开的抽屉，或过早释放。
- **核心问题**：面向规划的世界模型必须回答一个不同的问题——**候选动作是否在建立所需状态的同时保持已满足的约束**。
- **现有方法的缺口**：
  - **单体式（monolithic）状态表示**掩盖了底层实体，无法定位错误来源；
  - **标准实例级对象槽位（instance slots）**只能回答"有什么"，无法说明每个实体在任务中"扮演什么角色"——同一物体在不同指令下可能是 target、goal 或干扰项；
  - 交换式实例槽位把任务绑定与进度推进全部推给下游策略。
- **整体含义**：论文提出 **SR-WM（Semantically Rich World Model）**，将对象中心预测重构为连接视觉动力学与规划决策的**语义接口**，使任务结构直接进入预测通路与动作先验，而不仅是事后重排。

## 2. 方法论：核心思想与关键技术

### 2.1 核心思想
- 将视觉实体（task-agnostic entity hypotheses）**绑定到五个非交换式功能角色**：`gripper`、`target`、`goal`、`relation`、`phase`，形成任务条件化的统一角色状态 $Z_t$，同时作为动作生成、动力学预测、语义转移预测、选择与修复的状态空间。

### 2.2 关键技术细节
- **轻量基础**：基于 15M 参数的 LeWM（5M ViT-Tiny 编码器 + 10M transformer 预测器），保留原始预训练目标与 patch token。
- **软实体编码**：学习到的实体查询对多视角 patch token 交叉注意力，输出包含外观、几何、运动、置信度的软实体 $e_{t,n}=(f^{app}, g^{geom}, m^{motion}, c^{conf})$；实体不必与分割掩码一一对应。
- **可选掩码先验**：Grounding DINO 框可提示 SAM/SAM2 生成 proposal-to-patch 亲和度，**仅作为加性注意力偏置**（式 6，系数 $\lambda_{seg}$）；训练时对 proposal 集合、单个 proposal、偏置强度做三级 dropout，$\lambda_{seg}=0$ 即 patch-only 推理；proposal 索引不被当作持久物体地址。
- **任务条件角色绑定**：语言与本体状态条件化的角色查询对软实体做交叉注意力（式 7），五个查询**非交换、独立参数化**；目标/终点标签仅训练时使用，推理只需 RGB、本体感受与语言。
- **动作条件角色动力学**：动作编码器把 chunk 划分为 $J$ 个有序子段，角色 transformer 交替进行角色间自注意力与动作交叉注意力，并施加门控残差更新（式 8–9），门控可保持静态角色不变；预测中间转移而非仅端点，用于定位违规起始点。
- **语义转移监督**：轻量头解码接触/稳定抓取、谓词建立、谓词保持/违反、多条件合取满足、阶段身份与转移合法性、固定装置（抽屉位移、微波炉门角、炉灶激活）状态；建立与保持**分开监督**。
- **硬负样本动作判别**：正样本与保留观测和目标、但打乱段序、反转 approach–grasp、替换轨迹、扰动释放时机的负样本配对，使用 margin loss（式 10）；未通过预设 shuffle margin 的 checkpoint 被排除出语义选择。
- **角色条件 Flow-Matching 动作头**：以 $Z_t$ 与 $\ell$ 为条件，从 K 个独立噪声采样候选 chunk（式 11）。
- **阶段感知语义选择器**：输入当前/预测阶段、接触、建立、保持、固定装置、不确定性，MLP 打分（式 12）；阶段条件使相同位移在 approach/transport/release 阶段得分不同。
- **违规感知后缀重采样**：若最高分低于 $\eta$ 或预测在段 $j^\star$ 违规，则**锚定有效前缀 $A^{k^\star}_{1:j^\star-1}$，只重采样后缀**；训练用掩码动作 inpainting 损失，推理在每个 ODE 步后重置前缀坐标。
- **训练目标**：11 项损失分为三组 $L = L_{rep} + L_{sem} + L_{policy}$，覆盖 LeWM 潜预测、角色绑定、状态动力学、接触/抓取、谓词建立、关系保持、阶段、固定装置、FM、硬负排序、后缀修复。

## 6. 主要结论与发现

- **角色条件显著改善生成与覆盖**：Candidate 0 平均从 45.5% → **62.8%**；Oracle@4 从 68.0% → **89.5%**，说明语义结构在**选择之前**就改变了动作分布。
- **选择与修复带来部署收益**：语义选择器达到 **75.3%** top-1 成功（与 Oracle@4 仍有 14.2 个点差距），后缀修复进一步提升至 **83.0%**，pairwise 排序准确率 78.2%。
- **对分割掩码弱依赖**：patch-only 推理仍达 **72.6%**，损坏掩码仅降至 70.8%，oracle 掩码上界 78.4%——分割只是有益的结构先验而非必需输入。
- **动作因果敏感性依赖显式语义监督**：完整模型 shuffle gap 0.157、排序准确率 78.2%；移除语义头降至 60.8%，移除 shuffle 负样本塌缩到 53.7%（近随机），移除保持/阶段损失分别降至 69.4%/66.8%。
- **角色结构单调增益**：55.0 → 62.0 → 68.0 → 73.0 → **83.0%**，说明显式分解的角色架构远优于非结构化实例槽位。
- **跨任务迁移有效**：Object 训练的零样本在 Spatial/Goal 保持 58.4%/52.7%；适配后在 Goal 达 74.6%（从零训练 66.3%）、LIBERO-10 达 58.7%（从零 50.6%）；联合多套件预训练后适配达 78.4%。
- **主要失败模式**：(1) 严重感知遮挡导致丢失目标几何中心、过早预测谓词建立；(2) 粒度阶段错位，如释放阶段提前一个子段触发，缺少细粒度触觉反馈导致掉落。

## 7. 优点

- **概念清晰**：明确区分"实体假设"与"任务条件预测状态"，论证 SR-WM 不是"槽位 + 语言头"，而是用角色状态替换交换式实体集合作为预测接口。
- **架构轻量且模块化**：保留 15M LeWM 主干，完整系统 45.4M，避免引入基础模型级视觉骨干；语义模块参数可单独核算。
- **掩码设计优雅**：分割仅作加性注意力偏置 + 三级 dropout + $\lambda_{seg}=0$ 可退化，配合 patch-only / corrupt / oracle 三档诊断，实证"弱依赖"主张。
- **评估解耦彻底**：把表示质量、动作敏感性、候选覆盖、选择器质量、物理执行分开报告，并把 shuffle margin 作为 checkpoint 接受准则而非事后诊断。
- **修复机制有针对性**：只在最早违规边界处重采样后缀，与全 chunk 重采样在匹配生成调用预算下对比，避免"额外调用优势"混淆。
- **可复现性意识强**：附录给出符号接口表、11 项损失明细、标签构造规则、信息访问审计、provenance key 与物理部署门控。

## 8. 不足与局限

- **本体覆盖有限**：五角色本体假设单一主导的 gripper/target/goal，可能不适用于**双臂交互、可变形物体、工具使用、多同时目标**，这类任务可能需要可变基数的状态图。
- **监督成本**：谓词与阶段监督在仿真中廉价，但在真实物理交互中需要谨慎标注或估计；未支持谓词被显式报为解析错误而非静默负标签。
- **感知失败未被消除**：可选分割降低了对特定分割器的依赖，但不消除遮挡或绑定失败；弱依赖主张仅在表 3 的 no-mask / corrupt-mask 测试成立时有效。
- **修复的额外成本与安全风险**：前缀保留修复增加推理调用，且在没有碰撞检查与底层安全保障的情况下不适合安全关键执行。
- **系统级"小模型/实时"主张受限**：虽然保留主干约 15M，但完整系统 45.4M，作者明确不给出端到端"小模型"或实时性主张，除非表 7 的实测支持。
- **Oracle@K 非可部署**：高 oracle 伴随弱 top-1 选择意味着选择器问题未解决；论文自身将 Oracle@K 定位为分析上界。
- **实验范围**：全部结果基于 LIBERO 仿真，未见真实机器人实验数据（附录虽给出物理系统协议与部署门控，但主文报告的是仿真结果）；跨套件迁移的公平性受源预训练数据与总计算量未控制的限制。
- **无重复多次训练的方差报告**：成功率带 ± 标准差，但未说明训练种子数量与训练间方差来源。
