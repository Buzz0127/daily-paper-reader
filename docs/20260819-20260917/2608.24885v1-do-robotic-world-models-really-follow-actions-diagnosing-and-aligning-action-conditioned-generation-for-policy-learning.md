## 摘要
动作条件世界模型正越来越多地被用作学习型模拟器，用于策略评估与改进，但其有效性依赖于一个尚未验证的假设：生成出的未来能够忠实反映任意有效动作。现有基准通常局限于专家演示，导致对非专家动作遵循能力的评估不足。为填补这一空白，我们提出 WorldEcho，它利用视觉完整性和 SE(3) 轨迹对齐，在更广泛的动作分布上探测动作遵循能力。我们的诊断表明，当前世界模型能够较好地执行专家动作，但在多样化的非专家轨迹上表现不佳，要么忽略指令动作，要么生成视觉上无效的展开。我们进一步提出 WorldSync，从三个互补维度增强动作遵循：分布覆盖、表征基础以及干预效果对齐。它扩展了关于动作后果的训练分布，通过 Action-Forcing Expert 将中间视频表征建立在动作引发的机器人动力学之上，并使动作干预下的预测变化与真实未来中的相应变化对齐。在 RoboTwin 基准和真实机器人任务上的实验表明，WorldSync 提升了 WorldEcho 指标，并作为更可靠的模拟器用于迭代策略改进，使策略取得更高的成功率。

## Abstract
Action-conditioned world models are increasingly used as learned simulators for policy evaluation and improvement, yet their effectiveness rests on an unverified assumption: generated futures faithfully reflect arbitrary valid actions. Existing benchmarks are typically confined to expert demonstrations, leaving off-expert action following inadequately evaluated. To address this gap, we introduce WorldEcho, which probes action following over a broader action distribution using visual integrity and SE(3) trajectory alignment. Our diagnosis shows that current world models reasonably execute expert actions but struggle with diverse off-expert trajectories, either ignoring the commanded actions or producing visually invalid rollouts. We further propose WorldSync, which strengthens action following along three complementary axes: distributional coverage, representational grounding, and intervention-effect alignment. It broadens the training distribution over action consequences, grounds intermediate video representations in action-induced robot dynamics through an Action-Forcing Expert, and aligns predicted changes under action interventions with the corresponding changes in ground-truth futures. Experiments on RoboTwin benchmarks and real-robot tasks show that WorldSync improves WorldEcho metrics and serves as a more reliable simulator for iterative policy improvement, enabling policies to achieve higher success rates.

## 1. 核心问题与整体含义

- **研究动机**：动作条件世界模型（AC-WM）被广泛用作"学习型模拟器"，用于策略评估与迭代改进，以降低真实机器人交互的高昂成本。然而，这一应用建立在一个**未被验证的假设**之上：模型生成的未来画面能够忠实反映任意有效动作的后果。
- **核心问题**：现有机器人世界模型基准大多局限于**专家演示分布**，对"离专家动作"（off-expert action）的遵循能力评估严重不足。而策略评估与改进不可避免地会查询专家分布之外的动作（如策略探索、失败恢复、跨状态回放等）。
- **关键矛盾**：若模型对动作不忠实，则①评估阶段会产生"看似合理但动作不一致"的未来，造成仿真—真机策略性能落差；②后训练阶段需额外验证/拒绝/过滤不可靠 rollout，降低可用经验产出率。
- **整体含义**：论文提出"诊断—改进—验证"（Diagnose–Improve–Validate）闭环：先用 WorldEcho 诊断动作跟随缺陷，再用 WorldSync 针对性改进，最后通过下游策略改进验证其实用价值。

## 2. 方法论

### 2.1 问题形式化

- 给定当前多视角观测 $o_0$、语言指令 $c$ 和动作序列 $a_{1:H}$，AC-WM 建模 $p_\theta(I_{1:H} \mid o_0, c, a_{1:H})$。
- 用 $\Phi$ 从视频中提取末端执行器轨迹 $\hat\tau = \Phi(\hat I_{1:H})$、$\tau^{GT} = \Phi(I^{GT}_{1:H})$。
- **可靠世界模型的判据**：生成视觉有效的未来，且其诱导的机器人轨迹与查询动作的真实后果一致。

### 2.2 WorldEcho：动作跟随诊断基准

**（1）五类动作查询构造**（对专家分布依赖递减）：

| 类别 | 含义与诊断目标 |
|---|---|
| Demonstrated Action | 回放当前观测对应的专家动作，作为分布内基线 |
| Cross-State Replay | 将其他状态的专家动作用于当前状态，检验是否捕捉状态依赖的动作效果 |
| Local Perturbation | 对专家动作施加有界扰动，探测对专家流形附近局部变化的敏感性 |
| Policy Rollout | 使用学习策略产生的动作，反映策略评估/改进中的真实偏离 |
| Feasible-Space Sampling | 从更广的机器人动作空间采样有效动作，评估可控性 |

所有离专家查询均需通过可行性过滤，并在 RoboTwin 中从同一初始状态回放，得到动作专属的 GT rollout。

**（2）视觉完整性评估**（四项合取门控 $G_{vis} = G_{quality} \wedge G_{motion} \wedge G_{EEF} \wedge G_{arm}$）：
- 图像质量 $q$：MUSIQ 帧级感知保真度，阈值二值化；
- 运动平滑度 $m$：帧插值一致性衡量时序连续性；
- 末端执行器可见性：基于 SAM 的视频跟踪；
- 机械臂完整性：视觉语言评估器检测模糊、断裂或消失的机械臂。

**（3）末端执行器 SE(3) 轨迹对齐**：
- 局部位姿差异：$d_e(i,j) = [w_p^2 \|\hat p_i^e - p_j^{e,GT}\|_2^2 + w_R^2 d_{SO(3)}^2(\hat R_i^e, R_j^{e,GT})]^{1/2}$
- 旋转差异：$d_{SO(3)}(R_1,R_2) = \arccos(\text{clip}(\xi,-1,1))$，$\xi = \frac{\text{tr}(R_1^\top R_2)-1}{2}$
- 使用**位姿感知归一化动态时间规整（NDTW）**对齐两条轨迹，按对齐路径长度归一化（**不按参考轨迹空间范围归一化**，以保留绝对度量尺度）。
- **完整性门控评估协议**：$S_n = D_{NDTW,n}$（通过门控）或固定惩罚 $\kappa$（未通过）。先按任务内平均，再跨任务宏平均，避免样本多的任务主导排名。同时报告视觉通过率和未门控 NDTW。

### 2.3 WorldSync：三轴改进训练配方

**核心思想**：诊断出的失败源于两个根因——①离专家动作后果的支持不足（off-expert support gap）；②生成动力学对条件动作依赖弱。对应三条互补改进轴：

**（1）动作覆盖扩展（Distributional Coverage）**
- 训练数据统一覆盖专家行为、局部扰动、跨状态回放、策略 rollout 和广泛可行动作；
- 混入少量目标域真机演示以保持真实视觉保真度；
- 将仿真与真机动作统一表示为**机器人基坐标系下的相对笛卡尔末端执行器位姿位移**，构建共享 SE(3) 动作空间，实现跨域动作—后果关系迁移。

**（2）Action-Forcing Expert（AFE，表征接地）**
- 维护轨迹查询，逐层交叉注意力到视频块中间特征，在 SE(3) 中解码动作诱导的未来末端执行器轨迹；
- 损失：$\mathcal{L}_{AFE} = \frac{1}{H}\sum_{t=1}^{H}\|\rho(\hat\tau_t) - \rho(\tau_t)\|_2^2$；
- AFE **不直接读取动作、不回写视频流**，仅通过视频特征反传梯度，推理时移除。

**（3）Intervention-Effect 监督（IE，干预效果对齐）**
- 使用共享当前观测与指令、但执行不同动作的配对轨迹；
- 两分支使用**相同的流匹配噪声端点**，使动作成为唯一差异输入；
- 预测干预效果 $\Delta_\theta = v_\theta^A - v_\theta^B$，目标干预效果 $\Delta^* = x_0^B - x_0^A$；
- 损失：$\mathcal{L}_{IE} = \|\Delta_\theta - \Delta^*\|_2^2$，即在未来视频隐空间上对齐。

**（4）联合训练目标**
- 视频主干以流匹配训练：$\mathcal{L}_{FM} = \mathbb{E}\|v_\theta(x_t,t|o_0,c,a_{1:H}) - (\epsilon - x_0)\|_2^2$，其中 $x_t = (1-t)x_0 + t\epsilon$；
- 总损失：$\mathcal{L} = \mathcal{L}_{FM} + \lambda_{AFE}\mathcal{L}_{AFE} + \lambda_{IE}\mathcal{L}_{IE}$。

### 7.1 主要贡献与价值
- **问题提出**：首次系统性地将"动作跟随"（action following）作为机器人世界模型的一等评估维度，指出"专家分布内评估"会系统性掩盖模型缺陷，这一诊断视角对社区具有普遍警示意义。
- **基准贡献**：WorldEcho 提供五类递减依赖专家分布的动作查询、可行性过滤、统一初始状态回放和完整性门控评估协议，配套指标（门控 NDTW + 原始 NDTW + 视觉通过率）能同时刻画"视觉崩溃"与"动作不匹配"两类失败，诊断能力优于单一指标。
- **方法贡献**：WorldSync 的三轴配方（覆盖扩展 + AFE + IE）对应明确根因，且各组件有清晰的机制解释；AFE 在推理时移除、不改变部署形态，具有较低工程侵入性；共享 SE(3) 动作空间为跨仿真—真机迁移提供了可复用思路。
- **闭环验证**：不止于诊断，还通过下游策略改进（仿真 + 真机）验证改进的实际效用，使结论从"指标更好"推进到"策略更强"，增强了说服力。

### 7.2 局限性
- **绝对性能仍有限**：即使最优配置，门控误差仍在 0.06 m 量级、视觉通过率约 84%，距离可靠"学习型模拟器"仍有明显差距，离专家动作的跟随问题并未被根本解决。
- **优势幅度有限**：主实验中 WorldSync 与 CtrlWorld、Motus 的差距在百分位以内（0.0661 vs. 0.0670），原始 NDTW 甚至被 Cosmos-Predict2.5 反超，说明改进主要体现在"动作敏感性"而非全面领先。
- **算力与预算不透明**：未报告硬件与训练成本；训练更新步数不一致（60k vs. 20k/40k），可能使对比偏向自身方法，削弱公平性。
- **评估范围受限**：真机仅 1 个任务、消融仅 4 个任务，统计功效不足；门控本身依赖外部模型（MUSIQ、SAM、VLM 评估器），其阈值与误判会传导到主指标。
- **动作表示假设**：统一为基坐标系相对笛卡尔末端位姿位移，对关节空间动作、力/触觉交互、非抓取式操作（如推、擦）可能不适用，泛化边界未讨论。
- **任务与平台单一**：主评估集中在 RoboTwin 双臂桌面操作，结论对移动操作、长时程任务、动态环境的适用性未知。

## 8. 总体评价与启示

- **定位**：本文是一篇"评估驱动改进"的典型工作，价值更多在于**揭示盲区**与**提供诊断工具**，而非宣称彻底解决动作条件世界模型的保真问题。
- **对社区的核心启示**：
  1. 用世界模型做策略评估前，必须先验证其对**离专家动作**的响应，否则评估结论可能被乐观偏差污染；
  2. 数据覆盖往往比架构改动更关键——扩大动作分布是低成本、跨骨干通用的第一优先级；
  3. 显式的动作—后果监督（AFE 的表征接地、IE 的干预对齐）能有效弥补"条件依赖弱"的结构性缺陷，且不增加推理成本；
  4. 诊断、改进、验证应形成闭环，单靠指标提升不足以说明世界模型的实用价值。
- **可复现性与后续方向**：方法描述较完整、超参与协议有交代，但缺乏代码/算力细节；后续值得探索的方向包括——将动作跟随诊断扩展到关节空间与接触丰富任务、在更多真机任务上验证策略改进增益、以及研究门控评估协议本身的鲁棒性与模型依赖性。
