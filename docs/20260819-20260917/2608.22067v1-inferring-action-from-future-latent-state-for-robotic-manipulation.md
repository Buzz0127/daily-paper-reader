## 摘要
世界-动作模型（World-Action Models, WAMs）将机器人控制构建在视频生成骨干网络上，联合预测密集的未来视觉轨迹和机器人动作。我们认为，视频生成对于世界-动作建模而言是不必要的中间目标。对于机器人操作，世界模型的目标不是复现世界在每个中间时刻看起来如何，而是预测动作执行后世界将达到的状态。中间帧仅描述物理状态之间的视觉过渡，这会消耗大量模型容量和计算，但并未直接指定机器人动作意欲产生的物理结果。本文提出 DELE-w0.5，其不依赖视频生成，而是从预测的未来状态推断机器人动作。具体而言，DELE-w0.5 从对应的紧凑未来潜在状态推断动作序列。未来潜在状态捕获机器人交互中与动作相关的物理结果，并作为世界建模与动作生成之间的显式桥梁。DELE-w0.5 的核心设计原则是建模物理世界在机器人动作下如何变化，而非其视觉外观如何逐帧演化。该形式消除了密集视频表示引入的高维视觉冗余，因此能够实现更廉价的训练和低延迟推理。在四个长时程操作任务上的 480 次真实机器人试验中，我们的 DELE-w0.5 在所有比较策略中取得最佳性能，达到 62.5 的总体全任务成功率和 81.3 的宏有序阶段进度，分别比最强基线高出 47.5 和 30.7 个百分点。

## Abstract
World-Action Models (WAMs) build robot control on video-generation backbones, which jointly predict dense future visual trajectories and robot actions. We argue that video generation is an unnecessary intermediate objective for world-action modeling. For robotic manipulation, the goal of a world model is not to reproduce how the world looks at every intermediate moment, but to predict the state that the world will reach after an action is executed. The intermediate frames only describe the visual transition between physical states, which consumes substantial model capacity and computation, but do not directly specify the physical outcome that the robot action is intended to produce. In this paper, we propose DELE-w0.5, which infers robot actions from predicted future states without relying on video generation. Concretely, DELE-w0.5 infers the action sequence from its corresponding compact future latent state. The future latent state captures the action-relevant physical outcome of robot interaction and serves as an explicit bridge between world modeling and action generation. The core design principle of DELE-w0.5 is to model how the physical world changes under robot actions, rather than how its visual appearance evolves frame by frame. This formulation removes the high-dimensional visual redundancy introduced by dense video representations, and it therefore enables cheaper training and low-latency inference. Across 480 real-robot trials on four long-horizon manipulation tasks, our DELE-w0.5 achieves the best performance among all compared policies, attaining 62.5 overall full-task success and 81.3 macro ordered-stage progress, outperforming the strongest baseline by 47.5 and 30.7 percentage points, respectively.

## 1. 论文的核心问题与整体含义

- **研究背景**：具身智能中，VLA（Vision-Language-Action）与 WAM（World-Action Model）是两类主流机器人操作范式。VLA 直接从当前观测、本体状态和语言指令映射动作；WAM 则试图把“世界状态演化预测”与“动作生成”统一起来。
- **核心问题**：现有 WAM 多以视频生成为骨干，联合预测密集未来视觉轨迹和机器人动作。论文认为，这引入了不必要的中间目标：视频帧主要描述“视觉上如何过渡”，而不是“动作执行后物理世界变成什么”。
- **由此带来的代价**：
  - 未来视频是高维、外观敏感的表示，中间帧数量远多于动作序列，主导序列长度、显存和计算预算。
  - 训练继承大规模视频生成器的高成本。
  - 推理时需对高维未来视频-动作潜变量迭代去噪，控制回路被“生成并不执行的视觉轨迹”拖慢。
  - 优化视觉重建并不等价于优化动作相关控制特征。
- **整体含义**：论文主张，机器人操作的世界模型不应复现每个中间时刻的视觉外观，而应预测动作执行后与动作因果相关的未来状态。基于此，作者提出 **DELE-w0.5**（第 4 节又称 HeTu-1.0），直接从紧凑未来潜在状态推断动作，跳过视频生成，以降低训练成本、推理延迟，并提升长时程操作成功率。

## 2. 方法论：核心思想与关键技术

- **核心思想**：
  - 不生成未来视频，而是预测一个紧凑的、与动作相关的未来潜在状态 \(O_{t+\Delta t}\) 的 latent。
  - 以未来潜在状态作为世界建模与动作生成之间的显式桥梁，再从该状态推断动作块 \(A_t\)。
  - 概率形式对比：
    - VLA：\(p_\theta(A_t \mid O_t, q_t, L)\)
    - WAM：\(p_\theta(A_t, O_{t:t+\Delta t} \mid O_t, q_t, L)\)
    - DELE-w0.5：\(p_\theta(A_t, O_{t+\Delta t} \mid O_t, q_t, L)\)
  - 即：只预测终点未来状态，不预测整段视频轨迹。

- **输入与动作表示**：
  - 当前观测 \(O_t\)：多视角 RGB 图像，机器人含头视图和双臂腕视图，共 3 视角。
  - 本体状态 \(q_t\)，语言指令 \(L\)。
  - 动作块 \(A_t=[a_{t+1},\dots,a_{t+H}]\)，论文使用 \(H=60\)。
  - 单臂动作为 7-DoF：3 维位置增量、3 维欧拉角旋转、1 维夹爪状态；双臂扩展为 14-DoF。

- **视觉与语言编码**：
  - 语言用 Qwen3 文本编码器编码为 \(\hat l\)。
  - 视觉用 DINO-v3 编码当前观测为 latent \(\hat z_t\)。
  - 语言和视觉 token 经线性投影到统一隐藏维度 1024。

- **双流注意力架构**：
  - **条件流（Condition Stream）**：编码语言 \(L\) 和当前观测 \(O_t\)。将语言 token 与视觉 latent 拼接，经单流自注意力融合，再通过 AdaLN 调制生成 \(Q_c,K_c,V_c\)。
  - **噪声流（Noise Stream）**：对动作块 \(A_t\) 和未来观测 latent \(\hat z_{t+\Delta t}\) 加噪，生成 \(Q_n,K_n,V_n\)。
    - 动作加噪：\(A_t^\tau = \tau A_t + (1-\tau)\epsilon\)。
    - 未来观测 latent 加噪：\(z_{t+\Delta t}^\tau = \tau \hat z_{t+\Delta t} + (1-\tau)\epsilon\)。
    - 其中 \(\tau \sim U[0,1]\)，\(\epsilon \sim \mathcal N(0,I)\)。
  - 两流通过拼接 \(Q,K,V\) 和掩码注意力耦合，输出预测的动作和未来 latent。

- **训练注意力掩码**：
  - 语言和当前观测组成条件组，双向注意力，但不能看动作和未来观测，防止目标泄漏。
  - 动作 token 可看条件组和动作自身，但不能看未来观测；因此动作只从语言、当前观测和动作内部依赖学习。
  - 未来观测 token 可看所有组，用于学习“在指令、当前观测和动作条件下”的物理状态转移。

- **推理流程**：
  - 推理时移除未来观测 token 组。
  - 条件组和动作组的可见性规则不变。
  - 模型直接预测动作序列，不生成任何未来视觉 token，从而缩短推理序列、降低延迟。

- **流匹配目标**：
  - 回归动作速度场：\(\mathcal L_a\)。
  - 回归未来 latent 速度场：\(\mathcal L_o\)。
  - 总损失：\(\mathcal L = \mathcal L_a + \lambda \mathcal L_o\)，\(\lambda\) 平衡动作学习与未来状态预测。
