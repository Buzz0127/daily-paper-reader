## 摘要
世界动作模型（WAMs）通过建模观测如何演化来改进机器人控制，但在测试时生成未来观测会带来显著延迟。Fast-WAM 为提升效率移除了这一过程；然而，我们的匹配实现表明，Fast-WAM 的泛化能力低于未来感知的替代方案，尤其是在机器人演示稀少和分布外场景中。为弥合这一差距，我们提出 **LAWA**，一种 WAM 架构，使用紧凑的潜在动作作为未来意图的可操作表示，从而无需生成未来观测即可在测试时高效进行未来想象。具体而言，一个经无动作预训练增强的离散分词器产生以操作为中心的码本目标。LAWA 在推理时省略未来视频分支，同时将锚定到这些目标的连续潜在状态与可执行动作块联合去噪。在 RoboCasa 上，LAWA 在少样本和全数据设置下分别达到最先进的平均成功率 65.6% 和 80.8%，相比匹配的 Fast-WAM 基线分别提升 9.6 和 4.5 个百分点。它还保持了匹配的 Joint-WAM 变体的性能水平，同时推理延迟降低 42.9%。LAWA 还在 LIBERO-Plus 上展现出有竞争力的零样本鲁棒性，并在真实世界任务上取得更优性能。这些结果表明，未来想象不必被丢弃：用紧凑的潜在动作保留未来想象，可以在性能、泛化和延迟之间取得有效权衡。代码和模型将发布。

## Abstract
World action models (WAMs) improve robot control by modeling how observations evolve, but generating future observations at test time incurs substantial latency. Fast-WAM removes this process for efficiency; however, our matched implementations show lower generalization for Fast-WAM than for future-aware alternatives, especially with scarce robot demonstrations and in out-of-distribution scenarios. To bridge this gap, we introduce **LAWA**, a WAM architecture that uses compact latent actions as an operational representation of future intentions, enabling efficient test-time future imagination without generating future observations. Specifically, a discrete tokenizer enhanced by action-free pre-training produces manipulation-centric codebook targets. LAWA jointly denoises a continuous latent state anchored to these targets with executable action chunks while omitting the future-video branch at inference. On RoboCasa, LAWA achieves state-of-the-art average success rates of 65.6% and 80.8% in the few-shot and full data settings, improving over the matched Fast-WAM baseline by 9.6 and 4.5 points, respectively. It also preserves the performance level of the matched Joint-WAM variant while requiring 42.9% lower inference latency. LAWA also demonstrates competitive zero-shot robustness on LIBERO-Plus and superior performance on real-world tasks. These results show that future imagination need not be discarded: retaining it with compact latent actions yields an effective trade-off among performance, generalization, and latency. Code and models will be released.

## 1. 核心问题与研究背景

- **背景**：世界动作模型（World Action Models, WAM）将动作学习与未来视觉动态预测耦合，为动作生成器提供显式的任务进度与环境动态表征，在机器人演示稀缺时尤其有价值。
- **核心矛盾**：
  - **Joint-WAM** 类方法在测试时需要迭代去噪未来观测，推理延迟高，难以满足真实机器人实时控制需求。
  - **Fast-WAM** 为效率在推理时移除未来视频分支，仅保留训练期视频协同训练；但作者的**匹配实现对照实验**表明其泛化能力明显弱于 Joint-WAM，在少样本监督与分布外场景中差距尤为突出。
- **关键推论**：未来建模的收益并非仅来自"视频协同训练"这一正则化副作用，而可能确实源于显式的未来表征——因此不应简单丢弃未来想象，而应改变其**表示空间**。
- **论文含义**：提出 **LAWA**，把未来想象从**观测空间**迁移到**紧凑潜在动作空间**，以"潜在动作序列"作为未来意图（future intention）的操作化表示，在保留未来感知动作生成的同时避免昂贵的视觉生成。

## 2. 方法论

### 2.1 核心思想
- 将**时序结构化的潜在动作序列**定义为"未来意图"：它编码"应当发生的任务相关状态转移"，但不重建未来视觉细节。
- 训练时三支专家（视频 / 潜在动作 / 动作）联合去噪；**推理时丢弃未来视频分支**，仅联合去噪潜在意图与可执行动作块。

### 2.2 潜在动作分词器（Latent Action Tokenizer）
- **架构**（基于 ViPRA）：
  1. DINOv2 编码器提取每帧 patch token；
  2. 非因果 Transformer 通过**因子化空间-时间注意力**上下文建模，得到每帧特征 $F_k \in \mathbb{R}^{N \times d}$；
  3. 对相邻帧做**差分** $F_k - F_{k-1}$，空间压缩为 $L$ 个 token $h_k \in \mathbb{R}^{L \times d_q}$；
  4. 最近邻量化到可学习码本 $C=\{e_j\}_{j=1}^{K}$：$j^\star_{k,p}=\arg\min_j \|h_{k,p}-e_j\|_2^2$，$l_{k,p}=e_{j^\star_{k,p}}$；
  5. 因果前向解码器将投影后的潜在动作作为额外空间 token 与 $o_{k-1}$ 的 patch token 拼接，重建 $o_k$，迫使离散表示保留静态外观无法推断的转移信息。
- **操作中心辅助监督**：额外加入 SAM 风格掩码解码器，以 detached 视觉重建 token 为图像 token、投影潜在动作为 prompt，预测手/机械臂掩码；掩码目标由 **SAM 2 自动生成**，无需人工标注，可规模化。作者经验上发现掩码预测优于光流（Motus 方案）。
- **无动作自指视角视频预训练**：分词器与前向解码器在机器人数据 + 自指视角（egocentric）数据上协同训练；对**逐数据源帧采样**以对齐运动速度分布，并用**加权重平衡**（机器人视频约占期望训练样本的 20%）而非按数据集体量比例采样，以保持机器人域接地。

### 2.3 潜在动作作为意图 + 多模态联合注意力
- 策略训练时**冻结分词器**，将 $o_{t:t+H}$ 编码为目标潜在动作 $l_{t+1:t+H}$。
- 三支专家通过**多模态联合注意力**耦合，保留各自 Transformer 块与时间步条件；**结构化注意力掩码**规定可见性：
  - 当前观测 token $z_t$ **不能**访问未来；
  - 噪声未来视频 token 可访问所有视频 token；
  - 潜在动作 token 仅访问当前观测与潜在动作序列；
  - 动作 token 访问当前观测、潜在动作序列与动作序列。
  - → 动作专家可使用演化的未来意图，但不会泄漏未来视频信息。
- 所有专家均以语言指令（及可用时的本体感受）为条件。
- **推理**：省略未来视频 token，缓存当前观测特征，迭代去噪仅评估潜在动作与动作专家；训练与推理保持同一可见性掩码。
- **离散 vs 连续**：分词器目标为离散码本嵌入，但潜在专家在其**连续嵌入空间**做 flow matching；去噪中/后**不做最近邻投影**，动作专家以演化的连续潜在状态为条件——即"离散描述目标集合，测试时想象是该集合上的连续松弛"。

### 2.4 训练目标
- **阶段一（分词器预训练）**：$\mathcal{L}_{tok} = \mathcal{L}_1 + \lambda_{perc}\mathcal{L}_{perc} + \lambda_{mask}\mathcal{L}_{mask}$，其中 $\mathcal{L}_1$ 与基于 LPIPS 的 $\mathcal{L}_{perc}$ 监督下一帧重建，$\mathcal{L}_{mask}$ 用二值交叉熵 + Dice + IoU；采用**噪声替换量化（NSVQ）**避免额外码本损失项，并周期性刷新低使用率码本条目以防码本坍塌。
- **阶段二（专家训练）**：冻结分词器，按模态 $m\in\{vid, lat, act\}$ 独立采样高斯噪声与偏移 flow 时间 $\tau_m$，构造 $y_m^{\tau_m}=(1-\tau_m)y_m+\tau_m\epsilon_m$、$v_m=\epsilon_m-y_m$，最小化
  $\mathcal{L}_m=\mathbb{E}[w_m(\tau_m)\|\hat{v}_m^\theta - v_m\|_2^2]$；
  机器人策略总目标 $\mathcal{L}_{LAWA}=\lambda_{vid}\mathcal{L}_{vid}+\lambda_{lat}\mathcal{L}_{lat}+\lambda_{act}\mathcal{L}_{act}$（分别对应世界建模信号、码本转移目标、可执行控制）。

## 6. 主要结论与发现

- **性能**：RoboCasa 少样本 **65.6%**、全数据 **80.8%**，均为 SOTA；相比匹配 Fast-WAM 提升 **9.6 / 4.5** 点，与 Joint-WAM（64.1% / 78.8%）相当；少样本还超过 DIAL 7.3 点。
- **零样本鲁棒性**：LIBERO-Plus 平均 **74.4%**，超 Fast-WAM 14.4 点、Joint-WAM 4.0 点；在相机视角（+44.3）与传感器噪声（+27.5）扰动下增益最大。
- **效率**：延迟 **338.5 ms**，比 Joint-WAM 低 **42.9%**，同时显著优于更快的 Fast-WAM。
- **潜在动作确实被使用**：高斯扰动使成功率从 80.8% 降至 52.2%，时间打乱降至 56.4%——说明动作生成同时依赖潜在序列的**内容**与**时序组织**。
- **自指视角预训练的范式差异**：LAWA 增益 +5.9/+4.5 点，远高于 Fast-WAM（+1.5/+1.7）与 Joint-WAM（+1.0/+0.5）；**若无自指视角预训练，LAWA 反而落后 Joint-WAM 3

.3 点（即潜在动作分支单独存在不足以弥补移除未来视频的损失）。这说明 LAWA 的收益并非"潜在动作本身"，而是**大规模无动作视频预训练赋予潜在分词器的可迁移时序语义**；缺少该预训练时，潜在动作表示质量不足，反而成为噪声通路。
- **可扩展性**：随演示数据从 10% 增至 100%，LAWA 在少样本与全数据两条设置下均持续领先，且相对基线的优势未随数据增多而消失，说明其收益并非单纯的样本效率补偿。
- **机制验证（注意力可视化）**：在 RoboCasa WineToCabinetClose 上，动作专家对潜在动作 token 的注意力随去噪步推进而逐步集中到与任务阶段（接近、抓取、放置）对应的潜在 token 上，佐证潜在意图被当作"任务进度信号"使用，而非静态条件偏置。
- **消融结论**：潜在动作（LA）、自指视角预训练（EP）、辅助掩码监督（AL）三者贡献互补；移除任一组件均导致性能下降，其中 EP 的影响最大，AL 在掩码方案下优于光流方案。

## 7. 局限与不足

- **推理仍未实时**：338.5 ms 虽较 Joint-WAM 降低 42.9%，但仍显著慢于 Fast-WAM 的 196.5 ms，且未报告在更高控制频率下的表现；对高动态接触任务可能仍是瓶颈。
- **管线复杂度与外依**：方法依赖 DINOv2、SAM 2 自动掩码与大规规模自指视角视频预训练，训练流程多阶段、组件多，复现与迁移成本高；分词器一旦冻结，其表示能力上限即成为策略性能的天花板。
- **离散-连续设计缺乏理论刻画**：码本量化提供目标集合、推理时在连续嵌入空间做 flow matching 且不做最近邻投影，这一"连续松弛"的合理性主要靠经验验证，缺少对量化误差、码本利用率与策略性能关系的分析。
- **实验统计性不足**：未报告随机种子、方差或置信区间，多数对比差距在数个点以内，显著性无法判断；真实世界仅 4 任务 × 20 次试验，且未做跨物体、跨场景泛化评估。
- **对比公平性受限**：作者明确说明 Fast-WAM†/Joint-WAM† 与 LAWA 不共享参数量、目标函数与推理成本，"匹配实现"只能算受控而非等同比较。
- **可获取性**：代码与模型仅声明"将发布"，训练算力、参数量规模等关键复现信息缺失，第三方独立验证困难。

## 8. 总体评价与启示

- **核心贡献**：论文提出了一个有明确动机的操作化思路——**把"未来想象"从观测空间搬到潜在动作空间**，用紧凑、时序结构化的潜在动作序列充当 future intention。这既保留了 WAM 显式未来建模的收益，又避开了迭代生成未来视频的高昂成本，是对"Joint-WAM 慢 / Fast-WAM 弱"这一两难的结构性回答，而非简单的效率-性能折中。
- **方法论亮点**：
  - 将分词器的**离散码本**与策略的**连续 flow matching** 解耦——离散定义目标集合，连续提供可微松弛，兼顾语义稳定性与优化可行性；
  - 用**结构化注意力掩码**在训练期严格保证"动作可见未来意图、不可见未来观测"，推理期可直接裁剪视频分支而不改变可见性语义，训练-推理一致性设计干净；
  - 借助 **SAM 2 自动掩码**获得可规模化的操作中心监督，避开光流方案的噪声与标注成本。
- **最重要的经验发现**：**潜在动作分支的价值高度依赖无动作自指视角视频预训练**。去掉该预训练，LAWA 甚至不如 Joint-WAM。这一结果提示后续工作：潜在动作/未来意图类方法的关键瓶颈很可能在**表示预训练的数据规模与领域覆盖**，而非下游策略结构本身；仅做"少样本上的架构消融"容易得出误导性结论。
- **对领域的启示**：世界模型的"未来"未必需要以像素形式呈现；以任务相关的状态转移语义（潜在动作）作为未来表示，可能是在真实机器人约束下更可行的折中路线。同时，论文以匹配实现的 Fast-WAM/Joint-WAM 作对照、并用扰动实验证明通路的**功能性使用**，这种"不只看指标、还验证机制"的做法值得借鉴。
- **待观察**：在更高控制频率、更长时序、多物体泛化以及不同机器人本体上的表现尚未验证；若能与轻量化分词器或蒸馏结合以进一步压缩 338.5 ms 的延迟，其实用价值会显著提升。
