## 摘要
视觉-语言-动作（Vision-Language-Action, VLA）模型已在机器人操作中展现出有效性，但诸如 pi0.5 等最先进模型在单帧范式下运行，限制了其保留过去观测并形成精确空间感知的能力。本文提出 StreamPI，一种流式多模态时序建模框架，可在不引入任何额外参数的情况下，为单帧 VLA 赋予时序推理能力。一个核心设计是指令锚定的时序建模。它将每个（视觉观测，语言指令）对视为一个原子时序单元：对内的双向注意力实现跨模态融合，而对间因果注意力则保持自回归流式推理。这确保了语言指令在整个任务执行过程中作为持久的语义锚点。为弥合同步训练与异步真实机器人部署之间的差距，我们引入随机间隔流式训练策略：适当的帧间间隔（例如每 3 帧）可实现更快、更平滑的动作执行。此外，随机化间隔进一步提高了对帧时序扰动的鲁棒性，从而在实践中支持异步部署。进一步，通过利用 LLM 主干的长度外推能力，StreamPI 无缝继承预训练的单帧权重，并支持灵活的单帧和多帧推理。在涵盖依赖记忆和精确感知场景的真实机器人任务以及仿真基准 LIBERO 上的实验表明，StreamPI 在多样化任务上优于 pi0.5。

## Abstract
Vision-Language-Action (VLA) models have demonstrated effectiveness in robot manipulation, yet state-of-the-art models such as pi0.5 operate under a single-frame paradigm, limiting their ability to retain past observations and develop precise spatial perception. In this paper, we propose StreamPI, a streaming multimodal temporal modeling framework that equips single-frame VLA with temporal reasoning capability without introducing any additional parameters. One core design is instruction-anchored temporal modeling. It treats each (visual observation, language instruction) pair as an atomic temporal unit: bidirectional attention within each pair enables cross-modal fusion, while causal attention across pairs preserves autoregressive streaming inference. This ensures the language instruction serves as a persistent semantic anchor throughout task execution. To bridge the gap between synchronous training and asynchronous real-robot deployment, we introduce a andom-interval streaming training strategy: a proper inter-frame interval (e.g., every 3 frames) enables faster and smoother action execution. Beyond this, randomizing the interval further improves robustness to frame-timing perturbations, supporting asynchronous deployment in practice. Furthermore, by leveraging the length extrapolation capability of the LLM backbone, StreamPI seamlessly inherits pretrained single-frame weights and supports flexible single-frame and multi-frame inference. Experiments on real-robot tasks spanning memory-dependent and precise perception scenarios, as well as the simulation benchmark LIBERO, demonstrate that StreamPI outperforms pi0.5 across diverse tasks.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：VLA（Vision-Language-Action）模型已成为通用机器人操作的重要范式，π0 / π0.5 等 SOTA 模型采用 flow-matching 动作头 + VLM 主干，在语义泛化与高频灵巧控制上表现优异。
- **核心问题**：这些模型普遍运行在**单帧范式**下——每个动作仅由当前单张观测预测，不保留历史上下文，因此天然缺失两类关键能力：
  - **时序记忆**：无法推理"哪个杯子藏着物体""目标物体移动轨迹"等仅靠单帧无法消歧的任务；
  - **精确空间感知**：单帧缺乏运动视差与跨帧结构一致性，深度/位姿估计不足，影响精细抓取与放置。
- **已有方案的不足**：
  - 窗口式（window-based）多帧 VLA 需同时处理 K 帧，序列长度随时域线性增长，推理延迟高，往往被迫换小主干或加视频编码器；
  - 视频编码器引入新参数，其特征分布与预训练 VLA 不对齐，可能**破坏**原有视觉-语言表征。
- **论文归纳的四大挑战**：① 计算开销；② **指令遗忘**（视觉 token 膨胀稀释语言指令）；③ 训练-部署不匹配（训练用规则采样、部署是异步变率观测流）；④ 表征损坏（新增编码器参数）。
- **整体含义**：论文提出 StreamPI——一种**不增加任何参数**的流式多模态时序建模框架，让单帧 VLA（以 π0.5 为基座）获得持久时序推理能力，并兼容同步训练与异步真机部署。

## 2. 方法论

### 2.1 核心思想：指令锚定的原子时序单元

- 不再只对视觉帧做时序建模，而是把每个 **(视觉观测, 语言指令) 对**视为不可分的**原子时序单元**：
  - $u_t = (V_t,\ l_t)$，其中 $V_t=\{v_t^f, v_t^l, v_t^r\}$ 为前视 + 左右腕部三路多视角图像。
- 当前时刻的流式输入为最近 T 个原子单元拼接：$U = [u_{t-T+1}, \dots, u_t]$。
- 语言指令被**持续锚定**在每一个时间步上，因此无论时域多长，都不会被视觉 token 淹没，从机制上抑制"指令遗忘"。

### 2.2 双层注意力结构（全部通过注意力掩码实现）

- **对内双向注意力（Intra-pair Bidirectional）**：$h_\tau = \mathrm{Attn}_{bi}(V_\tau, l_\tau)$，同一时间步内图像与文本 token 互相可见，保证充分跨模态融合。
- **对间因果注意力（Inter-pair Causal）**：$o_t = \mathrm{Attn}_{causal}(h_{t-T+1}, \dots, h_t)$，跨时间步按自回归方式聚合历史，未来帧不泄漏到过去。
- 最终 $o_t$ 用于条件化动作生成：$a_t \sim \pi_\theta(\cdot \mid o_t)$。
- **无参数时序扩展**：不新增任何模块，仅通过**块状因果注意力掩码 + 扩展位置编码**重构注意力模式；借助 LLM 主干的**长度外推能力**，完整继承 π0.5 全部预训练权重，并天然支持单帧与多帧推理。

### 2.3 随机间隔流式训练策略

- **随机间隔采样**：给定基准帧间间隔 $\bar\delta$，加入扰动 $\epsilon \sim U(-\Delta, +\Delta)$，得到 $\delta = \bar\delta + \epsilon$ 并裁剪到 $[\delta_{min}, \delta_{max}]$；T 帧按步长 δ 从流式缓冲区采样（实验中 δ 均匀取自 [3, 7]）。
- **时序掩码（Temporal Masking）**：随机采样掩码数 $k \in \{0, \dots, T-1\}$，当 $k>0$ 时遮蔽最早的 k 帧，仅保留最近 T−k 帧，模拟流式推理的增量观测模式。
- 目的：弥合**同步训练**与**异步真机部署**（变帧率、变时间间隔）之间的分布差异。

### 2.4 流式推理（KV-Cache）

- 算法流程（Algorithm 1）：
  1. 初始化缓存 $C \leftarrow \varnothing$、缓存长度 $L_c \leftarrow 0$；
  2. 首帧 $t_0$：编码 $u_{t_0}$ 得到 $h_{t_0}$，预测动作 $a_{t_0}$，并把 $h_{t_0}$ 写入 KV-Cache；
  3. 后续时刻 $t_n$：只需编码**新到达的帧** $u_{t_n}$，其表示与缓存中的历史表示 $\{h_{t_0},\dots,h_{t_{n-1}}\}$ 做注意力，无需重算历史；
  4. 缓存更新；若 $L_c + 1 > T$ 则清空缓存（滚动窗口）；
  5. 输出动作块并下发。
- 效果：**推理开销与时间跨度基本无关**，只随 T 缓增，适合长时程操作。

## 6. 主要结论与发现

- **真机任务全面提升**（相对 π0.5 单帧基线）：
  - Shell Game（记忆）：46.7% → 80.0%，**+33.3%**；
  - Rolling Object Grasping（记忆/动态）：26.7% → 63.3%，**+36.6%**；
  - Pen Insertion into Narrow Bottle（精细感知）：40.0% → 66.7%，**+26.7%**；
  - Cup Insertion into Cup Sleeve（精细感知）：60.0% → 92.0%，**+32.0%**（尤其远距离位置收益最大）。
- **LIBERO**：在基准已接近饱和（π0.5 平均 96.9%）的前提下，StreamPI 平均提升 **1.4%**；T=5 达 **98.3%**，T=3 达 97.5%；LIBERO-Long 提升最明显（+2.6%），LIBERO-Goal 也有 +2.8%；**LIBERO-Spatial 无提升**（静态空间关系单帧已足够，额外运动线索反而不相关）。
- **CALVIN**：StreamPI(T=5) 平均序列长度 **4.547**，优于 π0.5（4.313）与 MemoryVLA（4.090）；第 5 个任务成功率 85.0% vs π0.5 79.5%、MemoryVLA 69.4%，说明 MemoryVLA 类记忆机制在长时程上存在误差累积。
- **消融结论**：
  - 对内注意力改为因果会一致掉点，且 T 越大掉得越多（T=5 时 LIBERO-Long −5.6%），印证指令锚定的必要性；
  - 对间因果聚合在 T=5 相比 T=1 带来 +1.8% 平均增益（LIBERO-Long +3.0%）；
  - 随机间隔训练优于固定间隔（T=3：96.4 → 97.5；T=5：97.0 → 98.3），且支持大间隔（如 δ=5）以降低在线推理频率；
  - 跨流泛化：T=5 训练的模型在 T=3 推理仅轻微下降，在 T=1 时仍超过 π0.5 基线，说明时序结构带来残差收益。
- **效率结论**：KV-Cache 流式推理使开销随 T 近似常数增长，T=5 仅增加约 9 ms。

## 7. 优点

- **零参数扩展**：完全通过注意力掩码与位置编码重构实现时序建模，完整继承 π0.5 预训练权重，避免新模块带来的表征漂移，也便于复用与部署。
- **指令锚定设计巧妙**：把 (图像, 指令) 作为原子单元，从结构上解决长时程"指令遗忘"，比单纯堆叠视觉历史更贴合语言条件操作的本质。
- **训练-部署对齐意识强**：随机间隔采样 + 时序掩码同时覆盖"变帧率"和"增量可见"两种真机特性，工程落地导向明确。
- **效率与精度兼顾**：KV-Cache 流式推理使时延随时域基本恒定，论文给出实测延迟曲线，说服力较强。
- **实验组合合理**：真机任务刻意设计为"记忆依赖"与"精细感知"两类互补场景，仿真侧另用 CALVIN 专门压测长时程组合，形成多维度验证。
- **诚实报告负结果**：明确指出 LIBERO-Spatial 无提升并给出解释，而非选择性汇报。

  - 训练时需加载全部帧，处理**极长

极长序列或高分辨率输入时显存占用会显著上升，训练成本随时域窗口 T 线性增长；此外论文未讨论在更大规模机器人数据或跨本体场景下的泛化性，也未验证触觉、力觉等额外模态的接入方式。

- **窗口机制的固有上限**：StreamPI 本质上仍是**有限窗口**方法，缓存长度达到 T 后按滚动方式丢弃最旧单元。对于持续时间远超 T 的任务（例如需要回忆几十步之前的藏匿位置），历史信息仍会被截断，只是把"单帧遗忘"推迟为"窗口外遗忘"，并未实现真正的无界记忆。论文的 Shell Game 等任务时间尺度相对可控，尚不足以暴露这一边界。
- **缓存清空策略较粗糙**：算法中当 $L_c + 1 > T$ 时直接清空缓存，而非逐出最旧的一项。这会造成周期性的上下文断层，在长时程连续操作中可能引入动作抖动或策略不一致；论文未报告此类现象的定量分析。
- **原子单元定义偏刚性**：将每个时间步固定绑定为"三视角图像 + 语言指令"，虽然有利于指令锚定，但也意味着任何一路视角缺失、指令中途变更或需要非均匀多模态输入（如仅腕部相机高频、前视相机低频）时，框架需要额外改造。论文未讨论指令在任务中途被更新或改写的情形。
- **超参数依赖人工设定**：随机间隔的基准 $\bar\delta$、扰动幅度 $\Delta$、采样区间 $[\delta_{min}, \delta_{max}]$（实验中取 [3, 7]）以及窗口 T 均为手工选择，缺少对这些超参与真机实际帧率、任务时间尺度之间关系的系统性敏感性分析。部署到不同控制频率的平台时，可能需要重新调参。
- **首帧与缓存重建的峰值开销未充分讨论**：虽然增量推理的摊销延迟很低，但当缓存清空后需要重新编码 T 帧，或需要并行处理多路高分辨率图像时，峰值显存与延迟仍可能成为瓶颈；论文的时延测试只给出稳态均值与标准差，未报告尾延迟（如 P95/P99），而这对实时机器人控制尤为关键。
- **训练成本报告不完整**：仅给出迭代次数与 GPU 型号，缺少总训练时长、GPU 小时数、显存峰值等关键信息，难以评估方法的实际训练门槛，也影响与其它 VLA 方法的成本对比。
- **真机对比基线单一**：真机实验只与 π0.5 单帧版本对照，未纳入 CronusVLA、MemoryVLA、4D-VLA 等同样主打时序/记忆的 VLA，因此无法判断"零参数注意力掩码"路线相对"显式记忆模块"或"视频编码器"路线的真实优劣。
- **统计效力有限**：单任务真机试验多在 15–30 次量级，成功率差异的置信区间较宽；论文未报告显著性检验或多次随机种子下的方差，部分提升（如 LIBERO 上 +1.4%）可能落在噪声范围内。
- **任务覆盖仍有偏向**：四类真机任务均集中在桌面级双臂操作，场景、物体种类与光照变化有限；缺少移动操作、多机器人协作、长时程多阶段装配等更复杂设定，结论的外推需谨慎。
- **负结果解释略显单薄**：LIBERO-Spatial 无提升被归因于"静态空间关系单帧已足够"，这一解释合理但缺少针对性实验（例如加入物体运动扰动后是否重新出现增益），因而仍属事后解释。
- **可复现性细节不足**：论文未提供代码/模型开源说明、随机间隔采样的具体实现伪代码（仅文字描述）、数据缓冲区的管理策略，以及真机实验中人类遥操作数据的质量控制流程，复现门槛较高。
- **与基座的耦合性**：方法完全建立在 π0.5 主干与其长度外推能力之上，若换用上下文窗口较短或位置编码外推能力较弱的 VLM 主干，块状因果掩码与扩展位置编码是否仍能零参数生效，尚待验证。

## 9. 总体评价与启示

- **定位清晰**：StreamPI 是一篇"以最小改动换取时序能力"的工程导向工作，其最大价值不在于提出全新架构，而在于证明**仅靠注意力掩码与位置编码重排**即可让成熟的单帧 VLA 获得可用的流式时序推理，同时保持预训练表征不被破坏。
- **方法论启示**：把语言指令与视觉观测绑定为原子时序单元，是对"指令遗忘"这一多帧 VLA 常见病症的精准结构性回应；相比事后加正则或加记忆模块，这种"从输入组织方式入手"的思路更简洁，也更容易迁移到其它 VLA。
- **训练-部署对齐的示范**：随机间隔采样 + 时序掩码这一组合，把真机异步、变率、增量可见的观测特性显式编码进训练分布，是 VLA 落地中值得借鉴的工程范式。
- **适用边界明确**：方法擅长的是"中等时程、依赖近期历史"的记忆与精细感知任务；对超长时程、强动态或多模态扩展场景，仍需窗口扩展、分层记忆或检索机制配合。
- **后续可探索方向**：① 自适应窗口与重要性驱动的缓存淘汰，替代当前的整体清空；② 将原子单元扩展到触觉/力/本体感知等模态；③ 在更大规模、跨本体数据上验证零参数时序扩展的通用性；④ 报告尾延迟与训练成本，完善可复现性。
