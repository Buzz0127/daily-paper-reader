## 摘要
许多最新的机器人策略通过使用大型预训练视觉-语言模型（VLM）作为动作主干来追求更强的控制力。我们提出了WorldDiT，一种统一的扩散Transformer架构，它将动作生成与视觉世界建模相结合，并且在没有大型预训练VLM动作主干的情况下实现了强劲的性能。在训练过程中，一个单一的扩散Transformer生成连续的动作块，并从未来的相机帧中预测归一化的RGB补丁目标。在四个LIBERO仿真套件中，WorldDiT在报告所有四个套件的方法中，处于总模型参数和平均成功率所报告的性能帕累托前沿上。这些结果为未来的规模扩展研究提供了一个强大的十亿参数以下基线。

## Abstract
Many recent robot policies pursue stronger control by using large pretrained vision-language models (VLMs) as the action backbone. We introduce WorldDiT, a unified diffusion transformer architecture that couples action generation with visual world modeling and achieves strong performance without a large pretrained VLM action backbone. During training, a single diffusion transformer generates continuous action chunks and predicts normalized RGB patch targets from future camera frames. Across four LIBERO simulation suites, WorldDiT lies on the reported Pareto frontier for total model parameters and mean success among methods reporting all four suites. These results provide a strong sub-billion-parameter baseline for future scaling studies.

- **核心问题**：当策略包含数十亿参数时，我们难以分辨性能提升究竟来自动作设计、预训练主干，还是两者组合的贡献。论文因此提出一个关键问题：**是否可以在不使用大型预训练VLM作为动作主干的情况下，仅依靠统一的扩散Transformer架构，将连续动作生成与未来视觉预测目标耦合，从而保持强控制性能？**
- **整体意义**：该研究尝试将“世界建模”（World Modeling）与“动作建模”（Action Modeling）统一到一个紧凑的扩散Transformer中，以低于十亿参数的规模提供强基准，为未来探索模型规模、数据多样性和部署环境之间的权衡提供基础。

## 2. 论文提出的方法论

### 2.1 核心思想
- 提出 **WorldDiT**：一个统一的扩散Transformer架构，在训练时同时执行两项任务：
  1. 生成连续的动作块（action chunk）；
  2. 从未来相机帧中预测归一化 RGB patch 目标。
- 核心洞见：**未来视觉预测作为辅助监督信号参与训练，但推理时被完全移除**，模型仅沿动作路径进行部署。这使得“世界模型”能力帮助学习表征，却不会增加推理开销。

### 2.2 结构设计
- **输入编码**：冻结的视觉编码器（MAE）与语言编码器（CLIP）分别处理多视角图像和语言指令；可训练的机器人状态编码器处理手臂与夹爪状态，三者拼接后送入共享DiT主干。
- **统一主干**：一个共享的DiT（深度4、隐藏维度1024、16个注意力头、4个寄存器token）同时预测动作流速度和RGB patch流速度。
- **动作目标**：预测一个 H=7 步的动作块 Aᵢ ∈ ℝ⁷ˣ⁷。
- **世界目标**：从未来主相机与腕部相机帧中，各取 64 个（共128个）归一化RGB patch token，每个patch为768维向量；损失仅作用于最终时间槽。

### 2.3 训练方法：Flow Matching
- 采用流匹配（Flow Matching）目标：对每个目标 y，采样噪声 ε ~ N(0, I) 和时间步 τ ~ U[0,1]，定义插值路径 x_τ = (1−τ)ε + τy，模型预测速度 v_θ(x_τ, τ, c)，回归目标为 (y − ε)。
- 总损失为动作速度损失与RGB patch速度损失的加权和：
  - L_total = w_action · L_action_flow + w_rgb · L_rgb_flow
  - 权重分别为 0.1 和 0.001。
- 上下文窗口：C=3 步观测，完整训练窗口 N=10 步。

### 2.4 推理流程
- 推理时仅执行动作路径：从标准高斯噪声初始化动作token，通过20步欧拉积分求解学到的速度场，获得动作块；执行前3个动作后，更新观测窗口并重新规划（receding-horizon control）。
- RGB patch预测头完全排除在推理图之外，保证推理效率。
