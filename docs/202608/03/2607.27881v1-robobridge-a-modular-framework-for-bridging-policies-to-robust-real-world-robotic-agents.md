## 摘要
视觉-语言-动作（VLA）模型作为机器人操作的一种可扩展方法，已引起越来越多的关注。尽管这些模型是有效的动作预测器，但将它们部署为机器人智能体时暴露了关键缺陷：缺乏故障恢复机制、长期执行不一致、以及对观测、任务或载体变化的鲁棒性有限。现有解决方案通过模型重训练或特定环境模块逐一解决这些限制，但需要的是一个通用框架，能够系统地将预训练VLA转化为机器人智能体。我们提出RoboBRIDGE，一个模块化框架，提供由五个协调模块（即Monitor、Perceptor、Planner、Controller和Robot Interface）组成的编排层，利用现成组件（包括预训练VLA）来构建稳健的机器人智能体。Monitor将快速故障检测与分层恢复相结合，在错误级联之前进行纠正。当环境偏离当前计划时，Planner触发重新规划，同时Perceptor异步更新场景理解，避免执行停滞。在Controller内部，基元技能微调将操作分解为具有专用LoRA适配器的域不变原语，从而降低使用VLA时对域偏移的敏感性。在LIBERO、RoboCasa以及涵盖多种机器人平台和VLA骨干的真实世界案例研究中，RoboBRIDGE始终优于独立策略和先前的增强型VLA部署。这些结果表明，可靠的机器人智能体不仅来源于扩展动作预测器，还来源于围绕它们进行结构化编排。

## Abstract
Vision-Language-Action (VLA) models have attracted growing interest as a scalable approach to robotic manipulation. While these models are effective action predictors, deploying them as robotic agents exposes critical gaps: no mechanism for failure recovery, inconsistent execution over long horizons, and limited robustness to shifts in observations, tasks, or embodiments. Existing solutions address these limitations individually through model retraining or environment-specific modules, yet what is needed is a general framework that systematically transforms a pretrained VLA into a robotic agent. We present RoboBRIDGE, a modular framework that provides an orchestration layer over five coordinated modules, namely Monitor, Perceptor, Planner, Controller, and Robot Interface, to compose robust robotic agents from off-the-shelf components, including pretrained VLAs. The Monitor pairs rapid failure detection with hierarchical recovery to correct errors before they cascade. When the environment diverges from the current plan, the Planner triggers replanning while the Perceptor updates scene understanding asynchronously, avoiding execution stalls. Within the Controller, primitive skill fine-tuning factors manipulation into domain-invariant primitives with dedicated LoRA adapters, reducing sensitivity to domain shifts when a VLA is used. Across LIBERO, RoboCasa, and real-world case studies spanning multiple robot platforms and VLA backbones, RoboBRIDGE consistently outperforms both standalone policies and prior augmented VLA deployments. These results suggest that reliable robotic agency does not arise from scaling action predictors alone, but from structured orchestration around them.

  2. **长任务执行不一致**——每一步推理相互独立，缺乏任务进度追踪与错误纠正能力；

- **现有工作局限**：已有相关研究（运行时监控、重规划、LLM 任务分解、跨域微调等）各自仅针对单一失败模式，且与特定模型架构或环境设置绑定，缺乏统一方案。
- **类比 LLM 智能体演变**：原始 LLM 通过工具调用、规划、验证等编排框架被转化为多功能智能体，而非依赖无限扩大模型规模。作者认为 VLA 面临相同瓶颈——缺失的不是更强的策略，而是**通用编排框架**。
- **核心主张**：可靠的机器人智能体来自围绕动作预测器的结构化编排，而非仅靠扩展预测器本身。

## 2. 方法论（核心思想与关键技术细节）

### 总体架构

提出 **RoboBRIDGE**，一个模块化、策略无关的编排框架，由五个协调模块组成：

| 模块 | 功能 |
|------|------|
| **Monitor** | 闭环监控执行结果，检测失败并触发分层恢复 |
| **Perceptor** | 将原始传感观测转换为对象中心（object-centric）场景状态（身份、3D 位姿、语义属性） |
| **Planner** | 接收精细状态与语言指令，将任务分解为有序的基元技能序列 |
| **Controller** | 容纳动作生成策略（任意 VLA 或经典控制器均可）的插槽 |
| **Robot Interface** | 抽象机器人特定 API、时序、安全限制与坐标变换 |

### 三大核心机制

**(a) 两阶段监控（Two-phase Monitoring）**

- **阶段一——轻量成功检查**：成功检查模型 \( D_{check} \) 周期性地将当前观测 \( o_t \) 与预期计划上下文 \( c_t \) 对比，输出二值成功标志与置信度，使用约束输出格式减少推理延迟，约 5Hz 运行，不阻塞控制循环；
- **阶段二——失败诊断与恢复**：仅在检测到高置信度失败（置信度 ≥ γ_thresh）时触发诊断模型 \( D_{diag} \)，输出恢复目标与原因，采用四级分层恢复策略（按重计算范围递增）：
  1. **retry**——重新执行当前基元；
  2. **regenerate**——保留当前计划与感知状态，重新生成轨迹；
  3. **replan**——基于最新感知结果重新规划；
  4. **re-perceive**——强制完整重新感知后再规划。

**(b) 异步感知的响应式规划（Reactive Planning with Asynchronous Perception）**

- **异步感知**：采用生产者-消费者架构，感知线程持续更新线程安全缓冲区 B，只保留最新检测结果，将感知延迟隐藏在执行为之后；
- **散度触发重规划**：每隔基元完成后，计算当前计划所用感知状态与最新状态的散度量：
  \[
  \Delta(\bar{o}_a, \bar{o}_b) = \max_{i \in O_a \cap O_b} \|p_a^{(i)} - p_b^{(i)}\|_2 + \lambda \cdot |O_a \triangle O_b|
  \]
  其中 \( p^{(i)} \) 是对象的 3D 位置，\(\triangle\) 为对称集差。当 \( \Delta \geq \tau \) 时，保持高层动作序列（如 PICK→PLACE），仅基于最新感知重新生成当前及后续基元技能的空间参数，避免冗余的高层推理。

**(c) 基元技能微调（Primitive Skill Fine-tuning）**

- **核心思想**：将操作分解为域不变的**基元技能集合** \( P = \{MOVE, GRIP, ROTATE, ...\} \)；
- **原语专用 LoRA 适配器**：在冻结的 VLA 骨干 \( f_\theta \) 上附加轻量 LoRA 模块 \( \Delta\theta_k \)，每个适配器单独在筛选后的对应原语演示数据上训练：
  \[
  f_{\theta + \Delta\theta_k}: (i, s_t, p_t) \mapsto a_t^{(k)}
  \]
- **控制器切换机制**：执行时按基元类型选择对应适配器，缺失时回退到所有注册适配器的平均：
  \[
  \text{RESOLVE}(p_t) = \begin{cases} \Delta\theta_{p_t} & \text{if adapter exists} \\ \frac{1}{|P|}\sum_{p \in P} \Delta\theta_p & \text{otherwise} \end{cases}
  \]
  切换在推理时原地完成，无需重新加载骨干模型。
- **动作生成与双路径执行**：预测 7-DoF 增量动作（平动 + 旋转 + 夹爪控制），优先通过 IK 解析器转为关节目标，失败时回退到笛卡尔速度指令，从而支持不同运动学接口的机器人。

## 3. 实验设计

### 数据集与基准

- **LIBERO**：标准化语言条件操作基准，涵盖多个任务套件（Object、Spatial、Goal、Long），评估跨任务/环境泛化能力，遵循官方评估协议；

- **真实世界实验**：两台机器人平台（Franka Emika Research 3、UR7e），长时程复杂任务，训练环境与未见环境均测试。

### 对比方法与控制

- **VLA 骨干**：三种——SmolVLA（轻量高效部署）、π0.5（开放世界泛化）、GR00T-N1.5（通用人形控制）；
- **核心对比设置**：控制器固定不变，仅比较“独立部署（w/o）”与“RoboBRIDGE 包裹（w/RB）”；
- **控制器类型对比**：LoRA 微调 vs. 全参数微调 vs. 经典 IK 控制器 vs. CycleVLA（带子任务回溯与自纠错解码的 VLA 变体）；
- **LLM 后端消融**：7 种 LLM（Claude Opus 4.6、Claude Sonnet 4.6、Claude Haiku 4.5、GPT-5 mini、GPT-5 nano、Gemini-3.1 Pro、Gemini-3 Flash）分别作为 Planner/诊断模型。

### 实现细节

- GR00T-N1.5-3B 采用 LoRA-only 适配（rank=128，alpha=256，dropout=0.1），分别训练 MOVE 和 GRIP 适配器；
- 训练超参：AdamW、bf16、batch size 64、零权重衰减、cosine 调度 + 5% warmup、500 epochs、学习率 5×10⁻⁵；
- 推理设置：chunk stride 4、EMA 平滑 α=0.6、10 去噪步、分辨率 224×224、最大水平 1000 步；
- Perceptor 固定为 Florence-2；Planner 和阶段二 Monitor 默认用 Claude Opus 4.6。

## 6. 主要结论与发现

1. **结构化编排有效**：RoboBRIDGE 在 LIBERO 上将平均成功率从 35.5% 提升至 39.7%；在 RoboCasa 上，三种 VLA 骨干无一例外获得提升（平均从 3.7% 到 7.5%，排除 PnP 后从 6.2% 到 11.4%），且无需重训或缩放基座策略；
2. **监控与规划互补且缺一不可**：单独提升规划能力（不同 LLM 后端）差距不大（1.8%~8.0%）；启用监控后性能显著分化，且诊断能力依赖 LLM 的推理能力，说明高质量故障诊断需要足够的模型容量；
3. **LoRA 微调 + 编排接近全量微调**：LoRA 微调 + RoboBRIDGE 达 27.1%，逼近独立全量微调的 31.9%，而更新参数量少得多；全量微调叠加框架后达 40.0%；
4. **模型内部自纠错不如外部编排**：CycleVLA 虽内置子任务回溯与自纠错解码，但独立部署仅 7.5%，远低于 RoboBRIDGE 包裹的任何控制器；
5. **框架策略无关**：经典 IK 控制器也能在框架内达到 22.1% 的平均成功率，证明设计可推广至非学习型策略；
6. **感知与接触丰富操作是瓶颈**：失败主要来自遮挡下的感知错误和不可逆的接触操作失败，需要更强感知鲁棒性和显式验证/确认机制。

## 7. 优点

- **模块化与策略无关性**：五模块设计清晰解耦，任意动作生成策略（学习型或经典控制器）均可插入 Controller 槽位，无需改骨干权重或重训模型；
- **从 LLM 领域迁移的编排范式**：类比 LLM→Agent 的成功路径，为解决 VLA 部署问题提供了高站位的系统视角；
- **两阶段监控的设计精妙**：轻量检查 + 按需深层诊断，兼顾实时性与诊断质量，且恢复层次分级合理，以最小代价纠正错误；
- **异步感知不阻塞执行**：生产者-消费者架构将感知延迟隐藏在控制循环之外，散度触发重规划既避免频繁重规划又保持对场景变化的响应性；
- **参数高效微调**：原语级 LoRA 适配器冻结骨干、按需切换，显著降低域偏移敏感性且训练成本低；
- **双路径执行策略**（IK 优先 + 速度指令回退）提升了跨机器人兼容性；
- **诚实报告局限性**：明确指出了原语覆盖不足、阈值手动设置、接触丰富任务失败等问题，为后续研究指明方向。

## 8. 不足与局限

- **真实世界验证不足**：真实实验细节少（无具体成功率、无任务难度的定量刻画），案例展示不足以支撑“广泛真实世界稳健性”的强论断；两个机器人平台的覆盖范围也有限；
- **原始性能提升幅度有限**：在较难的 RoboCasa 上，即使提升显著，绝对成功率仍低于 10%（个别任务除外），距离实用部署差距明显；LIBERO 上的提升较小且部分任务倒退，框架对相对成熟任务的增益可能有限；
- **手动设置的超参数**：监控阈值 γ、散度阈值 τ、恢复规则均为手工设定，缺乏自适应或从数据中学习的机制；

  - **内部效度**：未报告多次随机种子、重复实验或方差，无法排除改进由特定数据划分或初始化偶然性造成；监控阈值 γ、散度阈值 τ 等关键超参数均为手动设定，可能针对所选基准隐式调优，存在过拟合特定数据集的风险。
