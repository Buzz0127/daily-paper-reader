## 摘要
视觉-语言-行动（VLA）模型在具身人工智能中展现出巨大潜力，但其在GPU上的高推理延迟限制了实时部署。现有的加速器，如Dadu-Corki，虽然提高了效率，但将VLA模型视为全精度工作负载，留下了内存和计算方面的大量冗余未被充分利用。在本文中，我们提出了VQVLA，一种算法-硬件协同设计框架，通过利用权重相似性和执行动态来加速VLA推理。我们首先介绍了MotionVQ，一种运动感知的向量量化方案，根据机器人的执行状态动态调整量化精度，在保持任务成功率的同时减少内存访问。然后我们提出了一种合并质心的向量化GEMM范式，该范式基于码本索引表示，通过空间聚合和质心的时间复用消除冗余乘法。为了实现这些优化，我们设计了一种加速器，能够高效支持动态精度选择和质心复用计算。实验结果表明，与A100 GPU、Dadu-Corki、LUT-DLA、CodeGEMM和ShiftAddLLM相比，VQVLA分别实现了6.5倍、2.8倍、1.9倍、3.3倍和4.3倍的加速，且精度损失可忽略不计。

## Abstract
Vision-Language-Action (VLA) models have demonstrated strong potential for embodied AI, yet their high inference latency on GPUs limits real-time deployment. Existing accelerators, such as Dadu-Corki, improve efficiency but treat VLA models as full-precision workloads, leaving substantial redundancy in both memory and computation underexploited.   In this paper, we propose VQVLA, an algorithm-hardware co-design framework that accelerates VLA inference by exploiting weight similarity and execution dynamics. We first introduce MotionVQ, a motion-aware vector quantization scheme that dynamically adjusts quantization precision based on the robot's execution state, reducing memory access while preserving task success rate. We then propose a merged-centroid vectorized GEMM paradigm that operates on the codebook-index representation, eliminating redundant multiplications through spatial aggregation and temporal reuse of centroids. To realize these optimizations, we design an accelerator that efficiently supports dynamic precision selection and centroid-reuse computation. Experimental results show that VQVLA achieves 6.5x, 2.8x, 1.9x, 3.3x, and 4.3x speedup over the A100 GPU, Dadu-Corki, LUT-DLA, CodeGEMM, and ShiftAddLLM, respectively, with negligible accuracy degradation.

### 2. 方法论：核心思想、关键技术细节与算法流程

#### 2.1 核心观察（Motivation）
- **瓶颈定位**：Transformer backbone占VLA推理时间的80.6%，是主要瓶颈。
- **执行状态差异**：机器人运动幅度与空间邻近性相关——小动作（≤0.8）代表靠近物体的**执行状态**（对量化敏感），大动作代表**过渡状态**（对噪声更鲁棒）。实验证明过渡状态对噪声容忍度显著更高。
- **质心冗余**：VQ后索引矩阵存在热质心（高频访问），同一列内与跨列间均存在质心重复。

#### 2.2 MotionVQ：运动感知向量量化
- **状态预测**：基于上一步3D动作（Ax, Ay, Az）计算运动幅度
  \[
  D = \sqrt{A_x^2 + A_y^2 + A_z^2}
  \]
  与阈值 Td 比较：D ≤ Td → 执行状态；D > Td → 过渡状态。
- **精度自适应**：离线准备两套VQ配置——高精度配置VQ[256,2,256]（平均4.125 bit）用于执行状态，低精度配置VQ[128,2,64]（平均3.125 bit）用于过渡状态。运行时根据状态动态选择对应的码本和索引矩阵，减少内存足迹。

#### 2.3 合并质心向量化GEMM
- **空间聚合（Spatial Merging）**：利用同一列内多个权重向量映射到同一质心的现象，先累加对应的多个输入，再做一次乘法（乘法分配律），减少乘次数。
- **时间复用（Temporal Reusing）**：利用跨列重复出现的质心，构建结果缓存（tag = 质心ID + 权重向量ID），命中时直接复用之前计算的结果，跳过重复乘法。
- 通过离线Top-k热质心选择构建缓存，运行时用质心位置表指导查找。

#### 2.4 硬件架构（VQVLA Accelerator）
- **三大模块**：状态预测器（运动幅度计算+阈值比较）、矩阵乘法引擎（空间聚合PE阵列+时间复用PE阵列+加法树+结果缓存）、索引处理引擎（多IPU并行生成空间/时间质心位置表）。
- **关键设计**：3级流水加法树（支持8输入/4+4输入/2+2+2+2输入三模式）、1.5MB结果缓存、1:1空间-时间PE比。
- 数据流三步：①运动VQ获取码本索引 ②索引处理引擎构建位置表 ③矩阵乘法引擎执行空间聚合和时间复用。

### 7. 优点与亮点

- **洞察新颖且贴近实际**：将机器人执行状态（执行/过渡）与量化敏感度关联，用运动幅度作为轻量代理，设计简单有效。

- **多模型多任务评估**：覆盖5个VLA模型、多个任务集，对比充分，增加了结论的可信度。

- **纯算法GPU执行效率低**：VQVLA算法在GPU上存在45.2%性能损失，表明其只能通过专用硬件发挥价值，限制了在通用平台上的部署灵活性。

- **结果报告统计不够充分**：未报告多次运行的方差、置信区间或最坏情况，难以全面评估方法的稳定性。

- **未讨论扩展性**：VLA模型持续增大（未来超7B），VQ配置（如256/64质心）和硬件规模是否仍能保持最优尚无分析。
