## 摘要
通用机器人策略旨在将多模态观测和语言任务指令映射为跨多样任务的动作。然而，现有方法通常将未来表示为一个固定的、短期的视频-动作块。这种短期未来捕获了用于动作执行的局部场景演变，但它并未明确描述指定任务应如何从当前阶段进展到下一阶段的阶段级未来。因此，我们区分了机器人操作中两个互补的未来：一个用于捕获局部场景演变的短期物理未来，以及一个用于表示任务进展的阶段级语义未来。我们引入了JEPA-WAM，它用Stage-JEPA增强了一个基于Motus的世界动作模型（WAM），Stage-JEPA是一种目标条件下的联合嵌入预测架构（JEPA）预测器。给定当前观测和任务指令，Stage-JEPA使用冻结的V-JEPA2编码器提取当前状态表示，并预测下一个推断阶段的潜在目标。在干净和随机环境中的50个RoboTwin 2.0任务中，JEPA-WAM实现了90.25%的总体成功率，并将成功卷展中的平均执行步数相对于最强基线减少了5.97%。

## Abstract
Generalist robot policies aim to map multimodal observations and linguistic task instructions to actions across diverse tasks. However, existing methods typically represent the future as a fixed, short video-action chunk. This short-term future captures local scene evolution for action execution, but it does not explicitly describe the stage-level future that specifies how a task should progress from its current stage to the next. We therefore distinguish two complementary futures for robot manipulation: a short-term physical future to capture local scene evolution and a stage-level semantic future to represent task progress. We introduce JEPA-WAM, which augments a Motus-based World Action Model (WAM) with Stage-JEPA, a goal-conditioned Joint-Embedding Predictive Architecture (JEPA) predictor. Given the current observation and task instruction, Stage-JEPA uses a frozen V-JEPA2 encoder to extract the current-state representation and predicts the latent target of the next inferred stage. Across 50 RoboTwin 2.0 tasks in clean and randomized environments, JEPA-WAM achieves 90.25% overall success and reduces the mean number of execution steps in successful rollouts by 5.97% relative to the strongest baseline.

**核心区分：**
- **短期物理未来（short-term physical future）**：描述即时的视频-动作演变，覆盖局部场景变化。
- **阶段级语义未来（stage-level semantic future）**：指明下一个要达成的对象或关系状态，代表任务进展。

## 2. 方法论

### 2.1 总体框架
JEPA-WAM 为两阶段训练 + 闭环推理架构：
- **Stage I**：训练目标条件下的 JEPA 预测器，从当前观测和任务目标推断下一阶段未来。
- **Stage II**：冻结 JEPA 预测器，训练 WAM 生成短期视觉未来和动作块，并将预测阶段作为条件注入。
- **推理时**：两组件在滚动时域（receding-horizon）循环中顺序执行。

### 2.2 Stage I：训练 JEPA 预测器

**阶段对构建（Stage-pair construction）：** 无需人工阶段标注，采用基于 JEPA 特征的转移启发式自动构建监督：
- 每隔 8 帧采样候选中心帧，用**冻结的 V-JEPA2** 编码以候选中心为中心的 64 帧片段，获得 token 级表征。
- 通过局部窗口内表征变化打分（clip 级距离与 token 级最大距离的归一化最大值），配合时间非极大值抑制（NMS），保留最多 K=5 个转移关键帧。
- 关键帧与初始帧、终止帧共同构成阶段边界序列 B=(b₀,...,b_L)。每个当前帧 t 与其下一阶段边界 b_{i+1} 形成稠密的训练对 (t, b_{i+1})。

**目标条件下的阶段预测（Stage-JEPA）：**
- 输入：当前 64 帧观测切片 S_t（以 t 为中心）和语言指令 l。
- 使用**冻结的 V-JEPA2 编码器**分别编码当前切片和目标切片，得到当前潜在 z_t 与目标潜在 z^{target}_t。
- 可训练的预测器（从 V-JEPA2 预测器初始化 + 指令适配器）生成 token 级下一阶段预测，池化归一化后通过余弦损失对齐目标表征：

$$L_{stage} = \frac{1}{B}\sum_{i=1}^{B}\left(1 - (\hat{z}^{target}_i)^\top z^{target}_i\right)$$

仅优化预测器和指令适配器，编码器冻结。

### 2.3 Stage II：训练阶段条件化的 WAM

**WAM 基础架构：** 采用 Motus——Mixture-of-Transformers 架构，包含：
- 视频生成专家（初始化自 Wan2.2）：建模局部视觉演变；
- 动作专家：表示机器人状态与稠密动作块；
- 视觉-语言理解专家（冻结的 Qwen3-VL 编码器）：提取指令与观测相关特征。
- 三模态联合注意力（Tri-modal Joint Attention）在各 Transformer 层间进行信息交换。

**阶段条件注入（门控接口）：**
- 将 Stage-JEPA 输出的预测阶段 token 做均值池化，经 MLP 匹配 Wan 视频 token 维度：

$$h_t = P_\psi\left(\text{Pool}(\hat{Z}^{target}_t)\right) \in \mathbb{R}^{d_v}$$$$\alpha = 0.2\sigma(\beta)$$$$\tilde{X}^v_t = X^v_t + \alpha h_t$$

- α 为全局有界标量门控（sigmoid 有界），h_t 为样本特异的条件向量，广播到该样本所有视频 token。
- 训练目标保留 WAM 原有视频损失和动作损失，外加可选条件化接口正则化项：

$$L = L_{video} + L_{action} + L_{reg}$$$$L_{reg} = \lambda_g \alpha^2 + \lambda_\rho(\rho - \rho_0)^2, \quad \rho = \frac{\|\alpha h_t\|}{\|X^v_t\|}$$

其中 ρ₀ 为手动选定的目标幅度比率，第一个正则项将门控偏置向小的残差更新，第二项约束注入特征相对幅度。

### 2.4 闭环推理
- 维护因果 64 帧观测缓冲（无未来观测，不足时重复最早帧填充）。
- 每次策略查询：先由冻结的 JEPA 分支从观测缓冲和指令预测阶段潜在；再将该潜在通过同一条件化接口注入 WAM，预测短期视觉未来和动作块；环境执行动作块后更新观测缓冲并重复。
- 阶段边界与目标切片仅为训练时监督，推理时无需。

## 6. 主要结论与发现

1. **总体性能**：JEPA-WAM 在 50 任务平均成功率上达到干净环境 91.42%、随机化环境 89.08%，总体 90.25%，显著优于所有基线。
2. **类别优势**：在干净设置下 5/7 个语义类别、随机化下 6/7 个类别中优于 Motus。对依赖显式任务状态变化的任务（交接、目标放置、容器装箱、排列堆叠）提升最为显著。
3. **执行效率**：所有卷展平均长度从 156.28 降至 132.80 步（-15.02%）；成功卷展平均长度从 79.57 降至 74.82 步（-5.97%），说明阶段级引导减少了冗余纠正动作。
4. **消融结论**：
   - 去除 JEPA 分支造成最大性能下降 → 阶段条件化路径提供了超出短视界 WAM 骨干的额外信息。
   - 不注入未来潜在（仅修改当前观测表征）也降低成功率 → 预测的下阶段潜在应直接注入 WAM 视频流。
   - 去除 Stage-I 训练仍有竞争力（预训练 V-JEPA2 预测器已提供通用视觉结构），但阶段对训练带来最佳结果。
   - 去除门控正则化影响较小 → sigmoid 有界门控已能稳定残差更新，正则项提供额外尺度约束。
5. **真实机器人**：JEPA-WAM 在两个 LIFT2 任务上平均任务进度分数 48.00，优于 π0.5 的 41.50（Cube_Grasp：45.00 vs 33.50；Power_Strip：51.00 vs 49.50）。
6. **定性分析**：JEPA-WAM 在成功轨迹中更快推进到下一任务相关状态，而 Motus 表现出重复的上下振荡和局部修正。

- **模块化训练策略**：两阶段训练避免了细粒度视觉/动作损失干扰语义目标，原理清晰。
- **实验全面**：大规模模拟评估（50 任务、10,000 episode）+ 消融 + 效率分析 + 真实机器人验证，多层次覆盖。
- **诊断细致**：对自动构建的阶段监督做了统计诊断，诚实报告了中心切片跨边界和重叠问题，并解释其合理性。

## 8. 不足与局限

- **实验层面的局限**：
  - 基线数字依赖已发表结果而非完全复现，存在评估协议差异的潜在风险
  - 每个检查点仅评估一次（seed 0），未报告多次运行的平均值和方差
  - 真实机器人实验规模有限（2 任务 × 20 次），统计显著性不明确（尤其 Power_Strip 差距仅 1.5 分）
  - RoboTwin 为仿真生成数据，真实场景（如 LIFT2）覆盖任务类型较少

- **方法层面的局限**：
  - 在"获取与抬升"和"关节/设备交互"类别中，JEPA-WAM 未超越 Motus——对类别的适用性不均，依赖立即抓取几何/接触稳定性的任务阶段结构互补性有限
  - 自动阶段检测启发式（NMS 半径、候选数）存在手工设定超参数，可能影响不同任务分布的表现
  - 中心切片窗口造成训练监督与严格因果推断之间的不一致（文中已报告 82.97%-84.67% 的跨边界比例）
  - 61 帧的 V-JEPA2 输入需求引入了额外推理延迟和更大的观测缓冲需求

- **应用层面的局限**：
  - 推理延迟未在文中报告，高频闭环控制适用性未验证
  - 未讨论跨实体（cross-embodiment）泛化能力
  - 整体成功率增益对最直接基线 Motus 而言幅度不算很大（约 +2-3 个百分点），但效率改进相对显著
