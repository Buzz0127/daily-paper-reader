## 摘要
视觉-语言-动作（VLA）模型在现实世界中的部署通常受到效率-性能权衡、跨实体泛化以及执行平滑性的瓶颈制约。我们提出了NebulaVLA，一种异步双频架构，将高层语义推理与低层动作控制解耦，从而优化计算资源和模块化性。为了弥合异构机器人之间的语义鸿沟，我们引入了GESTURE-7，一种统一的基于语言的动作表示。此外，我们的引导动作算法通过基于掩码的平滑性约束来强制运动学连续性。综合评估表明，NebulaVLA显著优于同步基线，在LIBERO-Plus上实现了85.5%的平均成功率，并将动作生成加速了约2.7倍。这种异步设计为实际机器人应用实现了高效且响应迅速的控制。

## Abstract
Real-world deployment of Vision-Language-Action (VLA) models is often bottlenecked by efficiency-performance trade-offs, cross-embodiment generalization, and execution smoothness. We present NebulaVLA, an asynchronous dual-frequency architecture that decouples high-level semantic reasoning from low-level action control, optimizing computational resources and modularity. To bridge semantic gaps across heterogeneous robots, we introduce GESTURE-7, a unified language-grounded action representation. Furthermore, our Guide Action algorithm enforces kinematic continuity via mask-based smoothness constraints. Comprehensive evaluations demonstrate that NebulaVLA significantly outperforms synchronous baselines, achieving an 85.5\% average success rate on LIBERO-Plus and accelerating action generation by \textasciitilde 2.7$\times$. This asynchronous design enables highly efficient and responsive control for practical robotics.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：视觉-语言-动作（VLA）模型在真实机器人部署中面临三大瓶颈：
  1. **效率-性能权衡**：传统同步单频架构以统一时间分辨率处理语义推理与高频电机控制，难以兼顾两者需求；
  2. **跨形态泛化困难**：现有连续动作表示多为离散 token 映射或原始状态回归，缺乏跨异构机器人平台（如灵巧手、夹爪、机械臂）的统一语义抽象；
  3. **轨迹平滑性不足**：异步推理与动作块生成之间的时间错配导致执行抖动和 chunk 边界不连续，影响任务完成的稳定性。
- **整体含义**：论文认为 VLA 模型需从"单一大模型同步处理一切"的范式转向**快慢双系统协同**（fast-slow cognitive paradigm），通过异构频率解耦实现高效、可部署、可扩展的机器人操作。
- **核心主张**：可通过架构级（异步双频）、表示级（GESTURE-7）和算法级（Guide Action）的三重创新，同时改善效率、泛化和平滑性，而非仅依靠单一模型规模的扩展。

## 2. 论文提出的方法论

**整体架构**：NebulaVLA 采用**异步双频架构**，由两个系统组成：

- **System 2（S2，慢系统，约10 Hz）**：负责高层语义规划，输入自然语言指令和低频视觉信息，输出抽象动作引导。以 Qwen3-VL 作为视觉-语言骨干，通过可学习 token 从隐藏层提取特征作为 S1 的引导条件。
- **System 1（S1，快系统，约20 Hz）**：负责低层反应式动作执行，以 DiT（Diffusion Transformer）为核心，在高频视觉输入、动作历史与 S2 引导条件下进行扩散去噪生成动作块。S1 对 DINOv2 视觉编码器进行对比微调以增强视觉-本体感知对齐。

**关键技术一：GESTURE-7（统一动作表示）**
- 将末端执行器状态编码为 7 维向量：`[x, y, z, r, p, w, gesture]`：
  - `(x, y, z)`：笛卡尔位置（整数厘米）；
  - `(r, p, w)`：姿态角 roll/pitch/yaw（整数度）；
  - `gesture`：自然语言关键字，如"grasp"、"push"、"rotate"等。
- 不同本体执行相同动作共享同一关键字（如夹爪和灵巧手抓取均表示为"grasp"），实现跨平台语义统一，并天然支持语言条件下的强化学习。
- 位置和角度量化到整数级，以降低学习负担并抑制预测幻觉。

**关键技术二：Guide Action（引导动作机制）**
- 受图像外扩（Image Outpainting）启发，将 chunk 间拼接嵌入生成过程本身，替代后处理平滑方法。
- 生成下一动作块时，以未执行的先前动作（如 a4–a7）作为引导锚点，强制对齐新旧 chunk 的边界。
- 扩散去噪过程中通过二进制掩码 M 保留已知动作、只对新生成区域进行去噪。掩码定义为：M[1..k] = 1（锚点区严格保留），M[k+1..T] = 0（生成区由模型预测）。
- 引导点数在训练时从 0 到 3 随机采样，以适配不同推理延迟。

**训练流程（三阶段）**：
1. **Stage 1**：System 2 监督微调（SFT），涵盖五类任务——姿态回归、关键点回归、2D 路点预测、3D 轨迹预测、链式思维（CoT）生成；
2. **Stage 2**：System 2 强化学习（GRPO 算法），使用 GESTURE-7 距离、关键点定位奖励、路点奖励、轨迹奖励和格式奖励；
3. **Stage 3**：System 1 监督微调，使用加权流匹配损失（L2 损失），训练时冻结视觉编码器，并仅对掩码 M=0 的新生成区域计算损失。

## 6. 论文的主要结论与发现

- **模拟实验**：NebulaVLA 在 LIBERO-Plus 上取得 **85.5% 平均成功率**，超越 InternVLA-M1（81.3%）4.2%，显著超越 OpenVLA-OFT+（79.6%）、GR00T N1.5（59.0%）和 π0.5（58.0%）；在 Spatial、Object、Goal、Layout 等维度优势明显。
- **真机实验**：NebulaVLA-异频在 Pick-and-Place 上成功率 92.08%（较 InternVLA-M1 的 77.91% 高 14.2%），在 Feeding 上成功率 92.5%（较 InternVLA-M1 的 72.5% 高 20%）；推理延迟从 81ms（InternVLA-M1）和 115ms（同频）降至 **42ms**，即动作生成加速约 2.7 倍。

- **架构优势**：异频架构不仅提升性能、降低延迟，还支持 System 1 与 System 2 的分布式独立部署，有利于边缘计算场景。
