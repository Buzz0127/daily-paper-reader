## 摘要
视觉-语言-动作（VLA）模型提高了机器人操作的灵活性和通用性，但面对在线干扰（如任务目标变化、场景配置变化或机器人状态变化）时仍然脆弱。现有恢复方法通常需要失败数据、策略重训练或外部纠正代理，引入了额外的数据需求和执行风险。我们提出反事实重新对齐（CoRe），一种无需训练的框架，在推理时恢复冻结的VLA模型而不需要失败数据。检测到偏差后，CoRe想象策略在最近的有效状态下如何朝着当前目标继续前进，使用合成观察代替物理执行，然后在将控制权交还给策略之前，最小程度地重新对齐机器人和场景以重新加入这一想象延续。因此，恢复计划无需物理试错，保留了已完成的任务进度，并以统一方式处理情节中期的指令变化和物理扰动。在多个模拟器、VLA骨干和真实世界设置中的广泛实验表明，CoRe将成功率提高了最多85.0个百分点，接近正常水平，同时将物理恢复减少了42.2%，无需策略微调或特定失败的恢复训练。

## Abstract
Vision-language-action (VLA) models have improved the flexibility and generality of robotic manipulation, yet they remain fragile to online disruptions, such as changes in task goal, scene configuration, or robot state. Existing recovery methods often require failure data, policy retraining, or external corrective agents, introducing additional data requirements and execution risks. We propose Counterfactual Realignment (CoRe), a training-free framework that recovers a frozen VLA at inference time without failure data. Upon detecting a deviation, CoRe imagines how the policy would continue toward the current goal from a recent viable state, using synthesized observations in place of physical execution, and then minimally realigns the robot and scene to rejoin this imagined continuation before returning control to the policy. Recovery is therefore planned without physical trial-and-error, preserves completed task progress, and handles both mid-episode instruction changes and physical perturbations in a unified manner. Extensive experiments across multiple simulators, VLA backbones, and real-world settings show that CoRe improves success rates by up to 85.0 percentage points to near-nominal levels while reducing physical restorations by 42.2%, without policy fine-tuning or failure-specific recovery training.

## 2. 方法论

### 2.1 核心思想

CoRe 的核心是构建一条**反事实延续（counterfactual continuation）**：从最近一个仍然处于分布内（in-distribution）的状态出发，用**合成观测**替代真实物理执行，闭环保策略在目标指令 ℓ′ 下的行为，得到一条“如果策略继续执行会怎样”的短轨迹。随后物理系统只需最小程度地恢复场景并重新对齐到该轨迹的接合点，再把控制权交还给同一个冻结策略。整个恢复过程**在想象中完成规划，物理运动只发生在最后一步**。

形式化地，CoRe 求解以下优化问题（式 1）：
- 目标：最小化物理干预成本 |R(c)|，即需要操作的物体数量；
- 约束 1：策略在恢复配置 c 和目标指令 ℓ′ 下的延续必须处于分布内；
- 约束 2：已完成的子目标进度 P(c_now) 必须保留。

### 2.2 关键技术细节

1. **在线后缀 OOD 检测**
   - 监控策略动作头的**后缀潜在向量**（action-expert suffix latent），即动作解码前的最后一层隐藏状态。
   - 每次策略查询做 K 次随机前向，平均池化得到 h_t；计算按任务校准的马氏距离得分 s_t（式 2）。
   - 阈值 τ_k 在离线成功轨迹上进行校准；连续 n_consec 次查询超过阈值即触发恢复。优点：只需正常轨迹校准，无需训练专门检测器。

2. **阶段感知恢复锚定（Phase-Aware Recovery Anchoring）**
   - 检测到偏差后，从轨迹中寻找“发散起点”（divergence onset）：对锚帧分别用原指令 ℓ 和目标指令 ℓ′ 预测动作块，比较标准化动作差异或干净滚动下的 TCP 偏差（式 3、4）。
   - 由于查询粒度是动作块，发散起点只能定位到块级；再用块内逐步散度细化到控制步级（式 5），并用正运动学（FK）将锚点推进 h* 步。
   - 锚定受“阶段感知”约束：跳过被移动物体或活动关节未稳定的帧，并要求夹爪与所有可移动物体保持净空，确保锚点位于可复现的自由空间。

3. **合成反事实延续（Synthesized Counterfactual Continuation）**
   - 从锚点开始，用冻结策略 π 在目标指令 ℓ′ 下进行闭环保滚动，生成短轨迹 τ_B。
   - **观测合成**：
     - 维护每个物体的局部坐标系体素存储（从分割的 RGB-D 历史累积）和世界系背景存储。
     - 第三人称（exocentric）视角：编辑锚帧，移除臂和位移物体的像素，用背景体素投影填充空洞，再以 z-buffering 体素喷涂把位移物体重渲染到想象位姿，最后合成 FK 渲染的臂。
     - 第一人称（egocentric）视角：整个图像从体素存储在想象相机位姿下重建。
     - 残余孔洞用 LaMa 或 OpenCV Telea 修复。
   - **闭环保滚动**：每个想象节拍合成两个相机的观测，查询 π 得到动作，再用 FK 推进手臂构型（式 6：q_{t+1}=FK(q_t,a_t), ô_{t+1}=Synth(q_{t+1},p_t)）。
   - **终止条件**：TCP 接近任一物体表面 d_prox 时停止（FK 无法建模接触动力学），取接触前最后一帧作为接合状态 c*，既保证接合点位于自由空间，又尽可能保留生成的接近过程。长动作块骨干（如 X-VLA）需要额外加大净空。

4. **基于虚拟探测的最小恢复（Probe-Based Minimal Restoration）**
   - 并非所有位移物体都需要物理恢复：远离任务相关工作区的物体可能不影响从接合状态的延续。
   - 定义位移物体（相对接合姿态超差）；构造**强制恢复集 F**（目标指令引用的物体、任务实体半径 r_veto 内的物体、占据目标区域的物体）；其余位移物体作为可排除候选。
   - 按子集大小递增，每个候选子集 S⊇F 通过**虚拟探测**评估：从“混合种子”（S 中的物体在接合姿态、其余物体保持当前位姿）开始做反事实滚动，与“全恢复参考”比较臂构型轨迹的均方差 d_arm(S)（式 7），接受第一个小于阈值 ε 的子集。
   - 所有探测均在想象中完成（合成观测 + FK），不产生物理运动。

5. **物理重排与交接（Physical Rearrangement and Handoff）**
   - 只有最后阶段才移动机器人：按顶部优先高度顺序对 S* 中物体执行运动规划的 pick-and-place，每个放置验证到 ε_verify 以内，失败重试一次；不可恢复情况（抓取失败、位姿不可达）上报为结构化干预请求。
   - 手臂移动到接合构型 q*，轨迹截断到恢复锚点，控制权交还冻结策略 π；后续恢复在此基础上链式推进，而非回退到更早状态。

### 2.3 算法流程（文字说明）

每个策略查询：K 次随机前向 → 计算 OOD 得分；若连续触发则进入恢复：扫描轨迹定位发散起点 → 细化锚点 → 合成观测并闭环保滚动到接触边界 → 得到接合状态 c* → 构造强制集 F → 按大小递增虚拟探测候选子集 → 选择最小通过子集 S* → 物理恢复物体并移动手臂到 q* → 截断轨迹、恢复策略 RNG、交还控制。
