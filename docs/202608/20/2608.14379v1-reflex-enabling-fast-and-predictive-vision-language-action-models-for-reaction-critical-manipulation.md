## 摘要
视觉-语言-动作（VLA）模型最近在机器人操作中取得了令人鼓舞的性能。然而，现有基准主要评估静态操作任务上的泛化能力，很大程度上忽略了动态交互场景。为弥补这一空白，我们提出了ReflexBench，一个面向反应关键型操作的基准。ReflexBench包含六个动态任务，并引入了一个评估框架，该框架将模拟器步进与机器人控制解耦，同时支持同步和异步推理下的可配置延迟。基于ReflexBench，我们提出了ReflexVLA，一种专为反应关键型操作设计的高效VLA模型，无需大规模机器人数据预训练。ReflexVLA通过潜在未来预测和视觉骨干网络内的多帧时序融合增强了时序推理能力，同时通过批量视觉编码和CUDA Graph重放降低了部署延迟。实验表明，ReflexVLA在标准静态操作基准上保持竞争力的同时，持续提升动态操作性能，实际部署条件下的真实世界实验进一步证明了其有效性。项目网站：https://reflexvla.github.io

## Abstract
Vision-Language-Action (VLA) models have recently achieved promising performance in robotic manipulation. However, existing benchmarks mainly evaluate generalization on static manipulation tasks and largely overlook dynamic interaction scenarios. To address this gap, we present ReflexBench, a benchmark for reaction-critical manipulation. ReflexBench contains six dynamic tasks and introduces an evaluation framework that decouples simulator stepping from robot control while supporting configurable latency under synchronous and asynchronous inference. Building upon ReflexBench, we propose ReflexVLA, an efficient VLA model designed for reaction-critical manipulation without large-scale robot-data pretraining. ReflexVLA enhances temporal reasoning through latent future prediction and multi-frame temporal fusion within the vision backbone, while reducing deployment latency through batched visual encoding and CUDA Graph replay. Experiments show that ReflexVLA consistently improves dynamic manipulation performance while maintaining competitive accuracy on standard static manipulation benchmarks, and real-world experiments further demonstrate its effectiveness under practical deployment conditions. Project website: https://reflexvla.github.io

- **研究背景**：视觉-语言-动作（VLA）模型在机器人操作中取得了显著进展，但现有基准主要评估静态操作任务，忽略了动态交互场景。实际应用中的反应关键型操作（如接球、拦截移动物体、实时插入等）要求模型既能快速反应，又能对未来状态进行推理。
- **核心问题**：现有方法通常将“未来预测”和“推理效率”分开研究。一方面，动态操作基准缺少对延迟的真实建模；另一方面，提升预测能力往往带来额外计算开销，而加速推理的方法又未考虑未来感知。
- **论文意义**：提出 **ReflexBench**（面向反应关键型操作的基准）和 **ReflexVLA**（快速且可预测的 VLA 模型），同时解决动态环境中的“预见性”与“低延迟”问题，推动 VLA 在反应式操控场景中的实际部署。

## 2. 方法论

### 2.1 ReflexBench 基准

- 包含 **6 个动态操作任务**：
  - 传送带拾放（Conveyor Belt Pick-and-Place）
  - 接球（Ball Catching）
  - 打地鼠（Whack-a-Mole）
  - 滚动球拦截（Rolling Ball Interception）
  - 扔球（Ball Throwing）
  - 旋转插销插入（Rotating Peg Insertion）
- **延迟感知评估协议**：
  - 将模拟器步进与机器人控制解耦，环境在策略推理期间继续演化。
  - 支持 **同步推理** 和 **异步推理** 两种部署模式，并引入可配置的延迟阻塞机制。
  - 通过实时因子（RTF = t_sim / t_wall）将真实策略推理延迟换算为仿真内延迟。

### 2.2 ReflexVLA 模型

- **基准架构**：基于 VLA-Adapter，视觉编码器为融合 DINOv2 与 SigLIP 的 ViT，语言骨干为 Qwen2.5-0.5B，通过可学习 action queries 输出动作块（action chunk）。
- **三大核心设计**：

1. **潜在未来预测（Latent Future Prediction）**
   - 使用冻结的 DINOv3 提取未来观测的语义特征（维度 1024）。
   - 在输入序列中追加 H 个可学习的未来 token，H 与动作块大小一致。
   - 预测头将未来 token 的隐藏表示投影到 DINOv3 特征空间，损失函数为掩码余弦相似度：
     \[
     L_{future} = \frac{\sum_{i=1}^{H} m_i [1 - \cos(\hat{y}_{t+i}, y_{t+i})]}{\sum_{i=1}^{H} m_i}
     \]
   - 总损失：\[ L = L_{act} + \lambda_{future} L_{future} \]
   - 该设计避免直接预测图像像素，计算开销低。

2. **多帧时序融合（Multi-Frame Temporal Fusion）**
   - 输入 T 个历史观测，视觉编码器提取中间层（`X_mid`）和最终层（`X_final`）特征。
   - 对中间层特征，在每个空间 patch 上沿时间维度做**因果时序注意力**（causal temporal attention），并加入时间位置编码。
   - 融合后的时序增量加到当前帧最终特征上，得到增强表示。
   - 该方式只向语言模型暴露当前帧的融合 token，**不增加语言模型侧的计算复杂度**。

3. **推理延迟优化（Inference Latency Optimization）**
   - **批量视觉编码**：将 V 个视角 × T 帧图像合并为一次视觉编码器前向，减少框架开销。
   - **CUDA Graph 重放**：捕获整个推理管线（视觉编码、时序融合、语言模型、动作预测）为计算图，部署时直接重放，消除内核调度延迟。
