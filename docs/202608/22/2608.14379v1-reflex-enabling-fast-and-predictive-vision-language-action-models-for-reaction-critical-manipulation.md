## 摘要
视觉-语言-动作（VLA）模型近年来在机器人操作中取得了令人瞩目的性能。然而，现有基准主要评估静态操作任务上的泛化能力，在很大程度上忽视了动态交互场景。为解决这一空白，我们提出了ReflexBench，一个用于反应关键操作的基准。ReflexBench包含六个动态任务，并引入了一个评估框架，该框架将模拟器步进与机器人控制解耦，同时支持同步和异步推理下的可配置延迟。基于ReflexBench，我们提出了ReflexVLA，一种专为反应关键操作设计的高效VLA模型，无需大规模机器人数据预训练。ReflexVLA通过潜在未来预测和视觉骨干内的多帧时间融合增强了时间推理能力，同时通过批量视觉编码和CUDA Graph重放降低了部署延迟。实验表明，ReflexVLA在标准静态操作基准上保持竞争力的同时，持续提升动态操作性能，真实世界实验进一步验证了其在实际部署条件下的有效性。项目网站：https://reflexvla.github.io

## Abstract
Vision-Language-Action (VLA) models have recently achieved promising performance in robotic manipulation. However, existing benchmarks mainly evaluate generalization on static manipulation tasks and largely overlook dynamic interaction scenarios. To address this gap, we present ReflexBench, a benchmark for reaction-critical manipulation. ReflexBench contains six dynamic tasks and introduces an evaluation framework that decouples simulator stepping from robot control while supporting configurable latency under synchronous and asynchronous inference. Building upon ReflexBench, we propose ReflexVLA, an efficient VLA model designed for reaction-critical manipulation without large-scale robot-data pretraining. ReflexVLA enhances temporal reasoning through latent future prediction and multi-frame temporal fusion within the vision backbone, while reducing deployment latency through batched visual encoding and CUDA Graph replay. Experiments show that ReflexVLA consistently improves dynamic manipulation performance while maintaining competitive accuracy on standard static manipulation benchmarks, and real-world experiments further demonstrate its effectiveness under practical deployment conditions. Project website: https://reflexvla.github.io

## 方法论

### 1. ReflexBench 基准

- **任务组成**：包含6个动态操作任务，覆盖典型反应关键挑战：
  - 传送带抓取放置（Conveyor Belt Pick-and-Place）
  - 接球（Ball Catching）
  - 打地鼠（Whack-a-Mole）
  - 滚动球拦截（Rolling Ball Interception）
  - 掷球（Ball Throwing）
  - 旋转轴插入（Rotating Peg Insertion）
- **数据收集**：采用基于规划器的数据采集管线，将任务分解为多阶段子目标，通过预测未来轨迹规划动作；对于复杂交互，则训练任务特定的强化学习策略生成示范轨迹。
- **延迟感知评估协议**（核心创新）：
  - **解耦模拟器步进与机器人控制**：环境动态独立于策略计算持续推进，避免传统基准中“推理时环境暂停”的不真实设定；
  - **同步推理**：模拟器暂停直到策略推断完成，模型在指定延迟后执行动作块，模拟推理阻塞的真实部署；
  - **异步推理**：策略从当前观测推断新动作块，同时机器人执行前一轮动作块，推理与执行重叠，但动作为轻微“陈旧”状态；
  - **可控延迟注入**：可通过真实时间因子（RTF = t_sim / t_wall）将实际测量到的策略推断延迟转换为仿真延迟，实现可配置延迟测试。

### 2. ReflexVLA 模型

模型以紧凑型VLA架构为基础（融合DINOv2与SigLIP视觉编码器 + Qwen2.5-0.5B语言骨干），引入三项核心设计：

- **潜在未来预测（Latent Future Prediction）**：
  - 不使用高成本的像素级未来图像预测，而是使用**冻结的DINOv3编码器**提取未来观测（未来H步）的语义特征 y_{t+i} ∈ R^1024；
  - 在Transformer输入序列中追加H个可学习未来token，与动作块时间结构对齐；
  - 未来token通过投影头映射到DINOv3特征空间，使用**掩码余弦相似度损失**训练：
    
    L_future = Σ m_i [1 − cos(ŷ_{t+i}, y_{t+i})] / Σ m_i
    
  - 总损失：L = L_act + λ_future · L_future（λ_future = 0.05）；
  - 采用冻结目标编码器是关键——使用可训练编码器会导致训练不稳定降低31.9%。

- **多帧时序融合（Multi-Frame Temporal Fusion）**：
  - 避免将全部历史帧视觉token直接拼接进语言模型（造成二次复杂度爆炸），而是**在视觉骨干内部完成时序融合**；
  - 对视觉编码器中间层特征（保留更多局部外观与运动信息），在V个视角、T帧中，对每个patch的空间位置提取跨时间轨迹；
  - 归一化与降维后，应用**因果时序注意力**（防止未来信息泄漏），融合结果上采样后与当前帧最终层特征逐元素相加；
  - 语言模型侧视觉token数量与单帧设定一致，不增加LLM开销。

- **推理延迟优化（Inference Latency Optimization）**：
  - **批量视觉编码**：将V×T张图像合并为单次视觉编码器前向传播，减少重复框架开销并提升GPU利用率；
  - **CUDA Graph重放**：部署时计算图固定，将完整推理流水线捕获为CUDA Graph，新观测写入预分配缓冲区后直接重放整图，消除重复内核调度与运行时开销。

## 主要结论与发现

- **推理机制的影响**：低频推理下异步推理因观测-动作失配而劣于同步；随着频率增加，异步推理的优势逐步显现，最终优于同步推理；
- **块大小与执行horizon**：较大块大小+较短执行horizon在异步推理下效果最佳；
- **ReflexVLA核心结果**：在ReflexBench上取得50.4%平均成功率，超过所有基线（第二名PUMA为50.2%），同时仅用1B参数，是PUMA的1/4参数量；与基线VLA-Adapter相比提升20.1个百分点；
- **静态任务无损**：LIBERO平均97.2%，与最优97.3%相当，说明时序建模与预测模块不牺牲静态泛化能力；
- **延迟优化的双重收益**：批量编码+CUDA Graph将延迟从125.1ms降至65.0ms，同时成功率提升2.1个百分点——延迟降低本身即对反应关键任务产生直接性能增益；
- **真实实验验证**：在三项真实任务中优于SmolVLA，与PUMA相当（16/20 vs 13/20 传送带成功率等），验证了实际部署有效性。

- **基准设计贡献突出**：显式建模推理延迟，提供同步/异步双重评估范式，引入了更真实的环境-策略耦合评估方法；
