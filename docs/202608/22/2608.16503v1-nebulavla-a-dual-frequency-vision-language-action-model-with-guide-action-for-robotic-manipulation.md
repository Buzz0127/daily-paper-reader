## 摘要
视觉-语言-动作（VLA）模型在实际部署中常受限于效率与性能的权衡、跨实体泛化以及执行平滑性。我们提出了NebulaVLA，一种异步双频架构，将高层语义推理与低层动作控制解耦，优化了计算资源和模块化。为弥合异构机器人之间的语义鸿沟，我们引入了GESTURE-7，一种统一的语言接地动作表示。此外，我们的引导动作算法通过基于掩码的平滑约束强制执行运动学连续性。综合评估表明，NebulaVLA显著优于同步基线，在LIBERO-Plus上实现了85.5%的平均成功率，并将动作生成加速了约2.7倍。该异步设计为实际机器人应用提供了高效且响应迅速的控制。

## Abstract
Real-world deployment of Vision-Language-Action (VLA) models is often bottlenecked by efficiency-performance trade-offs, cross-embodiment generalization, and execution smoothness. We present NebulaVLA, an asynchronous dual-frequency architecture that decouples high-level semantic reasoning from low-level action control, optimizing computational resources and modularity. To bridge semantic gaps across heterogeneous robots, we introduce GESTURE-7, a unified language-grounded action representation. Furthermore, our Guide Action algorithm enforces kinematic continuity via mask-based smoothness constraints. Comprehensive evaluations demonstrate that NebulaVLA significantly outperforms synchronous baselines, achieving an 85.5\% average success rate on LIBERO-Plus and accelerating action generation by \textasciitilde 2.7$\times$. This asynchronous design enables highly efficient and responsive control for practical robotics.

**整体含义**
NebulaVLA通过异步双频架构、统一动作表征和引导动作机制，系统性地回应了上述三个挑战，为VLA模型从学术研究走向实际机器人部署提供了一种兼顾效率、泛化与平滑性的可行方案。

## 2. 论文提出的方法论

**核心思想**：受认知科学中"快慢双系统"（Kahneman, 2011）范式启发，将高层语义推理（深思熟虑的System 2）与低层动作控制（反应式的System 1）显式解耦，并以不同频率运行。

### 2.1 异构双频架构

- **System 2（慢系统，~10 Hz）**：以Qwen3-VL为骨干，处理自然语言指令和稀疏视觉输入，输出高层抽象动作引导（通过学习token提取隐藏层特征）。负责场景理解、任务规划和语义推理。
- **System 1（快系统，~20 Hz）**：基于DiT（Diffusion Transformer）的低层控制器，接收System 2的动作引导、高频视觉输入和动作历史，通过去噪过程生成连续执行动作。负责高频、反应式的电机控制。
- 两个系统通过显式数据流规范解耦，天然支持分布式部署；System 1和System 2可部署在不同计算设备上，适应边缘计算场景。

### 2.2 GESTURE-7 统一动作表征

- 将末端执行器状态编码为7维向量：**s = [x, y, z, r, p, w, g]**
  - (x, y, z)：笛卡尔位置（单位：厘米），量化为整数
  - (r, p, w)：欧拉角（roll, pitch, yaw，单位：度），量化为整数
  - g：离散手势token（自然语言关键词），如"grasp"、"push"、"rotate"、"release"
- 不同形态机器人执行相同动作共享相同关键词：例如，平行夹爪和灵巧手执行抓取动作均统一表示为"grasp"。
- 量化到整数厘米和整数度可降低学习负担、减少预测幻觉。
- 手势词汇表G可随任务需求自由扩展。

### 2.3 Guide Action 机构

- **灵感来源**：图像外推（Image Outpainting / RePaint）。
- **问题**：朴素异步算法在推理结束后执行"硬切换"（hard switch），导致轨迹在动作块边界出现明显跳变和机械抖动。
- **方法**：
  - 将下一动作块的生成条件化为上一动作块中**未执行的轨迹锚点**（如a4-a7）。
  - 去噪过程中引入二进制掩码M，强制保留已知动作（M=1的锚点区域），仅对新生区域（M=0）进行去噪生成。
  - 条件概率模型：pθ(A_full^(t-1) | A_full^t, A_prior, τ)，其中A_prior包含已执行历史动作和待执行引导动作。
  - 重注入操作：A_full^(t-1) = M ⊙ A_prior^(t-1) + (1-M) ⊙ A_noisy^(t-1)
- 训练时引导动作数量从0到3随机采样，以适应推理延迟变化。

### 2.4 三阶段训练流程

| 阶段 | 对象 | 方法 | 任务/损失 |
|------|------|------|-----------|
| Stage 1 | System 2 | 监督微调（SFT） | ①姿态回归（GESTURE-7格式）②关键点回归（2D）③2D路径点预测 ④3D轨迹预测（2Hz）⑤思维链（CoT）生成 |
| Stage 2 | System 2 | GRPO强化学习 | 基于GESTURE-7距离、关键点定位、路径点、轨迹、格式五种奖励函数 |
| Stage 3 | System 1 + System 2 | 监督微调（联合优化） | 加权流匹配损失，仅计算新生成区域：L(θ) = E[ (1-M) ⊙ (ε - εθ(x_t, t))² ] |

## 6. 论文的主要结论与发现

1. **性能领先**：NebulaVLA在LIBERO-Plus上实现**85.5%**平均成功率，超越InternVLA-M1（81.3%，+4.2%）、OpenVLA-OFT+（79.6%，+5.9%）、GR00T N1.5（59.0%）和π0.5（58.0%）。
2. **效率显著提升**：异构双频架构相比同频变体，推理延迟从115ms降至42ms（约**2.7倍加速**），同时成功率还有所提升；相比InternVLA-M1的81ms也明显降低。
3. **真实世界优势**：在Pick-and-Place（92.08% vs 77.91%）和Packaging Feeding（92.5% vs 72.5%）任务上，成功率大幅超越InternVLA-M1。
4. **Guide Action有效性**：关节急动度在所有7个关节上均有降低，平均下降25.6%，其中关节12和13分别降低41.2%和45.1%，有效消除动作块边界的轨迹不连续性。
5. **三阶段训练有效**：完整的SFT+RL+联合微调流程比省略SFT或RL的变体分别提升1.7%和2.5%。
6. **架构可部署性**：双系统解耦设计支持分布式部署和边缘计算，为实际机器人系统提供了工程可行性。

## 8. 不足与局限

1. **频率分配为静态经验值**：10Hz/20Hz的配置是经验确定的固定值，未探索最优频率组合，也未实现任务自适应的动态频率调度。不同任务类型可能对推理频率有不同需求。
2. **Guide Action的潜在延迟代价**：依赖固定引导锚点，在快速变化的环境中可能引入轻微响应延迟；引导点数训练时最多取3，推理时若实际延迟超限可能不匹配。
3. **Camera扰动下的性能下降**：在相机位姿扰动下，NebulaVLA性能低于InternVLA-M1。作者将其归因于GESTURE-7建立固定视觉-空间映射的假设，但这意味着该表征在视角变化下的鲁棒性不足，未来需引入视角条件建模。
4. **跨形态泛化验证不足**：GESTURE-7的核心卖点是跨本体（不同机器人/末端执行器）的语义统一，但实验仅在AgiBot A2单平台上验证，缺乏异质平台间的直接迁移实验。
5. **真实实验规模有限**：仅2个任务、单一机器人平台，对复杂的双机械臂协同、灵巧手精细操作等场景未覆盖。
6. **GESTURE-7位置坐标的局限性**：使用全局笛卡尔坐标（具体数值如(33,21,14)），未明确如何在不同相机坐标系或机器人基坐标系下实现泛化，可能对部署环境的标定精度敏感。
7. **工程部署的硬件同步挑战**：论文承认多传感器时间戳对齐、分布式时钟一致性等工程问题仍然存在，实际部署门槛未被完全消除。
8. **未报告资源消耗细节**：缺少训练时长、数据规模、System 1和System 2参数量等关键信息，限制了对方法可复现性的评估。
