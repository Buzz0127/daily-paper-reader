## 摘要
移动操作是具身智能的关键能力，使机器人能够在开放世界中完成复杂的多阶段任务。然而，移动操作对视觉-语言-动作（VLA）策略提出了两个关键挑战：在数据层面，高效收集高质量的全身演示需要移动基座与机械臂的协调控制；在模型层面，现有VLA模型主要依赖局部相机观测，其有限的视场阻碍了全局空间理解。为解决这些挑战，我们开发了一套全身遥操作系统和一个全景感知VLA策略。该系统通过单一VR界面实现对轮式双臂机器人的协调控制，并支持采集包含5.5小时多模态演示的真实世界移动操作数据集。在此基础上，我们提出PanoVLA，一种面向移动双臂操作的全景感知视觉-语言-动作策略。PanoVLA基于Mixture-of-Transformers架构，通过专门的全景编码和融合模块引入全局空间上下文，实现全景观测与语言指令、机器人状态的有效集成以生成动作。在四个真实世界移动操作任务上的评估表明，PanoVLA实现了91.3%的平均阶段完成率和73.4%的端到端成功率，显著优于局部视角基线。这些结果表明，融入全景空间上下文提高了移动机器人的空间理解能力和闭环操作性能。

## Abstract
Mobile manipulation is a key capability for embodied intelligence, enabling robots to accomplish complex multi-stage tasks in open-world environments. However, mobile manipulation poses two key challenges for vision-language-action (VLA) policies: At the data level, the efficient collection of high-quality whole-body demonstrations demands the coordinated control of both the mobile base and the robotic arms; at the model level, existing VLA models predominantly rely on local camera observations, whose limited field of view hinders global spatial understanding. To address these challenges, we develop a whole-body teleoperation system and a panoramic-aware VLA policy. The system enables coordinated control of a wheeled bimanual robot through a single VR interface and supports the acquisition of a real-world mobile manipulation dataset comprising 5.5 hours of multimodal demonstrations. Building upon this dataset, we propose PanoVLA, a panorama-aware vision-language-action policy for mobile bimanual manipulation. Built upon a Mixture-of-Transformers architecture, PanoVLA introduces global spatial context through dedicated panorama encoding and fusion modules, enabling effective integration of panoramic observations with language instructions and robot states for action generation. Evaluation on four real-world mobile manipulation tasks demonstrates that PanoVLA achieves an average stage completion rate of 91.3\% and an end-to-end success rate of 73.4\%, substantially outperforming local-view baselines. These results demonstrate that incorporating panoramic spatial context improves spatial understanding and closed-loop manipulation performance in mobile robots.

### 2.1 全身遥操作系统

- **硬件**：操作员佩戴VR头显和手持控制器，在腰部和双脚佩戴三个身体追踪器；机器人平台为轮式双臂结构（RANGER MINI底盘 + 两个6自由度PIPER臂 + 平行夹爪），传感器包括顶部360°全景相机、前视相机和两个腕部相机。

  - 机器人配置参数化为 \( q = (x_b, y_b, \theta_b, q_L, q_R) \)。
  - 优化目标：\( q^* = \arg\min_q \lambda_{pos}L_{pos} + \lambda_{rot}L_{rot} + \lambda_{base}L_{base} + \lambda_{reg}L_{reg} \)，分别对齐手/夹爪位置、姿态、基座运动以及正则项。

- **基座模式切换**：由于物理底盘只能执行部分自由度，系统按控制周期评估三种运动模式（自转、阿克曼转向、斜移）与期望运动之间的代价，选择代价最低的模式执行，并动态切换。

### 2.2 PanoVLA模型

- **整体架构**：基于Mixture-of-Transformers（MoT）的VLA策略，包含三个专家块：
  - **VLM专家**：使用Gemma-2B语言骨干 + SigLIP视觉编码器，编码局部视图、语言指令和本体状态。
  - **全景专家**：添加在VLM专家和动作专家之间，专门处理全景输入，输出任务相关的全局空间上下文。
  - **动作专家**：基于融合后的上下文，用条件流匹配预测连续动作块。
- **全景编码器**：
  - 输入同步的双鱼眼图像，通过球面重投影（spherical reprojection）生成等距柱状投影（ERP）全景图。
  - 使用全景基础模型**MTPano**提取语义分割和深度估计两个中间特征，拼接成统一稠密全景表征。
  - 经自适应平均池化降低至固定分辨率，再由轻量MLP层投影到全景专家的隐藏维度，形成全景token序列 \( Z_t^{pano} \in \mathbb{R}^{N_p \times d} \)。
- **融合机制**：
  - 采用Transformer的KV缓存作为融合接口。VLM专家生成VLM缓存 \( C_t^{vlm} \)，全景专家在块级因果注意力掩码下，基于全景token与VLM缓存执行联合自注意力，产生全景缓存 \( C_t^{pano} \)。
  - 动作专家使用拼接缓存 \( C_t = [C_t^{vlm}; C_t^{pano}] \) 预测动作，从而同时获取局部细粒度操作线索与全局空间线索。

## 3. 实验设计

### 3.1 数据集与任务

- 自采数据集：4类真实世界移动操作任务，每任务200条演示，共800条，约5.5小时：
  - **Move Pen**：将笔放入笔座，目标方向可为前/左/右。
  - **Move Block**：将积木转移到前方区域，积木可位于左/右/两侧。
  - **Open Curtain**：依次拉开两侧窗帘，需要双臂协调和左右交互。
  - **Wipe Table**：沿长桌擦除污渍并将抹布归位，涉及较长工作空间和多阶段状态跟踪。
- 数据模态：局部RGB（前视+双腕）、360°全景ERP图、本体状态（双臂关节、夹爪状态、基座位姿）、全身动作（17维：14维双臂+夹爪，3维基座速度）。

### 3.2 对比方法

- **π0.5**：基础VLA基线，仅使用局部相机，SigLIP编码。
- **π0.5 w/ Pano**：将ERP全景图直接作为额外图像输入，仍用SigLIP编码，不引入专用全景分支。
- **π0.5 w/ Stacked Pano**：将全景图重投影为3个间隔120°的透视视图并拼接为一张复合图，作为额外输入。
- **PanoVLA**：本文方法（MTPano编码 + 全景专家）。

### 3.3 评估协议

- 每个任务、每种方法进行15次闭环真实机器人试验，每次试验均从初始状态连续执行，不人工重置失败阶段。
- 指标：
  - **成功率（SR）**：整端到端任务是否完成（二元）。
  - **阶段完成率（SCR）**：各中间阶段完成比例的平均值。
- 训练设置：每种方法使用相同任务演示，训练30K步，AdamW，学习率5e-5（前5K步线性预热），bfloat16，4卡A100，per-GPU batch size 64。

### 3.4 消融实验

- 在Move Pen任务上，各变体均进行15次闭环试验。
- 消融维度1：全景专家规模（50M / 100M / 200M / 300M参数）。
- 消融维度2：全景编码器选择（SigLIP vs MTPano）。

## 6. 主要结论与发现

- PanoVLA在四个任务上的平均**SCR达91.3%**，**SR达73.4%**，显著优于局部视图基线π0.5（SCR 58.6%，SR 30.0%）。
- 直接加入全景图（π0.5 w/ Pano）能提升部分任务表现（平均SCR 80.8%，SR 56.7%），但效果不稳定；将全景重投影为透视拼接（π0.5 w/ Stacked Pano）效果居中（SCR 70.4%，SR 38.3%），说明单纯拓宽视野不如显式建模全景几何和融合上下文有效。
- 消融实验表明：MTPano（全景专用编码器）显著优于SigLIP（SCR 95.6% vs 75.6%）；100M参数的全景专家在数据有限条件下达到最优权衡，过大或过小均不利。
- 全景专家在需要多阶段状态跟踪的任务（如Wipe Table）中优势尤为明显，表明其有助于保持跨阶段的空间一致性和状态追踪能力。

## 7. 优点

- **数据采集端**：基于GMR的全身遥操作将基座作为虚拟浮动基座与双臂联合优化，操作员通过自然身体动作即可协调移动和操作，无需额外手柄，降低演示采集难度；整套系统依赖VR设备，部署便捷。
- **数据多样性**：数据集同时包含局部视角、全景视角、本体状态和全身动作，且为多任务、多空间布局设计，为后续研究提供了资源。
- **模型设计**：
  - 专门引入MTPano全景编码器，缓解了ERP图像与常规透视预训练编码器之间的域差异。
  - 利用KV缓存作为跨专家融合接口，轻量且与MoT架构自然衔接。
  - 全景专家可在语言指令条件下有选择地融合全局空间信息，避免简单拼接带来的噪声。
- **实验分析**：除端到端成功率外，还报告阶段完成率，并附任务级“阶段成功率曲线”分析，能更细致定位失败环节。

## 8. 不足与局限

- **实验规模有限**：每个任务仅15次试验，结果可能受随机因素影响；未提供多次重复的均值/方差或显著性检验，结论稳健性需要更强统计支撑。
