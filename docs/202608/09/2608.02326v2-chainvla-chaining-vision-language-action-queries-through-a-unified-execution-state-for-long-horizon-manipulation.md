## 摘要
人类通过保留对早期动作已建立状态的认识，同时持续调整正在进行的运动，来执行长时程操作。相比之下，动作分块的视觉-语言-动作（VLA）策略在每次查询时都会根据当前输入重复进行重新规划。现有方法要么通过记忆保留长期任务证据，要么通过动作重用和集成保留短期运动，使得跨查询交接不完整。我们引入了ChainVLA，一个12亿参数的VLA策略，通过联合且可修订的执行状态来链接连续查询。进度上下文将循环工作状态与稀疏事件记忆相结合，以携带观察推导的任务进度，而运动尾部则将前一个预测的未执行延续部分输入状态构建和动作生成中。这两个组件共同调节一个解码器，该解码器在最新观察下重新生成每个动作视野，使得携带的状态能够指导下一次预测而不固定它。ChainVLA在RMBench上达到62.8%的平均成功率，在四个LIBERO套件上达到98.8%，而移除运动尾部或进度上下文则分别将RMBench成功率降至11.2%和3.0%。这些不对称的消融实验与运动连续性有助于保留观察流（从中推断任务进度）的发现相一致。

## Abstract
Humans perform long-horizon manipulation by retaining knowledge of what earlier actions have established while continuously adapting the motion underway. By contrast, action-chunked vision-language-action (VLA) policies repeatedly replan from the current input at each query. Existing methods preserve either long-term task evidence through memory or short-term motion through action reuse and ensembling, leaving the cross-query handoff incomplete. We introduce ChainVLA, a 1.2B-parameter VLA policy that chains successive queries through a joint and revisable execution state. Progress Context combines a recurrent Working State with sparse event memory to carry observation-derived task progress, while Motion Tail feeds the preceding prediction's unexecuted continuation into state construction and action generation. Together, the two components condition a decoder that regenerates each action horizon under the latest observation, allowing the carried state to guide the next prediction without fixing it. ChainVLA reaches 62.8% average success on RMBench and 98.8% across four LIBERO suites, while removing Motion Tail or Progress Context reduces RMBench success to 11.2% and 3.0%, respectively. These asymmetric ablations are consistent with motion continuity helping preserve the observation stream from which task progress is inferred.

## 论文总结：ChainVLA: Chaining Vision-Language-Action Queries through a Unified Execution State for Long-Horizon Manipulation

### 1. 论文的核心问题与整体含义

长时程操作需要两种能力的耦合：一是**任务进度**——知道此前动作已经建立了什么（例如哪个目标已完成）；二是**运动连续性**——保持正在进行的动作并随时修正。然而，当前基于动作分块（Action Chunking）的VLA策略在每个查询节点都从当前观测、本体感受和指令**重新生成**一个动作视野，仅执行其严格前缀后再次重规划。这导致两个层面的跨查询交接缺失：

- **任务层面的模糊性**：当前观测可能无法反映此前已完成的子任务或已离开视野的决定性证据（如RMBench的Put Back Block任务）；
- **运动层面的断裂**：重新规划会丢弃前一次预测的未执行后缀，新生成的命令可能与被替代的运动不连贯，且这种不一致会通过影响后续观测流而持续积累。

现有方法各有侧重但并未统筹两者：记忆增强型政策（如MemoryVLA）保留观测历史但不保留预测连续体；动作集成/真实时执行类方法（如Temporal Ensemble、Real-time execution）保留短期运动但无法回溯早期任务证据。论文的核心问题因此是：**如何在一个可修订的、跨查询的统一执行状态中同时链接任务进度与运动连续体，同时保持对新观测的响应性？**

### 2. 论文提出的方法论

#### 核心思想
ChainVLA引入一个**联合且可修订的执行状态** s_k = (g_k, u_k)，其中：

- **Progress Context (g_k)**：用于携带由观测推导的任务进度（回顾性）；
- **Motion Tail (u_k)**：前一次预测的未执行后缀，直接跨越查询边界（前瞻性）。

该状态在每个查询被读取、更新、传递，使独立解码的动作块变成跨查询的链条。

#### 关键技术细节

1. **查询转移**
   - 形式化地定义了决策不充分（decision-insufficient）输入：相同输入下最优执行前缀集合交集为空；
   - 整体目标为 π_θ(· | x_k, s_k) ≈ π*(· | H_k)，状态转移函数为 s_{k+1} = F_θ(s_k, x_k)。

2. **Progress Context 的双层设计**
   - **递归工作状态（Recurrent Working State）**：通过8个学习工作查询对当前多模态token进行交叉注意力更新，并递归地与前一次live tokens融合；维护一个有界缓存（3件套FIFO）保留更早的live tokens；
   - **稀疏事件记忆（Sparse Event Memory）**：容量为16条事件记录，每条含视觉、阶段、时间特征及检索键；通过“工作状态摘要+阶段估计”构造检索查询，对事件进行年龄感知的余弦相似度打分，检索锚点和最高分记录；
   - 在训练时有阶段标注的数据，阶段头以真实阶段转移信号监督；无标注数据采用周期性查询时间写入规则。

3. **Motion Tail 的双通道用法**
   - **模型侧路径①**：将后缀编码为tail tokens，参与工作状态构建；
   - **模型侧路径②**：将归一化后缀对齐到全视野动作表示，作为条件初始化解码器状态：eA^{(0)}_{k+1} | u_{k+1} ~ N(μ_{k+1}, σ_u²I)；
   - 解码器仍重新生成每个视野位置，不复制或冻结任何位置，因此携带的状态是“可修订的先验”而非“固定计划”。

4. **后解码处理（执行侧交接）**
   - 将新生成计划与来入后缀的重叠步做线性混合后再执行。

5. **训练策略**
   - 按episode顺序展开同一转移；
   - 训练中后一查询以0.5的概率使用前一查询的**分离梯度（detached）**tail；
   - 损失包含条件流动作目标、阶段监督（如有）和重叠一致性正则化（权重0.2）。

#### 对比方法

### 6. 论文的主要结论与发现

1. **主结果**：ChainVLA在RMBench达到62.8%平均成功率（1.2B参数），超过具有完整5任务覆盖的最强对比方法Mem-0（52.8%，8B+2B）；LIBERO上平均98.8%，四个套件均≥98%（Long为98.2%），虽接近现有方法的上限，但验证了方法的广度。

2. **关键发现——不对称消融效应**：
   - 移除Progress Context（保留Motion Tail）→ 3.0%；
   - 移除Motion Tail（保留Progress Context）→ 11.2%；
   - 两者都移除 → 1.6%；
   - 两者各自个位数的贡献加不到62.8，说明它们并非独立叠加的改进，而是**顺序协同的两级链路**。

3. **机制解释**：Motion Tail的去留通过边界不连续性影响观测流——无tail时Put Back Block边界位置间隔达17.32mm，而Full仅0.66mm。跨80对配对rollout，Full在四个诊断指标上分别降低56.6%、40.4%、57.4%、43.1%。这种不连续导致机械臂访问示范未覆盖的视角，从而破坏Progress Context赖以构建的观测序列。因此**运动连续性保护了任务进度推断所依赖的观测流**。

4. **后解码平滑不足以替代**：Linear Continuation的边界指标多数低于Full但其成功率仅为0%（Put Back Block）和2%（Swap Blocks），Temporal Ensemble同样只有0%成功率。平滑只作用于已解码命令，无法改变解码时被固定的计划——必须将后缀提前到状态构建与动作生成中。

5. 固定三查询周期写入事件仍达53.4%，说明链不依赖阶段标注来写入有用事件。

### 7. 优点

1. **问题定义清晰且有理论支撑**：形式化定义“决策不充分输入”（Eq.1），将任务进度与运动连续性置于统一的执行状态框架中，并给出历史条件化生成目标（Eq.2-3）；

1. **实验设置的限制**：仅限固定频率模拟（RMBench/LIBERO），未在真实硬件上评估，也未改变控制频率；边界指标反映的是命令流而非物理轨迹，无法评价启动执行下的行为；
