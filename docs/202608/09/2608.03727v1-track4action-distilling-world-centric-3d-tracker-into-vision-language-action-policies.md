## 摘要
动作标签告诉视觉-语言-动作（VLA）策略要模仿哪些机器人命令，但不说明这些命令如何改变3D世界。对齐的演示片段包含了这一缺失的监督信息，因为其K帧转换记录了对应K个动作期间产生的几何、运动、可见性和相机变化。我们提出Track4Action，一种将这种已实现的转换从冻结的世界中心3D追踪器蒸馏到当前观察VLA策略的框架。在训练期间，Track4World将片段V_{t:t+K}编码为池化的追踪器特征。可学习的追踪查询从当前VLA隐藏状态推断该特征，在共享空间中匹配它，并通过特征级门控调节流匹配动作头。追踪器特征仅定义对齐目标，因此在部署时不需要片段或追踪器。Track4Action在零样本LIBERO-Plus上达到82.3%，比无对齐变体提高7.6个百分点，比LaMP提高3.0个百分点。在干净和随机化的RoboTwin 2.0分割上分别获得80.44%和81.48%的准确率，并在四个物理双臂任务上平均成功率为67.5%，比无对齐变体高25.0个百分点。在模拟和物理任务上的收益支持动作对齐的3D追踪器特征作为免追踪器VLA部署的特权监督。我们的项目页面可在https://wing0night.github.io/track4action-project-page获取。

## Abstract
Action labels tell a vision-language-action (VLA) policy which robot commands to imitate, but not how those commands change the 3D world. The aligned demonstration clip contains this missing supervision because its $K$ frame transitions record the geometry, motion, visibility, and camera change produced during the corresponding $K$ actions. We introduce Track4Action, a framework that distills this realized transition from a frozen world-centric 3D tracker into a current-observation VLA policy. During training, Track4World encodes the clip $V_{t:t+K}$ into a pooled tracker feature. Learnable track queries infer this feature from current VLA hidden states, match it in a shared space, and condition a flow-matching action head through a feature-wise gate. The tracker feature only defines the alignment target, so neither the clip nor the tracker is used at deployment. Track4Action reaches 82.3% on zero-shot LIBERO-Plus, improving the alignment-free variant by 7.6 points and LaMP by 3.0 points. It obtains 80.44% and 81.48% on the clean and randomized RoboTwin 2.0 splits, and 67.5% average success across four physical bimanual tasks, 25.0 points above the alignment-free variant. The gains across simulation and physical tasks support action-aligned 3D tracker features as privileged supervision for tracker-free VLA deployment. Our project page is available at https://wing0night.github.io/track4action-project-page.

## 2. 方法论

### 核心思想
- 演示中与动作块 `A*_t = (a_t, ..., a_{t+K-1})` 对齐的 K+1 帧主视角片段 `V_{t:t+K}` 记录了真实发生的世界转换；用冻结的 Track4World 编码该片段，得到场景、运动、可见性和相机信息的池化特征作为训练目标。
- 学生策略通过**可学习的 track queries** 从当前 VLA 隐状态中推断该追踪特征，既用于特征对齐，又通过**特征级门控（feature-wise gate）**融合回VLA序列，条件化流匹配动作头。

### 关键技术细节
1. **世界中心追踪器监督**：冻结模型 `T` 处理片段 `V_{t:t+K}`，得到追踪特征 `f^trk_t = sg[Pool(T(V_{t:t+K}))]`，`sg` 表示阻断梯度。
2. **特征蒸馏**：VLA 主干编码当前观测得到 `H_t = E_θ(l, I_t)`；track queries `Q` 通过交叉注意力读取 `H_t` 得到 `Z_t = D_θ(Q, H_t)`。
3. **对齐损失**：`L_align = ||\bar{z}_t - \bar{f}^trk_t||_2^2`，其中两表示映射到共享对齐空间。
4. **动作生成**：通过特征门控融合 `Z_t` 与 `H_t` 形成 `H^cond_t`，使用流匹配（flow matching）动作头，总损失为 `L = λ_act L_act + λ_align L_align`。
5. **部署无关性**：教师特征、片段、追踪器仅在训练时使用；部署时保留 track-query 与门控融合路径，但无需运行 Track4World。

- **Tracker 蒸馏显著提升控制性能**：

  - RoboTwin 2.0：干净 80.44%（+39.12）、随机化 81.48%（+41.58），均超过 Motus w/o Pretrain。
  - 物理双臂：平均成功率 67.5%（+25.0 对比无对齐变体），平均过程分数 75.0。
- **增益集中在对世界状态和运动要求高的场景**（长时程、OOD、双臂协调），在已经饱和的短时程 LIBERO 套件上增益较小。
- **部署无关性得到验证**：真实实验中部署时完全不运行 Track4World，仍能保持增益。
- **局限性下的发现**：可变形物体（毛巾折叠）仍是物理挑战（成功率仅 40%，低于 π0.5 的 70%）。

## 7. 优点

- **问题定义新颖**：将“动作对齐的3D追踪特征”作为特权监督，而非未来帧预测或显式几何重建，直击动作标签缺失世界状态信息的痛点。
- **设计干净且部署友好**：教师特征仅参与训练目标，动作头不接触教师特征；部署时保留 track-query 和门控路径但无需追踪器，不影响推断效率。
- **消融设计严谨**：“w/o Align.”变体在完全匹配的规模、数据、优化设置下对比，直接验证完整蒸馏通路的效果。
- **跨域验证全面**：覆盖单臂、双臂、零样本扰动、50 任务大规模基准和真实物理平台，结论具有较强泛化性。
- **与 VLA 架构兼容**：方法不依赖特定主干或动作解码器，可适配不同 VLA 骨干和动作头（论文声称与不同 VLA 及流匹配动作头兼容）。

## 8. 不足与局限

- **需要时间有序的演示**：训练目标依赖 `V_{t:t+K}` 片段，孤立图像-动作对无法提供同等监督；独立运动物体会削弱命令与场景变化的关联。
- **池化目标的局限**：段级池化可能丢失局部接触对应关系（如抓取点附近的细粒度接触信息）。
- **追踪器误差继承**：Track4World 在遮挡或快速运动下的误差会传导至训练目标；当前仅使用主视角相机，未利用多视角信息。
- **物理实验覆盖有限**：仅一个双臂平台、4 个任务、每种任务 10 次试验、3 种 OOD 变化，可变形物体泛化仍明显不足（未见过颜色毛巾成功率仅 20%）。
- **基准对比不完整**：RoboTwin 表格仅列部分任务；LIBERO-Plus 中 LaMP 在 Robot、Language、Background 上仍领先，且 OpenVLA/OFT、π0-FAST 等的一些设置未完全对齐以进行公平比较。
- **算力信息缺失**：论文未报告训练所需 GPU 类型/数量/时长，难以评估方法在资源有限场景下的可复现成本。
