## 摘要
视觉-语言-动作（VLA）模型在现实世界中的部署常常受制于效率与性能的权衡、跨本体泛化能力以及执行平滑性。我们提出NebulaVLA，一种异步双频架构，将高层语义推理与低层动作控制解耦，从而优化计算资源并提高模块化程度。为了弥合异构机器人之间的语义鸿沟，我们引入了GESTURE-7，一种统一的基于语言引导的动作表示。此外，我们的引导动作算法通过基于掩码的平滑性约束来保证运动学连续性。综合评估表明，NebulaVLA显著优于同步基线，在LIBERO-Plus上平均成功率达到85.5%，并将动作生成速度提升了约2.7倍。这种异步设计为实际机器人应用实现了高效且响应迅速的控制。

## Abstract
Real-world deployment of Vision-Language-Action (VLA) models is often bottlenecked by efficiency-performance trade-offs, cross-embodiment generalization, and execution smoothness. We present NebulaVLA, an asynchronous dual-frequency architecture that decouples high-level semantic reasoning from low-level action control, optimizing computational resources and modularity. To bridge semantic gaps across heterogeneous robots, we introduce GESTURE-7, a unified language-grounded action representation. Furthermore, our Guide Action algorithm enforces kinematic continuity via mask-based smoothness constraints. Comprehensive evaluations demonstrate that NebulaVLA significantly outperforms synchronous baselines, achieving an 85.5\% average success rate on LIBERO-Plus and accelerating action generation by \textasciitilde 2.7$\times$. This asynchronous design enables highly efficient and responsive control for practical robotics.

### 1. 核心问题与整体含义（研究动机与背景）

- **背景**：机器人操作正从模块化流水线转向端到端学习，VLA（Vision-Language-Action）模型通过统一感知、语言与控制，在自然语言指令跟随和泛化方面展现出显著潜力。自RT-1建立Transformer策略基础以来，OpenVLA、InternVLA系列等推动了该领域的快速发展。
- **核心问题**：现有VLA模型在现实部署中面临三大瓶颈：
  - **效率-性能权衡**：单体同步架构采用统一时间分辨率，无法同时支持低频语义推理与高频电机控制；
  - **跨本体泛化困难**：将连续运动学映射为离散token需要庞大的词汇表和大量演示数据，不同机器人平台之间缺乏统一动作语义；
  - **执行平滑性不足**：异步实时推理与动作块生成之间的时间错配导致明显抖动和执行不连续。
- **整体含义**：NebulaVLA从认知科学中"快慢双系统"范式出发，系统性解决上述问题，为高效、响应迅速的机器人实际操作控制提供了可行方案。

### 2. 方法论：核心思想、关键技术细节

#### 2.1 核心思想：异步双频架构

借鉴Kahneman的"快慢思维"理论，将控制流程解耦为两个独立频率的系统：

- **System 2（慢系统，10 Hz）**：采用Qwen3-VL作为视觉-语言骨干，负责高层语义规划。从自然语言指令和稀疏视觉输入中提取可学习token的隐藏层特征，输出抽象动作引导。
- **System 1（快系统，20 Hz）**：采用Diffusion Transformer（DiT），作为低层反应式控制器。利用Q-Former压缩System 2的引导信息，结合高频视觉输入（DINOv2编码）和动作历史，通过去噪过程输出执行动作。
- **两系统独立部署**：原生支持分布式部署，通过异步通信和负载分离最小化交互延迟。

#### 2.2 GESTURE-7：统一语言接地动作表示

- **定义**：端到端状态编码为7维向量 **[x, y, z, r, p, w, gesture]**，其中(x, y, z)为笛卡尔位置（整数厘米），(r, p, w)为姿态角（整数度），gesture为自然语言关键词（如 "grasp"、"push"、"rotate"）表示目标手部姿态。
- **统一语义**：不同本体（如灵巧手与平行夹爪）执行同一动作共享相同关键词，实现跨异构机器人的动作语义统一。
- **量化设计**：位置量化到整数厘米、角度量化到整数度，降低学习负担并缓解预测幻觉。
- **可扩展性**：gesture词汇表可自定义扩展。

#### 2.3 Guide Action：引导动作机制

- **动机**：异步策略推理与实际执行之间的时间失配导致动作块边界处硬切换，产生机械抖动。
- **核心思想**：受图像外扩（Image Outpainting）启发，将块拼接嵌入生成管线内部——用前一动作块中未执行的后续动作（例如a4–a7）作为"引导锚点"，条件化下一块的生成，确保无缝边界过渡。训练时引导动作点数从0到3随机采样以适应推理延迟可变性。
- **条件概率模型**：
  pθ(Aᵗ⁻¹_full | Aᵗ_full, A_prior, τ)
  其中A_full为完整动作块，A_prior为先验动作集（已执行历史+待执行引导动作），τ为时间位置查询。
- **掩码强制约束**（每个去噪步骤后）：
  Aᵗ⁻¹_full = M ⊙ Aᵗ⁻¹_prior + (1-M) ⊙ Aᵗ⁻¹_noisy
  其中二进制掩码M∈{0,1}^T：M[1..k]=1为锚定区域（严格保留已知动作），M[k+1..T]=0为生成区域（模型预测），⊙为逐元素乘法。

#### 2.4 三阶段训练流程

| 阶段 | 内容 | 关键点 |
|------|------|--------|
| **Stage 1** | System 2监督微调（SFT） | 五类任务：位姿回归（GESTURE-7格式）、2D关键点回归、2D路径点预测、3D轨迹预测、思维链生成（子任务分解+GESTURE-7轨迹） |
| **Stage 2** | System 2强化学习（GRPO） | 定义GESTURE-7距离（位置+姿态+手势三个分量加权）、关键点定位奖励、路径点奖励（点级欧氏距离+DTW轨迹匹配）、GESTURE-7轨迹奖励、格式奖励（权重0.5） |
| **Stage 3** | System 1监督微调（连续动作） | 联合优化两个系统，视觉编码器冻结；使用加权流匹配损失；损失仅施加于掩码M=0的新生成区域：L(θ) = E[ (1-M) ⊙ (ϵ - ϵθ(x_t, t))² ] |

### 6. 主要结论与发现

1. **仿真性能**：NebulaVLA在LIBERO-Plus上达到**85.5%**的平均成功率，超越InternVLA-M1（81.3%）4.2个百分点，大幅领先OpenVLA-OFT+（79.6%）、GR00T N1.5（59.0%）和π0.5（58.0%）。在Robot Initial State、Layout、Spatial、Object、Goal等维度均取得显著提升。
2. **真实世界性能**：在AgiBot A2上，NebulaVLA-Heter在两项任务中成功率最高（92.08%和92.5%），平均推理延迟仅42ms，相比InternVLA-M1（81ms）减少近一半，相比同频变体（115ms）降低约2.7倍。
3. **训练策略有效性**：三阶段训练（SFT→RL→S1 SFT）整体有效，System 2的SFT显著提升Layout维度（+6.2%），RL进一步强化Language和Layout维度表现。
4. **Guide Action有效性**：在全部7个关节上降低jerk，平均降幅25.6%，其中关节12和13分别减少41.2%和45.1%，有效消除了动作块边界的轨迹不连续。
5. **架构解耦可行性**：异构双频设计在成功率和延迟上均优于同频变体，工程上可分离部署，适应边缘计算场景。

### 7. 优点（方法/实验设计的亮点）

- **架构创新性**：将"快慢系统"认知范式引入VLA设计，系统间显式解耦时间尺度和计算负载，为效率与性能的权衡提供了结构性而非技巧性的解决方案。
- **统一动作表示设计精巧**：GESTURE-7以极简的7维向量+自然语言关键词兼顾了跨本体语义统一、RL友好（可做距离度量定义）和学习复杂度控制（量化到整数），避免了大规模离散token的开销。
- **Guide Action内生平滑**：将平滑约束嵌入扩散去噪过程而非事后处理，保证生成过程中语义一致性；训练时随机采样引导点数增强了推理延迟的鲁棒性；掩码恢复机制借鉴图像外扩成熟技术，数学表达简洁清晰。
- **训练管线层次分明**：三阶段渐进式优化（语义感知→推理增强→动作对齐），各阶段目标明确；思维链数据格式设计有利于可解释性和任务分解。
- **工程落地意识强**：真实部署的延迟数据、异构架构的工程灵活性验证了方法的实用性。
- **诚实的局限性陈述**：论文在结论部分主动指出频率静态分配、引导锚点延迟、硬件同步等未解决问题，态度客观。

### 8. 不足与局限

- **频率分配静态化**：10 Hz/20 Hz为经验设定且固定不变，最优频率可能随任务类型变化，动态自适应调度仍未解决。
- **Guide Action的响应延迟**：依赖固定引导锚点，在快速变化环境中可能引入轻微响应延迟。
- **Camera扰动维度的性能退化**：GESTURE-7的训练假设隐含建立了视觉特征与空间坐标的固定映射，相机位姿扰动会破坏这一对应关系。该项在消融中几乎一致退化（93.5→87.8→91.0），论文承认了这一点但未完全解决。
- **跨本体泛化未被验证**：论文的核心卖点之一是"跨异构机器人统一动作语义"，但所有实验仅在单一机器人平台（AgiBot A2和LIBERO仿真）上进行，缺少对灵巧手、夹爪等不同本体的直接比较。

- **训练成本未完整披露**：论文未说明训练时长、数据规模、各阶段迭代次数等关键训练细节，可复现性有限。
