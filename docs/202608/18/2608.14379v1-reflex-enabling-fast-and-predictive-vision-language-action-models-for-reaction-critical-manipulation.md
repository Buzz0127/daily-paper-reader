## 摘要
视觉-语言-动作（VLA）模型近来在机器人操作中取得了令人瞩目的性能。然而，现有基准主要评估静态操作任务上的泛化能力，而很大程度上忽略了动态交互场景。为弥补这一空白，我们提出了ReflexBench——一个面向反应关键型操作的基准。ReflexBench包含六个动态任务，并引入了一个评估框架，该框架将仿真器步进与机器人控制解耦，同时在同步和异步推理下支持可配置延迟。基于ReflexBench，我们提出了ReflexVLA，一种高效VLA模型，专为反应关键型操作设计，无需大规模机器人数据预训练。ReflexVLA通过潜在未来预测和视觉骨干网络内的多帧时间融合来增强时间推理，同时通过批量视觉编码和CUDA图重放来降低部署延迟。实验表明，ReflexVLA在标准静态操作基准上保持竞争性精度的同时，持续提升了动态操作性能；真实世界实验进一步证明了其在实际部署条件下的有效性。项目网站：https://reflexvla.github.io

## Abstract
Vision-Language-Action (VLA) models have recently achieved promising performance in robotic manipulation. However, existing benchmarks mainly evaluate generalization on static manipulation tasks and largely overlook dynamic interaction scenarios. To address this gap, we present ReflexBench, a benchmark for reaction-critical manipulation. ReflexBench contains six dynamic tasks and introduces an evaluation framework that decouples simulator stepping from robot control while supporting configurable latency under synchronous and asynchronous inference. Building upon ReflexBench, we propose ReflexVLA, an efficient VLA model designed for reaction-critical manipulation without large-scale robot-data pretraining. ReflexVLA enhances temporal reasoning through latent future prediction and multi-frame temporal fusion within the vision backbone, while reducing deployment latency through batched visual encoding and CUDA Graph replay. Experiments show that ReflexVLA consistently improves dynamic manipulation performance while maintaining competitive accuracy on standard static manipulation benchmarks, and real-world experiments further demonstrate its effectiveness under practical deployment conditions. Project website: https://reflexvla.github.io

## 2. 论文提出的方法论

**（一）ReflexBench——延迟感知的动态操作基准**

- **任务设计**：包含6个需要快速反应和预判的动态操作任务，涵盖输送带取放、接球、打地鼠、拦截滚动球、抛球入篮、旋转销钉插入等场景。
- **数据采集**：采用基于规划器的分段式数据收集管线，将任务分解为多个子目标（如预对齐→追踪→定时插入），规划器基于实时位置与速度预测未来轨迹；规划无法处理的复杂动力学任务使用强化学习策略生成示范。
- **延迟感知评估协议**：这是ReflexBench的核心贡献。传统模拟器在策略推理期间暂停环境，忽略了推理延迟的影响；ReflexBench将仿真器步进与机器人控制解耦，使环境动力学在策略计算期间持续演化。支持同步与异步两种推理模式，延迟值可控（手动指定或通过实测推理延迟与RTF换算），从而系统分析延迟对任务性能的影响。实际测量到的实时推理延迟按RTF换算后注入模拟器中，保证评估与真实部署条件一致。

**（二）ReflexVLA——快速且预测性的VLA模型**

ReflexVLA基于紧凑的VLA架构（融合DINOv2与SigLIP的视觉编码器 + Qwen2.5-0.5B语言骨干），引入三项关键设计：

1. **潜在未来预测（Latent Future Prediction）**
   - 采用冻结的DINOv3模型编码未来观测得到语义特征作为预测目标：
     - $y_{t+i} = \phi_{DINOv3}(o_{t+i})$
   - 在输入序列中追加H个可学习的未来token，与动作块大小一致，每个token对应一个未来控制步。
   - 通过掩码余弦相似度损失训练，与动作预测损失联合优化：
     - $\mathcal{L} = \mathcal{L}_{act} + \lambda_{future} \mathcal{L}_{future}$
   - 该设计使模型在训练中学会预测场景的时间演化，不增加推理开销。

2. **多帧时间融合（Multi-Frame Temporal Fusion）**
   - 在视觉骨干网络内部执行时间融合，而非简单拼接多帧图像token（后者会导致语言模型侧计算量随帧数线性增长）。
   - 具体做法：对中间层（而非最终层）特征，按同一空间位置的跨帧轨迹应用因果时间注意力，融合结果与当前帧最终特征相加后送入语言模型，使语言模型消费的视觉token数与单帧一致。

3. **推理延迟优化（Inference Latency Optimization）**
   - 批量视觉编码：将所有视图与历史帧图像合并为一次视觉编码器前向调用，减少框架开销。
   - CUDA Graph重放：将完整推理管线捕获为CUDA Graph，部署时只需将新观测拷贝到预分配缓冲区并重放图，消除重复的内核调度与运行时开销。

## 6. 主要结论与发现

1. **推理范式影响显著**：异步推理在低频率时因观测-动作失配而性能差于同步；随着频率提升（≥30Hz），异步推理逐渐反超同步，说明高频异步执行是动态操作的有效范式。
2. **块大小与执行步长存在最优组合**：大体上，较大块大小 + 较小执行步长在异步推理下表现更优。
3. **ReflexVLA整体性能领先**：在ReflexBench上以1B参数量达到50.4%的平均成功率，超过所有基线（PUMA 50.2%、SmolVLA 38.3%、OpenVLA-OFT 36.0%等），仅在"拦截滚动球"任务上低于PUMA。
4. **不牺牲静态泛化**：ReflexVLA在LIBERO上达到97.2%的平均准确率，与最优基线（97.3%）几乎持平，说明动态操作为导向的设计不损害静态任务能力。
5. **三项设计均有贡献**：潜在未来预测（冻结目标）+26.0%、中间层时间融合+34.9%、延迟优化+2.1%并同时将延迟从125ms降至65ms。
6. **真实世界有效**：在三个实际任务上超越SmolVLA，以1B参数与4B的PUMA达到相当水平（输送带16/20 vs 13/20，按按钮22.5 vs 20.8，接球6.7 vs 5.4）。

## 7. 优点

- **基准设计切实回应了部署痛点**：ReflexBench将推理延迟显式纳入评估，解耦仿真器步进与机器人控制，支持同步/异步双模式，比现有动态基准更贴近真实部署条件。
- **方法设计精妙且高效**：潜在未来预测避免了像素级重建的高成本；多帧时间融合在视觉骨干内部完成而不增加语言模型的token开销；这些设计使其在1B规模下即可超越更大参数量的模型。
- **静态性能保持良好**：证明针对性设计不会削弱通用能力，提升了方法的实用性价值。
- **消融体系完整、结论清晰**：渐进式消融精准量化了每个组件的贡献，包括对"可训练vs冻结预测目标"和"中间层vs最终层时间融合"的设计决策验证。
- **前置参数分析合理**：对推理频率、块大小、动作执行步长的系统分析为后续实验配置提供了依据，而不随意设定。
- **真实实验验证充分**：覆盖了任务设置、评估指标和对比模型的多个维度，能有效支持结论。

## 8. 不足与局限

- **训练规模与预训练的局限**：ReflexVLA的预训练方式未在大规模机器人数据上进行预训练，未来预测与时间融合模块仅通过微调阶段引入，作者认为这可能限制了方法的全部潜力。
- **延迟优化方式有限**：推理延迟优化仅使用了批量视觉编码和CUDA Graph重放，未探索更先进的推理机制（如RTC），效果提升和通用性有一定限制。
- **任务多样性有限**：虽然ReflexBench包含6个动态任务，但相比PUMA的35个任务、Behavior-1K的1000个任务，任务的广度相对有限。打地鼠等任务成功率已达到饱和（100%），区分度不足；接球任务所有模型都低于7.3%，任务难度可能过高；另外每个任务仅200个示范episode，规模较小。
- **消融实验覆盖不足**：消融结果仅在输送带取放任务上报告（部分表格含该任务），未展示其他5个动态任务上的消融效果。
- **对比公平性存疑**：未能明确各基线是否在完全相同的训练数据与训练流程下进行；仅依赖已发表的权重或报告数据可能导致比较的不公平。
- **真实实验的范围有限**：仅验证了3个任务，未覆盖全部6个模拟任务；未报告在静态任务上的真实实验。
- **真实世界的具体延迟未报告**：虽然对比了推理延迟从125ms降至65ms，但未报告实际部署中策略的真实推理延迟与控制系统延迟。
- **结果方差较大**：部分任务（如拦截滚动球）成功率标准差达7%以上，存在一定的结果波动性。
