## 摘要
视觉-语言-动作（VLA）模型在机器人操作任务上表现出色，但在视觉和环境变化下性能往往会下降。潜在世界建模为提高鲁棒性提供了一种有前景的方法，然而现有方法通常独立编码相机视角，并在不显式建模其几何关系的情况下预测整体场景动态。我们提出了GWM-VLA，一种用于VLA学习的几何感知潜在世界建模框架。GWM-VLA结合了几何感知的多视角状态编码、全局上下文条件下目标视角预测，以及由机器人动作监督驱动的共享潜在-动作表示。具体而言，VGGT-$\Omega$在每一步联合聚合多视角观测，以构建几何感知的多视角状态。潜在世界模型使用多视角聚合后获得的块令牌和寄存器令牌，来预测选定目标视角的下一步块令牌，从而在无需预测完整多视角状态的情况下保留多视角几何信息。在实验中，我们将腕部视角作为目标视角，更强调末端执行器运动以及局部夹爪-物体交互。最后，共享的潜在-动作表示同时条件化潜在世界模型和流匹配动作头，使得潜在预测监督和真实机器人动作监督能够共同塑造同一潜在-动作表示。在仿真和真实环境中的实验均证明了GWM-VLA的有效性和鲁棒性。

## Abstract
Vision-Language-Action (VLA) models achieve strong robotic manipulation performance but often degrade under visual and environmental shifts. Latent world modeling offers a promising approach to improving robustness, yet existing methods commonly encode camera views independently and predict holistic scene dynamics without explicitly modeling their geometric relationships. We propose GWM-VLA, a geometry-aware latent world modeling framework for VLA learning. GWM-VLA combines geometry-aware multi-view state encoding, global context-conditioned target-view prediction, and shared latent-action representations grounded by robot-action supervision. Specifically, VGGT-$Ω$ jointly aggregates multi-view observations at each timestep to construct geometry-aware multi-view states. The latent world model predicts the next-step patch tokens of a selected target view using patch and register tokens obtained after multi-view aggregation, thereby retaining multi-view geometric information without predicting the complete multi-view state. We use the wrist view as the target in our experiments, placing greater emphasis on end-effector motion and local gripper-object interactions. Finally, the shared latent-action representations condition both the latent world model and the flow-matching action head, allowing latent-prediction supervision and ground-truth robot-action supervision to jointly shape the same latent-action representations. Experiments across both simulation and real-world environments demonstrate the effectiveness and robustness of GWM-VLA.

- **背景问题**：视觉-语言-动作（VLA）模型在机器人操作任务中表现优异，但在视觉和环境变化（如相机视角、光照、背景纹理、物体布局、传感器噪声等变化）下性能会显著下降。部分策略可能过度依赖外观层面的相关性，而非真正捕捉场景随机器人动作产生的状态变化。
- **现有方法的不足**：
  - 显式世界模型（如 DreamZero、π0.7）需要生成未来图像/视频，预测目标必须建模纹理、光照、背景等与控制无关的外观细节，成本高且效率低。

  - 现有几何基础模型（VGGT、VGGT-Ω）虽能联合聚合多视图并编码跨视角几何结构，但如何将其作为潜在世界模型的预测状态仍未被探索。
- **核心目标**：提出一种几何感知的潜在世界建模框架，显式建模多视图间的几何关系，通过预测动作引发的潜在状态变化来提升 VLA 策略在分布偏移下的鲁棒性。

### 2. 方法论：核心思想与关键技术细节

**总体架构**：GWM-VLA 由三大组件构成，整体流程为：VGGT-Ω 逐时间步聚合多视图观测 → 潜在世界模型预测目标视角的下一步 patch tokens → 共享潜在动作表示同时驱动潜在预测与流匹配动作生成。

#### 2.1 几何感知多视图状态编码（Geometry-Aware Multi-View State Encoding）

- 采用预训练的 **VGGT-Ω** 作为多视图几何编码器，在每个时间步 $t$ 将全部 $V$ 个相机视角的观测 **联合** 处理（而非独立编码）为一个几何样本：
  - $\\{R_t, P_t\\} = E_\Omega(\\{I^v_t\\}_{v=1}^V)$，其中 $R_t$ 为 register tokens，$P_t$ 为 patch tokens。
- 不同时间步之间独立处理，同一时间步的所有视角通过 VGGT-Ω 进行跨视角几何聚合。
- VGGT-Ω 在训练期间保持**冻结**。

#### 2.2 全局上下文条件下的目标视角预测（Global Context-Conditioned Target-View Prediction）

- **核心思想**：不预测完整的潜在多视图状态（避免将预测目标分散到所有相机流），而是只预测**选定的目标视角** $v^\star$ 的 patch tokens，同时利用对应的 register tokens 提供全局几何上下文。
- 目标视角选为**手腕视角（wrist view）**，因其与末端执行器运动和局部夹爪-物体交互紧密耦合。
- 预测公式：$\hat{p}_{1:T} = F_\phi(p_{0:T-1}, r_{0:T-1}, A_{0:T-1})$，其中 $F_\phi$ 为动作条件下的因果潜在世界模型。
- **因果注意力掩码**：同一时间步内的 token 可双向交互，时间步 $t$ 的 token 只能关注不晚于 $t$ 的 token（公式 6）。
- 训练采用**教师强制（teacher forcing）**，监督目标通过 VGGT-Ω 编码未来多视图观测获得：$p_{t+1} = E_\Omega^{P,v^\star}(O_{t+1})$。
- 损失函数为 ℓ1 潜在预测损失：$L_{wm} = \\frac{1}{T}\\sum_{t=0}^{T-1}\\|\\hat{p}_{t+1} - p_{t+1}\\|_1$。

#### 2.3 统一潜在动作表示（Unified Latent Action Representation）

- 采用 **Qwen3-VL-2B** 作为视觉-语言骨干，输入当前多视图观测和语言指令。
- 插入时间步分组的可学习 latent action query tokens（每步 $K$ 个 token），从 VLM 隐藏状态中获取潜在动作序列 $A_{0:T-1}$。
- **与 VLA-JEPA 的关键差异**：VLA-JEPA 为动作生成额外引入 embodied-action queries，而 GWM-VLA **直接复用**同一潜在动作序列同时条件化潜在世界模型和流匹配动作头，使得潜在预测监督和真实机器人动作监督共同塑造同一表示。

#### 2.4 条件流匹配动作头（Conditional Flow-Matching Action Head）

- 使用条件流匹配（Flow Matching）生成动作块（action chunk），条件为共享潜在动作序列和当前本体感受状态 $s_0$。
- 优化目标：$L_{action} = E\\left[\\|v_\psi(u_\gamma, \\gamma | A_{0:T-1}, s_0) - (u_{0:T-1} - \\epsilon)\\|_2^2\\right]$，其中 $u_\gamma = (1-\\gamma)\\epsilon + \\gamma u_{0:T-1}$。

#### 2.5 联合优化

- 总损失：$L = L_{action} + \\lambda L_{wm}$，默认 $\\lambda = 0.1$。
- 世界模型损失仅作为**辅助训练目标**，部署推理时不使用。

### 6. 主要结论与发现

- **LIBERO（分布内）**：GWM-VLA 平均成功率 **97.1%**，与 OpenVLA-OFT 并列最佳，比 robot-only VLA-JEPA 高 1.0 个百分点；在 4 个任务套件上表现一致稳定。
- **LIBERO-Plus（分布外鲁棒性）**：平均成功率 **76.9%**，达到 SOTA，比 OpenVLA-OFT 高 7.3 个百分点，比 VLA-JEPA 高 **14.0 个百分点**；在语言、光照、物体布局扰动下排名第一，在相机视角、机器人初始状态、背景扰动下排名第二；对视觉噪声、背景、相机视角和语言变化的增益最显著。
- **真实世界**：GWM-VLA 在 ID 和 OOD-layout 设置下表现最好，总体平均成功率最高；但在 OOD-task（组合式指令泛化）设置下不如 π0.5（53.3% vs 60.0%），说明空间鲁棒性与组合式指令泛化是不同维度的挑战。
- **消融结论**：
  - 手腕视角作为预测目标最佳（92.8% vs 第三人称 87.8%，混合 92.4%）。
  - VGGT-Ω 层级越深（第 24 层）效果越好，表明精细化的几何表示对潜在世界建模更有益。
  - 直接共享潜在动作表示优于额外 embodied query（+4.8 个百分点）。
- **定性探针**：预测的潜在状态能够保留场景布局和夹爪/操作物体周围的几何信息，但细节被平滑。

### 7. 方法亮点

- **几何感知的多视图联合编码**：首次将 VGGT-Ω 的联合聚合多视图表示用作潜在世界模型的预测状态，显式建模跨视角几何关系，而非简单拼接独立视图特征。
- **目标视角聚焦预测策略**：只预测手腕视角的 patch tokens，同时借助 register tokens 保留全局几何上下文——在降低预测负担的同时保留了多视图几何信息，设计精巧。
- **共享潜在动作表示**：用同一组潜在动作 token 同时条件化世界模型与动作头，让预测监督和真实动作监督联合塑造表示，避免了 VLA-JEPA 中额外引入 embodied query 造成的表示割裂。
- **仅用机器人演示预训练**：不需要人类视频数据即可达到 SOTA 性能，数据门槛更低。
- **鲁棒性增益显著**：在 LIBERO-Plus 上相对最强基线提升 7.3 个百分点，证明几何感知世界建模确实是提升分布外鲁棒性的有效途径。

### 8. 不足与局限（续）

- **训练与部署的潜在不一致**：世界模型损失仅在训练阶段作为辅助目标，部署推理时完全不使用。这意味着模型在测试时无法利用世界模型的在线预测来纠正或规划动作，世界模型的收益完全依赖它能否在训练中塑造出更鲁棒的共享表示，而缺少推理时的闭环验证或自我改进机制。
- **目标视角选择的局限性**：方法仅预测手腕视角的潜在状态，在部分任务（如需要全局场景推理的任务）中，手腕视角可能不是信息量最大的视角。虽然消融实验显示手腕视角优于第三人称视角，但这一结论仅在 LIBERO-Spatial 上验证，是否适用于更广泛的任务尚不清楚。
- **对 VGGT-Ω 编码器的依赖**：VGGT-Ω 在训练期间保持冻结，其表征是否完全适配机器人操作场景未被验证。若遇到与预训练数据分布差异极大的视觉输入（如极端传感器噪声或非典型相机几何），冻结编码器可能成为性能瓶颈。

- **基准覆盖不足**：

  - 真实世界实验仅覆盖抓取-放置任务，缺乏对长时程操作、灵巧操作或装配任务的验证。
  - 未在更通用的开放世界基准（如 RoboCasa、BridgeData V2 或大规模真实遥操作数据集）上进行评估。
- **对比公平性细节缺失**：论文提到与 VLA-JEPA 的比较控制了预训练数据（robot-only），但未报告其他基线（如 π0、GR00T N1）所使用的预训练数据组成和计算量，无法完全排除数据或算力差异对结果的影响。
- **消融实验说服力有限**：三组受控消融均在单卡、小 batch、10,000 步的轻量设置下进行，且只报告 LIBERO-Spatial 的结果。该设置下最优方案的绝对性能远低于主实验（92.8% vs 97.1%），说明消融结论可能无法外推到完整训练配置。
- **定性探针缺乏量化验证**：潜在状态可视化只通过定性观察得出“保留大致几何信息”的结论，没有像重建误差、对应点精度等定量指标，其说服力有限。

---

### 9. 总结与展望（简要）

GWM-VLA 通过将几何感知的多视图编码器（VGGT-Ω）引入潜在世界模型，成功解决了 VLA 策略在视觉分布偏移下鲁棒性不足的问题，在 LIBERO-Plus 上取得了显著增益，并验证了共享潜在动作表示的有效性。未来工作可在以下方向延伸：将世界模型用于推理时的在线规划或动作修正；探索自适应目标视角选择机制；将几何感知世界模型扩展到更长时程任务和更丰富的真实世界操作场景；以及降低 VGGT-Ω 与 VLM 联合推理的计算成本，提升实时部署能力。
