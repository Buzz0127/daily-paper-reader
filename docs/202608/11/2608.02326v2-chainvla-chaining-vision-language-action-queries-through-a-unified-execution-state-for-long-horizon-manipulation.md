## 摘要
人类通过保留先前动作所建立的知识，同时不断调整正在进行的动作，来执行长时程操作。相比之下，动作分块的视觉-语言-动作（VLA）策略在每次查询时都会根据当前输入反复重新规划。现有方法要么通过记忆保留长期任务证据，要么通过动作重用和集成保留短期运动，导致跨查询交接不完整。我们提出了ChainVLA，一个1.2B参数的VLA策略，通过联合且可修订的执行状态链接连续查询。进度上下文将循环工作状态与稀疏事件记忆相结合，以携带源自观察的任务进度，而运动尾部则将先前预测的未执行延续部分馈送到状态构建和动作生成中。这两个组件共同调节一个解码器，该解码器在最新观察下重新生成每个动作视界，允许携带的状态引导下一次预测而不固定它。ChainVLA在RMBench上达到62.8%的平均成功率，在四个LIBERO套件上达到98.8%，而移除运动尾部或进度上下文分别将RMBench成功率降至11.2%和3.0%。这种不对称消融与运动连续性有助于保留推断任务进度所依赖的观察流这一观点一致。

## Abstract
Humans perform long-horizon manipulation by retaining knowledge of what earlier actions have established while continuously adapting the motion underway. By contrast, action-chunked vision-language-action (VLA) policies repeatedly replan from the current input at each query. Existing methods preserve either long-term task evidence through memory or short-term motion through action reuse and ensembling, leaving the cross-query handoff incomplete. We introduce ChainVLA, a 1.2B-parameter VLA policy that chains successive queries through a joint and revisable execution state. Progress Context combines a recurrent Working State with sparse event memory to carry observation-derived task progress, while Motion Tail feeds the preceding prediction's unexecuted continuation into state construction and action generation. Together, the two components condition a decoder that regenerates each action horizon under the latest observation, allowing the carried state to guide the next prediction without fixing it. ChainVLA reaches 62.8% average success on RMBench and 98.8% across four LIBERO suites, while removing Motion Tail or Progress Context reduces RMBench success to 11.2% and 3.0%, respectively. These asymmetric ablations are consistent with motion continuity helping preserve the observation stream from which task progress is inferred.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **问题背景**：长时程操作要求机器人既保留早期动作建立的任务进度，又持续调整正在进行的运动。人类通过"已建立的任务进度"与"反馈修正的运动预测"的耦合来执行此类任务。
- **现有方法的缺陷**：动作分块式 VLA 策略（如 Diffusion Policy、π0 等）通过"严格前缀执行 + 重新规划"的循环方式工作，但每次查询都从当前输入重新生成整个动作视界，缺少两个层面的显式交接：
  - **任务层面**：早期任务证据可能从当前视角消失（如 RMBench 的 Put Back Block 任务，相同观测和指令可能对应不同历史，需要不同决策）；
  - **运动层面**：重新规划丢弃了前次预测的未执行后缀，导致新预测前缀与所替代的运动不一致。
- **现有解决思路的局限**：记忆增强策略（如 MemoryVLA、Mem-0 等）保留任务证据但不保留未执行运动延续；时序集成/实时执行/原生延续方法（如 Temporal Ensemble、实时流执行）保留短期运动但无法回溯早期任务证据。
- **核心研究问题**：如何让 VLA 策略跨查询链接"任务进度"与"运动延续"，同时保持每次新预测对最新观测的响应性？

## 2. 论文提出的方法论

### 核心思想
- 提出 **ChainVLA**（1.2B 参数），通过一个**联合且可修订的执行状态** `s_k = (g_k, u_k)` 链接连续查询，将"单独解码的动作块"转变为"跨查询的链"。该状态每个查询被读取、更新并向前传递。

### 两大核心组件
- **Progress Context（进度上下文）** `g_k`：携带源自观测的任务进度，由两部分组合：
  - **循环工作状态（Working State）** `W_k = (L_k, B_k)`：L_k 为实时令牌（live tokens），B_k 为有界缓存；8 个学习的工作查询通过交叉注意力更新；
  - **稀疏事件记忆（Sparse Event Memory）** `C_k`：仅在被触发时写入的事件序列，每个事件含视觉特征、阶段信息、时间特征；检索使用年龄感知的余弦相似度评分（公式 5）。
- **Motion Tail（运动尾部）** `u_k`：携带前一次预测的未执行后缀，通过两条模型侧路径影响下一次查询：
  - 尾令牌注入工作状态构建；
  - 尾对齐的轨迹初始化动作生成（公式 6：`A(0) = μ + σ₀ε`，即用前次后缀作为高斯采样的均值先验）。

### 关键机制
- **条件流解码器**：在每个查询下，解码器在最新观测、进度上下文和运动尾部的条件下重新生成完整的动作视界，不复制或冻结任何位置——携带状态只是"可修订的先验"而非固定计划。
- **查询转移公式**：`(A_k, W_k, C_{k+1}) = F_θ(x_k, D_k, W_{k-1}, C_k, u_k)`，`u_{k+1} = Tail(A_k)`，即把前次预测的未执行后缀（第 h_exec+1 到 H 步）作为下一次查询的传入尾部。
- **训练方式**：按事件顺序展开训练，携带的后缀在训练时被截断（detach）；使用条件流动作目标 + 阶段监督（有标注时）+ 重叠一致性正则化（0.2 权重）。

## 6. 论文的主要结论与发现

- **主结果**：RMBench 平均成功率 62.8%（1.2B 参数），超过最佳完整覆盖对比方法 Mem-0（52.8%，8B+2B）；LIBERO 四套件平均 98.8%（Long 套件 98.2%）。
- **关键消融发现**：

- **平滑 ≠ 成功**：Linear Continuation 和 Temporal Ensemble 能达到甚至低于 Full 的边界不连续值，但成功率仅 0~2%（对比 Full 的 96%/74%）——证明增益来自"后缀进入状态构建和生成"而非"平滑输出接缝"。
