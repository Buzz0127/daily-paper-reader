## 摘要
动作标签告诉视觉-语言-行动（VLA）策略要模仿哪些机器人命令，但不告知这些命令如何改变3D世界。对齐的演示片段包含这一缺失的监督信息，因为其K帧转换记录了对应该K个动作所产生的几何、运动、可见性和摄像机变化。我们提出Track4Action，一个将这种已实现的转换从冻结的世界中心3D追踪器蒸馏到当前观测VLA策略中的框架。在训练期间，Track4World将片段V_{t:t+K}编码为池化追踪器特征。可学习的追踪查询从当前VLA隐藏状态推断此特征，在共享空间中匹配它，并通过特征门控调节流匹配动作头。追踪器特征仅定义对齐目标，因此在部署时既不使用片段也不使用追踪器。Track4Action在零样本LIBERO-Plus上达到82.3%，比无对齐变体提高7.6个百分点，比LaMP提高3.0个百分点。在干净和随机化RoboTwin 2.0分割上分别获得80.44%和81.48%的成绩，在四个物理双臂任务上平均成功率为67.5%，高出无对齐变体25.0个百分点。在仿真和物理任务中的提升支持将动作对齐的3D追踪器特征作为无追踪器VLA部署的特权监督。我们的项目页面可在 https://wing0night.github.io/track4action-project-page 获取。

## Abstract
Action labels tell a vision-language-action (VLA) policy which robot commands to imitate, but not how those commands change the 3D world. The aligned demonstration clip contains this missing supervision because its $K$ frame transitions record the geometry, motion, visibility, and camera change produced during the corresponding $K$ actions. We introduce Track4Action, a framework that distills this realized transition from a frozen world-centric 3D tracker into a current-observation VLA policy. During training, Track4World encodes the clip $V_{t:t+K}$ into a pooled tracker feature. Learnable track queries infer this feature from current VLA hidden states, match it in a shared space, and condition a flow-matching action head through a feature-wise gate. The tracker feature only defines the alignment target, so neither the clip nor the tracker is used at deployment. Track4Action reaches 82.3% on zero-shot LIBERO-Plus, improving the alignment-free variant by 7.6 points and LaMP by 3.0 points. It obtains 80.44% and 81.48% on the clean and randomized RoboTwin 2.0 splits, and 67.5% average success across four physical bimanual tasks, 25.0 points above the alignment-free variant. The gains across simulation and physical tasks support action-aligned 3D tracker features as privileged supervision for tracker-free VLA deployment. Our project page is available at https://wing0night.github.io/track4action-project-page.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：动作标签仅告诉 VLA 策略“模仿哪个命令”，却未揭示该命令如何改变 3D 世界。相同的末端执行器位移可能穿过自由空间、接触物体或改变相机视角，这些区别决定任务成败，但动作标签不包含此类信息。
- **背景**：现有工作通过未来预测（世界模型）或几何感知（3D 结构编码、场景流）来补充动作学习，但其监督目标通常是未来内容、显式几何变量或单帧空间特征，**未利用演示片段中动作块所实际实现的运动专用表示**。
- **核心思想**：演示视频中与动作块对齐的 K+1 帧片段，记录了对应 K 个动作的几何、运动、可见性和相机变化。论文提出将冻结的世界中心 3D 追踪器（Track4World）提取的动作对齐追踪特征作为“特权监督”，在与动作块共享时间对齐的表示空间中蒸馏进 VLA 策略，而部署时完全不需要片段或追踪器。

## 2. 论文提出的方法论

- **整体框架**：训练时分为“教师分支”（冻结 Track4World）和“学生分支”（当前观测 VLA 策略）；部署时仅保留学生分支，追踪器与片段均被丢弃。
- **问题定义**：策略预测归一化动作块 A*_t = (a_t, ..., a_{t+K-1})，训练样本同时提供主视角片段 V_{t:t+K} = (o_t, ..., o_{t+K})，K 个动作对应 K 个帧间转换，由此建立动作与世界变化的时间对应关系。
- **世界中心追踪器监督**：冻结的 Track4World 模型 T 将片段编码为场景、运动、相机 token 并池化为紧凑追踪特征：

  ```
  f_trk_t = sg[Pool(T(V_{t:t+K}))]
  ```

  sg 表示停止梯度。该特征归纳了动作块实现期间恢复的 3D 结构与运动。
- **特征蒸馏**：VLA 骨干编码当前图像与指令得到 H_t；可学习的 track queries Q 通过交叉注意力读取 H_t 得到动作面向的瓶颈表示 Z_t = D_θ(Q, H_t)。对齐损失：

  ```
  L_align = || z̄_t - f̄_trk_t ||²₂
  ```

  即池化后的查询特征与追踪特征在共享对齐空间中的均方误差。
- **动作生成与部署**：通过特征门控将 Z_t 与 VLA 序列融合为动作条件 H_cond_t，门控保留语义上下文同时暴露蒸馏出的追踪线索。教师特征 f_trk_t 从不进入动作头。总损失：

  ```
  L = λ_act L_act + λ_align L_align
  ```

  使用流匹配动作头，优化条件速度目标。部署时计算 H_t、Z_t、H_cond_t 并从噪声迭代生成动作块，完全不需要片段、追踪器、追踪目标和对齐分支。

## 6. 论文的主要结论与发现

- **核心结论**：动作对齐的 3D 追踪器特征可作为有效的特权监督，提升 VLA 策略部署时的任务成功率，且推理时无追踪器依赖。
- **仿真结果**：
  - LIBERO 平均 97.0%（较无对齐变体高 2.8 点，主要增长来自 Long 套件 +9.6 点）；
  - 零样本 LIBERO-Plus 平均 82.3%（较无对齐变体高 7.6 点，较 LaMP 高 3.0 点），相机扰动提升 18.3 点，全部七个维度均无回归；
  - RoboTwin 2.0 干净/随机化条件分别 80.44%/81.48%，高于最强基线 Motus w/o Pretrain 2.88/4.48 点，且随机化下差距反而扩大。
- **物理结果**：
  - 四个物理任务平均成功率 67.5%（π0.5 为 65.0%，无对齐变体为 42.5%）；
  - 平均过程分数 75.0，与 π0.5 持平，高出无对齐变体 14.4 点；
  - OOD 平均成功率从 23.3% 提升至 50.0%。
- **发现**：追踪蒸馏在长视界任务、零样本分布偏移和双臂动作空间中增益最大；短视界、饱和的分布内任务中增益较小。

## 7. 优点

- **思想新颖**：首次将世界中心 3D 追踪器的池化特征作为 VLA 的“特权监督”，且训练与部署解耦——追踪器只定义对齐目标，不进入动作头，部署完全无额外依赖。
- **设计巧妙**：track queries 同时承担“学生表示”和“动作头输入”的双重角色，使对齐损失直接塑造面向控制的表示，而非孤立的辅助解码器；特征门控保留语义上下文的同时引入追踪线索。
- **时间对齐严谨**：目标特征与动作块共享相同的 K 帧转换，描述的是“这个动作块导致的特定世界变化”而非泛化视频内容。
- **实验覆盖广**：从分布内 LIBERO 到 7 维零样本 OOD、50 任务双臂仿真再到真实物理双臂操控，且消融对比在匹配数据和模型规模下进行，验证充分、公平性良好。
- **物理验证有说服力**：真实平台上的 4 任务 × 3 OOD 设置确认了仿真增益可迁移到真实世界。

## 8. 不足与局限

- **数据要求**：需要时间有序的演示片段，孤立图像-动作对无法提供此监督；片段中独立运动物体可能削弱动作与世界变化的关联。
- **表示粒度**：池化目标强调片段级世界运动，可能丢失局部接触对应等细粒度信息。
- **追踪器误差继承**：Track4World 在遮挡或快速运动下的误差会传导到蒸馏目标中。
- **视角限制**：仅使用主视角相机，未利用多视角信息。
- **物理评估范围有限**：仅一个双臂平台、四个任务、三种视觉变化，缺少对不同夹具、相机配置和更复杂物理扰动的测试。
- **变形物体短板**：物理毛巾折叠成功率（40%）显著低于 π0.5（70%），说明变形体操控仍需改进。
- **算力资源未披露**：未报告 GPU 类型、数量、训练时长，可复现性和算力成本评估受限。
