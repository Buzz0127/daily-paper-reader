## 摘要
具身视觉运动模型，包括扩散策略（DP）和视觉-语言-动作（VLA）模型，已在机器人操作基准测试中展现出 promising 性能。然而，其潜力仍从根本上受限于大规模具身轨迹数据集的稀缺，导致在分布外（OOD）场景中的组合泛化能力不足，且捕获可复用技能结构的能力有限。为解决这一局限，我们提出了基于技能的记忆（SkillMemo）框架，该框架将长时程演示隐式分解为潜在原子技能，并将技能级特征集成到动态情景记忆库中，以解决组合任务。具体而言，我们首先引入了一个基于混合专家（MoE）架构的专家引导轨迹分割模块，该模块将轨迹隐式划分为由学习到的门控系数表示的不同技能原语。我们进一步设计了一种技能级情景记忆架构，将紧凑的技能表示存储为可检索的键值对。在推理过程中，记忆库检索最相关的技能原语，并将其与模型当前的门控分布融合，为细化动作预测提供鲁棒的上下文先验。在仿真基准和真实世界操作任务上的大量实验表明，SkillMemo 能持续增强 DP 和 VLA 骨干网络，实现最先进的性能并超越 $\pi_{0.5}$，同时对未见过的任务配置展现出强大的组合泛化能力。

## Abstract
Embodied visuomotor models, including Diffusion Policy (DP) and Vision-Language-Action (VLA) models, have demonstrated promising performance on robotic manipulation benchmarks. However, their potential remains fundamentally constrained by the scarcity of large-scale embodied trajectory datasets, leading to insufficient compositional generalization in out-of-distribution (OOD) scenarios with limited capability to capture reusable skill structures. To address this limitation, we propose Skill-Based Memory (SkillMemo) framework that implicitly decomposes long-horizon demonstrations into latent atomic skills and integrates skill-level features into a dynamic episodic memory bank for solving compositional tasks. Specifically, we first introduce an expert-guided trajectory segmentation module built upon a Mixture-of-Experts (MoE) architecture, which implicitly partitions trajectories into distinct skill primitives represented by learned gating coefficients. We further design a skill-level episodic memory architecture that stores compact skill representations as retrievable key-value pairs. During inference, the memory bank retrieves the most relevant skill primitives which are subsequently fused with the model's current gating distribution, providing a robust contextual prior to refine action predictions. Extensive experiments on the simulation benchmark and real-world manipulation tasks demonstrate that SkillMemo consistently enhances both DP and VLA backbones, achieving state-of-the-art performance and outperforming $π_{0.5}$, while exhibiting strong compositional generalization to unseen task configurations.

- **整体含义**：论文提出 SkillMemo 框架，通过**隐式分解长时程演示为潜在原子技能**，并将技能级特征结构化地存储于动态情景记忆库中，从而在稀缺数据条件下增强模型的组合泛化能力——这是朝着"让机器人像人类一样复用既往经验解决新任务"这一目标的一次重要尝试。

## 2. 论文提出的方法论

论文提出 SkillMemo 框架，核心由两大模块组成：

### 2.1 专家引导轨迹分割（EGTS, Expert-Guided Trajectory Segmentation）

- **核心思想**：不采用显式规则来切分轨迹，而是通过 MoE 架构**隐式地**将完整轨迹分解为一系列潜在原子技能。
- **机制细节**：
  - 给定轨迹 $\tau = \{(x_t, a_t)\}_{t=1}^T$，模型通过 MoE 层计算：$y_t = \sum_{i=1}^N g_i(h_t) \cdot E_i(h_t)$；
  - 每个专家 $E_i$ 捕获一种重复出现的局部运动原语；门控网络 $G$ 通过随时间变化的加权系数 $g_i(h_t)$ 隐式定义技能分割边界。
- **正则化策略**：
  - 基于**部分信息分解（PID）理论**引入协同信息损失 $L_{PID} = -[I(\{A,B\};G) - I(A;G) - I(B;G)]$，鼓励不同专家之间的互补性与高阶协同，防止技能重叠；
  - 配合负载均衡损失和 top-k 路由策略防止专家坍缩（expert collapse）。

### 2.2 技能级情景记忆架构（SLMA, Skill-Level Memory Architecture）

- **记忆存储**：将每个技能段编码为键值对：
  - **键（Key）**：该段内所有时刻潜在特征的质心 $k_m = \frac{1}{L}\sum_{t \in \tau_m} h_t$，用于高效检索；
  - **值（Value）**：该段内完整时间步的门控权重序列 $v_m = \{g(h_t)\}_{t \in \tau_m}$，保存技能复现所需的执行知识。
- **记忆检索**：推理时，用当前观测特征 $q_t$ 与所有记忆键计算余弦相似度，取 top-N 命中项；通过**可靠性阈值 δ** 过滤低质量检索，再以插值方式融合检索到的门控分布与当前预测：$g'(q_t) = \lambda g(q_t) + (1-\lambda)\frac{1}{N}\sum_{n=1}^N v_n[t']$，从而为动作预测提供上下文先验。
- **记忆更新**：面向终身学习场景，设计了有限容量（$M_{max}$）下的动态剪枝策略，按三重标准淘汰低效用记忆：
  - 时间戳最久远（模拟人类遗忘）；
  - 从未被检索命中；
  - 始终未通过可靠性阈值（低质量条目）。
- **整体流程**：训练阶段完成技能分解与记忆写入 → 推理阶段检索相似技能 → 门控融合细化动作预测 → 持续更新记忆库。

## 6. 论文的主要结论与发现

- **SkillMemo 一致提升 DP 与 VLA 骨干性能**：
  - DP 骨架：平均成功率 64.6%，较 DP 提升 3.4%，超越所有 DP 基线；
  - VLA 骨架：UniAct-SkillMemo 提升 5.5%（67.2→72.7），UniVLA-SkillMemo 提升 2.0%，π0.5-SkillMemo 达到 **98.0%**，超越 π0.5（96.8%）1.2%，也超越 MemoryVLA（96.5%）1.5%。
- **EGTS 与 SLMA 各自有效且互补**：消融显示 EGTS 单独带来稳定提升，SLMA 在组合推理任务上增益尤其显著。
- **隐式技能分割确实捕获语义技能**：门控权重在抓取碗、开灶台等关键动作时刻出现显著峰值，说明 MoE 路由在学习无显式标签的技能原语。
- **记忆增强带来零样本组合泛化**：如 Goal 训练模型在未见 Spatial 套件上达 75.6%，甚至超过 Spatial 套件本身的分布内基线（72.1%）3.5%，验证了技能复用机制的有效性。
- **真实世界中技能可迁移**：草莓上盘从 65.0% 提升至 75.0%，确认技能记忆可在物理环境中组合复用。
- **专家数量权衡**：N=5 为最佳精度-开销平衡点；N≥8 后精度增益趋缓、耗时显著上升。
- **核心结论**：技能级记忆（而非整体视觉-语义记忆）是最大化 VLA 组合泛化性能的关键机制。

## 7. 优点

- **方法层面**：
  - **隐式技能分解**避免了显式分割标签的人工成本，具有通用性和可扩展性；

  - 记忆的键值设计将"技能是什么"（门控分布）与"何时使用"（质心特征）解耦，检索高效且语义清晰；
  - 动态记忆更新机制考虑了终身学习场景，具备实际部署的可持续性；
  - **即插即用**：SkillMemo 作为插件式框架，可灵活适配 DP 和各类 VLA 骨干模型。
- **实验层面**：
  - 可视化专家激活权重，提供隐式技能分割的具体证据；
  - 零样本跨套件评估设计巧妙，直接验证组合泛化能力；

## 8. 不足与局限

- **理论分析深度不足**：PID 损失的推导与性质缺乏理论证明，未分析其对收敛性的影响；λ 与 δ 等关键超参数未做敏感性分析实验。
- **实验覆盖仍有欠缺**：
  - 真实世界仅验证了 DP 骨架，VLA 骨架的真机表现未经验证；

  - 未见任务泛化实验只基于较小的 UniAct 骨干，强骨干上是否仍有同等增益未知。
- **公平性隐患**：与 MemoryVLA 对比时参数量不匹配（3.6B vs 7.3B），与部分基线（如 CogACT）未在同一训练预算下严格对齐，存在小规模不公平比较风险。

- **现实约束未充分讨论**：对于更长时程任务（数百步以上）、多物体交互、动态环境等更具挑战性的场景，技能记忆的有效性和检索质量未加验证。
