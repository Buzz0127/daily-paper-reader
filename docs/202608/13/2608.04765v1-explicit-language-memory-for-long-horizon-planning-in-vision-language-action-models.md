## 摘要
视觉-语言-动作（VLA）模型为连接视觉感知、语言理解和机器人控制提供了统一范式。然而，现有VLA模型在长时程任务中仍面临重大挑战：稀疏的专家示范限制了跨任务的组合泛化；长时程任务的非马尔可夫性质使得仅依赖于当前观测的策略难以维持时间一致性；有限的闭环纠错能力导致执行误差不断累积；端到端的动作微调可能削弱视觉-语言模型（VLM）主干网络的高层语义表示。为解决这些问题，我们提出了一种带有显式语言记忆模块的分层长时程VLA架构。核心思想是将离散的时间观测转换为具有时序逻辑的连贯文本记忆序列。该系统被解耦为高层VLM和低层VLA：高层VLM通过视觉问答训练范式进行语义推理，而低层VLA在子任务指令和视觉观测的条件下执行精确的连续控制。高层VLM利用先前的记忆作为上下文锚点，递归更新语言记忆和子任务指令，从而在长时程执行过程中实现持续的时间跟踪和动态纠错。我们在多个仿真环境中评估了所提方法，并在真实机器人平台上进行了仿真到现实的迁移实验。结果表明，显式语言记忆提高了VLA模型在复杂长时程任务上的成功率和鲁棒性，同时为决策过程提供了可解释的语义说明。

## Abstract
Vision-language-action (VLA) models provide a unified paradigm for connecting visual perception, language understanding, and robotic control. However, existing VLA models still face major challenges in long-horizon tasks: sparse expert demonstrations constrain cross-task compositional generalization; the non-Markovian nature of long-horizon tasks makes it difficult for policies conditioned only on current observations to maintain temporal consistency; limited closed-loop error correction allows execution errors to accumulate; and end-to-end action fine-tuning may weaken the high-level semantic representations of vision-language model (VLM) backbones. To address these issues, we propose a hierarchical long-horizon VLA architecture with an explicit language-memory module. The central idea is to convert discrete temporal observations into a coherent textual memory sequence with temporal logic. The system is decoupled into a high-level VLM and a low-level VLA: the high-level VLM performs semantic reasoning through a visual question answering training paradigm, while the low-level VLA executes precise continuous control conditioned on subtask instructions and visual observations. The high-level VLM recursively updates both language memory and subtask instructions using the previous memory as a contextual anchor, enabling persistent temporal tracking and dynamic correction during long-horizon execution. We evaluate the proposed method in multiple simulation environments and conduct sim-to-real experiments on a real robotic platform. The results demonstrate that explicit language memory improves the success rate and robustness of VLA models on complex long-horizon tasks while providing an interpretable semantic account of the decision process.

## 1. 论文的核心问题与整体含义

**研究动机与背景：**

- 视觉-语言-动作（VLA）模型为机器人控制提供了统一范式，能够把视觉感知、语言理解和连续动作生成集成到一个策略中。
- 然而，现有 VLA 模型在**长时程（long-horizon）任务**中面临四方面核心挑战：
  1. **稀疏专家示范**限制了跨任务的组合泛化能力；
  2. 长时程任务具有**非马尔可夫性**，仅依赖当前观测的单一图像无法区分相同视觉状态下不同的任务阶段，导致跳步、重复已完成动作或失败后继续执行后续动作；
  3. **闭环纠错能力有限**，执行误差沿时间累积；
  4. **端到端动作微调**可能削弱 VLM 主干的高层语义表示。
- 简单把所有历史帧拼接进输入虽然能提供上下文，但计算成本和上下文长度随任务时长增长，难以实时部署。
- 论文因此提出一种**紧凑、可解释的替代方案**：用显式自然语言记忆维护任务历史，支撑长时程规划。

## 2. 方法论

**核心思想：**

- 将长时程策略分解为**高层语义规划（VLM）**和**低层动作生成（VLA）**两个模块。
- 高层 VLM 通过**视觉问答式训练范式**，读取全局指令、当前观测和上一时刻的语言记忆，递归更新记忆并产生当前子任务指令；
- 低层 VLA 以当前观测和子任务指令为条件，输出固定长度的连续动作块。
- 显式语言记忆是一种**滚动压缩的文本摘要**：保留已完成里程碑、当前阶段证据、关键物体属性和下一意图；子任务完成后将细节压缩为过去时态的简短陈述，注意力转向下一阶段。

**关键技术细节：**

- 策略分解形式：

  \[
  \pi(a_{t:t+H}, s_t, m_t | o_t, m_{t-1}, l) =
  \pi_{LL}(a_{t:t+H} | o_t, s_t) \cdot \pi_{HL}(s_t, m_t | o_t, m_{t-1}, l)
  \]

- 记忆更新示例：
  - 更新前：“I am moving to the red radio on the coffee table.”
  - 更新后：“I moved to the radio, and I am going to pick up the red radio.”
- **自动化监督流程**：从专家视频、技能标注和时间戳出发，用通用 VLM 逐帧生成 ①简洁子任务（动作+目标物体+上下文），②第一人称语言记忆；并要求避免“帧”“序列”等实现术语。
- **独立分支训练**：
  - 高层 PaliGemma 以自回归方式预测记忆与子任务，损失为 \(L_{HL}\)；
  - 低层 VLA 沿用 π0.5 的 flow-matching 动作专家，以均方误差形式优化 \(L_{LL}\)；
  - 两分支独立训练，避免单目标联合训练中语义生成与连续控制损失的平衡问题。
- **闭环推理**：内存初始为 \(m_0=\emptyset\)，循环执行“观测 → 更新记忆与子任务 → 生成动作块 → 执行 → 根据终止条件判断是否结束”；同时输出可解释的文本日志。

## 3. 实验设计

**场景与 Benchmark：**

- **BEHAVIOR-1K 打开收音机**：任务为“打开客厅桌子上的收音机”，分为 MoveTo、PickUp、PressOn、PlaceOn 四个阶段。
- **Genie Sim 3.0 包裹分拣**（基于 Isaac Sim 的人形操作平台）：
  - 单包裹任务：跟随包裹、拾取、放入扫描区、扶正、再次拾取、放入蓝色箱子，共六个计分阶段；
  - 连续任务：对不同颜色的包裹依次完成扫描与分拣，按完成的 Upright 阶段计分。
- **真实 XLeRobot 平台**：低成本的 SO-ARM 101 双臂 + LeKiwi 移动底座，任务为从桌上取物并放到盘子上，分为 Follow、PickUp、MoveTo、Place 四个阶段，含 25 条人工遥操作轨迹、20 次评估试验。

**对比方法：**

- 基线为原生 **π0.5** 策略；
- 对照方法为 **π0.5 + 显式语言记忆**（本文方法）。

**主要结果：**

- BEHAVIOR-1K：平均阶段成功率从 30.0% 提升到 40.0%，PickUp 阶段从 10% 提升到 30%。
- Genie Sim 单包裹：41.7% → 63.9%；连续分拣：31.3% → 46.9%，且能完成第三、第四个包裹的 12.5% 试验（基线从未完成）。
- 真实 XLeRobot：62.5% → 66.3%（任务较短，提升幅度相对有限）。

## 6. 主要结论与发现

- **显式语言记忆能提升长时程任务的阶段一致性和整体成功率**，在仿真和真机上都有一致性改善。
- 记忆的**证据条件化更新**机制能减少“过早推进阶段”的错误，例如在收音机按钮未按下时就跳到放置阶段，或在包裹未完成扫描时就直接放进篮子。
- 语言记忆提供**可解释的决策日志**，有助于区分“高层语义错误”和“低层控制错误”。
- 文本化的失败状态支持**上下文内失败恢复**（如抓取失败后重新打开夹爪并重试），无需额外恢复控制器。
- 语言记忆**不能替代低层运动控制能力**：PressOn（按按钮）这类接触密集动作即便语义正确也可能因几何对齐、力度等问题失败。
- 总体而言，显式语言记忆为长时程 VLA 提供了紧凑、可解释且跨环境有效的时序推理机制。

## 7. 优点

- **分层解耦设计**：高层语义规划与低层连续控制分别优化，避免了单模型端到端联合训练中的目标冲突。
- **显式记忆的可读性与可诊断性**：记忆和子任务均为自然语言，便于人工审查、失败归因和日志分析。
- **滚动压缩机制**：在保留当前及下一阶段关键信息的同时，压缩已完成阶段，避免将全部历史帧拼接入上下文，保持计算成本可控。
- **自动化监督标注流水线**：可从专家视频、技能级标注与时间戳自动生成帧级记忆和子任务目标，降低人工标注成本。
- **支持简单失败恢复**：失败状态被写入记忆后，后续推理可以修正策略，无需显式实现专门的恢复控制器。
- **实验覆盖仿真与真实**：在同一方法下验证了从模拟到真实平台的迁移可能性。

## 8. 不足与局限

- **真实实验覆盖有限**：仅做了短时程的单一取放任务，无法支撑数分钟乃至十分钟级、多物体、多交互或环境动态变化的真实世界评估。
- **统计可靠性不足**：未报告多种子、多随机数下的方差或置信区间，难以判断提升的稳定性。
- **缺乏系统性消融**：没有单独验证“记忆模块”相对其他历史建模方式（如视觉记忆、时刻嵌入）的优势，也没有分析记忆长度、压缩粒度等超参数的影响。
- **系统开销增加**：高层 VLM 的递归调用带来额外计算、端到端延迟和部署复杂度。
- **语义记忆不解决低层控制瓶颈**：对接触丰富的操作（如按按钮）几乎无帮助，仍受低层数据量与运动精度限制。
- **失败恢复依赖示范覆盖**：可靠的恢复行为需要大量包含失败与纠正轨迹的标注数据，当前演示数据中此类样本不足。
- **未来方向**：将语言记忆扩展为多模态记忆（结合触觉、力觉与视觉证据），并收集更广的失败-恢复示范，以让高层规划者在模糊状态中获得更可靠依据。
