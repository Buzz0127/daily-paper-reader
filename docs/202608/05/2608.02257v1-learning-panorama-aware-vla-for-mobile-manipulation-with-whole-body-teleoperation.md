## 摘要
移动操纵是具身智能的关键能力，使机器人能够在开放世界环境中完成复杂的多阶段任务。然而，移动操纵对视觉-语言-动作(VLA)策略提出了两个关键挑战：在数据层面，高质量全身演示的高效采集需要移动底座和机械臂的协调控制；在模型层面，现有的VLA模型主要依赖局部相机观测，其有限的视场阻碍了全局空间理解。为解决这些挑战，我们开发了一套全身遥操作系统和一种全景感知的VLA策略。该系统通过单一VR接口实现轮式双臂机器人的协调控制，并支持采集包含5.5小时多模态演示的真实世界移动操纵数据集。在此基础上，我们提出了PanoVLA，一种用于移动双臂操纵的全景感知视觉-语言-动作策略。PanoVLA基于Mixture-of-Transformers架构，通过专门的全景编码和融合模块引入全局空间上下文，能够将全景观测与语言指令和机器人状态有效集成以生成动作。在四个真实世界移动操纵任务上的评估表明，PanoVLA实现了91.3\%的平均阶段完成率和73.4\%的端到端成功率，显著优于局部视角基线。这些结果表明，融入全景空间上下文能够提升移动机器人的空间理解和闭环操纵性能。

## Abstract
Mobile manipulation is a key capability for embodied intelligence, enabling robots to accomplish complex multi-stage tasks in open-world environments. However, mobile manipulation poses two key challenges for vision-language-action (VLA) policies: At the data level, the efficient collection of high-quality whole-body demonstrations demands the coordinated control of both the mobile base and the robotic arms; at the model level, existing VLA models predominantly rely on local camera observations, whose limited field of view hinders global spatial understanding. To address these challenges, we develop a whole-body teleoperation system and a panoramic-aware VLA policy. The system enables coordinated control of a wheeled bimanual robot through a single VR interface and supports the acquisition of a real-world mobile manipulation dataset comprising 5.5 hours of multimodal demonstrations. Building upon this dataset, we propose PanoVLA, a panorama-aware vision-language-action policy for mobile bimanual manipulation. Built upon a Mixture-of-Transformers architecture, PanoVLA introduces global spatial context through dedicated panorama encoding and fusion modules, enabling effective integration of panoramic observations with language instructions and robot states for action generation. Evaluation on four real-world mobile manipulation tasks demonstrates that PanoVLA achieves an average stage completion rate of 91.3\% and an end-to-end success rate of 73.4\%, substantially outperforming local-view baselines. These results demonstrate that incorporating panoramic spatial context improves spatial understanding and closed-loop manipulation performance in mobile robots.

### 2. 方法论：PanoVLA 与遥操作系统

#### 2.1 全身遥操作系统
- **硬件接口**：单套可穿戴VR设备——VR头显（6-DoF头部追踪）+ 双手柄（手部姿态与夹爪指令）+ 三个身体追踪器（腰部及双脚踝）。
- **人体运动重建**：将稀疏追踪数据实时重建为SMPL人体模型，提取骨盆运动、脚部运动及双手姿态作为重定向输入。
- **通用运动重定向（GMR）**：将机器人配置参数化为 `q = (x_b, y_b, θ_b, q_L, q_R)`，其中 `(x_b, y_b, θ_b)` 为平面底盘位姿，`q_L` 和 `q_R` 为双臂关节配置。
- **优化目标**：通过最小化加权目标函数获得机器人配置：
  `q* = argmin (λ_pos·L_pos + λ_rot·L_rot + λ_base·L_base + λ_reg·L_reg)`
  - L_pos：手与夹爪位置对齐
  - L_rot：手与末端执行器方向对齐
  - L_base：底盘平面运动与操作者骨盆位移及朝向耦合
  - L_reg：约束关节极限与过度配置变化
- **关键创新**：将移动底盘建模为3-DoF平面虚拟浮动基座，与双臂关节联合优化。当目标末端位姿超出机械臂工作空间时，优化器自动调整底盘平移与偏航，减少重定向误差。
- **模式切换策略**：基于成本驱动的模式切换，在每个控制周期评估三种运动模式（自旋、阿克曼转向、对角平移）与期望平移/旋转的匹配成本，选择成本最低的模式执行，实现底盘运动对操作者意图的动态跟随。

#### 2.2 数据集
- **规模**：4个任务 × 200条演示轨迹 = 800条轨迹，约5.5小时，约50万同步帧（25 Hz）。
- **观测模态**：局部RGB（1前视 + 2腕部相机）、顶部360°全景相机（等距柱状投影ERP）、本体感觉状态、全身动作（17维：双臂14维 + 底盘3维）。
- **任务设计**：覆盖不同目标方向（前/左/右）、双侧交互顺序操作、大工作空间长时序操作：
  - Move Pen：将笔放入笔筒（前/左/右）
  - Move Block：将积木移至前方区域（左/右/双侧）
  - Open Curtain：打开双侧窗帘（左/右）
  - Wipe Table：沿长桌擦拭污渍并归还抹布

#### 2.3 PanoVLA 模型框架
- **基础架构**：基于 π0.5 的 Mixture-of-Transformers（MoT）双专家架构，插入第三个全景专家块（VLM专家 + 全景专家 + 动作专家）。
- **全景编码器**：
  1. **球面重投影**：将双鱼眼图像投影到公共球面并栅格化为ERP图像
  2. **全景特征提取**：使用 MTPano 全景基础模型，提取分割分支（语义）与深度分支（几何）的中间特征并拼接
  3. **令牌适配**：通过自适应平均池化压缩为固定分辨率，经轻量MLP映射到全景专家隐藏维度
- **全景专家（Panorama Expert）**：
  - 使用 Transformer KV 缓存作为融合接口，对全景令牌与VLM缓存执行块级因果注意力的联合自注意力
  - 生成全景缓存，与VLM缓存拼接后供动作专家使用
  - 使动作专家同时利用局部细微操纵线索和机器人中心全局空间上下文
- **训练目标**：使用条件流匹配（Conditional Flow Matching），最小化预测速度场与目标速度场之间的均方误差。

### 3. 实验设计

#### 3.1 基准与对比方法
- **π0.5**：标准局部视角VLA基线（仅局部相机 + 语言 + 本体状态）

### 6. 主要结论与发现

- **核心结果**：PanoVLA以91.3%的平均SCR和73.4%的平均SR大幅超越标准π0.5基线（58.6% SCR / 30.0% SR）。
- **全景感知的价值**：全景信息在移动操纵中的目标搜索、全局定位场景下提供了显著增益；但收益不仅来自"更宽的视野"，更取决于全景几何结构的表征方式与架构融合方式。
- **全景专家作用**：在需要多阶段状态跟踪的任务中（如Wipe Table），全景专家有效跟踪任务状态转换并保持跨阶段全局空间一致性，末阶段完成率73.3%，显著高于原始全景输入基线（26.7%）。
- **编码器选择**：MTPano（全景专用）远优于SigLIP（透视图像预训练），印证了全景特殊几何结构需要专用编码器。
- **专家规模**：100M是容量与数据效率的最佳平衡点；超过100M后，在有限微调数据下未见持续增益。

### 7. 优点

- **系统级闭环贡献**：将数据采集与模型学习统一设计，遥操作系统和VLA模型形成完整的数据-训练-评估闭环。
- **GMR全身遥操作**：将底盘建模为虚拟浮动基座，实现通过自然人体运动同时协调底盘与双臂，无需额外的操纵杆或键盘，显著降低操作者负担。
- **全景感知建模**：识别出全景图像与透视图像之间的域差异，使用全景专用编码器（MTPano）提取语义+几何双分支特征，并通过独立专家模块进行KV缓存级融合——设计具有可解释性和架构合理性。
- **严格的受控对比**：通过仅改变全景表征/融合方式的三种受控基线，清晰隔离了全景信息本身的贡献，而非简单对比不同模型的整体性能。
- **丰富的多模态数据集**：时间同步记录局部视图、全景视图、本体状态与全身动作，为后续研究提供数据资产。

### 8. 不足与局限

- **任务覆盖有限**：仅4个任务，未涵盖更复杂的室内环境（如多房间导航、动态障碍物、人机交互等）。
- **试验数量较少**：每任务15次试次的统计功效有限，且缺少多次重复实验的标准差或置信区间报告，结果稳定性难以评估。
- **消融范围有限**：消融仅针对专家规模和编码器选择，未消融全景专家本身的作用（例如直接拼接全景token而不经过专家处理），也未验证不同VLM主干下的泛化性。
- **数据集规模与多样性**：5.5小时数据量相对小型（如Open X-Embodiment百万级轨迹），且来自单一机器人平台、单一操作者，任务指令简单固定，可能限制跨任务泛化能力的结论。
- **全景技术路径的部署限制**：MTPano编码器特征提取计算成本较高；顶部安装的全景相机在实际部署中可能受遮挡、光照不均等因素影响。
- **动作空间表达局限**：17维动作中底盘仅3维平面速度（vx, vy, ω），未考虑地面起伏或非平坦地形。
- **无跨场景泛化验证**：未测试模型在新环境、新物体布局下的零样本或少样本泛化能力。
