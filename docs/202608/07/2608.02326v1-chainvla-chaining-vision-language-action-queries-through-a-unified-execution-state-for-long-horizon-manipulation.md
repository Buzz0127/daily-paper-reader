## 摘要
人类通过保留先前动作所建立的知识，同时不断调整进行中的动作，来执行长时程操作。相比之下，动作分块的视觉-语言-动作（VLA）策略在每次查询时从当前输入重复进行重新规划。现有方法要么通过记忆保留长期任务证据，要么通过动作重用和集成保留短期运动，导致跨查询交接不完整。我们引入了ChainVLA，一个1.2B参数的VLA策略，通过联合且可修订的执行状态来链接连续查询。进度上下文将循环工作状态与稀疏事件记忆相结合，以携带源自观测的任务进度，而运动尾流则将先前预测的未执行延续部分馈送到状态构建和动作生成中。这两个组件共同条件化一个解码器，该解码器在最新观测下重新生成每个动作视界，使得携带的状态能够指导下一次预测而不固定它。ChainVLA在RMBench上达到62.8%的平均成功率，在四个LIBERO套件上达到98.8%，而移除运动尾流或进度上下文分别将RMBench成功率降至11.2%和3.0%。这些不对称的消融结果与运动连续性有助于保持观测流相一致，而任务进度正是从该观测流中推断出来的。

## Abstract
Humans perform long-horizon manipulation by retaining knowledge of what earlier actions have established while continuously adapting the motion underway. By contrast, action-chunked vision-language-action (VLA) policies repeatedly replan from the current input at each query. Existing methods preserve either long-term task evidence through memory or short-term motion through action reuse and ensembling, leaving the cross-query handoff incomplete. We introduce ChainVLA, a 1.2B-parameter VLA policy that chains successive queries through a joint and revisable execution state. Progress Context combines a recurrent Working State with sparse event memory to carry observation-derived task progress, while Motion Tail feeds the preceding prediction's unexecuted continuation into state construction and action generation. Together, the two components condition a decoder that regenerates each action horizon under the latest observation, allowing the carried state to guide the next prediction without fixing it. ChainVLA reaches 62.8% average success on RMBench and 98.8% across four LIBERO suites, while removing Motion Tail or Progress Context reduces RMBench success to 11.2% and 3.0%, respectively. These asymmetric ablations are consistent with motion continuity helping preserve the observation stream from which task progress is inferred.

## 1. 核心问题与整体含义（研究动机与背景）

长时程操作要求策略在持续执行过程中同时处理两类信息：

- **任务进度**：此前动作已建立的任务证据（如哪些子任务已完成、目标物体被放在了哪里）。
- **运动延续**：当前正在进行的动作如何平滑地延续并接受修正。

人类在执行长时程任务时天然耦合这两者，然而当前主流的行动分块 VLA（Vision-Language-Action）策略采用**重复缩窄视界（receding-horizon）查询**机制：每次查询从当前观测+本体感受+指令预测一段固定长度的动作序列，仅执行严格前缀（strict prefix），然后重新规划。这种设计存在两个层面的跨查询交接缺失：

| 缺失层面 | 具体问题 | 示例 |
|---------|---------|------|
| 任务级 | 当前视野可能无法反映早期任务证据，相同观测+指令可能对应不同历史，需要不同决策 | RMBench 的 Put Back Block 任务 |
| 运动级 | 重新规划丢弃了前次预测的未执行后缀，新预测前缀与即将被替换的运动可能在边界处不一致 | 边界处命令产生突变 |

现有的两种弥补路线各有不足：**记忆增强策略**保留循环状态或压缩任务历史，但不保留前次预测的未执行运动；**时间集成/实时执行/原生延续策略**保留短期运动却无法追溯早期任务证据。核心研究问题由此提出：**如何让 VLA 策略在每次新预测都响应最新观测的同时，将任务进度与运动延续跨越查询链接起来？**

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 核心思想：统一且可修订的执行状态

ChainVLA 的核心创新是引入一个跨查询传递的**联合执行状态** sk = (gk, uk)，包含两个互补组件：

- **进度上下文 gk（Progress Context，回顾性）**：由循环工作状态（Working State）与稀疏事件记忆（Sparse Event Memory）融合而成，携带观测衍生的任务进度。
- **运动尾流 uk（Motion Tail，前瞻性）**：前一次预测未被执行的连续动作后缀，直接跨越查询边界传入下一次预测。

状态每轮被读取、更新并前向传递，使各自独立解码的动作块拼接为跨查询链条。但任何携带状态均作为**可修订先验**而非固定计划——解码器在最新观测下重新生成每个视界位置。

### 2.2 理论框架与形式化定义

在严格前缀重规划机制（1 ≤ hexec < H）下，策略的近似目标为：

```
Πθ(· | xk, sk) ≈ Π*(· | Hk)，sk+1 = Fθ(sk, xk)
```

查询转换可写为（式3）：

```
(Ak, Wk, Ck+1) = Fθ(xk, Dk, Wk−1, Ck, uk)
uk+1 = Tail(Ak) = (ak,hexec+1, ..., ak,H)
```

其中 Dk 为已执行动作历史，Wk 为工作状态，Ck 为稀疏事件记忆。

### 2.3 关键技术细节：进度上下文（任务进展的携带）

**循环工作状态**（式4）：8个学习的工作查询（working queries）通过交叉注意力处理当前多模态令牌 Xk，并结合来自已执行历史、运动尾流、本体感受与查询时间编码的池化条件向量。更新过程融合了循环上一查询现场令牌的递归路径，并通过有效性掩码在回合开始时置零。工作状态输出两部分：**现场令牌 Lk**（直接进入进度上下文融合）和**池化检索摘要 W̄k**（驱动事件检索与阶段估计）。

**稀疏事件记忆与检索**（式5）：事件记录包含视觉特征、阶段信息、时间特征与检索键；首个有效查询保留为锚点，后续由阶段转换（有标注数据）或周期规则（无标注数据）触发写入。检索时采用年龄感知的余弦相似度评分：

```
ρk,i = cos(LN(qek), LN(κi + Emb_age(clip(k − bi))))
```

每次读取锚点与得分最高的非锚点记录，通过交叉注意力融合为读出令牌 Zek，再与 Lk 融合为进度上下文。

### 2.4 关键技术细节：运动尾流（未完成运动的携带）

运动尾流的传递通过三条路径：

1. **尾流令牌 → 工作状态构建**：前次预测的未执行后缀经动作空间归一化和学习投影编码为尾流令牌，进入工作状态更新。
2. **轨迹对齐初始化**（式6）：将尾流对齐到全视界动作表示作为解码器初始均值，叠加高斯噪声：

```
μk+1 = I(uk+1)，εk+1 ~ N(0, I)
eA(0)ₖ₊₁ = μk+1 + σu·εk+1
```

3. **执行侧重叠混合**：解码后将新再生计划与前一后缀在重叠步骤线性混合（与模型侧路径分离）。

这两个部分的不同之处在于时间覆盖范围：进度上下文可以跨越许多查询，而运动尾流只连接紧邻的前一次预测。

### 2.5 训练流程

训练按回合顺序展平与推理相同的状态转换；以 0.5 概率使用前任的分离预测尾流，否则掩蔽尾流路径；损失函数包含标准条件流动作目标、阶段监督（有标注时）和重叠一致性正则化项（权重0.2，惩罚连续预测在时间对齐重叠上的分歧，但不固定新视界中的动作）。训练过程使用分离后的预测尾流（detached tail），避免梯度跨查询回传。

## 6. 主要结论与发现

1. **统一执行状态的价值**：ChainVLA 以 1.2B 参数量在 RMBench 上达到 62.8% 平均成功率（优于 8B+2B 的 Mem-0 的 52.8%），在 LIBERO 四套件上平均 98.8%（Long 套件 98.2%）。

2. **两半组件不可相互替代且不可缺少**：移除运动尾流后成功率从 62.8% 降至 11.2%，移除进度上下文后降至 3.0%，两者均移除仅剩 1.6%。两个单项低分并不叠加为高分——说明两者是**顺序衔接的链条**而非并行独立的能力。

3. **运动连续性对任务进度推断的支撑作用**：移除运动尾流后即使记忆通路完整保留，性能仍大幅下降；配对边界实验显示 Full 在各诊断指标上均显著更低（CDp降56.6%、CDR降40.4%、B2降57.4%、RMSE3降43.1%）。这说明边界处剧烈的命令突变会导致机械臂访问非示范分布的视点序列，破坏工作状态/事件记忆的输入分布——运动连续性保护了任务进度推断所依赖的观测流。

4. **后解码平滑不能替代模型侧条件化**：Linear Continuation 在边界指标上比 Full 更平滑，但成功率仅 0–2%（Full 为 96%/74%）；说明"平滑"本身不是目标，先验必须在**状态构建与动作生成之前**进入模型，而非事后聚合。

5. **稀疏事件写入不需要阶段标注也能工作**：固定三查询写入达到 53.4%，虽低于完整版 62.8%，但显著高于其他内存方法。

## 7. 方法或实验设计的优点

- **问题建模清晰**：将跨查询交接缺失拆解为任务级与运动级两个层面，并形式化"当前输入决策不足"（式1），界定清晰。
- **统一可修订的状态设计**：进度上下文与运动尾流以"条件先验"而非"硬性固定"的方式进入解码器，既维持连续性又保持对最新观测的响应性，是设计上的关键进步。
- **不对称消融揭示了因果关系方向**：通过任务进度侧与运动侧的不对称退化（11.2 vs 3.0），有力支持了"运动连续性保护观测流→观测流支撑任务进度推断"的因果链解释。
- **训练-推理一致的循环展开**：训练时按回合顺序展平查询转换并传递分离后的预测尾流，与部署行为对齐。
- **实验设计中的对照组区分度高**：FIFO Hist. + TE（现有方法的近似替代）、Linear Continuation（仅执行侧平滑）、Temporal Ensemble 等替代方案都使用了相同协议，能有效将该方法与既有做法区分开。
- **诊断指标界定严谨**：边界指标明确定义、承认局限（非物理平滑度、非积累状态偏差），成功率仍为最终标准。
