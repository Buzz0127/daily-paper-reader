## 摘要
视觉-语言-动作（VLA）模型在机器人操作中表现出色，但当典型指令被简单改写时，其性能会急剧下降。尽管这种脆弱性通常通过昂贵的数据扩展来解决，但我们的探测揭示，根本原因在于架构而非语义理解的缺乏。具体而言，我们证明当前的VLA模型内部实际上成功保留了正确的任务身份。失败实际上源于动态视觉观察和文本的联合编码，这引入了系统性的特征偏移。由于下游动作策略对这些变化高度敏感，它无法将保留的语义转化为正确的控制命令。为解决这一结构性瓶颈，我们提出了基于语义重绑定（GSR），一种优雅的干预方法，通过将独立提取的任务语义与原生视觉特征显式融合，彻底重新初始化动作专家并从头训练，从而绕过不稳定的联合路由。这种有针对性的干预仅使用典型示范即可显著恢复释义不变性。在LIBERO-Para基准上，GSR将成功率提升了高达44.6%。它使轻量级模型能够与大规模扩展的基线相媲美，并将最先进的模型推至70.4的新纪录PRIDE分数，在指令生成能力上超越了最近引入的大规模预训练模型Xiaomi-Robotics-0。基于这些见解，我们还引入了ParaVLA，一个原生解耦的0.33B参数模型，对指令改写表现出近乎完美的鲁棒性。最终，我们的工作证明，通过优雅的结构设计可以实现鲁棒的语义基础，而无需采用低效的强力数据扩展范式。

## Abstract
Vision-Language-Action (VLA) models excel in robotic manipulation but suffer catastrophic performance drops when canonical instructions are simply paraphrased. Although this brittleness is typically addressed through costly data scaling, our probing reveals that the root cause is architectural rather than a lack of semantic understanding. Specifically, we demonstrate that current VLAs successfully retain the correct task identity internally. The failure actually stems from the joint encoding of dynamic visual observations and text, which introduces systematic feature shifts. Because the downstream action policy is highly vulnerable to these variations, it fails to translate the preserved semantics into correct control commands. To resolve this structural bottleneck, we propose Grounded Semantic Re-binding (GSR), an elegant intervention that bypasses unstable joint routing by explicitly fusing independently extracted task semantics with native visual features to train a completely re-initialized action expert from scratch. This targeted intervention dramatically restores paraphrastic invariance using only canonical demonstrations. On the LIBERO-Para benchmark, GSR improves success rates by up to 44.6 percent. It enables lightweight models to rival massively scaled baselines and pushes state-of-the-art models to a new record PRIDE score of 70.4, outperforming the recently introduced large-scale pretrained model Xiaomi-Robotics-0 in instruction generation capabilities. Building on these insights, we also introduce ParaVLA, a natively decoupled 0.33B-parameter model exhibiting near-perfect robustness to instruction rewording. Ultimately, our work proves that robust semantic grounding can be achieved through elegant structural design, bypassing the inefficient brute-force data scaling paradigm.

## 2. 论文提出的方法论

### 2.1 核心思想：Grounded Semantic Re-binding（GSR）

GSR 是本文提出的核心方法，其核心思想是：

1. **绕过不稳定的联合路由**：不依赖 VLA 原生语言编码路径（其将动态图像与指令联合编码，易受措辞变化影响），而是使用冻结的 T5 编码器独立提取纯任务语义。
2. **显式融合语义与视觉特征**：将 T5 提取的语义特征注入模型原生的视觉-状态表示中，在模型自身的多模态计算管线内实现语义接地（grounding）。
3. **重新初始化动作专家**：从零开始训练新的动作策略，使模型从训练伊始就学习如何将 T5 条件、视觉特征和机器人状态联合映射为动作，而不是保留原有对原始语言输入的动作映射。

### 2.2 关键诊断发现与设计依据

- **因果干预验证**：在 VLA-Adapter 执行 paraphrase 时，仅将 Qwen 输出特征替换为 canonical 指令的特征，即可将成功率从 60% 提升至 96%，直接证明正确语义信息已保留，但下游策略处理不当。
- **视觉影响实验**：将辅助 Qwen 分支的图像替换为固定 dummy 图像，成功率从 46.82% 提升至 61.58%，说明动态视觉输入的联合编码加剧了特征偏移。
- **措辞方向移除实验**：用 8 个任务估算 32 个特征方向（区分 canonical 与 paraphrase），从剩余 2 个未参加任务的 Qwen 输出中移除这些方向，动作差距从 0.4361 降至 0.2282，验证语言变化引入的是系统性的、可分离的特征偏移。

### 2.3 架构感知的 GSR 实施指南

- 使用冻结 T5-large 作为稳定语义源（不接收图像或状态信息）。
- 识别各模型核心多模态融合阶段，将投影后的 T5 语义直接注入该融合点。
- 对原生语言路径进行差异化处理：
  - **VLA-Adapter**：将原生文本替换为固定中性提示“perform the task”，强制依赖 T5 语义；T5 特征作为 sidecar K/V 注入 Bridge-Attention 动作策略。
  - **SmolVLA**：同样替换为中性提示，T5 特征通过 grounding attention 注入 SmolVLM 的原生语言槽位，再经原生多模态计算后控制动作。
  - **π0.5**：其原生 PaliGemma 路径本身已经可靠，因此保留真实指令，T5 作为补充语义输入注入任务令牌位置。
- 所有 GSR 变体仅使用 LIBERO-Goal 的 10 个 canonical 任务演示训练，不使用任何 paraphrase 数据。

### 2.4 ParaVLA：原生解耦架构

ParaVLA 是本文提出的 0.33B 参数模型，采用原生解耦架构：冻结 T5 处理指令，DINOv2 处理图像，两者仅在最终的动作专家中融合。该模型对指令改写表现出近乎完美的鲁棒性（canonical 92.0%、paraphrase 91.0%，差距仅 1%）。

## 3. 实验设计

### 3.1 数据集与 Benchmark

- **Goal-100 诊断集**：10 个任务 × 10 个固定初始状态，配对 canonical、人工 paraphrase 和循环错误任务指令。
- **真实机器人实验**：AgileX PiPER 双臂机器人，4 个拿取 + 2 个堆叠任务，共享同一视觉场景，评估 30 个 trials（每任务每条件 5 次）。

## 6. 主要结论与发现

- **根因定位**：VLA 模型在 paraphrase 下的失败并非语义理解缺失，而是架构层面的特征利用失败——视觉-语言联合编码引入系统性特征偏移，下游动作策略对这些变化高度敏感。
- **GSR 有效性**：仅使用 canonical 演示训练，GSR 使 VLA-Adapter 的 Full Para 成功率从 46.82% 提升至 70.94%，SmolVLA 从 4.47% 提升至 49.12%，π0.5 从 73.60% 提升至 75.59%。
- **性能纪录**：GSR + π0.5 取得当前最高 PRIDE 分数（70.4），超越 Xiaomi-Robotics-0（69.2），使其在 4,092 episode 的 Full Para 综合评估中最优。
- **轻量模型接近大规模基线**：VLA-Adapter（0.51B）经 GSR 后性能接近 π0.5（3.6B）的大规模预训练基线，证明结构设计可以替代暴力数据扩展。
- **架构感知原则**：不同模型任务信息融合阶段不同。VLA-Adapter 的最终 Bridge-Attention block 是严格的任务信息瓶颈；SmolVLA 和 π0.5 则为分布式处理，无单一控制点。GSR 的注入点必须适应架构。
- **不稳定的原生编码器会劫持控制**：VLA-Adapter 和 SmolVLA 的原生语言路径在冲突测试中会主导动作输出，因此必须中性化原文本输入；π0.5 的原生路径本身可靠，应保留。
- **T5 语义是增益来源**：单纯增加模型容量（Qwen-VL 替代 T5、无语言模型参数）无法改善 paraphrase 鲁棒性，增益完全来自冻结 T5 的稳定、无视觉语义特征。
- **原生解耦可行**：ParaVLA 证明语言-视觉全程解耦的架构可获得近乎完美的改写不变性，但面临 VLM 级扩展性瓶颈。

## 7. 优点

- **诊断方法论严谨且有因果性**：不仅给出相关性证据（Retrieval@1、R 指标），还通过 token 替换干预、视觉替换、特征方向移除等因果实验精确锁定失败环节，使设计动机非常扎实。
- **成本意识突出**：不依赖 paraphrase 数据或大规模数据扩展，仅用 canonical 演示即可大幅提升改写鲁棒性，在效率和性能之间建立了新平衡。
- **跨架构普适性验证**：在三种架构差异显著（独立动作策略、早期 V-L 融合、超大预训练）的模型上验证了方法的通用性，并系统总结出架构感知的实施指南。
- **消融与冲突测试设计巧妙**：语言路线权威实验（C/C、W/C、C/W）清晰揭示了不同模型内部指令控制权分布，为是否中性化原生文本提供了经验依据。
- **轻量级高效**：ParaVLA 仅 0.33B 参数即达到接近 benchmark 顶级的 paraphrase 鲁棒性（Full Para 72.51%，PRIDE 66.9），T5 缓存设计使推理时无额外语言编码成本。
- **控制严格的评测协议**：统一锁定噪声、种子、初始状态等变量；报告了成对统计检验和置信区间，增强了可比性。

## 8. 不足与局限

- **解耦架构的规模瓶颈**：ParaVLA 在升级更大视觉模型时未展现出 VLM 常见的缩放能力，原生解耦范式在规模化方面存在明显挑战，论文本身也承认这一点。
- **大规模架构的收敛代价**：π0.5 等参数密集的模型在 GSR 下需要双倍训练步数才能恢复 canonical 成功率，文中提出的“重新初始化动作专家”策略对大型动作头的收敛不够友好。
- **真实机器人验证有限**：真机实验仅 6 个任务、每条件下 5 次 trials，且多个任务（任务 3 拿最右方块、任务 5/6 堆叠）GSR 也全部失败，无法充分说明方法的真实世界泛化能力。此外，共享视觉场景导致 native 模型 0% 成功率这一对比可能过于极端。
- **诊断数据依赖性**：部分诊断（如特征子空间移除）需要配对的 canonical-paraphrase 指令来估计方向，这在真实部署中不可获取；其目的主要是验证假设而非直接做推理时干预。
- **未披露训练时间与总能耗**：文中给出 GPU 型号、数量和步数，但未报告墙钟时间、电源消耗等实操信息。
- **原生机型差异性处理存在启发式成分**：π0.5 保留原生指令、VLA-Adapter/SmolVLA 中性化的决策依赖于对原生路径可靠性的测试判断，尚缺乏统一的自动判定标准。
- **评估范围集中**：主要评估限于 LIBERO（Goal/Para）模拟环境和单一真实平台，未覆盖更广泛的任务类型、物体类别或多种机器人构型。
