## 摘要
人类通过保留早期动作已建立的知识，同时持续调整正在进行的运动，来执行长程操作。相比之下，动作分块的视觉-语言-动作（VLA）策略在每次查询时从当前输入重复重新规划。现有方法要么通过记忆保留长期任务证据，要么通过动作重用和集成保留短期运动，导致跨查询交接不完整。我们提出了ChainVLA，一个1.2B参数的VLA策略，通过一个联合且可修订的执行状态来链式连接连续的查询。进度上下文将循环工作状态与稀疏事件记忆相结合，以携带从观测中得到的任务进度；而运动尾部将先前预测中未执行的延续部分馈送到状态构建和动作生成中。这两个组件共同约束一个解码器，该解码器在最新观测下重新生成每个动作视野，使得携带的状态能够指导下一次预测而不将其固定。ChainVLA在RMBench上达到62.8%的平均成功率，在四个LIBERO套件上达到98.8%，而去除运动尾部或进度上下文分别将RMBench成功率降至11.2%和3.0%。这些不对称的消融实验与运动连续性有助于保留用于推断任务进度的观测流这一观点一致。

## Abstract
Humans perform long-horizon manipulation by retaining knowledge of what earlier actions have established while continuously adapting the motion underway. By contrast, action-chunked vision-language-action (VLA) policies repeatedly replan from the current input at each query. Existing methods preserve either long-term task evidence through memory or short-term motion through action reuse and ensembling, leaving the cross-query handoff incomplete. We introduce ChainVLA, a 1.2B-parameter VLA policy that chains successive queries through a joint and revisable execution state. Progress Context combines a recurrent Working State with sparse event memory to carry observation-derived task progress, while Motion Tail feeds the preceding prediction's unexecuted continuation into state construction and action generation. Together, the two components condition a decoder that regenerates each action horizon under the latest observation, allowing the carried state to guide the next prediction without fixing it. ChainVLA reaches 62.8% average success on RMBench and 98.8% across four LIBERO suites, while removing Motion Tail or Progress Context reduces RMBench success to 11.2% and 3.0%, respectively. These asymmetric ablations are consistent with motion continuity helping preserve the observation stream from which task progress is inferred.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究问题**：长时程（long-horizon）机器人操作中，采用动作分块（action-chunked）策略的 VLA 模型在每次查询（query）时都会从当前输入重新规划动作，导致跨查询（cross-query）的任务进度信息与运动中未完成的延续部分丢失。
- **现有方法的缺陷**：
  - **记忆增强类方法**：通过循环状态、稀疏观测或压缩任务历史来保留长期任务证据，但**不保留上一次预测中未执行的动作后缀**（即运动延续被丢弃）。
  - **时间集成/实时执行类方法**：通过动作重用、时间集成等保留短期运动，但**无法回溯更早的任务证据**。
  - 二者未能在**同一个查询转移中同时**兼顾任务进度与运动连续性。
- **核心假设（人类行为启示）**：人类在执行长程操作时，既保留已有动作建立的任务进度，又持续修正当前运动；且运动连续性影响观测流，进而影响任务进度的推断。论文据此提出一个关键问题：**如何在不牺牲对最新观测响应性的前提下，让 VLA 策略跨查询同时衔接任务进度与运动延续？**

## 2. 方法论

ChainVLA 是一个 1.2B 参数的 VLA 策略，核心是引入一个**联合且可修订的执行状态（unified execution state）**，由两个互补组件构成：

- **进度上下文（Progress Context，$g_k$）**：
  - 结合**循环工作状态（Recurrent Working State）**与**稀疏事件记忆（Sparse Event Memory）**，携带从观测中推导出的任务进度。
  - 工作状态通过可学习的工作查询（working queries）对当前多模态输入进行交叉注意力编码，并递归更新上一次的活性 token（live tokens），同时维护一个边界缓存（bounded FIFO）存储历史 token。
  - 稀疏事件记忆仅在有触发写入时更新（阶段标注数据按阶段转移写入，无标注数据按固定间隔写入），通过年龄感知的余弦相似度检索与当前执行估计相关的事件证据。
- **运动尾部（Motion Tail，$u_k$）**：
  - 携带上一次预测中**未执行的后缀**（unexecuted suffix，即 $u_{k+1} = \text{Tail}(A_k)$)，直接作为下一查询的条件先验。
  - 通过两条路径起作用：①编码为尾部 token 参与工作状态构建；②对齐动作空间后用带噪初始化（式 6）参与解码器的动作生成。
- **查询转移（query transition）**：式 (2)–(3) 定义了递归的状态更新与策略条件生成：$s_{k+1} = F_\theta(s_k, x_k)$，解码器在**最新观测、进度上下文和运动尾部共同条件下重新生成完整动作视野**，携带状态只作为“可修订的先验”，不固定任何动作。
- **训练方式**：按 episode 顺序展开同一状态转移，使用条件流（conditional flow）动作目标 + 阶段监督（若有标注）+ 重叠一致性正则（overlap-consistency）训练；训练中运动尾部以 0.5 概率脱离（detached）传递。

## 3. 实验设计

- **RMBench**（主要诊断基准）：
  - 包含 5 个任务：Observation、Rearrange Blocks、Put Back Block、Swap Blocks、Swap Tasks，均考验记忆依赖（如初始布局、目标/返回位置记忆、隐藏物体等）。
  - 每任务 50 条演示、训练 100 个 rollout episodes 评估。
- **LIBERO**（广度验证）：
  - 4 个套件（Spatial、Object、Goal、Long），每个套件微调一个模型，每任务 50 episodes 评估。
- **对比方法**：
  - 通用类别：Diffusion Policy (DP)、ACT、π0、π0.5、X-VLA、OpenVLA、SpatialVLA、GR00T-N1、π0-FAST 等。
  - 记忆相关：MemoryVLA、Mem-0、MemER、MemoAct、PAM、Goal2Skill 等。
- **消融与干预控制**：
  - 状态侧消融：w/o Stage Annotation、w/o Live Tokens、w/o Event Readout、w/o Progress Context。
  - 运动侧消融：w/o Tail Tokens、w/o Trajectory Init、w/o Motion Tail。
  - 无状态替代：w/o Both（仅保留当前观测+动作历史）、FIFO Hist. + TE（固定长度观测历史+时间集成）。
  - 后处理平滑控制：Linear Continuation、Temporal Ensemble（仅输出侧平滑，不进行模型内条件化）。
- **边界诊断指标**：位置/姿态命令不连续度（CD$_p$、CD$_R$）、边界二阶差分（B2）、三步重叠动作 RMSE3，用于检验查询边界的命令衔接质量。

## 6. 主要结论与发现

- **性能**：ChainVLA 在 RMBench 平均成功率 62.8%（优于完整五任务覆盖的最强基线 Mem-0 52.8%），在所有任务上均为最优或次优；LIBERO 四套件平均 98.8%（其中 Long 98.2%）。
- **关键消融不对称**：去掉 Motion Tail 后 RMBench 降至 11.2%，去掉 Progress Context 降至 3.0%，同时去掉仅 1.6%；这说明两个组件不是独立叠加的改进，而是**连续协作的系统依赖**。
- **运动连续性保护任务进度推断**：去掉 Motion Tail 时配对边界表现出更大的命令不连续（如位置 CD 从 0.66 mm 升至 17.32 mm 的示例），Full 在全部 80 对场景中显著降低四个边界指标（池化降低 56.6%、40.4%、57.4%、43.1%）；但后处理平滑控制（Linear Cont. / Temporal Ens.）虽能达到更低边界不连续度，成功率仍只有 0–2%，证明仅平滑输出**无法替代模型内状态条件化**。
- **核心表述**：进度上下文与运动尾部分别对应任务进度与运动延续，二者在查询边界上形成“链式”结构，且运动尾部通过维持稳定观测流间接服务于任务进度记忆。

## 7. 优点

- **概念清晰、问题刻画准确**：将跨查询交接形式化为“任务进度”+“未完成运动”两部分，并用严格前缀重规划框架下的决策充分性定义（式 1）说明输入不足，理论视角明确。
- **统一且可修订的机制设计**：执行状态作为条件先验而非固定计划；解码器始终基于最新观测重生成每个地平线位置，避免“旧计划僵硬传导”问题。
- **消融设计极具说服力**：通过“移除状态 vs 仅后处理平滑”的对比，证明模型内条件化路径的必要性；用边界诊断指标将状态衔接量化为可测指标。
- **训练/部署一致性**：有序训练展开与 rollout 采用同一状态转移，运动尾部在训练中以 detachment 传递，兼顾稳定与一致性。
- **参数量小、效率高**：1.2B 参数在 RMBench/LIBERO 上以较少参数超越 7B/8B 级方法，具有实用潜力。

## 8. 不足与局限

- **评估范围有限**：所有实验在**固定频率仿真**（RMBench/LIBERO）上完成，未在真实机器人硬件上验证；边界诊断测的是命令流而非物理轨迹，不涉及执行器限制、实时异步控制等实际部署问题。
