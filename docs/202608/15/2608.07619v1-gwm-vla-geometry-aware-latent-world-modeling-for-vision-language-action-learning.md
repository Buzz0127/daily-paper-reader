## 摘要
视觉-语言-动作（VLA）模型在机器人操作任务上表现出色，但在视觉和环境变化下性能往往下降。潜世界建模为提高鲁棒性提供了一种有前景的方法，但现有方法通常独立编码相机视角，并预测整体场景动态，而没有显式建模它们之间的几何关系。我们提出了GWM-VLA，一种用于VLA学习的几何感知潜世界建模框架。GWM-VLA结合了几何感知的多视角状态编码、全局上下文条件下的目标视角预测，以及由机器人动作监督驱动的共享潜动作表示。具体而言，VGGT-Ω在每个时间步联合聚合多视角观察，以构建几何感知的多视角状态。潜世界模型利用多视角聚合后得到的patch和register tokens来预测所选目标视角的下一步patch tokens，从而在无需预测完整多视角状态的情况下保留多视角几何信息。在实验中，我们使用腕部视角作为目标，更加关注末端执行器运动和局部夹爪-物体交互。最后，共享的潜动作表示同时为潜世界模型和流匹配动作头提供条件，使得潜预测监督和真实机器人动作监督能够共同塑造相同的潜动作表示。在仿真和真实环境中的实验证明了GWM-VLA的有效性和鲁棒性。

## Abstract
Vision-Language-Action (VLA) models achieve strong robotic manipulation performance but often degrade under visual and environmental shifts. Latent world modeling offers a promising approach to improving robustness, yet existing methods commonly encode camera views independently and predict holistic scene dynamics without explicitly modeling their geometric relationships. We propose GWM-VLA, a geometry-aware latent world modeling framework for VLA learning. GWM-VLA combines geometry-aware multi-view state encoding, global context-conditioned target-view prediction, and shared latent-action representations grounded by robot-action supervision. Specifically, VGGT-$Ω$ jointly aggregates multi-view observations at each timestep to construct geometry-aware multi-view states. The latent world model predicts the next-step patch tokens of a selected target view using patch and register tokens obtained after multi-view aggregation, thereby retaining multi-view geometric information without predicting the complete multi-view state. We use the wrist view as the target in our experiments, placing greater emphasis on end-effector motion and local gripper-object interactions. Finally, the shared latent-action representations condition both the latent world model and the flow-matching action head, allowing latent-prediction supervision and ground-truth robot-action supervision to jointly shape the same latent-action representations. Experiments across both simulation and real-world environments demonstrate the effectiveness and robustness of GWM-VLA.

### 1. 核心问题与研究动机

- **背景问题**：视觉-语言-动作（VLA）模型虽在机器人操控中表现优异，但在**相机视角、光照、背景、物体布局、传感器噪声**等视觉与环境变化下，性能会显著退化。作者认为，根本原因在于部分策略依赖外观特征的相关性（appearance-specific correlations），而非真正理解动作如何驱动场景状态变化。
- **已有方案及其不足**：
  - 显式世界模型（如 DreamZero、π0.7）需生成未来图像，被迫建模纹理、光照等与控制无关的外观细节，预测目标冗赘。
  - 潜世界模型（如 VLA-JEPA）预测未来潜表征而非图像，更为紧凑，但其使用预训练编码器对各相机视图**独立编码、拼接融合**，未显式建模视图间的几何对应关系和空间结构。
- **本文目标**：探索如何将**几何感知的多视图表示**用作潜世界模型的预测状态，在规避完整多视图预测开销的同时，提升 VLA 在分布偏移下的鲁棒性。

### 2. 方法论：GWM-VLA 框架

#### 核心思想

GWM-VLA 由三大支柱组成：**几何感知多视图状态编码**、**全局上下文条件下的目标视图预测**、**由机器人动作监督驱动的共享潜动作表征**。整体架构如图 2 所示。

#### 关键技术细节

1. **几何感知多视角状态编码（Geometry-Aware Multi-View State Encoding）**
   - 使用预训练且**冻结**的 VGGT-Ω 编码器，在每个时间步对所有相机视图进行**联合聚合**，输出 register tokens 与 patch tokens：
     
     {R_t, P_t} = E_Ω({I^v_t}⁽ᵛ⁾)
     
   - 同一时间步所有视图联合处理，不同时间步独立处理。

2. **全局上下文条件下的目标视角预测（Global Context-Conditioned Target-View Prediction）**
   - 不在多视图全部状态上施加预测损失，只预测**选定的目标视图**（实验中默认腕部视图）的 patch tokens。
   - 提取目标视图的 register tokens 作为预测时的**全局几何上下文**；patch tokens 与 register tokens 均是在多视图聚合后产生的，因此保留了跨视图几何信息，却只增加单视图预测负担。
   - 潜世界模型使用**时间因果注意力**（timestep t 的 token 只能关注 ≤ t 的 token），训练时采用 teacher forcing，预测目标定义为：
     
     L_wm = (1/T) Σ ||p̂_{t+1} - p_{t+1}||₁
     
   - 监督目标来自同一 VGGT-Ω 编码器对下一帧多视图观测的编码结果。

3. **共享潜动作表征（Unified Latent Action Representation）**
   - 采用 Qwen3-VL-2B 作为视觉语言骨干，插入时间步分组的可学习潜动作查询 token（latent action queries），从当前观测与语言指令中解码出潜动作序列 A_{0:T-1}。
   - 与 VLA-JEPA 额外引入 embodied-action query 不同，GWM-VLA **直接用同一潜动作序列**同时条件化潜世界模型和流匹配动作头。
   - 训练目标为联合优化：
     
     L = L_action + λ·L_wm（默认 λ = 0.1）
     
   - 潜世界模型损失仅在训练时作为辅助监督，部署时无需使用。

4. **条件流匹配动作头（Conditional Flow-Matching Action Head）**
   - 使用流匹配（Flow Matching）生成连续动作块，以共享潜动作序列和当前本体感觉状态 s₀ 为条件，建模多模态动作分布，损失函数为：
     
     L_action = E[||v_ψ(u_γ, γ | A, s₀) - (u - ε)||²]

### 3. 实验设计

#### 数据集与 Benchmark

- **预训练**：DROID 数据集（约 76,000 条带动作标签的遥操作轨迹，覆盖多种任务、视角、工作区与背景）。
- **仿真**：
  - **LIBERO**：四个任务套件（Spatial、Object、Goal、LIBERO-10），作为分布内（in-distribution）评测。
  - **LIBERO-Plus**：七个扰动维度（相机视角、机器人初始状态、语言指令、光照、背景、视觉噪声、物体布局），作为分布外（OOD）鲁棒性评测。
- **真实世界**：SO-101 机械臂 + LeRobot 部署栈，采集 100 条遥操作演示 / 5 个拾放任务；三类评测：分布内（ID）、OOD 任务（物体-容器重组合）、OOD 物体布局。

#### 对比方法

- 与 11 种代表性方法对比：LAPA、UniVLA、OpenVLA-OFT、π0、π0-FAST、CoT-VLA、WorldVLA、villa-X、GR00T N1、π0.5、VLA-JEPA。
- 最直接可比的基线为**仅用机器人数据预训练的 VLA-JEPA**（与 GWM-VLA 同为 robot-only 设置）。

#### 消融实验

- **目标视角选择**：腕部视角（92.8%） vs 第三方视角（87.8%） vs 混合视角（92.4%）。

- **动作条件方式**：直接共享潜动作 token（92.8%） vs 额外引入 embodied query（88.0%）。
- **定性探测**：训练并冻结深度解码器，可视化预测的下一帧潜状态还原深度与点云的能力。

### 6. 主要结论与发现

- **分布内性能不降**：LIBERO 平均成功率 97.1%，与最优基线并列（OpenVLA-OFT），较 robot-only VLA-JEPA 提高 1.0 个百分点。
- **分布外鲁棒性显著提升**：LIBERO-Plus 平均成功率 76.9%，达到 SOTA，较 VLA-JEPA（62.9%）高出 **14.0 个百分点**，在语言、光照、物体布局扰动下排名第一。
- **腕部视图目标最优**：与末端执行器运动和局部抓取-物体交互紧密相关，作为预测目标效果最佳。
- **深层几何表征更有益**：VGGT-Ω 后期层的表征（Layer 24）作为潜状态时策略成功率最高。
- **共享潜动作表征有效**：直接在潜世界模型与动作头之间共享潜动作 token，优于引入额外 embodied query 的方案。
- **可视化探测确认**：预测的潜状态确实保留了下一帧的场景几何（含夹爪附近结构），尽管细节略有平滑。
- **真实世界验证**：在有限演示下平均成功率最高，尤其在 ID 与 OOD 布局设置中优势明显；但 OOD 任务组合泛化弱于 π0.5。

### 7. 方法亮点与优点

- **预测目标设计巧妙**：只预测单个目标视图的 patch tokens，却通过 register tokens 和 VGGT-Ω 联合聚合保留了多视图几何信息，实现“轻量预测、全局几何”的平衡。
- **共享动作表征的耦合设计**：让潜预测与真实动作两个目标共同塑造同一组潜动作 token，直接耦合动力学学习与策略学习，无需额外动作接口。
- **利用几何基础模型的前沿特性**：VGGT-Ω 冻结使用，避免引入大量可学习参数；挖掘 VGGT 系列模型跨视图几何建模能力——即发挥 VGGT-Ω 作为视觉骨干的潜力；将该能力首次嵌入潜世界模型的预测状态。
- **实验链条完整**：从 DROID 大规模预训练、LIBERO 双基准评测到真实机器人部署，并辅以消融与可视化分析。
- **与同条件基线对比清晰**：强调 robot-only 对比，避免人类视频预训练数据上的不公平优势。
- **鲁棒性提升幅度显著**：相对于同类潜世界模型基线（VLA-JEPA），在 LIBERO-Plus 上提升 14 个百分点，证明几何感知对 OOD 鲁棒性的价值。

### 8. 不足与局限性

- **多视图依赖限制预训练数据规模**：VGGT-Ω 需要同一时刻多视角观测，无法直接用于大规模人类视频预训练——作者自认这是主要限制。
- **固定目标视图不具自适应性**：默认腕部视图在 LIBERO-Spatial 上最优，但其他任务/传感器布局下未必最优，缺乏自适应选择机制。
- **OOD 任务泛化能力不足**：真实世界中 OOD 任务设置（组合新指令）弱于 π0.5（53.3% vs 60.0%），说明空间鲁棒性与组合指令泛化是不同维度的挑战。
- **消融实验规模受限**：仅在一个任务套件（LIBERO-Spatial）、单 GPU 短训练下进行，统计可靠性有限；未在 LIBERO-Plus 上做消融。
- **部分扰动维度仍非最优**：LIBERO-Plus 中机器人初始状态扰动（54.7%）略低于 VLA-JEPA（55.7%）；相机视角扰动也未排第一，说明几何感知并非对所有扰动维度都充分。
- **效率与工程细节缺失**：未报告推理速度、训练时长、参数量、显存占用等信息，难以评估实用成本。
- **真实实验样本量偏小**：每个任务仅 10 次尝试，统计置信度有限。
- **潜状态质量缺乏定量指标**：定性探测仅能说明潜状态保真度，没有量化预测误差对策略的影响或对场景几何的客观度量。
