## 摘要
视觉-语言-动作（VLA）模型的通行做法是将预训练的VLM与单独训练的流匹配动作专家耦合。这使得VLM成为上下文编码器而非决策者。我们提出G0.5，一种预训练的自回归VLA，其中单个Transformer解码器在单一目标下生成推理与动作词元。三个组件使其在基础模型规模上可行：一个可学习的跨具身动作分词器，将异构机器人动作映射到共享词汇表；一条原生思维链流，将任务分解、对象接地和动作提示与动作词元交错；以及一个视觉记忆模块，通过视觉编码器注入多秒历史信息。由于推理与动作共享同一组权重，预训练VLM的能力得以迁移至物理行为：模型严格遵循指令，且提示直接引导动作粒度、任务时域和分布外场景处理，无需额外训练。G0.5在大型机器人数据集集合并结合VQA样本上预训练，在7个独立场景中超越最先进模型：R1lite和R1pro机器人上的真实世界微调（76.7%，对比π_{0.5}的53.3%和GR00T-N1.7的24.4%）；2025年BEHAVIOR挑战赛中使用通用策略完成50项长时程家庭移动操作任务（31.4%，对比π_{0.5}的26.3%和挑战赛冠军的26.1%）；DROID后训练后零样本迁移到未见环境和物体（82.5%）；语言跟随的抓取-放置基准；LIBERO（98.9%）；RoboTwin 2.0（93.3%）；以及SimplerEnv-Bridge（87.3%）。

## Abstract
The prevailing recipe for Vision-Language-Action (VLA) models couples a pretrained VLM with a separately trained flow-matching action expert. This makes the VLM a context encoder rather than a decision-maker. We introduce G0.5, a pretrained autoregressive VLA in which a single transformer decoder emits reasoning and action tokens under a single objective. Three components make this tractable at foundation-model scale: a learnable cross-embodiment action tokenizer that maps heterogeneous robot actions into a shared vocabulary; a native chain-of-thought stream interleaving task decomposition, object grounding, and action hints with action tokens; and a visual memory module that injects multi-second history through the vision encoder. Because reasoning and action share a single set of weights, the pretrained VLM's capabilities carry over to physical behavior: the model follows instructions closely, and prompts directly steer action granularity, task horizon, and out-of-distribution scene handling without further training. Pretrained on a large collection of robot datasets together with VQA samples, G0.5 surpasses state-of-the-art models across 7 independent regimes: real-world fine-tuning on R1lite and R1pro robots (76.7\% vs.\ 53.3\% for $π_{0.5}$ and 24.4\% for GR00T-N1.7), the 2025 BEHAVIOR Challenge on 50 long-horizon household mobile manipulation tasks using a generalist policy (31.4\% vs.\ 26.3\% for $π_{0.5}$ and 26.1\% for the challenge winner), DROID post-training followed by zero-shot transfer to an unseen environment and objects (82.5\%), a language-following Pick-and-Place benchmark, LIBERO (98.9\%), RoboTwin 2.0 (93.3\%), and SimplerEnv-Bridge (87.3\%).

### 1. 核心问题与整体含义

- **背景**：视觉-语言-动作（VLA）模型是通用机器人控制的主流范式。当前主流做法采用“VLM-as-Encoder”架构——将预训练VLM作为上下文编码器，将隐藏状态或KV缓存传递给单独训练的流匹配/扩散动作专家，由专家输出连续动作。这类代表包括π0、π0.5、GR00T系列、SmolVLA等。
- **核心问题**：VLM-as-Encoder架构使VLM沦为条件编码器而非决策者，其原生生成能力（思维链推理、上下文学习、提示驱动的动作调控）只能通过压缩的条件瓶颈间接影响行为，无法作为动作生成的天然组成部分。而早期自回归VLA（如RT-2、OpenVLA）虽让VLM直接作为行动者，却因动作分词效率低下（逐维度逐时间步分箱）而难以扩展到高频、高维、长时程控制。
- **本文立场**：作者主张回归自回归路线，但解决其原始瓶颈（过度动作分词化）——让VLM成为**能推理、能行动、能记忆、能上下文自适应**的统一自回归生成器，而非在其之上堆叠越来越复杂的动作专家。论文的核心含义是：**VLA的前进方向是让VLM保持预训练所赋予的自回归推理者本质，同时学会行动。**

### 2. 方法论

#### 核心思想
G0.5将感知、推理与动作统一在**单一自回归过程中**，共享同一词汇表、同一组权重、同一交叉熵目标。推理token与动作token在同一前向传播中生成，由同一个解码器输出。

#### 关键技术细节

- **统一序列模板**：所有输入输出序列化为单一自回归序列，分为条件段（多视角RGB、具身标识、任务指令、本体感觉状态，user端无loss）和生成段（CoT轨迹+动作码，assistant端全量loss，见公式1）。训练损失为：
  L(θ) = -Σ_{i∈G} log p_θ(x_i | x_{<i})
  其中G为生成段token索引。单一loss同时监督CoT生成与动作生成，无辅助回归目标或专家蒸馏。

- **跨具身结构化动作分词器（ActionCodec）**：
  - 将异构机器人动作分解为语义对齐的运动部件（左臂、右臂、左手爪、右手爪、下半身），每部分填充到共享最大维度，训练残差向量量化（RVQ）模型。
  - 引入时间对比损失以提高时间相邻动作的token一致性。
  - 动作跨度展开为R个残差轮次，每轮包含当前激活的DoF组标记及8个动作码，**仅预测活跃部件，空转部件不生成token**——支持稀疏动作预测。
  - 将所有机器人映射到统一的27维动作空间（9+1+9+1+7），插槽填充noop标记，无需每机器人适配器。
  - 与FAST的固定DCT管线不同，该码本是**端到端学习、跨具身设计**的。

- **原生思维链（CoT）**：
  - 四类自描述推理目标：子任务分解（Subtask:）、关键物体定位（BBox:）、2D抓取轨迹（Trace:）、帧级动作提示（ActionHint:）。
  - 每个训练步从8种组合中随机抽取（含无CoT基线），全部在同一next-token目标下监督。
  - 推理token与动作token共享解码器、上下文和目标——不是分离阶段，而是同一生成过程的耦合阶段。
  - 与ECoT/CoT-VLA等外挂推理模块不同，本研究CoT直接参与动作生成过程，并在推理时可通过提示词开关CoT模式，无需重新训练。

- **视觉记忆模块**：
  - 在ViT每4层插入分解的空间-时间注意力模块（跟随π0.7和MEM设计），顺序混合跨时间步和空间patch的信息。
  - 最终层丢弃所有历史token以严格约束计算时延；训练时随机丢弃所有历史帧（30%概率）以防止过拟合。
  - 用连续状态嵌入替代离散文本分词器，使本体感觉输入与对应视觉帧精确同步。

- **预训练**：单阶段训练，混合14种具身机器人数据+Web VQA+具身VQA+自动标注数据。自动标注流水线利用Gemini 3和Doubao Seed 2.0 Pro生成多粒度语言注释，SAM3跟踪生成边界框和掩膜，前向运动学计算2D末端执行器轨迹。每个机器人样本分配8种CoT格式之一（加权随机采样）。优化采用AdamW，视觉塔全程不冻结。

### 6. 主要结论与发现

- **统一自回归流有效**：G0.5在7个基准上全面超越或追平最强基线，证明自回归VLA并非瓶颈，反而具有结构性优势。
- **推理能力向行为迁移**：G0.5零样本语言跟随率超过经后训练的π0.5，表明AR动作监督**保护而非削弱**VLM的指令跟随能力。
- **预训练表征高效迁移**：BEHAVIOR上单epoch后训练即超过π0.5四epoch和四检查点冠军，说明预训练backbone承载了通用移动操作先验。
- **CoT在阶段条件任务中收益大**：CoT对单阶段任务几乎无帮助（PP Bench仅~1.6pp提升），但对五阶段长时程任务提升显著（AR进度分2.4→3.8），表明CoT价值在任务以阶段条件子目标序列呈现时最大。
- **AR比FM头更受益于CoT**：同一CoT下AR提升远超FM头，推测源于AR token与CoT同流可直接注意力交互，而FM头只能条件于池化摘要。
- **AR原生支持RL**：token级对数概率直接供GRPO等比例型RL算法使用，无需SDE重表述等额外变换，收敛更快更稳。
- **数据分布决定下游强弱项**：预训练分布以pick-and-place为主→开放空间抓放任务表现强；容器交互类任务（微波炉、橱柜）偏弱但随训练延长显著改善。
- **视觉记忆预训练益处可迁移**：即使后训练用单帧输入，预训练中的时间注意力仍提升导航密集长时程任务表现。

### 7. 优点

- **架构统一性**：单一自回归流、单一目标、单一权重——设计极简而优雅，推理与动作深度融合而非拼接。
- **跨具身分词器设计精细**：结构化动作分解尊重形态学拓扑，活跃部分稀疏预测大幅降低解码负担，统一27维动作空间免去每机器人适配器。
- **原生CoT而非外挂**：推理token与动作token共享解码器与损失，CoT可直接调制后续动作生成——这是结构性创新而非简单拼接。
- **实验全面且分层清晰**：7个基准分别回答不同研究问题，形成“零样本→后训练→长时程→真实世界→语言跟随→上下文→组件消融”的完整验证链条。
- **主动暴露弱点**：诚实报告低对比度抽屉插入的弱点、视觉记忆仅覆盖秒级历史、提示调行为仅为定性观察——较好的学术诚信。
- **RL兼容性验证独特**：AR token的对数概率天然适配RL，这是VLM-as-Encoder范式难以企及的优势。

### 8. 不足与局限

- **实验覆盖偏差**：
  - 真实世界评估仅限自家平台（R1-Lite/R1-Pro），缺乏独立第三方平台验证；DROID评估仅一臂一夹具。
  - 下半身驱动（lower_body）虽纳入统一动作空间，但**未单独评估**。
  - 零样本探测样本量极小（n=5），结论统计效力弱。
- **感知局限**：抽屉插入和半透明橱柜任务弱，高对比度标记将G0.5从60%拉到100%而基线几乎不变，说明G0.5在低视觉对比度下可靠定位能力不足——作者承认是“感知限制，AR无法单独解决”。
- **视觉记忆范围有限**：仅覆盖多秒历史，长时程记忆（分钟级）未解决。
- **定性声明未系统化**：提示词调控行为（副词、空间线索、近义动词）仅为定性观察，作者自认需系统研究。
- **零样本定义存在争议**：DROID评估是“环境+物体级零样本”而非数据集级零样本（先经DROID后训练）；长时程零样本任务虽场景不在预训练分布中，但使用了阶段条件提示——这是一种受控的评估模式而非完全自然交互。
- **基础模型依存**：初始化自Qwen3.5 2B，可能引入该基础模型的固有偏置和局限。
- **预训练数据细节披露有限**：14种具身的清单、各类数据配比、总token数等关键信息未明示，复现门槛较高。
- **与π0.5的对比在容器交互类任务上仍有明显劣势**（如microwave popcorn: 0.55 vs 0.95），说明通用性仍受预训练分布显著制约。
