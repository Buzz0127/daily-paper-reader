## 摘要
现代视觉-语言-动作（VLA）策略已获得广泛的操作技能，但通常从当前观察或短的固定长度历史中生成每个动作块。然而，现实世界的操作往往是非马尔可夫的，要求机器人从长时程交互历史中保留并推理与任务相关的信息以决定下一步动作。为应对这一挑战，我们提出HyMeS，一种混合学习框架，利用编码代理的推理和记忆管理能力来引导马尔可夫VLA进行记忆依赖的操作。具体而言，HyMeS通过基于梯度的模仿学习学习低级运动技能，而编码代理则通过启发式学习获取高级记忆管理策略，即从回滚反馈中迭代更新可执行的启发式系统。此外，我们通过多模态阶段完成验证来闭环引导与执行之间的循环，利用本体感觉信号和多帧VLM判断更新记忆。与端到端的记忆增强VLA相比，HyMeS仅需针对可复用运动技能的示范，而非每个历史依赖的任务配置，从而实现了数据高效的组合泛化。在RoboMemArena上，HyMeS将平均累积成功率从52.5%提升至66.2%，平均任务成功率从41.3%提升至60.1%，优于pi0.5，并在累积成功率上超过PrediMem 4.5个百分点，任务成功率上超过14.5个百分点。

## Abstract
Modern vision-language-action (VLA) policies have acquired broad manipulation skills, but typically generate each action chunk from the current observation or a short fixed-length history. However, real-world manipulation is often non-Markovian, requiring robots to retain and reason over task-relevant information from long-horizon interaction histories to determine the next action. To address this challenge, we propose HyMeS, a hybrid learning framework that leverages the reasoning and memory-management capabilities of coding agents to steer a Markovian VLA for memory-dependent manipulation. Specifically, HyMeS learns low-level motor skills through gradient-based imitation learning, while a coding agent acquires high-level memory-management strategies through heuristic learning by iteratively updating an executable heuristic system from rollout feedback. Furthermore, we close the loop between steering and execution through multimodal stage-completion verification, which updates memory using proprioceptive signals and multi-frame VLM judgments. Compared with end-to-end memory-augmented VLAs, HyMeS requires demonstrations only for reusable motor skills rather than for every history-dependent task configuration, enabling data-efficient compositional generalization. On RoboMemArena, HyMeS improves mean cumulative success from 52.5% to 66.2% and mean task success from 41.3% to 60.1% over pi0.5, while outperforming PrediMem by 4.5 points in cumulative success and 14.5 points in task success.

## 一、核心问题与整体含义（研究动机与背景）

- **核心瓶颈**：现代视觉-语言-动作（VLA）模型虽然已获得广泛的操作技能，但其天然具有**马尔可夫性**——每个动作块仅由当前观测或短固定长度历史生成，无法处理真实世界中普遍存在的**非马尔可夫任务**。
- **现实场景的鸿沟**：真实操作往往需要从长时程交互历史中提取任务相关信息以决定当前动作。例如，按按钮的次数由卡片上数字决定，但卡片只在任务开始时可见；当第一按完成、手臂抬起后，当前观测本身无法区分"继续按"与"提起结束"两种互斥的动作模式。
- **现有方案的局限**：
  - **端到端记忆增强VLA**（如PrediMem）将记忆机制嵌入网络权重并联合训练，导致记忆获取与运动学习紧密耦合，需要大量覆盖组合记忆配置的昂贵专家演示，且存在灾难性遗忘、潜在记忆缓冲区难以检查和编辑等问题；
  - **推理时引导类方法**（如VLS）虽然保持策略冻结，但引导是反应式的，仅依赖当前观测，无法维持任务级记忆。
- **本文提出的范式转变**：将记忆问题从"学习历史表征"转变为"学习记忆管理策略"，把**技能放在权重中、记忆放在代码中**，实现数据高效的组合泛化——示范只覆盖可复用的运动技能，而无需枚举所有历史依赖的任务配置。

## 二、方法论：HyMeS混合学习框架

### 核心思想

HyMeS（**Hy**brid learning for **Me**mory-dependent manipulation with a coding agent to **S**teer a Markovian VLA）将学习过程解耦为两个互补的组成部分，通过不同的学习机制获取各自能力：

| 组件 | 学习内容 | 学习空间 | 学习方式 |
|------|----------|----------|----------|
| VLA策略 | 低级运动技能 | 权重空间 | 梯度模仿学习（flow matching微调） |
| 编码代理 | 高级记忆管理策略 | 代码空间 | 启发式学习（基于rollout反馈迭代修订可执行启发式程序） |

### 关键技术细节

1. **权重空间中的运动技能学习**：以预训练VLA（如π0.5）初始化马尔可夫流匹配策略πθ(aₜ|oₜ, ℓ)，通过标准flow matching目标微调速度场。微调完成后的策略权重固定不变，记忆获取不修改任何网络参数。

2. **代码空间中的记忆策略学习**：编码代理迭代维护可执行程序 P = (C, V, U)，包含约束选择规则C、事件验证规则V、记忆更新规则U。记忆状态显式表示为 st = (plan, ρₜ, Bₜ, Nₜ, Fₜ)，包含阶段计划、当前阶段、任务绑定、重复事件计数和持久交互状态。编码代理通过 rollout 得到的符号执行追踪 ξₙ 与基准阶段判定 bₙ 对比，定位失败阶段，诊断约束奖励设定或验证规则问题，修订程序：P⁽ⁿ⁺¹⁾ = Edit(P⁽ⁿ⁾, ξₙ, bₙ)。

3. **记忆条件动作引导（Steering）**：根据当前阶段 ρₜ 和符号记忆 st 选择可微约束 Rρₜ(a, oₜ; st)（如到达阶段实例化末端位置与语义目标间的距离约束），将其梯度注入流匹配速度场：**v̂ = vθ⋆(aτ, τ|oₜ, ℓ) + λₜ∇Rρₜ(aτ, oₜ; st)**，引导去噪过程选择与当前记忆状态一致的动作模式。λₜ 采用sigmoid衰减调度，在接近交互区域时减弱引导，让学习到的运动策略主导接触丰富的执行。

4. **多模态进度验证与记忆更新（PACE）**：双证据流融合——本体感觉证据检测动作依赖的运动模式并维护持久事件，Qwen3-VL-8B视觉证据基于至多5帧RGB图像判断阶段完成（区分进行中与已完成动作）。两条通道的二元判定做逻辑或合并，并在滑动窗口（w=5, k=3）内做投票抑制孤立错误：et = I[Σdᵢ ≥ k]。事件通过后更新记忆并激活下一阶段约束。

## 六、主要结论与发现

1. **核心有效性**：在完全相同的策略权重下，HyMeS在仿真中实现 CSR 从52.5%→66.2%、TSR 从41.3%→60.1%的显著提升，验证了"权重中的技能+代码中的记忆"设计范式的有效性。

2. **相比端到端记忆增强方法更优**：HyMeS相比PrediMem在TSR上大幅领先14.5个百分点，说明将中间进度转化为完整任务成功的能力更强，即混合设计优于将记忆嵌入权重的端到端方案。

3. **类别差异**：
   - 最大TSR增益出现在计数（+30.0）、转移（+26.6）、序列任务（+22.5），归功于显式计数器、对象-位置关联和阶段状态的维护；
   - 遮挡是记忆注入最困难的类别：PrediMem甚至低于反应式π0.5（CSR 38.3% vs. 50.4%），显示不可靠的记忆会主动误导执行；HyMeS在CSR上与π0.5持平（50.6%）但TSR提升7.0点，说明已验证的阶段转换能限制错误绑定的危害。

4. **真实场景验证**：SO-101上TSR从25.7%提升至57.1%（+31.4点），且单个符号状态同时支持线索保留、计数和源-位置关联三种记忆能力。

5. **消融发现**：
   - rollout经验学习使CSR和TSR分别提升8.5和18.4个百分点；
   - 单一验证信号均导致性能明显下降（纯视觉：CSR-16.0/TSR-21.7；纯本体感觉：CSR-8.8/TSR-8.4），双信号互补证据使阶段转换更可靠。

6. **可解释性价值**：符号记忆在每个控制步可读，失败可定位到记忆更新、运动执行或事件验证三个环节，为后续改进提供方向。

## 七、优点

1. **范式创新性强**：将"记忆"从隐式权重表征转变为显式可执行代码，实现记忆逻辑与运动技能的解耦，概念上简洁而有效。

2. **数据效率显著**：演示预算随可复用技能数量扩展而非随历史依赖配置数扩展，新记忆配置（不同目标颜色、不同计数要求）只需编辑代码空间程序，无需重新采集演示。

3. **不修改策略权重**：记忆获取过程完全不涉及策略权重的梯度更新，避免了端到端记忆增强方法的灾难性遗忘问题；完全冻结的π0.5验证了该方法的即插即用特性。

4. **强可解释性**：符号记忆状态在每个控制步可读，失败可逐步定位到记忆更新、运动执行或验证环节，大大降低了调试和分析难度。

5. **双向闭环设计**：不同于现有单向引导方法（VLS等），PACE将执行反馈（本体感觉+视觉）读回用于事件检测和记忆更新，形成记忆条件约束与物理执行之间的双向耦合。

6. **实验设置严谨**：同权重对比隔离变量、修正基准协议中的误报、排除非记忆因素干扰的任务选择策略，都体现了实验设计的客观性。

7. **引导衰减调度**：sigmoid衰减机制让记忆引导在全局行为选择阶段主导，在接触丰富执行阶段让位于学习到的运动策略，兼顾了引导效果和执行鲁棒性。

## 八、不足与局限

1. **任务表示范围有限**：当前方法仅适用于历史信息可被紧凑符号状态（st）表征的任务；对于需要隐式、层次化或连续记忆表示的任务，该框架可能需要扩展。

2. **运动能力依赖**：任务成功仍受底层VLA运动能力制约——正确记忆+适当引导并不能保证接触丰富的执行成功（如文中展示的瞄准偏差导致的抓取失败），HyMeS无法修复策略本身的运动缺陷。

3. **遮挡场景的视觉验证鲁棒性不足**：在多帧VLM判断在遮挡条件下的可靠性最差，导致遮挡任务类型上CSR未能超过反应式基线。

5. **实验规模有限**：真实机器人仅3个任务，每任务试验次数较少（10-15次）；仿真中每任务10-20回合；未报告标准差、置信区间或多种子实验，统计稳健性有待增强。

6. **编码代理依赖**：启发式学习依赖Opus 4.8（闭源商业模型）的程序修订能力，方法的可复现性和对底层LLM能力的敏感性未做系统分析和替代方案测试。
