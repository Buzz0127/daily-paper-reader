## 摘要
具身视觉运动模型（包括扩散策略（DP）和视觉-语言-动作（VLA）模型）已在机器人操作基准测试中展现出令人瞩目的性能。然而，其潜力仍从根本上受限于大规模具身轨迹数据的稀缺，导致在分布外（OOD）场景中的组合泛化能力不足，且难以捕获可复用的技能结构。为解决这一局限，我们提出基于技能的具身记忆（SkillMemo）框架，该框架将长视距演示隐式分解为潜在原子技能，并将技能级特征集成到动态情景记忆库中，以解决组合任务。具体而言，我们首先引入一个基于混合专家（MoE）架构的专家引导轨迹分割模块，该模块通过学习的门控系数将轨迹隐式划分为不同的技能原语。我们进一步设计了一种技能级情景记忆架构，将紧凑的技能表示存储为可检索的键值对。在推理过程中，记忆库检索出最相关的技能原语，并将其与模型当前的门控分布融合，为细化动作预测提供稳健的上下文先验。在仿真基准和真实世界操作任务上的大量实验表明，SkillMemo能够一致性地提升DP和VLA骨干网络的性能，达到最先进水平，并优于π_{0.5}，同时展现出对未见任务配置的强大组合泛化能力。

## Abstract
Embodied visuomotor models, including Diffusion Policy (DP) and Vision-Language-Action (VLA) models, have demonstrated promising performance on robotic manipulation benchmarks. However, their potential remains fundamentally constrained by the scarcity of large-scale embodied trajectory datasets, leading to insufficient compositional generalization in out-of-distribution (OOD) scenarios with limited capability to capture reusable skill structures. To address this limitation, we propose Skill-Based Memory (SkillMemo) framework that implicitly decomposes long-horizon demonstrations into latent atomic skills and integrates skill-level features into a dynamic episodic memory bank for solving compositional tasks. Specifically, we first introduce an expert-guided trajectory segmentation module built upon a Mixture-of-Experts (MoE) architecture, which implicitly partitions trajectories into distinct skill primitives represented by learned gating coefficients. We further design a skill-level episodic memory architecture that stores compact skill representations as retrievable key-value pairs. During inference, the memory bank retrieves the most relevant skill primitives which are subsequently fused with the model's current gating distribution, providing a robust contextual prior to refine action predictions. Extensive experiments on the simulation benchmark and real-world manipulation tasks demonstrate that SkillMemo consistently enhances both DP and VLA backbones, achieving state-of-the-art performance and outperforming $π_{0.5}$, while exhibiting strong compositional generalization to unseen task configurations.

## 2. 方法论：核心思想、关键技术细节

### 2.1 整体框架

- SkillMemo 包含两个核心模块：
  1. **专家引导轨迹分割（Expert-Guided Trajectory Segmentation, EGTS）**
  2. **技能级记忆架构（Skill-Level Memory Architecture, SLMA）**

### 2.2 EGTS：隐式技能分解

- 传统方法将整条轨迹作为整体学习，缺乏结构化的技能分解。
- SkillMemo 利用**混合专家（Mixture-of-Experts, MoE）架构**对轨迹进行隐式分割：

$$y_t = \sum_{i=1}^{N} g_i(h_t) \cdot E_i(h_t)$$

其中 $h_t$ 为时刻 $t$ 的中间层特征，$E_i$ 为第 $i$ 个专家网络，$g_i(h_t)$ 为门控权重（gating weight）。每个专家隐式捕获一种重复出现的**局部运动原语**，而门控网络随时间变化的激活模式隐式定义了技能的时间边界。

- **协同信息正则化**：基于部分信息分解（Partial Information Decomposition, PID）理论，引入损失项：

$$L_{\text{PID}} = -\left[ I(\{A, B\}; G) - I(A; G) - I(B; G) \right]$$

该损失鼓励两个专家的联合表征比各自单独表征携带更多任务相关信息，促进专家形成互补性、非重叠的技能分工。

- 同时采用**负载均衡损失（load-balancing loss）** 和 **top-k 路由策略**，防止专家崩溃（expert collapse）。

### 2.3 SLMA：技能级记忆架构

#### ① 记忆存储（Memory Storage）

- 对每个技能片段计算**质心特征**作为记忆键（key）：

$$k_m = \frac{1}{L} \sum_{t \in \tau_m} h_t$$

- 将片段的**完整门控权重序列**作为记忆值（value）：

$$\mathcal{M} = \{(k_m, v_m) \mid v_m = \{g(h_t)\}_{t \in \tau_m}\}_{m=1}^{M}$$

这种设计保留了技能的动态时序信息，同时通过质心聚合保证了检索效率。

#### ② 记忆检索（Memory Retrieval）

- 推理时，使用**余弦相似度**计算当前观测特征 $q_t$ 与所有记忆键的相似度：

$$s(q_t, k_m) = \frac{q_t \cdot k_m}{\|q_t\| \|k_m\|}$$

- 选出 top-N 最相关的记忆条目，并通过**可靠性检查**（平均相似度是否超过阈值 $\delta$）决定是否启用记忆。
- 若启用，则将检索到的门控分布与当前门控分布融合：

$$g'(q_t) = \lambda g(q_t) + (1 - \lambda) \frac{1}{N} \sum_{n=1}^{N} v_n[t']$$

其中 $\lambda$ 控制记忆干预强度。

#### ③ 记忆更新（Memory Update）

- 记忆库容量有限（$M_{\text{max}}$），引入**基于使用频率的优先剪枝策略**：
  - 移除时间戳最久远的记忆；
  - 移除长期未被检索到的记忆；
  - 移除在检索中反复未能通过可靠性阈值的低质量记忆。
- 这一机制模拟人类认知中的“遗忘”过程，在记忆多样性与质量之间取得平衡。

## 6. 主要结论与发现

- **SkillMemo 一致提升骨干模型性能**：无论是在 DP 还是 VLA 骨干上，加入 SkillMemo 都能带来稳定提升。
- **达到 SOTA 性能**：π0.5-SkillMemo 在 LIBERO 平均成功率上达到 **98.0%**，比 π0.5 提升 **1.2%**（98.0% vs. 96.8%），比 MemoryVLA 提升 **1.5%**（98.0% vs. 96.5%）。
- **强组合泛化能力**：SkillMemo 在跨套件零样本评估中，在 Goal 套件上训练的模型在未见的 Spatial 套件上达到 75.6%，甚至超过直接在 Spatial 上训练的基础模型（72.1%），证明其能有效**复用和重组已学技能**。
- **隐式技能分解的有效性**：专家激活权重的可视化表明，门控系数在关键动作阶段（如抓取碗、开炉子）出现明显峰值，说明 MoE 路由机制确实学习到了语义上有意义的技能原语。
- **真实世界验证**：SkillMemo 在真实 UR5e 操作任务上显著优于 DP，尤其在高难度任务（如“玉米入锅”+7.5%、“黄油入锅”+12.5%）和未见组合任务上提升明显。

## 7. 优点

- **视角独特**：将“技能学习”与“记忆增强”有机结合，提出技能级别的记忆单元，区别于现有方法中“整体视觉语义记忆”的做法，更具行为层面的可解释性和可复用性。
- **隐式分解避免了显式标注的依赖**：通过 MoE 路由实现无需人工标签的数据驱动技能发现，实用性强。
- **理论支撑充分**：引入 PID 理论的正则化项来促进专家协同与分工，具备较好的理论依据。
- **通用性强**：SkillMemo 作为插件式模块可叠加在多种骨干模型（DP、UniAct、UniVLA、π0.5）上，适用面广。
- **记忆动态管理**：包含存储、检索、可靠性过滤、容量更新与剪枝的完整记忆生命周期设计，贴近现实持续学习场景。
- **实验全面**：覆盖模拟、真实、单任务、组合泛化、消融、专家数量敏感性等多维度评估，结果可信度较高。

## 8. 不足与局限

- **隐式技能的可解释性有限**：虽然实验可视化展示了门控激活与关键动作的对应关系，但隐式分解出的“技能”缺乏语义标签，难以直接用于跨任务的人为干预或策略解释。
- **记忆构建依赖训练集分布**：记忆库存储的是训练阶段见过的技能特征，若新任务涉及的技能完全不在训练分布之内，记忆检索的增益可能下降。
- **推理开销未充分讨论**：论文报告了专家数量对推理时间的影响（N=5 时 3.93s），但未与基线模型做完整的推理延迟对比，也未见真实场景中的实时性评估。
- **真实实验仅验证 DP 骨干**：VLA 模型在真实场景中的 SkillMemo 增强效果未被验证，削弱了结论的普适性。
- **跨套件零样本泛化的“零样本”纯度存疑**：LIBERO 各套件共享物体、布局与操作语义，真正的开放世界 OOD 泛化仍需在更异构的任务环境中验证。
- **超参数依赖**：$\lambda$（记忆干预强度）、$\delta$（可靠性阈值）、$N$（专家数）、$M_{\text{max}}$（记忆容量）等超参数对性能影响较大，论文未提供系统的敏感性分析。
- **未与显式技能分割方案对比**：论文主要在隐式分解框架内验证，未与显式构建技能库的方法（如 RoboMatrix、Atomic Skill Library 等）在同一框架下进行直接对比。
