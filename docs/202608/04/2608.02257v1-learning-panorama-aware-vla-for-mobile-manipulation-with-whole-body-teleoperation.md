## 摘要
移动操作是具身智能的关键能力，使机器人能够在开放世界环境中完成复杂的多阶段任务。然而，移动操作对视觉-语言-动作（VLA）策略提出了两个关键挑战：在数据层面，高效采集高质量的全身演示需要移动基座和机械臂的协调控制；在模型层面，现有的VLA模型主要依赖局部相机观测，其有限的视野阻碍了全局空间理解。为解决这些挑战，我们开发了一个全身遥操作系统和一个全景感知的VLA策略。该系统通过单一VR接口实现对轮式双臂机器人的协调控制，并支持获取包含5.5小时多模态演示的真实世界移动操作数据集。在此数据集基础上，我们提出了PanoVLA，一种用于移动双臂操作的全景感知视觉-语言-动作策略。PanoVLA基于Mixture-of-Transformers架构，通过专门的全景编码和融合模块引入全局空间上下文，使全景观测与语言指令和机器人状态有效集成以生成动作。在四个真实世界移动操作任务上的评估表明，PanoVLA实现了91.3%的平均阶段完成率和73.4%的端到端成功率，显著优于局部视图基线。这些结果表明，整合全景空间上下文提高了移动机器人的空间理解和闭环操作性能。

## Abstract
Mobile manipulation is a key capability for embodied intelligence, enabling robots to accomplish complex multi-stage tasks in open-world environments. However, mobile manipulation poses two key challenges for vision-language-action (VLA) policies: At the data level, the efficient collection of high-quality whole-body demonstrations demands the coordinated control of both the mobile base and the robotic arms; at the model level, existing VLA models predominantly rely on local camera observations, whose limited field of view hinders global spatial understanding. To address these challenges, we develop a whole-body teleoperation system and a panoramic-aware VLA policy. The system enables coordinated control of a wheeled bimanual robot through a single VR interface and supports the acquisition of a real-world mobile manipulation dataset comprising 5.5 hours of multimodal demonstrations. Building upon this dataset, we propose PanoVLA, a panorama-aware vision-language-action policy for mobile bimanual manipulation. Built upon a Mixture-of-Transformers architecture, PanoVLA introduces global spatial context through dedicated panorama encoding and fusion modules, enabling effective integration of panoramic observations with language instructions and robot states for action generation. Evaluation on four real-world mobile manipulation tasks demonstrates that PanoVLA achieves an average stage completion rate of 91.3\% and an end-to-end success rate of 73.4\%, substantially outperforming local-view baselines. These results demonstrate that incorporating panoramic spatial context improves spatial understanding and closed-loop manipulation performance in mobile robots.

## 1. 核心问题与整体含义（研究动机与背景）

移动操作（Mobile Manipulation）是具身智能领域的核心能力，要求机器人在开放世界中完成搜索目标、移动接近、双臂协同操作等多阶段复杂任务。论文指出，将VLA模型从桌面操作推广到移动双臂机器人面临两大耦合挑战：

- **数据层面**：高质量全身演示的采集需要同时协调移动基座与双臂的运动。现有遥操作系统大多将移动基座与机械臂的控制解耦（如基座使用摇杆、手臂使用操作器），导致示范动作不够流畅，尤其在大范围接近、搬运和操作任务中。
- **模型层面**：现有VLA模型主要依赖前视和腕部相机等局部观测，视野受限。在基座平移、旋转以及机械臂自遮挡的情况下，目标物体或关键区域容易移出视野，导致机器人缺乏机器人中心的全局空间理解。

论文的核心命题是：**全景观测（Panoramic Observation）能够提供机器人中心的全局空间上下文，从而弥补局部视野不足的问题**，而关键在于如何有效编码全景图像（其非透视畸变与常规预训练视觉编码器存在显著域差距）并将其融入VLA动作生成流程。

## 2. 研究方法论

### 2.1 全身遥操作系统（数据采集）

- **硬件接口**：操作者佩戴VR头显（6-DoF头部追踪）、双手持控制器（手部姿态与夹爪指令）、腰部及双踝共三个身体追踪器。
- **姿态重建**：将稀疏追踪数据实时重建为SMPL人体模型，提取骨盆运动、足部运动及双手姿态作为重定向输入。
- **运动重定向（GMR）**：将机器人配置参数化为 q = (x_b, y_b, θ_b, q_L, q_R)，即平面基座位姿加双臂关节配置。通过优化目标求解：

  q* = argmin_q [λ_pos L_pos + λ_rot L_rot + λ_base L_base + λ_reg L_reg]

  其中 L_pos 对齐手与夹爪位置，L_rot 对齐手与末端执行器姿态，L_base 将基座平面运动与操作者骨盆位移和朝向耦合，L_reg 惩罚关节极限和过度构型变化。移动基座被建模为3-DoF平面虚拟浮动基座，与双臂关节联合优化。

- **模式切换策略**：为在物理基座上执行虚拟3-DoF命令，提出基于代价驱动的模式切换策略——每个控制周期在自旋、阿克曼转向、斜向平移三种运动模式中选择代价最低者执行，定期动态切换以跟踪操作者意图。

### 2.2 PanoVLA模型

- **整体架构**：基于Mixture-of-Transformers（MoT）的三专家架构，由VLM专家、全景专家和动作专家组成。采用块级因果注意力掩码——块内双向注意力，后续块可关注自身及前面块。
- **全景编码器（Panorama Encoder）**：三阶段流程——球面重投影（将双鱼眼图像映射为ERP全景图）、全景特征提取（使用MTPano全景基础模型，融合语义分割与深度估计分支特征）、token适配（自适应平均池化压缩空间分辨率，MLP映射到全景专家隐藏维度）。
- **全景专家（Panorama Expert）**：通过KV缓存（KV Cache）作为融合接口。VLM专家从局部观测、语言指令和本体感知状态生成C_vlm，全景专家在全景token上执行与C_vlm的联合自注意力，生成全景缓存C_pano，动作专家联合使用两个缓存预测动作。
- **训练目标**：采用条件流匹配（Conditional Flow Matching），学习条件速度场：L = E[||v_act(x_τ, τ|C_t) - u(x_τ|a)||²]。

## 3. 实验设计

### 3.1 数据集与Benchmark

- **遥操作系统**采集了包含**800条成功轨迹、约5.5小时、约50万帧同步数据**的真实世界数据集，每条轨迹20–30秒，25Hz采样率。
- 数据模态包括：局部RGB观测（前视+双腕部相机）、顶装360度全景观测（ERP格式）、本体感知状态（双臂绝对关节位置、夹爪状态、基座平面位姿）、全身动作（17维：14维双臂+夹爪、3维基座速度命令）。
- **四个真实世界任务**（每个任务200条轨迹）：
  | 任务 | 目标 | 空间设置 |
  |------|------|----------|
  | Move Pen | 将笔放入笔筒 | 前方/左/右 |
  | Move Block | 将积木转移到前方区域 | 左/右/双侧 |
  | Open Curtain | 打开两侧窗帘 | 左/右 |
  | Wipe Table | 擦拭污渍并归还毛巾 | 长桌 |

### 3.2 对比方法（Baselines）

- **π0.5**：仅使用局部相机视图的标准VLA基线。
- **π0.5 w/ Pano**：将ERP全景图作为额外图像输入，用与局部视图相同的SigLIP编码器处理，不设专门全景分支。
- **π0.5 w/ Stacked Pano**：将全景重投影为三个视角（光轴间隔120°）并拼接为复合图像输入。
- **PanoVLA**：本文方法，MTPano编码+全景专家融合。

### 3.3 评估协议

- 每个任务15次闭环真实机器人试验，单次不间断 rollout，无手动重置。
- 指标：**成功率（SR，任务级二元指标）**和**阶段完成率（SCR，各阶段完成比例平均）**。

## 6. 主要结论与发现

- **全景上下文显著提升移动操作性能**：PanoVLA平均阶段完成率91.3%、端到端成功率73.4%，远高于局部视图基线π0.5（58.6% SCR、30.0% SR）。
- **全景感知需要专门设计而非直接拼接**：直接将ERP图经SigLIP编码（π0.5 w/ Pano）虽有提升（80.8% SCR、56.7% SR），但表现不稳定（Wipe Table SR仅20.0%）；将全景重投影为透视图拼接（Stacked Pano）平均SCR仅70.4%，表明全景几何建模方式至关重要。
- **全景专家有效支持多阶段状态跟踪**：在Wipe Table任务中，PanoVLA与π0.5 w/ Pano的SCR差距不大（84.4% vs 74.4%），但最终SR差距显著（46.7% vs 20.0%），说明全景专家能维持跨阶段的全局空间一致性，帮助机器人可靠地重新定位毛巾并归还。
- **MTPano优于SigLIP作为全景编码器**：MTPano在Move Pen上SCR 95.6% vs SigLIP 75.6%；100M专家参数量是数据效率与表达能力的较优平衡点。

## 7. 优点

- **任务与数据设计扎实**：构建了包含全景观测的全身遥操作数据采集系统，数据集包含800条真实轨迹、多模态同步记录，任务设计覆盖不同目标方向、双侧交互和长距离操作，涵盖多样的空间布局，为后续研究提供了有价值的基准。
- **模型设计具有清晰动机**：全景编码器采用专门的全景基础模型（MTPano），通过语义+深度特征融合应对全景非透视畸变的域差距；KV缓存作为融合接口的设计简洁高效，无需修改VLM主干。
- **模块化的MoT架构**：在π0.5基础上插入全景专家，可复用已有VLA骨干，方法论上便于推广。
- **公平的对比设置**：三个基线仅在全景建模方式上变化，其余训练数据与优化设置保持一致，有效隔离了变量。
- **消融覆盖关键设计维度**：专家规模与编码器选择两个消融直接支撑了核心设计决策。

## 8. 不足与局限

- **统计功效有限**：每任务15次试验的样本量偏小，缺乏多次重复或置信区间报告，结论可能受随机波动影响。
- **消融范围不足**：消融仅在Move Pen任务上执行，未覆盖需要多阶段状态跟踪的Open Curtain和Wipe Table任务，结论泛化存疑。
- **模型规模扩展性未验证**：300M专家反而不如100M（73.3% vs 86.7% SR），论文将其归因于数据量有限，但未提供不同数据规模下的扩展性实验。
- **基座运动模式切换可能抑制操作灵活性**：物理基座仅能执行自旋、阿克曼转向、斜向平移三种模式之一，模式切换延迟可能限制复杂连续运动。
- **未与其他最新VLA方法对比**：未与Stable π0.5或π0.7等替换视觉编码器的方法对比。
- **任务范围有限**：四个任务均为室内近距操作场景，未涉及更复杂的导航-操作长时程任务或动态环境；目标物体种类有限，泛化性未验证。
- **训练细节报告不够完整**：未报告端到端训练时长、数据预处理细节（如本体感知归一化范围的确定方式）、MTPano冻结对全景特征适配的影响等。
- **基线公平性存疑**：π0.5 w/ Pano直接使用SigLIP编码全景图可能因预训练偏差处于劣势，但未尝试对SigLIP做全景数据适配；且MTPano参数量远超SigLIP，计算开销差异未在表中报告。
- **单平台验证**：仅在RANGER MINI + Piper双臂机器人上验证，未展示跨平台迁移能力。
