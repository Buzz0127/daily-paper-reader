## 摘要
世界行动模型（WAMs）根据预测的未来来调节机器人动作，但迭代的视频展开增加了部署延迟。我们探讨动作生成是需要不断演化的展开轨迹，还是仅仅需要其未来表示。在全部40个LIBERO任务上，对四个WAMs进行的配对的闭环干预表明，遮罩或重新赋值未来缓存值会改变执行并降低成功率，这表明对未来值及其分配位置的敏感性。然而，对于Joint和Cosmos-2，重放一个固定的最终干净键/值（K/V）缓存几乎可以保持未经修改的执行，末端执行器平均位移误差为1.7至1.9厘米，成功率为97.9%至98.2%。这将缓存消费与生产分开：这些模型可以重用固定缓存，但仍需要迭代展开来构建它。因此，我们提出RIFT（通过未来令牌的无展开想象），它使用学习的预期令牌在一次骨干网络前向传播中构建完整的未来K/V缓存，同时保留原有的未来读取接口。在LIBERO上，RIFT实现了98.8%的成功率，接近基于展开的Joint、IDM和LingBot-VA的98.4%至98.6%，同时将动作块延迟降低了68.2%至89.1%。在RoboTwin 2.0上，RIFT在清洁/随机场景中达到92.9/92.6%的成功率，这是所评估方法中观察到的最高值。这些结果支持在部署时无需迭代视频生成的无展开未来条件设定。

## Abstract
World action models (WAMs) condition robot actions on predicted futures, but iterative video rollout increases deployment latency. We ask whether action generation requires the evolving rollout trajectory or only its future representation. Across four WAMs on all 40 LIBERO tasks, paired closed-loop interventions show that masking or reassigning future-cache values changes execution and reduces success, indicating sensitivity to future values and their assigned positions. For Joint and Cosmos-2, however, replaying one fixed final-clean key/value (K/V) cache nearly preserves unmodified execution, with $1.7$ to $1.9$~cm end-effector average displacement error and $97.9\%$ to $98.2\%$ success. This separates cache consumption from production: these models can reuse a fixed cache but still require iterative rollout to construct it. We therefore propose RIFT (\emph{Rollout-free Imagination via Future Tokens}), which uses learned anticipation tokens to construct a complete future K/V cache in one backbone pass while retaining the original future-read interface. On LIBERO, RIFT achieves $98.8\%$ success, close to rollout-based Joint, IDM, and LingBot-VA at $98.4\%$ to $98.6\%$, while reducing action-chunk latency by $68.2\%$ to $89.1\%$. On RoboTwin~2.0, RIFT reaches $92.9/92.6\%$ on clean/randomized scenes, the highest observed among the evaluated methods. These results support rollout-free future conditioning without iterative video generation at deployment.

## 1. 核心问题与研究动机

- **背景**：世界行动模型（WAMs）将未来视频预测与机器人控制耦合——单个网络先预测一段短未来视频，再以此预测为条件生成动作。这种"未来读取"（future read）机制显著提升了任务成功率。
- **痛点**：然而，未来的构建依赖迭代式视频生成（rollout），导致部署延迟是"仅当前状态"策略的 **3.3× 至 9.6×**。
- **已有方案的不足**：
  - Fast-WAM 在部署时丢弃未来分支；PFD 将未来校正蒸馏进当前路径。二者虽降低延迟，但与显式读取未来表示的策略仍有性能差距。
  - 关键混淆：现有对比同时改变了"未来表示的可用性"和"构建该表示的过程"（rollout），因此无法回答：**动作生成究竟需要逐步演化的 rollout 轨迹，还是仅需要其最终的未来表示？**
- **本文核心问题**：能否在保留显式测试时未来条件化的前提下，**完全跳过迭代视频 rollout**？

## 2. 方法论

### 2.1 核心思想（先分析、再设计）

论文分两步推进：

1. **干预分析（定位问题）**：以未来位置的 K/V 缓存（future cache）为干预位点，在 4 个 WAMs 上进行配对闭环干预，分离"缓存消费"与"缓存生产"。
2. **方法设计（解决问题）**：提出 **RIFT（Rollout-free Imagination via Future Tokens）**，用学习到的 anticipation tokens 在**一次骨干网络前向**中构建完整的未来 K/V 缓存。

### 2.2 干预实验设计（关键洞察）

- 干预协议：
  - **记录**：正常生成视频，存储逐层、逐去噪步的未来 K/V。
  - **重放**：固定非目标输入，替换或编辑未来 K/V。
  - **度量**：末端执行器平均位移误差（EE-ADE，cm）与任务成功率（SR），采用配对执行（同初始状态、同策略种子）。
- 干预类型：
  - **Masked future**：遮罩未来读取；
  - **Noise / Frozen present**：注入噪声或冻结当前帧值；
  - **Spatial shuffle / Temporal swap**：空间置换 / 时间交换未来值；
  - **Final-clean replay**：将最终干净 K/V 缓存固定重放于所有去噪步。
- 关键发现：
  - 动作对**未来值内容及其位置**高度敏感（mask 将成功率从 98.4% 降至 9.7%）；
  - 但对**值的演化过程**不敏感——固定同一份最终干净 K/V，Joint 和 Cosmos-2 仍保持 97.9%–98.2% 成功率，EE-ADE 仅 1.7–1.9 cm。

### 2.3 RIFT 方法细节

- **架构**：保留 Fast-WAM-Joint 架构和未来读取接口；Wan2.2-5B 视频 DiT + 1B 动作专家（共约 6B 参数）。
- **缓存写入（一次前向）**：

  \[
  C_\phi(o, l) = \text{CachePrefill}_\phi([f_0(o); E], o, l)
  \]

  其中 \(E \in \mathbb{R}^{m \times d}\) 为可学习 anticipation tokens，占据未来时空位置；完整对齐时 \(m = 196\)（LIBERO）或 \(m = 240\)（RoboTwin 2.0）。
- **注意力掩码**：视频 token 不关注动作 token，因此缓存是动作无关的（action-independent），支持记录与重放。
- **动作解码**：

  \[
  \hat{a}_{1:H} = \text{ActionDenoise}(o, l; C_\phi(o, l))
  \]

  固定缓存服务所有去噪求值，与 Finding 2 验证的固定缓存消费模式一致。

### 2.4 训练目标

总损失：

\[
\mathcal{L} = \mathcal{L}_{\text{vid}} + \mathcal{L}_{\text{act}} + \lambda_{\text{FM}} \mathcal{L}_{\text{FM}} + \lambda_{\text{probe}} \mathcal{L}_{\text{probe}}
\]

- \(\mathcal{L}_{\text{vid}}\)：原生视频流匹配监督（无 anticipation tokens）；
- \(\mathcal{L}_{\text{act}}\)：部署匹配的动作流匹配损失，仅对干净行计算；
- \(\mathcal{L}_{\text{FM}}\)：在最终 anticipation states \(S_\phi\) 条件下，对真实未来 \(Y\) 做条件流匹配：
  \[
  X_\sigma = (1-\sigma)Y + \sigma\epsilon,\quad v^\star_\sigma = \epsilon - Y
  \]
- \(\mathcal{L}_{\text{probe}}\)：停止梯度的线性探针（RMS 归一化），提供确定性未来潜在读出的诊断信号。

**部署时**：一次 cache prefill → 固定 Cϕ → 标准动作流（10 步 flow matching），无视频去噪、无 VAE 解码。

## 6. 主要结论与发现

1. **位置敏感性（Finding 1）**：WAM 动作专家使用未来值时，其**内容与位置绑定**——遮罩、噪声、冻结、空间置换、时间交换均显著破坏执行；但不同模型的敏感度顺序不同（Joint/IDM 对时间交换最敏感，LingBot-VA 对空间置换最敏感）。
2. **固定缓存充分性（Finding 2）**：对 Joint 和 Cosmos-2，用一份最终干净 K/V 缓存替代演化中的完整缓存，几乎不损失性能（EE-ADE ≤ 1.9 cm，SR ≥ 97.9%）。结论：**动作不需要缓存随去噪演化**，但该缓存仍需通过 rollout 构建——这为 RIFT 提供了设计动机。
3. **RIFT 有效性**：
   - LIBERO：成功率 **98.8%**，超过 Fast-WAM（96.8%）和 PFD（97.3%），与 rollout 方法（98.4%–98.6%）持平；
   - 延迟 **247.9 ms/块**，为 current-only 的 1.1×，较 rollout 方法降低 68.2%–89.1%；
   - LIBERO-Plus：OOD 成功率 **81.1%**，较最强 baseline（Fast-WAM-IDM）高 9.7 个百分点；
   - RoboTwin 2.0：clean/randomized 均为最高（92.9%/92.6%）。

## 7. 方法亮点与优势

- **清晰的问题分解**：将"未来表示消费"与"未来表示生产"彻底分离，先用干预实验定位需求，再有针对性地设计生产机制，逻辑链条完整。
- **干预协议具有方法论价值**：利用 WAM 注意力掩码使缓存动作无关的特性，将因果追踪思想（如 causal tracing）引入机器人策略分析；物理执行提供厘米级的可解释读数，而非潜在空间距离。
- **轻量高效**：一次缓存预填充等价于一次普通视频骨干前向，无视频扩散/解码成本；训练增加的模块（FM head、线性探针）在部署时完全移除。
- **训练技巧严谨**：
  - 双前向设计（原生视频监督 + 部署匹配训练）互不干扰；
  - 70% 课程后引入首帧潜在扰动并排除于动作损失，确保动作训练输入干净；
  - 条件流匹配避免 L2 回归的条件均值塌缩问题；
  - 停止梯度探针不会反向影响部署表示。
- **跨场景迁移验证**：同一接口在 LIBERO 与 RoboTwin 2.0（双臂、域随机化场景）均有效，且 OOD 鲁棒性全面提升。

## 8. 不足与局限

- **仅仿真评估**：LIBERO 与 RoboTwin 2.0 均为仿真环境；文中明确承认"物理机器人仍未验证"。
- **干预覆盖面有限**：仅对 4 个 WAM 模型做干预，且 Cosmos-2 不支持时间交换、IDM 类模型的结构性 N/A 限制了干预矩阵完整性。
- **跨模型对比为描述性**：不同架构、不同预训练来源的模型间数值差异无法严格归一化归因。
- **算力信息披露不足**：未报告 GPU 数量、训练时长与总计算成本，可复现性受一定影响。
- **RoboTwin 2.0 单种子评估**：统计效力弱于 LIBERO，列出的数值差异可能部分来自评估噪声。
- **不确定性监控为旁路**：L2–FM 一致性告警仅作为可选的 shadow mode，未纳入部署延迟，其实际部署价值（如告警误报率、干预成功率）有待进一步实验。
- **干预外推限制**：全文的"固定缓存充分性"针对特定模型族（Joint/Cosmos-2 的共享注意力接口），不代表对所有 WAM 架构均成立。
