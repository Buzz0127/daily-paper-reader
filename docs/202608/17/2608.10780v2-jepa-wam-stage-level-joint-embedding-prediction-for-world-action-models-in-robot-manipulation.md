## 摘要
通用机器人策略旨在将多模态观测和语言任务指令映射到跨多样任务的动作。然而，现有方法通常将未来表示为一个固定的短视频-动作块。这种短期未来捕捉局部场景演变以执行动作，但并未明确描述指定任务如何从当前阶段进展到下一阶段的阶段级未来。因此，我们区分了机器人操作中两个互补的未来：用于捕捉局部场景演变的短期物理未来，以及用于表示任务进展的阶段级语义未来。我们引入了JEPA-WAM，它通过Stage-JEPA（一种目标条件联合嵌入预测架构（JEPA）预测器）增强了基于Motus的世界动作模型（WAM）。给定当前观测和任务指令，Stage-JEPA使用冻结的V-JEPA2编码器提取当前状态表示，并预测下一推断阶段的潜在目标。在干净和随机化环境中的50个RoboTwin 2.0任务中，JEPA-WAM实现了90.25%的总体成功率，并将成功回滚中的平均执行步数相对于最强基线减少了5.97%。

## Abstract
Generalist robot policies aim to map multimodal observations and linguistic task instructions to actions across diverse tasks. However, existing methods typically represent the future as a fixed, short video-action chunk. This short-term future captures local scene evolution for action execution, but it does not explicitly describe the stage-level future that specifies how a task should progress from its current stage to the next. We therefore distinguish two complementary futures for robot manipulation: a short-term physical future to capture local scene evolution and a stage-level semantic future to represent task progress. We introduce JEPA-WAM, which augments a Motus-based World Action Model (WAM) with Stage-JEPA, a goal-conditioned Joint-Embedding Predictive Architecture (JEPA) predictor. Given the current observation and task instruction, Stage-JEPA uses a frozen V-JEPA2 encoder to extract the current-state representation and predicts the latent target of the next inferred stage. Across 50 RoboTwin 2.0 tasks in clean and randomized environments, JEPA-WAM achieves 90.25% overall success and reduces the mean number of execution steps in successful rollouts by 5.97% relative to the strongest baseline.

## 论文总结

### 1. 核心问题与研究动机

- **现有方法的局限**：通用机器人策略（如 VLA）通常直接从观测和指令映射到动作，没有显式建模环境应如何随任务进展而变化；而现有世界动作模型（WAM）虽然联合预测未来视频和动作，但将未来表示为密集时间块，只能捕捉局部运动和接触动态，将任务相关的物体状态或关系变化隐含在稠密时序展开中，缺乏对"下一个有意义的任务阶段状态"的显式描述。
- **关键洞察**：作者将机器人操作的未来建模区分为两种互补的尺度：
  - **短期物理未来**：描述局部场景演变的视频-动作演化；
  - **阶段级语义未来**：指定下一个应达到的物体或关系状态（如空间对齐、机器人-物体交互）。
- **核心问题**：如何让机器人策略在生成局部动作之前，先预测任务进展的下一阶段？像素级目标图像预测不适合此目标，因为它更强调外观而非任务完成。
- **解决思路**：利用联合嵌入预测架构（JEPA）天然适合建模阶段级未来——它在表示空间中预测目标状态的潜在表示，保留任务相关的语义与物理结构，同时对低级外观不敏感。

### 2. 方法论

- **整体框架**：JEPA-WAM 由两个顺序训练阶段组成，将 Stage-JEPA（目标条件 JEPA 预测器）与 Motus 世界动作模型（WAM）耦合。预测的下一阶段潜在表示作为内部进度目标，注入 WAM 以同时指导短视频预测和动作生成。

- **Stage I：训练 JEPA 预测器（Stage-JEPA）**
  - **自动阶段边界构建**：无需人工阶段标签。使用冻结 V-JEPA2 编码器对每个候选中心帧（每 8 帧采样）编码 64 帧片段，通过表示变化评分（基于片段级池化表示的欧氏距离和 token 级最大距离的归一化最大值）和时序 NMS（半径 r=3，最多 K=5）自动选出关键阶段边界；这些边界与首尾帧一起构成阶段序列 B=(b₀,…,b_L)，每个当前帧 t 与其所在阶段 [bᵢ, bᵢ₊₁) 的下一边界 bᵢ₊₁ 构成稠密训练对。
  - **目标条件预测**：冻结 V-JEPA2 编码器，可训练的目标条件预测器（初始化自 V-JEPA2 预测器）和指令适配器。给定当前观测切片 Sᵗ 和指令 l，预测下一阶段潜在表示；通过余弦损失对齐预测潜在与目标潜在：
    - L_stage = (1/B) Σ [1 − (ẑ_targetⁱ)ᵀ z_targetⁱ]

- **Stage II：训练阶段条件 WAM**
  - 冻结 Stage-JEPA，训练 Motus（Mixture-of-Transformers 架构，含视频生成专家、动作专家、视觉-语言理解专家）和条件注入接口。
  - **门控注入机制**：将 Stage-JEPA 输出的预测 token 均值池化后经 MLP 匹配 Wan 视频 token 维度，通过全局标量门控 α=0.2σ(β)（初始化为 0.02）进行加性注入到视频 token 中：X̃_vᵗ = X_vᵗ + αhᵗ。
  - **正则化**：含两项辅助门控损失——λ_g α²（偏置门控向小的残差更新）和 λ_ρ(ρ−ρ₀)²（限制注入强度相对比例）。
  - 训练目标保持 WAM 原生视频和动作损失：L = L_video + L_action + L_reg。

- **闭环推理**：维护因果 64 帧观测缓冲（不足时重复最早帧填充），每次查询时依次执行：Stage-JEPA 预测下一阶段潜在 → WAM 以该潜在为条件预测短视频未来和动作块 → 环境执行动作块后更新缓冲。阶段边界只在训练时使用。

### 3. 实验设计

- **数据集/Benchmark**：RoboTwin 2.0 双机械臂操作基准，覆盖 **50 个任务**，分为干净（clean）和随机化（randomized）两种环境配置。
- **评估协议**：每个任务-配置对执行 100 个闭环回合，共 5,000 回合/配置，10,000 回合/检查点；主要指标为任务成功率。任务按语义分为 7 类：抓取与提升、交接、目标放置、容器装箱、排列与堆叠、关节/设备交互、工具使用与动态操作。
- **对比方法**：
  - GO-1（AgiBot 具身基础模型）
  - π0.5（通用 VLA）
  - X-VLA（大规模跨任务/跨体现预训练的 VLA）
  - Motus（WAM，最强基线）
  - 基线结果引自 Motus 论文，JEPA-WAM 与 Motus 使用相同闭环评估协议。
- **消融实验**（4 组）：
  - w/o JEPA（移除 JEPA 预测器及其阶段引导输入）
  - w/o future-latent injection（不注入未来潜在，仅用于当前观测表示）
  - w/o Stage-I training（不进行阶段配对训练，保留预训练 V-JEPA2 初始化）
  - w/o gate regularizers（移除门控正则化损失）
- **补充实验**：真实机器人 LIFT2（ARX R5）平台上的 2 个任务（Cube_Grasp 和 Power_Strip），各 20 次评估，使用 0-100 任务进度评分，与 π0.5 对比。

### 4. 资源与算力

- **硬件**：8 块 NVIDIA A800 80GB GPU（两个阶段均使用）。
- **Stage I**：冻结 V-JEPA2 编码器（FP16），可学习的预测器和指令适配器（FP32）训练 1,000 步，学习率 1×10⁻⁵，权重衰减 0.01，100 步预热；每 GPU batch size 32，有效 batch size 256。
- **Stage II**：BF16 训练 4 个完整 epoch，学习率 1×10⁻⁶，权重衰减 0.01，200 步预热；每 GPU batch size 4，梯度累积 8 步，有效 batch size 256（4×8×8）。
- **模型规模细节**：V-JEPA2 输入为 64 帧 256×256 片段，产生 32×16×16=8192 个 token（维度 1024）；预测时采样 512 个上下文 token 位置和 256 个目标 token 位置。

### 5. 实验数量与充分性

- **仿真实验规模**：50 个任务 × 2 种配置 × 100 回合 × 2 个检查点 = 20,000 个闭环评估回合；另含 4 组消融实验（每组同样覆盖全部 50 任务）。

  - **充分之处**：任务覆盖面广（50 个任务涵盖 7 类操作语义），干净/随机双环境设置验证了泛化性；完整的逐任务结果（附录表 6）提供了透明度；消融实验针对核心设计决策逐一验证；补充了真实机器人验证。

### 6. 主要结论与发现

- **成功率**：JEPA-WAM 在干净环境下平均成功率 91.42%，随机化环境 89.08%，整体平均 90.25%，超过所有基线（Motus：88.66%/87.02%）。
- **类别层面**：在 7 个语义类别中，JEPA-WAM 在干净设置下 5 类最优、随机化设置下 6 类最优。提升最显著的是交接（Handover）、目标放置和容器装箱等依赖显式任务进度转换的类别。
- **执行效率**：JEPA-WAM 将整体平均回合长度从 156.28 步降至 132.80 步（相对 Motus 减少 15.02%）；仅考虑成功回合时，平均长度从 79.57 降至 74.82 步（减少 5.97%）。
- **消融结果**：
  - 移除 JEPA 造成最大性能下降（说明阶段条件路径提供超出短时 WAM 主干的信息）；
  - 不注入未来潜在也会降低性能（支持直接注入 WAM 表示而非仅修改当前观测）；
  - 无 Stage-I 训练仍具竞争力（预训练 V-JEPA2 已提供有用的通用视觉结构），但在干净/随机/整体上均非最优；
  - 移除门控正则化下降较小（sigmoid 有界门控已提供稳定性）。
- **定性分析**：案例研究显示 Motus 存在反复上下移动物体的冗余修正行为，而 JEPA-WAM 更快推进到任务完成阶段。

### 7. 方法亮点

- **概念贡献明确**：清晰地区分短期物理未来与阶段级语义未来，为机器人未来建模提供了新的理论视角。
- **自动阶段监督构建**：无需人工阶段标签，利用冻结 V-JEPA2 特征的表示变化自动推断阶段边界，实用性强且可扩展到其他数据集。
- **两阶段训练设计的合理性**：先学习语义目标（Stage I），再在冻结该目标的前提下学习局部执行细节（Stage II），避免了细节损失干扰语义目标。
- **门控注入机制设计精细**：全局标量门控 + 辅助正则化（幅值约束和相对比例约束）在注入与扰动之间取得平衡。
- **推理时无额外信息需求**：阶段边界和目标切片仅在训练时使用，推理时只依赖因果观测缓冲，保持部署可行性。
- **消融设计针对性强**：每个消融对应一个明确的设计决策，验证逻辑清晰。

### 8. 不足与局限

- **实验覆盖的局限**：
  - 仿真实验仅在 RoboTwin 2.0 一个基准上进行，缺少对其他基准（如 RLBench、CALVIN）或真实多样化场景的验证；
  - 真实实验任务少（2 个）、数据量小（50-116 条轨迹）、评估次数有限（各 20 次），且仅与 π0.5 对比，统计置信度不足。
- **基线公平性问题**：GO-1、π0.5、X-VLA 的结果为引用他人报告值，未在统一环境中复现；不同方法的硬件、数据、训练细节差异可能影响比较公平性。
- **方法局限**：
  - 阶段边界检测基于启发式（表示变化的 NMS），没有与人工标注质量对比，也没有系统分析超参数敏感性；
  - 在某些类别（如抓取与提升、关节/设备交互）提升有限甚至略低于 Motus，说明当前间接条件注入方式对需要精密接触/力学约束的任务帮助有限；
  - 64 帧 V-JEPA2 输入窗口较长（约 44.74 帧平均阶段长度小于窗口），当前切片可能跨越阶段边界或与目标切片重叠，训练监督存在时间模糊性（作者将其定性为"时间上下文化的表示级监督"）；
  - 门控注入仅作用于视频 token，对动作流的影响是间接的。
- **实际部署考虑**：文中未报告推理延迟，作者在结论中也承认需降低 WAM 推理延迟以支持更高频闭环控制。
