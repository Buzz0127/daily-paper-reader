## 摘要
动作标签告诉视觉-语言-行动（VLA）策略要模仿哪些机器人指令，但不说明这些指令如何改变3D世界。对齐的示范片段包含了这一缺失的监督信息，因为其K帧转换记录了在相应K个动作期间产生的几何、运动、可见性和相机变化。我们提出了Track4Action，一个将这种已实现的转换从冻结的世界中心3D追踪器蒸馏到当前观测VLA策略中的框架。在训练期间，Track4World将片段V_{t:t+K}编码为池化的追踪器特征。可学习的追踪查询从当前VLA隐藏状态中推断该特征，在共享空间中进行匹配，并通过特征级门控对流匹配动作头进行条件化。追踪器特征仅定义对齐目标，因此在部署时不使用片段或追踪器。Track4Action在零样本LIBERO-Plus上达到82.3%，比无对齐变体提高7.6个百分点，比LaMP提高3.0个百分点。在干净和随机化的RoboTwin 2.0分割上分别获得80.44%和81.48%的准确率，在四个物理双臂任务上平均成功率为67.5%，比无对齐变体高出25.0个百分点。在仿真和物理任务上的收益支持将动作对齐的3D追踪器特征作为无追踪器VLA部署的特权监督。我们的项目页面可在https://wing0night.github.io/track4action-project-page获取。

## Abstract
Action labels tell a vision-language-action (VLA) policy which robot commands to imitate, but not how those commands change the 3D world. The aligned demonstration clip contains this missing supervision because its $K$ frame transitions record the geometry, motion, visibility, and camera change produced during the corresponding $K$ actions. We introduce Track4Action, a framework that distills this realized transition from a frozen world-centric 3D tracker into a current-observation VLA policy. During training, Track4World encodes the clip $V_{t:t+K}$ into a pooled tracker feature. Learnable track queries infer this feature from current VLA hidden states, match it in a shared space, and condition a flow-matching action head through a feature-wise gate. The tracker feature only defines the alignment target, so neither the clip nor the tracker is used at deployment. Track4Action reaches 82.3% on zero-shot LIBERO-Plus, improving the alignment-free variant by 7.6 points and LaMP by 3.0 points. It obtains 80.44% and 81.48% on the clean and randomized RoboTwin 2.0 splits, and 67.5% average success across four physical bimanual tasks, 25.0 points above the alignment-free variant. The gains across simulation and physical tasks support action-aligned 3D tracker features as privileged supervision for tracker-free VLA deployment. Our project page is available at https://wing0night.github.io/track4action-project-page.

# Track4Action 论文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **问题背景**：视觉-语言-行动（VLA）策略将视觉观测和语言指令直接映射为机器人动作指令。然而，传统的动作标签只告诉策略“要执行什么命令”，却未说明这些命令如何改变3D世界（如场景中哪些点发生了移动、是否发生接触、可见性如何变化等）。
- **核心洞见**：与动作块（action chunk）对齐的演示视频片段中包含了这种缺失的监督信息——K个动作对应的K帧转换记录了几何、运动、可见性和相机变化。因此可以利用一个冻结的“世界中心3D追踪器”（world-centric 3D tracker，即Track4World）将这种实现的转换编码为特权监督信号，用于训练VLA策略。
- **关键思路**：将追踪器特征作为训练时的特权监督（privileged supervision），而在部署时完全移除追踪器和示范片段，保持VLA原有的“当前观测→动作”接口不变。

## 2. 方法论

- **总体框架**：Track4Action由训练专用的“教师分支”（冻结的Track4World）和部署保留的“学生策略路径”组成。
- **问题公式化**：
  - 给定语言指令 \(l\)、当前RGB观测 \(I_t\)、可选机器人状态 \(s_t\)，策略预测归一化动作块 \(A^*_t = (a_t, \ldots, a_{t+K-1})\)。
  - 训练时，同一示范样本还提供主视角片段 \(V_{t:t+K} = (o_t, \ldots, o_{t+K})\)，其中K个动作恰好对应K个帧间转换。
- **教师目标构建**：
  - 冻结的Track4World模型 \(T\) 处理片段 \(V_{t:t+K}\)，估计世界中心3D轨迹及场景、运动、可见性、相机参数等，然后池化为紧凑的追踪器特征：
    \[
    f^{trk}_t = \text{sg}[\text{Pool}(T(V_{t:t+K}))]
    \]
  - \(\text{sg}\) 表示停止梯度；目标特征仅用于对齐，不进入动作头。
- **学生蒸馏机制**：
  - VLA骨干先编码当前观测与语言得到隐藏状态 \(H_t = E_\theta(l, I_t)\)。
  - 引入可学习“追踪查询”（track queries）\(Q\)，通过交叉注意力从 \(H_t\) 中提取紧凑表示：\(Z_t = D_\theta(Q, H_t)\)。
  - 将 \(Z_t\) 与教师特征映射到共享空间后计算对齐损失：
    \[
    L_{\text{align}} = \|\bar{z}_t - \bar{f}^{trk}_t\|_2^2
    \]
- **动作生成与门控融合**：
  - 将 \(Z_t\) 通过特征级门控（feature-wise gate）融合回VLA序列，形成动作条件 \(H^{\text{cond}}_t\)，供流匹配（flow-matching）动作头使用。
  - 教师特征本身不进入动作头，仅定义训练目标。
- **总损失**：
  \[
  L = \lambda_{\text{act}} L_{\text{act}} + \lambda_{\text{align}} L_{\text{align}}
  \]
  - \(L_{\text{act}}\) 为流匹配的条件速度损失，\(L_{\text{align}}\) 为对齐损失。
- **部署时**：仅保留学生路径（VLA骨干+追踪查询+门控融合+动作头），不使用片段、Track4World、对齐分支。

## 7. 优点

- **方法新颖性**：将“世界中心3D追踪器特征”作为特权监督蒸馏进VLA，避免了部署时对追踪器的依赖，保持VLA接口不变。
- **设计巧妙**：
  - 追踪查询同时用于对齐和监督动作头，使蒸馏目标直接塑造动作相关表示，而非独立辅助头。
  - 时间对齐（K动作↔K帧转换）使目标信息高度动作相关，而非通用视频内容。
  - 特征级门控融合保留了原有语义上下文，同时注入追踪信息。
- **实验全面**：覆盖分布内、零样本OOD、大规模双臂仿真、真实物理操纵；消融对比控制严格，结论可信。
- **跨场景一致性**：方法在单臂/双臂、仿真/物理、不同动作空间中均表现稳定增益。

## 8. 不足与局限

- **训练数据要求**：需要时间有序的演示片段，无法用于孤立的图像-动作对。
- **目标质量受限**：
