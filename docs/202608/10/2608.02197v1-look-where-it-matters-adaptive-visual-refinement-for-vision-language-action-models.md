## 摘要
VLA模型的视觉表示在空间精确的机器人操作中仍然不可靠。我们发现VLA中的视觉编码器也存在之前在通用Vision Transformers中记录的注意力伪影，并进一步表明，在具身策略中，这些伪影与后训练期间获得的空间感知能力密切相关。随着编码器学习任务相关信息（如物体位置、深度顺序和局部几何），有限的全局token容量导致部分信息溢出到低信息patch token中。我们引入AtVLA，一个将可学习的寄存器token插入视觉编码器的框架。仅使用具身数据和原始动作目标进行端到端训练，这些寄存器成为具身空间信息的专用载体，而剩余的patch token恢复清洁且空间上准确的注意力分布，这对于精确的目标定位和细粒度接触至关重要。干净的注意力恢复了可靠的定位，但无法恢复在低分辨率观测中丢失的几何细节。因此，AtVLA将注意力修正与不确定性门控的局部细化相结合。动作专家采样多个动作块，并从它们的分歧中估计不确定性；仅对于不确定的预测，动作条件的注意力展开识别任务相关区域，该区域被裁剪、以高分辨率重新编码，并附加到缓存前缀以生成精化动作。在LIBERO、SimplerEnv和一个具有挑战性的单视图真实世界基准上，AtVLA将平均LIBERO成功率从94.2%提高到98.4%，真实世界成功率从46.5%提高到69.0%。裁剪大约在30%的重新规划步骤中触发，导致在代表性部署设置下总计算量仅为基础模型的1.4-1.6倍。

## Abstract
Visual representations of VLA models remain unreliable for spatially precise robotic manipulation. We uncover that vision encoders in VLAs also exhibit attention artifacts previously documented in generic Vision Transformers, and further show that, in embodied policies, these artifacts are closely associated with spatial perception capabilities acquired during post-training. As the encoder learns task-relevant information such as object location, depth ordering, and local geometry, limited global-token capacity causes part of this information to spill into low-information patch tokens. We introduce AtVLA, a framework that inserts learnable register tokens into the visual encoder. Trained end-to-end using only embodied data and the original action objective, these registers emerge as dedicated carriers of embodied spatial information, while the remaining patch tokens recover clean and spatially faithful attention distributions crucial for precise target localization and fine-grained contact. Clean attention restores reliable localization, but cannot recover geometric details lost in low-resolution observations. AtVLA therefore couples attention rectification with uncertainty-gated local refinement. The action expert samples multiple action chunks and estimates uncertainty from their disagreement; only for uncertain predictions, action-conditioned attention rollout identifies the task-relevant region, which is cropped, re-encoded at high resolution, and appended to the cached prefix for refined action generation. Across LIBERO, SimplerEnv, and a challenging single-view real-world benchmark, AtVLA improves the average LIBERO success rate from 94.2% to 98.4% and real-world success from 46.5% to 69.0%. The cropping is triggered on approximately 30% of replanning steps, resulting in only 1.4-1.6x the total computation of the base model under the representative deployment setting.

## 1. 论文的核心问题与整体含义

- **研究背景**：视觉-语言-动作（VLA）模型通过大规模视觉-语言预训练继承丰富的语义先验，并将其迁移到连续机器人控制策略中。然而，机器人操作不仅需要语义理解，更需要空间精确的视觉表征（如目标定位、几何推理、精细接触）。
- **核心问题**：当前 VLA 模型的视觉编码器在具身后训练中会产生**注意力伪影**（attention artifacts）——低信息背景 patch 被当作全局信息仓库，导致空间局部特征被污染。作者进一步揭示，这些伪影与后训练获得的空间感知能力（物体位置、深度顺序、局部几何等）密切相关：全局 token 容量有限，部分空间信息“溢出”到 patch token 中，损害了精确操作所需的定位与接触推理。
- **第二个瓶颈**：即使定位正确，低分辨率观测（如第三方相机）也可能丢失目标及接触区域的局部几何细节，而腕部相机虽能提供近景，却对视角和位姿变化高度敏感。
- **整体含义**：AtVLA 提出了**"注意力修正 + 不确定性门控的局部视觉细化"**的互补框架——先用寄存器 token 恢复干净的注意力分布以解决"看哪里"的问题，再通过自适应裁剪高分辨率重编码解决"看得够不够细"的问题，从而以较小额外计算代价显著提升 VLA 的空间精确操作能力。

## 2. 论文提出的方法论

### 2.1 核心思想
- 两个互补机制：
  1. **寄存器增强的视觉编码**（Register-Enhanced Visual Prefix）：在 SigLIP 编码器中插入可学习寄存器 token，作为全局信息的专用存储槽，使 patch token 恢复干净、空间保真的注意力分布。
  2. **不确定性门控的局部视觉细化**（Uncertainty-Gated Local Visual Refinement）：动作专家采样多个动作块，估计预测不确定性；仅当不确定性超过阈值时，利用动作条件注意力定位任务相关区域，裁剪并以高分辨率重新编码，实现选择性 coarse-to-fine 感知。

### 2.2 关键技术细节

**（1）寄存器增强的视觉前缀**
- 在 224×224 输入（patch size 14，共 256 个 patch token）上，插入 Nr = 4 个可学习寄存器嵌入，置于 class token 之后：
  \[
  X_t = [x_{cls}; r_1, \ldots, r_{N_r}; p_1, \ldots, p_{N_b}]
  \]
- 编码器输出寄存器特征 \(R_t\) 和空间 patch 特征 \(P_t\)，两者都通过 PaliGemma 视觉投影器注入多模态前缀。不同与原始仅将寄存器作为内部工作空间的做法，AtVLA 保留寄存器输出作为额外的全局上下文槽供策略使用。

**（2）不确定性门控的动作预测**
- LLM 骨干只对基础前缀计算一次 KV 缓存，动作专家（flow-matching）从 K 个独立高斯基始中采样动作块：
  \[
  A^{(k)}_{1:H} = \text{ODESolve}(v_\theta, z^{(k)}_0 | C^b_t)
  \]
- 不确定性通过在**平移动作维度**和**近期 h 步动作**上的样本间标准差衡量：
  \[
  U_t = \frac{1}{h|D_{tr}|}\sum_{j=1}^{h}\sum_{d\in D_{tr}}\sqrt{\frac{1}{K-1}\sum_{k=1}^{K}(A^{(k)}_{j,d}-\bar{A}_{j,d})^2}
  \]
- 若 \(U_t \le \tau\)，直接返回均值动作块（置信路径）；若 \(U_t > \tau\)，触发裁剪细化路径。

**（3）注意力引导的局部细化**
- 从动作采样中已有的注意力矩阵出发，对所有 head 和选定的去噪步数求平均，加残差连接并做行归一化，然后通过注意力展开（attention rollout）跨层传播 token 影响：
  \[
  M_{roll} = \bar{M}_L \bar{M}_{L-1} \cdots \bar{M}_1
  \]
- 将前 h 个动作 token 行对 256 个图像 patch 列的影响力reshape为 16×16 显著性图，双线性上采样到输入分辨率。
- 采用**对比式窗口搜索**：选择内部注意力与其周围环形区域差异最大的方形窗口，避免全图扩散和孤立峰值。
- 选中的区域裁剪后 resize 到 224×224，用同一寄存器增强编码器重新编码；裁剪侧寄存器输出被丢弃（基础寄存器已提供全局上下文），仅保留 256 个 patch 特征；归一化坐标通过 MLP 编码为位置嵌入加到每个裁剪 token 上。
- 扩充前缀只预填充新增的裁剪段，基础图像/语言/状态的 KV 缓存被复用。

**（4）训练方法与三阶段课程**
- 冻结预训练 π0 骨干，保留原始动作目标 \(L_{\pi0}\)，仅在新引入组件上训练：
  - **Stage 0（20K 步）**：寄存器适应。前 4K 步仅更新寄存器嵌入，后 16K 步解锁 SigLIP 最后 4 个 transformer 块，让上层视觉层将具身全局信息重组到寄存器槽中。
  - **Stage 1（10K 步）**：真实标注裁剪对齐。冻结视觉编码器，训练裁剪位置编码器和 rank-32 LoRA 适配器。
  - **Stage 2（40K 步）**：联合精化与推理对齐。LoRA 适配器在 SigLIP、Gemma 和动作专家中均可训练，目标为：
    \[
    L = L_{\pi0} + \lambda_{ag}L_{ag}
    \]
    其中 \(L_{ag}\) 鼓励动作到图像的注意力集中在任务相关区域。裁剪来源逐步从标注裁剪过渡到模型自身注意力 rollout 生成的裁剪，并引入 30% 的裁剪 dropout 以匹配部署时的双路径推理。

## 6. 论文的主要结论与发现

- **注意力伪影可被具身后训练修复**：仅使用具身数据和动作目标训练寄存器 token，即可消除高范数伪影，恢复与任务相关物体对齐的干净注意力，无需额外的视觉预训练或通用视觉监督。
- **寄存器 token 确实承载具身空间信息**：线性探针表明，寄存器特征在物体定位、深度和表面法线预测上的一贯优于 CLS token 和平均池化 patch 特征（三项分数均超过 0.70）；移除寄存器导致所有 LIBERO 套件显著下降，说明其不只是抑制伪影，还保留了任务相关的具身空间知识。
- **裁剪不仅提升局部精度，还改善长期规划**：裁剪对 LIBERO-Long-10 和真实世界长视野任务有额外增益，归因于后续决策获得了更多相关视觉上下文。
- **性能提升显著**：
  - LIBERO 平均成功率从 π0 的 94.2% 提升至 98.4%；
  - 真实世界成功率从 46.5% 提升至 69.0%（π0 → AtVLA）；
  - SimplerEnv 上在两个任务取得领先，Open/Close Drawer 上表现中规中矩（因橱柜占据大部分画面，裁剪收益有限）。
- **计算开销可控**：在 K=4、约 30% 触发率的代表性部署设置下，总计算量为 π0 的 1.4–1.6 倍；置信路径不增加任何裁剪编码开销。

## 7. 优点

- **发现新颖且有价值**：首次系统揭示 VLA 视觉编码器中注意力伪影与具身后训练所获空间信息之间的因果关系，为理解 VLA 感知瓶颈提供了新视角。
- **方法优雅而轻量**：寄存器 token 仅增加 4,608 个参数；裁剪路径按需触发（约 30% 步骤），避免了对所有输入进行高分辨率处理的昂贵成本；通过 KV 缓存复用将额外开销控制在 1.4–1.6×。
- **训练设计严谨**：三阶段课程（寄存器适应 → 标注裁剪对齐 → 联合精化与推理对齐）有效避免新组件扰动预训练表征；裁剪来源从标注逐步过渡到模型自身注意力 rollout，配合裁剪 dropout 消除了训练-测试分布差距。
- **模块化消融清晰**：受控变体（+Registers、+Cropping）与完整模型共享初始化，能够清晰归因每个组件的贡献；寄存器数量消融与线性探针分析相互印证，共同支持"寄存器承载空间信息"的核心假设。
- **部署实用性强**：不确定性门控在动作块重规划层面评估而非每个低层控制步，裁剪窗口搜索使用对比式准则避免全图扩散和孤立峰值，并包含无效 rollout 的鲁棒处理。

## 8. 不足与局限

- **真实世界基准的非公开性**：自建真实世界基准（Kitchen、Building Blocks）未公开，且采用单目第三方相机设置，不同实验室的硬件配置差异可能导致结果难以直接复现或比较。
- **SimplerEnv 覆盖不全**：省略了 WidowX 套件，理由合理，但减少了对更广泛具身设置的验证。
- **裁剪条件对等的公平性疑问**：π0 + Cropping 使用外部 VLM 生成裁剪（无具身后训练），与 AtVLA 的端到端注意力引导裁剪并非完全对等；作者承认外部裁剪质量差导致性能受限，但这恰好说明"具身监督"的必要性，也可能让人质疑该对照是否高估了 AtVLA 裁剪分支的相对优势。
- **不确定性阈值校准的泛化性**：阈值按具身（embodiment）单独校准，依赖一个 episode-disjoint 的校准集；对于未见过的环境或任务分布，30% 触发率预算是否仍然成立尚不明确。
- **注意力 rollout 的成本描述不够精确**：论文说明注意力展开复用动作采样中已计算的注意力矩阵，但第 7 点提到收集"所有 18 层"的注意力在多个去噪步（3, 6, 9）上，这在工程实现上的存储和内存管理开销可能比文中表述的更复杂。
- **长期记忆与多视角扩展**：方法主要聚焦单步重规划时的视觉细化，对跨时间步的注意力一致性和多相机视角融合（简化为独立编码后拼接）的讨论较为有限。
- **训练流程复杂**：三阶段、70K 步、多种学习率分段和裁剪课程策略，对工程复现和超参数敏感性的要求较高。
