## 摘要
人类通过保留先前动作已建立的知识，同时不断调整进行中的运动，来执行长时间跨度的操作。相比之下，动作分块的视觉-语言-动作（VLA）策略在每次查询时都从当前输入重复进行重新规划。现有方法要么通过记忆保留长期任务证据，要么通过动作重用和集成保留短期运动，导致跨查询交接不完整。我们引入了ChainVLA，一个12亿参数的VLA策略，通过联合且可修订的执行状态来链接连续查询。进度上下文将循环工作状态与稀疏事件记忆相结合，以携带从观察中得出的任务进度，而运动尾部则将先前预测的未执行延续部分馈送到状态构建和动作生成中。这两个组件共同条件化一个解码器，该解码器在最新观察下重新生成每个动作视野，允许携带的状态指导下一次预测而不固定它。ChainVLA在RMBench上达到62.8%的平均成功率，在四个LIBERO套件上达到98.8%，而移除运动尾部或进度上下文则分别将RMBench成功率降低至11.2%和3.0%。这些不对称的消融结果与运动连续性有助于保留推断任务进度所依据的观察流这一观点一致。

## Abstract
Humans perform long-horizon manipulation by retaining knowledge of what earlier actions have established while continuously adapting the motion underway. By contrast, action-chunked vision-language-action (VLA) policies repeatedly replan from the current input at each query. Existing methods preserve either long-term task evidence through memory or short-term motion through action reuse and ensembling, leaving the cross-query handoff incomplete. We introduce ChainVLA, a 1.2B-parameter VLA policy that chains successive queries through a joint and revisable execution state. Progress Context combines a recurrent Working State with sparse event memory to carry observation-derived task progress, while Motion Tail feeds the preceding prediction's unexecuted continuation into state construction and action generation. Together, the two components condition a decoder that regenerates each action horizon under the latest observation, allowing the carried state to guide the next prediction without fixing it. ChainVLA reaches 62.8% average success on RMBench and 98.8% across four LIBERO suites, while removing Motion Tail or Progress Context reduces RMBench success to 11.2% and 3.0%, respectively. These asymmetric ablations are consistent with motion continuity helping preserve the observation stream from which task progress is inferred.

## 1. 核心问题与整体含义（研究动机与背景）

- **问题核心**：动作分块的 VLA 策略（action-chunked VLA）在长时间跨度操作中，每次查询（query）都从当前观测重新规划，导致跨查询的状态交接不完整，产生两个耦合层面上的歧义：
  - **任务层面**：早期任务证据（如初始布局、已完成的子任务）可能已不在当前视角中，当前观测不足以决定下一个动作；
  - **运动层面**：重新规划会丢弃上一次预测中未执行的延续部分（unexecuted suffix），使新预测的动作前缀与它所替代的运动产生不一致。
- **现有方法的不足**：记忆增强策略只能保留长时任务证据，Temporal Ensemble / 实时执行等方法只能保留短时运动连续性，两者无法同时兼顾；且现有状态统计均通过观测推导，无法携带策略自身的意图信息。
- **核心研究问题**：如何在每次重新规划时既保留任务进度与运动连续性，又让新预测充分响应最新观测？作者将此类比于人类的序列行为与感觉运动控制机制。
- **总体意义**：提出了一种跨查询状态交接的新范式，将独立解码的动作块转化为一条"链"，为长时间跨度操作中的部分可观测问题提供了有效解决方案。

## 2. 研究方法论

### 核心思想
- ChainVLA 构建一个**联合且可修订的执行状态** \(s_k = (g_k, u_k)\)，包含两个互补部分：
  - **Progress Context（进度上下文）\(g_k\)**：回顾性的观测推导状态，携带任务进度；
  - **Motion Tail（运动尾部）\(u_k\)**：前瞻性的预测推导状态，携带上一查询未执行的连续动作。
- 每次查询将该状态"读取—更新—传递"，使当前输入 \(x_k = (o_k, r_k, \ell)\) 与携带状态共同条件化新动作预测，而非直接复用旧动作，从而保持可修订性。

### 关键技术细节
- **工作状态（Working State）**：循环更新，\(W_k = (L_k, B_k)\)，其中 \(L_k\) 为当前活动 token，\(B_k\) 为有界缓存；通过交叉注意力将此前状态与当前多模态编码融合：
  \[
  \tilde{L}_k = \text{CrossAttn}(Q_W + \eta_k, X_k),\quad L_k = \text{LN}(\tilde{L}_k + m_{k-1}^{\text{live}} \cdot \text{CrossAttn}(\tilde{L}_k, L_{k-1}))
  \]
- **稀疏事件记忆（Sparse Event Memory）**：仅在触发写入时更新，事件记录含视觉特征、阶段信息（Stage Info）与时间特征；检索采用年龄感知得分：
  \[
  \rho_{k,i} = \cos(\text{LN}(q_k^e),\ \text{LN}(\kappa_i + \text{Emb}_{\text{age}}(\text{clip}(k - b_i))))
  \]
- **运动尾部（Motion Tail）**：将上一预测的未执行后缀 \(u_{k+1} = \text{Tail}(A_k) = (a_{k,h_{exec}+1}, \ldots, a_{k,H})\) 通过两条模型侧路径传入：
  1. 编码为 tail tokens 条件化工作状态更新；
  2. 对齐动作空间初始化解码器：\(\tilde{A}_{k+1}^{(0)} = \mu_{k+1} + \sigma_u \epsilon_{k+1}\)。
- **查询转移统一公式**：
  \[
  (A_k, W_k, C_{k+1}) = F_\theta(x_k, D_k, W_{k-1}, C_k, u_k),\quad u_{k+1} = \text{Tail}(A_k)
  \]
- **训练方式**：训练与推理共享同一转移过程，按情节顺序展开；前驱 tail 以 0.5 概率被 detached 后条件化下一查询；训练目标包括条件流动作损失、阶段监督（有标注时）与重叠一致性正则化（权重 0.2）。
- 后解码执行侧还会对重叠步骤做线性混合（blend），但这与模型侧两条路径相互独立。

## 6. 主要结论与发现

1. **整体性能**：ChainVLA 在 RMBench 上平均成功率 62.8%（1.2B 参数），超过最强完整覆盖对比方法 Mem-0（52.8%，8B+2B 参数）；在 4 个 LIBERO 套件上平均 98.8%，其中 LIBERO-Long 达 98.2%。
2. **两组件均不可或缺且非独立**：移除 Motion Tail 后 RMBench 降至 11.2%，移除 Progress Context 降至 3.0%，同时移除仅剩 1.6%；两个个位数到低十位数的部分状态之和远不及完整模型，说明二者构成级联依赖而非独立增益。
3. **不对称消融的解释**：运动连续性帮助保留观测流，从而支撑任务进度推断——运动断裂导致机械臂偏离演示视点，使后续检索面对分布外查询，记忆通路接收的输入已经退化。
4. **仅靠平滑无法替代**：Linear Continuation 与 Temporal Ensemble 能在边界指标上取得更低数值，但成功率仍为 0%–2%（对比 Full 的 96% 与 74%），说明"何时使用后缀"（解码前条件化）比"是否使用后缀"（解码后平滑）关键得多。
5. **后解码混合不构成成功原因**：Linear Continuation 完全保留了执行侧 blend，仅移除模型侧路径，96% 对 0% 的差距可归因于模型侧条件化路径本身。

## 7. 优点与亮点

- **概念创新**：首次将任务进度（回顾性）与未完成运动（前瞻性）统一纳入一个可修订的跨查询执行状态，两者分别对应部分可观测控制中的信念状态与预测侧延续，概念上清晰且互补；
- **保持最新观测响应性**：解码器在最新观测下重新生成整个动作视野，携带状态仅作为先验而非固定计划，兼顾连续性与适应性；
- **实验设计严谨**：匹配消融（matched interventions）、边界诊断指标、后解码平滑控制等设计有效分离了"执行侧平滑"与"模型侧条件化"的贡献；
- **效率优势**：以 1.2B 参数超越多数 3B–10B 参数的记忆增强 VLA 方法，参数效率突出；
- **诚实披露**：作者明确声明外部基线可比性受限、单种子无显著性检验、仿真局限等，方法论上比较透明。

## 8. 不足与局限

- **评测范围有限**：仅在固定频率的仿真环境（RMBench、LIBERO）中评估，无真实硬件部署、未变化控制频率，边界诊断描述的是指令流而非物理轨迹；
- **统计严谨性不足**：所有内部条件只使用单一种子，未报告种子方差与显著性检验，成功率与边界指标应视为点估计；
- **外部可比性受限**：对比参照行沿用原文数字，骨干、演示数量、优化预算与成功判据可能不一致，仅用于定位而非机制论断；
