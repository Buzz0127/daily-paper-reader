## 摘要
视觉-语言-动作（VLA）模型在现实世界中的部署常常受到效率与性能权衡、跨具身泛化以及执行平滑性的制约。我们提出了NebulaVLA，一种异步双频架构，将高层语义推理与低层动作控制解耦，优化了计算资源和模块化程度。为了弥合异构机器人之间的语义鸿沟，我们引入了GESTURE-7，一种统一的基于语言的动作表示。此外，我们的引导动作算法通过基于掩码的平滑性约束强制执行运动学连续性。全面评估表明，NebulaVLA显著优于同步基线，在LIBERO-Plus上实现了85.5%的平均成功率，并将动作生成加速了约2.7倍。这种异步设计为实际机器人应用实现了高效且响应迅速的控制。

## Abstract
Real-world deployment of Vision-Language-Action (VLA) models is often bottlenecked by efficiency-performance trade-offs, cross-embodiment generalization, and execution smoothness. We present NebulaVLA, an asynchronous dual-frequency architecture that decouples high-level semantic reasoning from low-level action control, optimizing computational resources and modularity. To bridge semantic gaps across heterogeneous robots, we introduce GESTURE-7, a unified language-grounded action representation. Furthermore, our Guide Action algorithm enforces kinematic continuity via mask-based smoothness constraints. Comprehensive evaluations demonstrate that NebulaVLA significantly outperforms synchronous baselines, achieving an 85.5\% average success rate on LIBERO-Plus and accelerating action generation by \textasciitilde 2.7$\times$. This asynchronous design enables highly efficient and responsive control for practical robotics.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：机器人操作正从模块化流程转向端到端学习，VLA（Vision-Language-Action）模型成为主流范式，如 RT-1、OpenVLA、InternVLA 系列等，展现出语言指令跟随与任务泛化的潜力。
- **核心问题**：作者指出现有 VLA 模型在实际部署中面临三大瓶颈：
  1. **效率与性能的权衡**：单一大一统的同步架构只能采用统一时间分辨率，无法同时满足低频语义推理与高频电机控制的需求。
  2. **跨本体泛化不足**：连续运动学映射到离散词元需要庞大词表和大规模演示数据，难以统一异构机器人（如灵巧手与夹爪）的动作语义。
  3. **执行平滑性差**：异步实时推理与动作块生成之间存在时间错配，导致轨迹抖动和边界不连续。
- **整体含义**：本文提出 NebulaVLA，通过“双频异步架构 + 统一动作表示 + 引导动作机制”系统性解决上述问题，使得 VLA 在真实机器人上实现高效、平滑、可泛化的控制。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 核心思想：快慢双频架构（Fast-Slow Paradigm）

- 借鉴 Kahneman 的“快慢思考”认知范式，将系统解耦为：
  - **System 2（慢系统，约 10 Hz）**：负责高层语义推理与任务规划，基于 Qwen3-VL 视觉语言模型，输出抽象的动作引导（action guidance）；
  - **System 1（快系统，约 20 Hz）**：负责低层反应式动作控制，基于 Diffusion Transformer（DiT），结合高频视觉输入和 System 2 的引导输出实时生成动作。
- 两个系统通过显式数据流解耦，支持分布式部署，降低交互延迟。

### 2.2 GESTURE-7：统一语言化末端执行器表示

- 将末端状态表示为 7 维向量：`[x, y, z, r, p, w, gesture]`
  - `(x, y, z)`：笛卡尔位置（量化到整数厘米）
  - `(r, p, w)`：姿态角 roll, pitch, yaw（量化到整数度）
  - `gesture`：自然语言关键词，如 "grasp", "push", "rotate", "release" 等，不同形态机器人执行相同动作时共享同一关键词。
- **优点**：统一了异构本体（灵巧手/夹爪/机械臂）的动作语义；与语言模型天然兼容，可直接用于强化学习（RL）。

### 2.3 Guide Action：引导动作机制

- **动机**：异步策略推理会导致动作块切换时出现硬切换（hard switch）和机械抖动。
- **做法**：
  - 生成下一个动作块时，将上一个块中未执行的动作（例如 a4–a7）作为“引导点”条件输入；
  - 扩散去噪过程中，使用二进制掩码 `M` 强制保留已知动作（引导区域 M=1），只让模型生成新区域（M=0）；
  - 公式如下：
    - 条件概率模型：`pθ(A_{t-1}^{full} | A_t^{full}, A_prior, τ)`
    - 掩码更新：`A_{t-1}^{full} = M ⊙ A_{t-1}^{prior} + (1-M) ⊙ A_{t-1}^{noisy}`
    - 训练损失：`L(θ) = E_{ε,t} [(1-M) ⊙ (ε - εθ(x_t, t))^2]`
  - 引导点数量在训练时随机采样 0~3 个，以适应不同推理延迟。

### 2.4 三阶段训练流程

1. **Stage 1：System 2 监督微调（SFT）**
   - 构建三类任务组：空间定位（GESTURE-7 位姿回归、2D 关键点回归）、轨迹预测（2D 路点、3D 轨迹点，2 Hz）、推理与规划（Chain-of-Thought + 未来 GESTURE-7 轨迹）。
2. **Stage 2：System 2 强化学习（RL）**
   - 使用 GRPO 算法，在保留 SFT 任务的同时设计多类奖励函数：
     - GESTURE-7 距离（位置、姿态、手势匹配的加权）；
     - 关键点定位奖励；
     - 路点奖励（点级距离 + DTW）；
     - 轨迹奖励（基于 GESTURE-7 距离）；
     - 格式奖励（正则约束输出格式）。
3. **Stage 3：System 1 监督微调（连续动作）**
   - 冻结视觉编码器，联合优化 System 2 和 System 1；
   - 使用带掩码的 L2 损失，仅约束新生成动作区域，确保训练与推理频率严格对齐。

- **总体结论**：异步双频架构、GESTURE-7 表示和 Guide Action 机制共同实现了高效、平滑、可泛化的机器人操作。
