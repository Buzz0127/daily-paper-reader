## 摘要
长时程机器人操作要求机器人既能可靠地执行单个技能，又能在扩展任务中连贯地排序这些技能。大多数分层视觉-语言-动作（VLA）模型在每次前向传播中做出每个决策，没有机制为困难或后果严重的选择分配额外的计算。我们提出了$τ_0$-VLA，一种分层机器人基础模型，通过世界模型引导的测试时计算，将高层子任务生成构建为计算可扩展的推理问题。在每次推理步骤中，高层策略使用执行记忆生成子任务，并在需要时在提交输出之前搜索替代方案。然后，低层策略在多个机器人实体上执行生成的子任务。该策略在40,115小时异构真实世界数据上进行多模态协同训练。在域内和分布偏移设置中，分配额外的测试时计算显著提高了下一个子任务预测的准确性，并且这些增益转化为在长时程机器人操作任务上更高的闭环成功率。

## Abstract
Long-horizon robot manipulation requires a robot to both execute individual skills reliably and sequence them coherently over extended tasks. Most hierarchical vision-language-action (VLA) models make each such decision with a single forward pass, leaving no mechanism to allocate additional computation to difficult or consequential choices. We introduce $τ_0$-VLA, a hierarchical robot foundation model that formulates high-level subtask generation as a compute-scalable inference problem through world-model-guided test-time computation. At each inference step, the high-level policy uses execution memory to generate a subtask and, when needed, searches over alternatives before committing to its output. A low-level policy then executes the generated subtask across multiple robot embodiments. The policy is trained on 40,115 hours of heterogeneous real-world data with multimodal co-training. Across in-domain and distribution-shifted settings, allocating additional test-time computation substantially improves next-subtask prediction accuracy, and these gains translate into higher closed-loop success on long-horizon robot manipulation tasks.

## 2. 方法论

### 整体架构
- τ₀-VLA 是一个分层系统，由两部分组成：
  - **高层策略 μ**：生成当前子任务，并决定是否需要测试时搜索。
  - **低层策略 π_θ**：将子任务指令映射为具体动作片段，跨多种机器人本体执行。

### 高层策略：记忆增强 + 自适应测试时计算
- 输入上下文为 `h_t = (ℓ, M_{t-1}, z*_{t-1}, o_t)`，其中：
  - ℓ：全局任务指令；
  - M_{t-1}：执行记忆；
  - z*_{t-1}：上一步生成的子任务；
  - o_t：当前多视角观测。
- 高层策略包括四个模型：
  - **Proposal模型 P**：更新执行记忆，并生成直接子任务建议 `z_dir_t`。
  - **World模型 W**：给定头部相机图像和候选子任务，预测该子任务完成后的终态图像。
  - **Value模型 V**：给定任务指令、候选子任务和预测终态图像，输出候选质量分数 `v ∈ [0.05, 0.95]`（通过五级 ordinal VQA 训练实现）。
  - **Reflective模型 F**：基于最终保留的搜索分支摘要和真实上下文，生成最终提交的子任务。

### 自适应路由
- 由 Proposal 模型前向传播中的 token 置信度与 logit margin 计算路由信号：
  - `u_all`：全部生成 token 的平均概率；
  - `u_mem`：`<memory>` 字段 token 的平均 logit margin；
  - 若任一统计量低于阈值，则触发 TTC；否则走快速路径直接提交建议。

### 世界模型引导的测试时搜索
- 使用**束搜索（beam search）**，参数为：
  - N：分支因子（每节点采样候选数）；
  - B：束宽；
  - D：搜索深度。
- 搜索流程（Algorithm 1）：
  1. 初始化一个根分支；
  2. 对每个保留分支，独立调用 Proposal 模型 N 次，得到 N 个候选子任务；
  3. 对每个候选，World 模型预测终态头部图像，Value 模型打分；
  4. 子分支累积分数 = 父分支分数 + 当前候选分数；
  5. 每层全局保留 Top-B 分支；
  6. 递归扩展至深度 D；
  7. 最终将保留分支摘要 `C_t` 交给 Reflective 模型，生成最终子任务 z*_t。
- 搜索内部产生的记忆均为分支局部记忆，不覆盖真实持久执行记忆。

### 低层策略
- 使用 **Mixture-of-Transformers（MoT）动作专家** 与 Qwen3.5-2B 视觉语言骨干结合。
- 统一 40 维状态/动作空间：覆盖末端执行器、手臂关节、夹爪、腰部、移动底座。
- 使用**掩码条件流匹配（masked flow matching）**训练动作生成：
  - 插值：`a^τ = τ M ε + (1-τ) M a`；
  - 目标速度：`u = M(ε - a)`；
  - 仅对激活通道计算损失。
- 动作片段长度 H=30，推理时用 10 步均匀 Euler 更新从噪声积分到动作。

### 训练数据与监督信号
- 低层策略：40,115 小时真实世界异构数据（内部演示、自主策略 rollout、UMI 数据、公开数据），并混入多模态 VLM 数据做协同训练。
- 高层策略：从已有任务/阶段/可执行子任务标注及分段演示中自动构造监督，无需额外人工标注。
- 训练了对**记忆进行自纠错**的机制：通过扰动演示中的记忆（滞后、超前、错误失败等），训练高层策略修复与观测不一致的记忆。

## 6. 主要结论与发现

- 将测试时计算引入高层子任务生成，可显著提升**下一个子任务预测准确率**，并且提升幅度随计算预算增加而增大（存在饱和趋势）。
- TTC 带来的预测增益**可转化为物理机器人闭环任务的成功率和进度提升**，例如：
  - Make Milk Tea：Plan Once 5/10 → TTC 7/10；
  - Book Organization：6/10 → 9/10；
  - Clean Room：5/10 → 7/10。
- 执行记忆对长时程任务至关重要：
  - Clean Room、Prepare Ingredients、Tomato and Egg Stir Fry 等任务的失败集中在状态跟踪环节；
  - 显式记录“是否已加盐”等视觉上不明显的状态，可避免重复或跳步。
- 低层策略在跨实体直接执行中优于 GR00T N1.7、LingBot-VLA、π0.5：
  - Collect Laundry SR 10/10；
  - Tidy Makeup Table 各任务组 SR 9–10/10。
- 分层结构整体上优于“整任务直接执行”：
  - 长时程任务平均 SR 由 27.50% 提升到 45.00%（Plan Once 分层）。

## 7. 优点

- 提出“子任务级 TTC”的层次化 VLA 范式，介于“动作级搜索”和“纯语言推理”之间，适合长时程任务。
- 用**世界模型预测终态图像 + Value 模型评估**的方式，把候选子任务与物理后果关联起来，实现“提交前评估”。
- 搜索支持**分支因子、束宽、深度**三维扩展计算预算，能灵活控制推理成本。
- 高层策略具备**可纠错执行记忆**，通过自动扰动生成训练数据，无需额外人工标注。
- 低层策略使用统一 40 维状态/动作空间 + 掩码流匹配，支持固定底座、双臂、移动全驱控等多本体。
- 数据来源规模大（40K+ 小时）且异构，并采用多模态协训练保护 VLM 语义能力。
- 实验含物理机器人闭环验证、跨本体迁移、分布偏移和计算-精度分析，工程完成度高。

- **算力细节缺失**：未报告 GPU 型号/数量/训练时长，难以评估复现成本与效率。
