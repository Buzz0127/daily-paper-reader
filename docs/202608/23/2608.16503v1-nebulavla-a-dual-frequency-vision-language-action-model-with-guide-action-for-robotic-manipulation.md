## 摘要
视觉-语言-动作（VLA）模型在现实世界中的部署常受限于效率与性能的权衡、跨实体泛化以及执行平滑性。我们提出NebulaVLA，一种异步双频架构，将高层语义推理与低层动作控制解耦，优化计算资源与模块化。为弥合异构机器人之间的语义鸿沟，我们引入GESTURE-7，一种统一的基于语言的动作表示。此外，我们的引导动作算法通过基于掩码的平滑性约束强制运动学连续性。综合评估表明，NebulaVLA显著优于同步基线，在LIBERO-Plus上达到85.5%的平均成功率，并将动作生成加速约2.7倍。这种异步设计使实际机器人应用能够实现高效和响应灵敏的控制。

## Abstract
Real-world deployment of Vision-Language-Action (VLA) models is often bottlenecked by efficiency-performance trade-offs, cross-embodiment generalization, and execution smoothness. We present NebulaVLA, an asynchronous dual-frequency architecture that decouples high-level semantic reasoning from low-level action control, optimizing computational resources and modularity. To bridge semantic gaps across heterogeneous robots, we introduce GESTURE-7, a unified language-grounded action representation. Furthermore, our Guide Action algorithm enforces kinematic continuity via mask-based smoothness constraints. Comprehensive evaluations demonstrate that NebulaVLA significantly outperforms synchronous baselines, achieving an 85.5\% average success rate on LIBERO-Plus and accelerating action generation by \textasciitilde 2.7$\times$. This asynchronous design enables highly efficient and responsive control for practical robotics.

### 1. 论文的核心问题与整体含义（研究动机和背景）
- 视觉-语言-动作（VLA）模型在机器人操作领域正从模块化流程转向端到端学习，但实际部署中仍面临三大核心瓶颈：
  1. **效率-性能权衡**：传统同步单体架构使用统一时间分辨率，无法同时满足低频语义推理（如10Hz）与高频电机控制（如20Hz）的需求；
  2. **跨本体泛化不足**：将连续运动学映射为离散token需要极大词表和大规模示范数据，难以在不同机器人形态间形成统一动作语义；
  3. **执行平滑性差**：异步实时推理与动作块生成之间的时间错配，导致轨迹出现明显抖动和不连续。
- 论文提出 **NebulaVLA**，一种异步双频架构，受“快慢思考”认知范式的启发，将审慎推理（System 2）与反应式控制（System 1）解耦，从而在保持高效率的同时提升任务成功率，并改善跨实体泛化与轨迹平滑性。

### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程
- **整体架构**：分层式“快慢”双频系统：
  - **System 2（慢系统，约10Hz）**：使用 Qwen3-VL 作为视觉-语言骨干，处理自然语言指令和稀疏视觉输入，输出高层抽象动作引导（隐藏层特征 + 文本token）。
  - **System 1（快系统，约20Hz）**：使用 DINOv2 视觉编码器和高频视觉输入，以 System 2 的引导为条件，通过去噪扩散Transformer（DiT）生成具体动作。
  - 两系统通过显式数据流规范解耦，支持分布式部署，降低交互延迟。
- **统一动作表示 GESTURE-7**：
  - 将末端执行器状态编码为7维向量：`[x, y, z, r, p, w, gesture]`，前6维为量化后的笛卡尔位置（整数cm）和姿态角（整数度），第7维为自然语言手势关键词（如 `grasp`, `push`, `rotate`）。
  - 不同形态机器人执行相同动作共享相同关键词，从而统一跨本体动作语义，并支持与语言条件强化学习结合。
- **Guide Action 机制**：
  - 借鉴图像外推（Image Outpainting）思想，在生成下一个动作块时，将上一块中未执行的动作点（如 `a4–a7`）作为条件锚点，强制新块起始状态与旧轨迹对齐。
  - 去噪过程中使用二进制掩码 `M`：锚点区域严格保持已知动作，生成区域由模型预测。公式为：
    - 条件概率：`pθ(A_{t-1}^{full} | A_t^{full}, A_prior, τ)`
    - 掩码更新：`A_{t-1}^{full} = M ⊙ A_{t-1}^{prior} + (1−M) ⊙ A_{t-1}^{noisy}`
    - 训练时引导点数在0~3之间随机采样，以适应不同推理延迟。
- **三阶段训练流程**：
  - **Stage 1（System 2 SFT）**：基于GESTURE-7进行监督微调，包括姿态回归、关键点回归、2D航点预测、3D轨迹预测、链式思维生成等任务。
  - **Stage 2（System 2 RL）**：使用GRPO强化学习进一步提升轨迹规划能力，奖励函数包括GESTURE-7距离、关键点定位、航点（含DTW距离）、轨迹层级奖励和格式奖励。
  - **Stage 3（System 1 SFT）**：联合优化System 2和System 1，使用加权流匹配损失（L2 loss），损失仅作用于掩码为0的新生成区域，保证训练与推理频率严格对齐。

### 7. 优点
