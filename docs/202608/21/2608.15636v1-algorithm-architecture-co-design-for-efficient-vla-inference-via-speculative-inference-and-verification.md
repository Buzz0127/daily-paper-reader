## 摘要
视觉-语言-动作（VLA）模型在具身智能领域展现了卓越能力，但其高计算成本和受限的预测动作长度阻碍了实时部署。尽管专为高效具身智能设计的加速器Dadu-Corki已被提出，但它并未利用机器人与环境之间固有的交互模式，导致预测动作长度相对较短。我们观察到，机器人环境自然地在主动状态（精确动作至关重要）与非主动状态（动作对任务成功影响有限）之间交替。这一洞察催生了新的调度机会：在非主动状态下进行长动作长度的推测性预测，并在主动状态下进行选择性验证。我们提出SpecVLA，一个算法-系统协同设计框架，自适应地平衡动作长度、推理延迟与任务可靠性。在算法方面，SpecVLA引入了状态感知的VLA推理执行范式，以及利用差分残差和块级混合精度量化构建硬件友好的小型验证模型（sVLA）。在系统方面，我们开发了由GPU和机器人专用硬件模块组成的异构架构，以及通过并行执行解耦VLA和sVLA的推测性数据流。在LIBERO和ManiSkill基准上对OpenVLA和RDT的全面评估表明，SpecVLA在保持任务成功率的同时显著降低了端到端延迟。通过实现长动作长度推测性预测与及时验证，SpecVLA实现了兼具高效率和可靠性的实时机器人操作。

## Abstract
Vision-Language-Action (VLA) models have demonstrated remarkable capabilities in the field of embodied AI, but their high computational cost and limited predicted action length hinder real-time deployment. Although Dadu-Corki, a dedicated accelerator for efficient embodied AI, has been introduced, it does not exploit the inherent interaction patterns between the robot and its environment, which results in a relatively short predicted action length. We observe that robotic environments naturally alternate between active states-where precise actions are crucial-and inactive states-where actions have limited impact on task success. This insight enables a new scheduling opportunity: long-action-length speculative prediction in inactive states, paired with selective verification in active states.   We propose SpecVLA, an algorithm-system co-design framework that adaptively balances action length, inference latency, and task reliability. On the algorithm side, SpecVLA introduces a state-aware VLA inference execution paradigm and a hardware-friendly construction of a smaller verification model (sVLA) using differential residuals and block-wise mixed-precision quantization. On the system side, we develop a heterogeneous architecture consisting of a GPU and a robotic-specific hardware module, along with a speculative dataflow that decouples VLA and sVLA through parallel execution. Comprehensive evaluations on OpenVLA and RDT across LIBERO and ManiSkill benchmarks show that SpecVLA reduces end-to-end latency significantly while preserving task success rate. By enabling long-action-length speculative prediction with timely verification, SpecVLA achieves real-time robotic manipulation with both high efficiency and reliability.

## 1. 核心问题与整体含义

- **背景**：视觉-语言-动作（VLA）模型在具身智能中表现出色，但推理延迟通常超过600ms，难以满足实时控制要求。已有加速器（如Dadu-Corki）虽能通过异构系统隐藏通信和部分推理延迟，但未利用机器人与环境交互的固有模式，预测动作长度较短（单次推理<4个动作），仍无法充分发挥潜能。
- **关键观察**：
  - 机器人操作过程中，环境状态会交替出现**主动状态**（如抓取、对准、放置，动作精度对任务成败至关重要）和**非主动状态**（如手爪移向目标，中间动作对结果影响有限）。
  - 连续环境帧具有高时间冗余性，使得一个量化的小型VLA（sVLA）可以在极低算力下产生高质量短期动作预测，但对长序列预测会严重退化。
- **核心问题**：如何在保持高任务成功率的前提下，通过延长预测动作长度来摊销昂贵的VLA推理成本，从而显著降低端到端延迟，实现实时可靠的机器人操作。
- **整体含义**：SpecVLA提出“非主动状态长动作推测 + 主动状态选择性验证”的新执行范式，并通过算法-系统协同设计（包括轻量sVLA、异构硬件和推测性数据流）将理论加速转化为实际系统效率，展示了高效具身智能系统的可行路线。

## 2. 方法论

### 2.1 核心思想

- SpecVLA采用“预测-验证”框架：
  - **非主动状态**：直接使用全精度VLA预测长动作序列（如8个动作），不进行逐动作验证，执行后一次性摊销推理成本。
  - **主动状态**：先用VLA预测长序列，然后对每个动作执行前，调用轻量sVLA基于最新传感器图像生成“期望动作”，用加权L1距离与预测动作比较。若相似则接受执行；若差异超阈值则拒绝并回滚，重新调用VLA生成新序列。

### 2.2 环境状态预测算法（Algorithm 1）

- 输入：机器人手爪状态 \(G_s\)、手爪坐标 \(G_c\)、物体坐标集合 \(\{O_c\}\)、距离阈值 \(T_d\)。
- 流程：
  1. 计算手爪与每个物体的欧氏距离 \(D_i = \sqrt{\sum_{k=1}^3 (G_c[k]-O_{ic}[k])^2}\)；
  2. 统计距离小于 \(T_d\) 的物体数量 \(n\)；
  3. 若手爪状态为张开（-1）且 \(n<1\)，判定为**非主动状态**；否则为**主动状态**。
- 该预测是轻量的，由机器人端传感器信息直接计算，适合硬件实现。

### 2.3 动作验证

- 对每个动作维度先做 min-max 归一化：
  \(\tilde{A}[k] = (A[k]-A_{low}[k])/(A_{high}[k]-A_{low}[k])\)。
- 计算加权L1距离：\(L_1(\tilde{A},\tilde{A}')=\sum_{k=1}^7 w[k]|\tilde{A}[k]-\tilde{A}'[k]|\)，其中权重 \(w[k]=1/\sigma[k]\)（\(\sigma[k]\)为该维度历史标准差）。方差大的维度对误差容忍度高，赋予低权重；稳定维度更关键，赋予高权重。
- 距离小于阈值 \(T_s\) 则接受预测动作，否则拒绝并触发VLA重新推理。

### 2.4 sVLA的构造：差分残差 + 块级混合精度量化

- **差分计算**：利用相邻时间步特征高度相似，先计算残差 \(\Delta X_i = X_i - X_{i-1}\)，残差分布更窄（见图3），更适合量化。
- **块级量化**：将残差矩阵划分为固定大小块，对每个块计算绝对值之和，与阈值 \(T_z\)、\(T_h\) 比较：
  - 和 < \(T_z\)：块置零（0-bit）；
  - 和 > \(T_h\)：高精度（8-bit）；
  - 否则：低精度（4-bit）。
- 高精度块进一步拆分为“高比特分量”和“低比特分量”，使所有块在硬件上统一用低精度数据路径计算，避免复杂控制逻辑。
- 最终输出通过残差输出与上一时间步输出累加得到，实现逐层的量化-累积推理。

### 2.5 异构系统架构与推测数据流

- 系统由**GPU**（执行全精度VLA）与**机器人专用硬件模块**（执行sVLA、状态预测、预处理）组成。
- **推测性数据流**：VLA可在无需等待sVLA验证结果的情况下**提前推测执行**下一轮动作序列。当sVLA验证通过时，GPU可提前终止当前VLA计算并开始新一轮推测；验证失败时则继续完成VLA计算。同时机器人动作执行也与两端计算并行，整体延迟得以隐藏。
- **机器人专用硬件模块**包含：
  - SIMD PE阵列：统一低精度数据路径，支持块标签控制累加（低精度块直接累加，高比特分量左移后累加）；
  - 可重构状态预测器：复用距离计算流水线，支持环境状态预测模式和动作验证模式，降低硬件开销；
  - 预处理模块：集成残差生成、块量化、标签生成，减少数据搬运，形成紧耦合流水线。
- 硬件在28nm工艺、500MHz频率下综合，面积1.93mm²，功耗567.74mW。

## 6. 主要结论

- SpecVLA通过**状态感知的推测推理与验证**，在非主动状态延长预测动作长度以摊销VLA成本，在主动状态用轻量sVLA进行逐动作校验，实现了平均有效动作长度7.1，显著减少昂贵的VLA调用。
- 差分残差结合块级混合精度量化构建的sVLA在保持验证质量的同时大幅降低计算量（仅剩全精度约10.22%的FLOPs）。
- 异构架构（GPU + 机器人专用硬件）与推测数据流使VLA、sVLA和动作执行并行化，隐藏相互依赖延迟，端到端性能显著提升。
- 最终在LIBERO和ManiSkill上，SpecVLA相比A100 GPU和Dadu-Corki分别获得2.9×和1.9×加速，每动作延迟约61ms，满足实时性；任务成功率与基线相当甚至略优（有噪声时+0.3%）。
- 结论：长动作推测与及时验证相结合，能够同时实现高效率和可靠性，支持实时机器人操作。

## 7. 优点

- **算法-系统协同设计**：从机器人环境状态的物理直觉出发，将推测执行与验证机制延伸到VLA推理全栈，比单纯量化/剪枝更贴合具身智能场景。
- **利用时间冗余**：差分残差量化硬件友好，避免复杂混合精度控制，且量化后大部分块为0-bit或4-bit，计算量大幅降低。
- **推测数据流设计巧妙**：通过VLA的提前推测执行，使验证过程不再成为关键路径，并利用机器人动作执行时间并行计算，有效隐藏延迟。
- **专用硬件轻量高效**：复用距离计算流水线同时支持状态预测和动作验证，预处理模块紧耦合，面积仅1.93mm²、功耗约568mW，适合边缘部署。
- **实验设计较全面**：覆盖多种模型、任务、对比方法和消融，并加入噪声鲁棒性测试，证据链较扎实。
- **性能指标吸引力强**：相对多个SOTA方法都有可量化的端到端加速和能效提升。

## 8. 不足与局限

- **缺乏真实物理验证**：所有实验均在LIBERO和ManiSkill的仿真环境内完成，传感器噪声虽人为模拟，但仍无法完全替代真实机器人执行中的物理约束、延迟抖动和不可逆状态变化。
- **回滚机制的物理局限**：论文提到验证失败时使用反向补偿动作恢复，并认为在单步粒度下可安全恢复；但若遇到物理不可逆过程（如完全闭合夹爪、接触形变），该机制可能失效，论文并未深入讨论。
- **阈值和超参数依赖人工调整**：\(T_s, T_d, T_z, T_h, L\)通过单维扫描确定，缺乏自适应/自动调优机制，跨场景泛化可能需要重新校准。
- **成功率的基线问题**：在困难任务（如RDT-PlugCharger）上，基线成功率仅为2%，SpecVLA虽有1%提升但绝对成功率很低，说明对复杂任务的提升有限，且SpecVLA可能继承基线的泛化缺陷。
- **仿真/硬件协同验证的差距**：硬件模块通过RTL综合和cycle-level simulator评估，但未进行实际流片或FPGA原型验证；GPU延迟实测与模拟器结果之间的对齐细节未详述。
- **算力与资源信息不完整**：未说明VLA模型训练/微调的GPU数量、时长、能耗，也缺少GPU完整功耗数据，可能影响能效对比的精确性。

- **对比公平性存疑**：文中部分对比方法（如Spec-VLA、HeiSD等推测解码方案）在命名或理念上与本文相近，但各方法在预测长度、验证阈值、token稀疏比例、剪枝率等关键超参数上的设定可能不同，论文对这些设置是否统一对齐说明有限；且基线延迟可能来自不同硬件/软件环境（如CUDA版本、编译优化、是否使用TensorRT等），可能影响比较的公平性。

总体来看，SpecVLA在创新性和系统性上较为突出：从“主动/非主动状态”这一物理直觉出发，将推测执行、轻量验证与专用硬件设计贯通为一个完整方案，展示了很高的工程完成度。其核心贡献不仅在于算法层面的长动作预测与验证机制，更在于通过异构架构和推测数据流将算法收益真正落地为端到端延迟与能耗的双重提升。不过，其当前证据仍主要来自仿真环境，真实物理机器人上的鲁棒性、阈值的自适应能力以及软硬件的开源程度，是决定其能否被广泛采纳的关键后续工作。
