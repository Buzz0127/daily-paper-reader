## 摘要
视觉-语言-动作（VLA）模型近年来在机器人操作中取得了令人瞩目的性能。然而，现有基准主要评估静态操作任务的泛化能力，而在很大程度上忽略了动态交互场景。为解决这一空白，我们提出了ReflexBench，一个用于反应关键操作的基准。ReflexBench包含六个动态任务，并引入了一个评估框架，该框架将模拟器步进与机器人控制解耦，同时支持同步和异步推理下的可配置延迟。基于ReflexBench，我们提出了ReflexVLA，一种为反应关键操作设计的高效VLA模型，无需大规模机器人数据预训练。ReflexVLA通过潜在未来预测和视觉骨干内的多帧时间融合增强了时间推理能力，同时通过批量视觉编码和CUDA图重放降低了部署延迟。实验表明，ReflexVLA持续提升动态操作性能，同时在标准静态操作基准上保持具有竞争力的准确性，真实世界实验进一步证明了其在实际部署条件下的有效性。项目网站：https://reflexvla.github.io

## Abstract
Vision-Language-Action (VLA) models have recently achieved promising performance in robotic manipulation. However, existing benchmarks mainly evaluate generalization on static manipulation tasks and largely overlook dynamic interaction scenarios. To address this gap, we present ReflexBench, a benchmark for reaction-critical manipulation. ReflexBench contains six dynamic tasks and introduces an evaluation framework that decouples simulator stepping from robot control while supporting configurable latency under synchronous and asynchronous inference. Building upon ReflexBench, we propose ReflexVLA, an efficient VLA model designed for reaction-critical manipulation without large-scale robot-data pretraining. ReflexVLA enhances temporal reasoning through latent future prediction and multi-frame temporal fusion within the vision backbone, while reducing deployment latency through batched visual encoding and CUDA Graph replay. Experiments show that ReflexVLA consistently improves dynamic manipulation performance while maintaining competitive accuracy on standard static manipulation benchmarks, and real-world experiments further demonstrate its effectiveness under practical deployment conditions. Project website: https://reflexvla.github.io

### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

**ReflexBench 基准设计**：
- 包含六个动态操作任务：传送带抓放、接球、打地鼠、滚球拦截、抛球入筐、旋转插销。
- 提出**延迟感知评估协议**：将模拟器步进与机器人控制解耦，显式模拟推理延迟对行动的影响。
- 支持**同步推理**（阻塞式，推理期间环境暂停）与**异步推理**（推理与执行重叠），并可通过可配置延迟参数控制阻塞窗口。
- 定义了实时因子（Real-Time Factor, RTF）：
  \[
  \text{RTF} = \frac{t_{\text{sim}}}{t_{\text{wall}}}
  \]
  用于将真实世界推理延迟转换为仿真中的等效延迟。

**ReflexVLA 模型三大核心组件**：
1. **潜在未来预测（Latent Future Prediction）**
   - 使用冻结的 DINOv3 编码器提取未来观测的语义特征 \(y_{t+i} \in \mathbb{R}^{1024}\)。
   - 在输入序列中插入 \(H\) 个可学习的“未来 token”，每个 token 对应动作块中的一个未来控制步骤。
   - 经过 Transformer 后，将第 \(i\) 个未来 token 的隐表示投影到 DINOv3 特征空间：
     \[
     \hat{y}_{t+i} = f_{\text{pred}}\left(h_{\text{future}}^i\right)
     \]
   - 使用掩码余弦相似度损失监督：
     \[
     \mathcal{L}_{\text{future}} = \frac{\sum_{i=1}^{H} m_i \left[1 - \cos(\hat{y}_{t+i}, y_{t+i})\right]}{\sum_{i=1}^{H} m_i}
     \]
   - 总损失：\(\mathcal{L} = \mathcal{L}_{\text{act}} + \lambda_{\text{future}} \mathcal{L}_{\text{future}}\)

2. **多帧时间融合（Multi-Frame Temporal Fusion）**
   - 在视觉骨干的**中间层特征**上执行时间融合，因为中间层保留更多局部外观与运动信息。
   - 对每个视图 \(v\) 和每个 patch 位置 \(p\)，将 \(T\) 个历史帧的特征串联成时间轨迹。
   - 先归一化、降维并添加时间位置编码，然后通过**因果多头注意力**（causal MHA）融合，防止未来信息泄漏。
   - 融合后的残余特征 \(\Delta x_{v,p,t}\) 加到当前帧的最终层特征上：
     \[
     \tilde{x}_{v,p,t} = x^{\text{final}}_{v,p,t} + \Delta x_{v,p,t}
     \]
   - 最终只将当前帧的融合特征送入语言模型，保证视觉 token 数量与单帧一致，避免语言模型端的额外计算开销。

3. **推理延迟优化（Inference Latency Optimization）**
   - **批量视觉编码**：将 \(V\) 个视图 × \(T\) 帧的所有图像拼成单个 batch 送入视觉编码器，减少重复调用开销。
   - **CUDA Graph 重放**：将完整推理管线（视觉编码、时间融合、多模态投影、语言模型、动作预测）捕获为一张计算图 \(G\)：
     \[
     \hat{a}_{t:t+H-1} = G(x_{\text{text}}, x_{\text{vision}}, x_{\text{state}})
     \]
     执行时将新观测复制到预分配缓冲区并直接重放图，消除内核调度与运行时开销。
