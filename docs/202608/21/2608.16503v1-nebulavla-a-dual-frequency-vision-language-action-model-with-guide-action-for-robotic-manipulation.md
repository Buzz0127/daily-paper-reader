## 摘要
视觉-语言-动作（VLA）模型在现实世界中的部署常常受到效率与性能权衡、跨实体泛化以及执行平滑性的制约。我们提出了NebulaVLA，一种异步双频架构，将高层语义推理与低层动作控制解耦，从而优化计算资源和模块化程度。为弥合异构机器人之间的语义差距，我们引入了GESTURE-7，一种统一的语言接地动作表示。此外，我们的引导动作算法通过基于掩码的平滑性约束来强制运动学连续性。综合评估表明，NebulaVLA显著优于同步基线，在LIBERO-Plus上实现了85.5%的平均成功率，并将动作生成加速约2.7倍。这种异步设计为实际机器人技术实现了高效且响应迅速的控制。

## Abstract
Real-world deployment of Vision-Language-Action (VLA) models is often bottlenecked by efficiency-performance trade-offs, cross-embodiment generalization, and execution smoothness. We present NebulaVLA, an asynchronous dual-frequency architecture that decouples high-level semantic reasoning from low-level action control, optimizing computational resources and modularity. To bridge semantic gaps across heterogeneous robots, we introduce GESTURE-7, a unified language-grounded action representation. Furthermore, our Guide Action algorithm enforces kinematic continuity via mask-based smoothness constraints. Comprehensive evaluations demonstrate that NebulaVLA significantly outperforms synchronous baselines, achieving an 85.5\% average success rate on LIBERO-Plus and accelerating action generation by \textasciitilde 2.7$\times$. This asynchronous design enables highly efficient and responsive control for practical robotics.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：机器人操作正在从模块化流水线转向端到端学习，视觉-语言-动作（VLA）模型通过统一感知、语言与控制，实现了自然语言指令跟随和复杂任务执行。然而，现有 VLA 模型在实际部署中面临三大瓶颈：
  - **效率与性能的刚性权衡**：传统单体同步架构采用统一时间分辨率，无法同时支持低频语义推理（如 10 Hz）和高频电机控制（如 20 Hz），导致计算开销与实时响应难以兼顾。
  - **跨本体泛化不足**：现有动作表征（尤其是离散 token 化方法）需要极大词汇表和大量演示数据来覆盖连续运动空间，难以在不同机器人形态（如灵巧手、夹爪、机械臂）之间统一动作语义。
  - **轨迹平滑性差**：异步推理与动作块生成之间的时间失配会导致明显的抖动和运动不连续，尤其在动作块边界处出现“硬切换”。

- **整体含义**：论文提出 NebulaVLA，一种基于“快慢思维”认知范式的异步双频 VLA 模型，系统性地解决上述问题，在提高任务成功率的同时显著降低推理延迟、提升跨实体泛化能力并保证执行平滑性，为实际机器人操控提供了一种高效且可部署的异步设计范式。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 2.1 核心思想
- 采用**异构双频架构**（Heterogeneous Dual-Frequency Architecture），将高层语义规划（System 2，约 10 Hz）与低层反应式控制（System 1，约 20 Hz）完全解耦，实现计算资源优化和模块化分布式部署。
- 提出**GESTURE-7** 统一动作表征，以自然语言关键字映射不同本体的同义动作，弥合跨机器人语义鸿沟。
- 提出**Guide Action** 机制，借鉴图像外扩（Image Outpainting）思想，将轨迹连续性约束内化到扩散生成过程中，避免后处理平滑。

### 2.2 关键技术细节

#### （1）System 2（S2）：高层语义规划器
- 以 **Qwen3-VL** 为视觉语言骨干，处理自然语言指令和稀疏视觉输入（~10 Hz）。
- 通过可学习 token 提取隐藏层特征，作为对 System 1 的抽象动作引导。

#### （2）System 1（S1）：低层动作控制器
- 受 InternVLA-M1 启发，但做了两点优化：
  - 对预训练 **DINOv2** 视觉编码器进行对比微调，利用视觉输入和末端执行器状态增强视觉-本体感觉对齐。
  - 集成 **Guide Action** 机制，确保轨迹连续和平滑。

#### （3）GESTURE-7 统一表征
- 将末端执行器状态编码为 7 维向量：`[x, y, z, r, p, w, gesture]`。
  - `x, y, z`：笛卡尔位置（整数厘米）；
  - `r, p, w`：滚转、俯仰、偏航角（整数度）；
  - `gesture`：自然语言关键词，如 `grasp`、`push`、`rotate`、`release` 等，统一不同实体的相同动作。
- 该表示天然支持跨本体泛化，并能无缝集成语言条件强化学习。

#### （4）Guide Action 机制
- 在生成下一个动作块时，将前一个块中**未执行的动作**作为“引导动作”条件，强制新块起始状态与已执行轨迹对齐。
- 训练过程中引导动作点数随机采样 0~3，以适应推理延迟变化。
- 条件概率模型：

  \[
  p_\theta(A^{t-1}_{full} \mid A^t_{full}, A^{prior}, \tau)
  \]

  其中 \(A^{prior}\) 为已知动作集合（已执行历史 + 引导动作），\(\tau\) 为时间位置编码。

- 每步去噪后，通过二元掩码强制保留已知动作：

  \[
  A^{t-1}_{full} = M \odot A^{t-1}_{prior} + (1 - M) \odot A^{t-1}_{noisy}
  \]

  其中 \(M[1..k]=1\) 为锚点区域（严格保留），\(M[k+1..T]=0\) 为生成区域。

- 这样避免了传统异步算法中的“硬切换”导致机械抖动，也无需 RTC 等后处理平滑。

### 2.3 三阶段训练流程

- **Stage 1：System 2 监督微调（SFT）**  
  三类任务组：
  1. 空间接地：GESTURE-7 格式的末端位姿回归 + 2D 关键点回归；
  2. 轨迹预测：2Hz 的 2D 航点预测与 3D 轨迹点预测；
  3. 推理与规划：基于视觉、指令和当前状态，生成思维链子任务分解以及未来 GESTURE-7 轨迹。

- **Stage 2：System 2 强化学习（RL）**  
  使用 GRPO 算法，沿用 Stage 1 的任务，设计具体奖励函数：
  - GESTURE-7 距离（位置 + 方向 + 手势一致性加权）；
  - 关键点定位奖励（指数衰减）；
  - 航点奖励（点级欧氏距离 + DTW 轨迹距离）；
  - 轨迹奖励（逐点 GESTURE-7 距离）；
  - 格式奖励（正则匹配，权重 0.5）。

- **Stage 3：System 1 监督微调（连续动作）**  
  联合优化 S2 与 S1 权重（视觉编码器冻结），使用 L2 损失，并通过 Guide Action 掩码仅对生成区域计算损失：

  \[
  L(\theta) = \mathbb{E}_{\epsilon, t} \left[ (1 - M) \odot (\epsilon - \epsilon_\theta(x_t, t))^2 \right]
  \]

## 6. 论文的主要结论与发现

- **仿真性能**：NebulaVLA 在 LIBERO-Plus 上整体成功率达到 **85.5%**，超过 InternVLA-M1（81.3%）4.2%，优于 OpenVLA-OFT+（79.6%）、GR00T N1.5（59.0%）和 π0.5（58.0%）。

- **训练策略**：三阶段逐步优化有效，S2 SFT 显著提升 Layout 维度，S2 RL 进一步提升语言和布局相关语义空间表现；但 S2 SFT/RL 在 Camera 扰动维度上有轻微下降，归因于 GESTURE-7 固定视觉-空间映射对视角扰动的敏感性。

## 7. 优点

- **架构创新性强**：异步双频设计（S2 10Hz / S1 20Hz）自然地平衡了语义推理计算开销与实时控制需求，并支持分布式部署（可分离到不同计算设备），工程实用性高。
- **统一动作表征实用**：GESTURE-7 通过自然语言关键词将不同本体的相同动作语义统一，量化到整数 cm/度降低了学习难度，且与 RL 无缝兼容，具有可扩展的手势词表。
- **平滑机制内生**：Guide Action 将平滑约束嵌入扩散去噪过程，而非事后滤波，保证了跨 chunk 语义一致性，且训练时随机采样引导点数增强了实际部署时的鲁棒性。
- **实验设计较完整**：涵盖仿真标准基准、真实机器人、训练策略消融、机制消融和量化指标（SR、延迟、jerk），对比方法均公开可复现。
