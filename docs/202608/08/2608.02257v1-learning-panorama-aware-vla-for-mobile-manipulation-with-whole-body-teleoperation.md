## 摘要
移动操纵是具身智能的关键能力，使机器人能够在开放世界环境中完成复杂的多阶段任务。然而，移动操纵对视觉-语言-动作（VLA）策略提出了两个关键挑战：在数据层面，高效收集高质量的全身示范要求对移动基座和机械臂进行协调控制；在模型层面，现有VLA模型主要依赖局部相机观察，其有限的视野阻碍了全局空间理解。为了应对这些挑战，我们开发了一个全身遥操作系统和一个全景感知的VLA策略。该系统通过单个VR接口实现了对轮式双臂机器人的协调控制，并支持获取一个包含5.5小时多模态示范的真实世界移动操纵数据集。基于这个数据集，我们提出了PanoVLA，一种面向移动双臂操纵的全景感知视觉-语言-动作策略。PanoVLA基于Transformer混合架构，通过专用的全景编码和融合模块引入全局空间上下文，从而能够将全景观察、语言指令和机器人状态有效整合以生成动作。在四个真实世界移动操纵任务上的评估表明，PanoVLA实现了平均阶段完成率91.3%和端到端成功率73.4%，显著优于局部视角基线方法。这些结果表明，融合全景空间上下文能够提升移动机器人的空间理解能力和闭环操纵性能。

## Abstract
Mobile manipulation is a key capability for embodied intelligence, enabling robots to accomplish complex multi-stage tasks in open-world environments. However, mobile manipulation poses two key challenges for vision-language-action (VLA) policies: At the data level, the efficient collection of high-quality whole-body demonstrations demands the coordinated control of both the mobile base and the robotic arms; at the model level, existing VLA models predominantly rely on local camera observations, whose limited field of view hinders global spatial understanding. To address these challenges, we develop a whole-body teleoperation system and a panoramic-aware VLA policy. The system enables coordinated control of a wheeled bimanual robot through a single VR interface and supports the acquisition of a real-world mobile manipulation dataset comprising 5.5 hours of multimodal demonstrations. Building upon this dataset, we propose PanoVLA, a panorama-aware vision-language-action policy for mobile bimanual manipulation. Built upon a Mixture-of-Transformers architecture, PanoVLA introduces global spatial context through dedicated panorama encoding and fusion modules, enabling effective integration of panoramic observations with language instructions and robot states for action generation. Evaluation on four real-world mobile manipulation tasks demonstrates that PanoVLA achieves an average stage completion rate of 91.3\% and an end-to-end success rate of 73.4\%, substantially outperforming local-view baselines. These results demonstrate that incorporating panoramic spatial context improves spatial understanding and closed-loop manipulation performance in mobile robots.

## 1. 核心问题与整体含义（研究动机与背景）

移动操纵（Mobile Manipulation）是具身智能的关键能力，要求机器人同时协调移动底盘、双臂与夹爪，在开放环境中完成多阶段任务。然而，现有视觉-语言-动作（VLA）模型在应用于移动双臂机器人时面临两个核心挑战：

- **数据层面**：高效采集高质量的全身（whole-body）示范数据，需要操作者同时协调移动基座运动与双臂操作、夹爪控制。现有遥操作系统多将移动与操作分离（如使用操纵杆控制底盘），导致示范动作不连贯、质量有限。
- **模型层面**：现有 VLA 模型主要依赖前视相机和腕部相机等局部视角，视野有限，在机器人移动、旋转或臂部自遮挡时，目标物体、地标或目标区域容易超出视野范围，无法建立以机器人为中心的全局空间理解，影响长时程任务的闭环执行。

针对上述问题，本文做了系统性的工作：设计一套基于 VR 的全身遥操作系统以高效采集移动双臂操纵数据，提出一个以全景图（Panorama）感知增强的 VLA 策略 PanoVLA，并构建真实世界数据集进行验证。

## 2. 提出的方法论

### 2.1 全身遥操作系统

- **操作者接口**：操作者佩戴 VR 头显（提供 6-DoF 头部追踪）、双手持控制器（手部姿态 + 夹爪指令）、腰部和双踝佩戴三个身体追踪器，构成轻量稀疏动捕系统。
- **运动重定向（Retargeting）**：将稀疏动捕流实时重建为 SMPL 人体状态，提取骨盆位姿、双手位姿和下肢运动线索，通过通用运动重定向（GMR）公式优化得到全机器人的配置参数。

机器人配置参数化为：

\[
q = (x_b, y_b, \theta_b, q_L, q_R)
\]

其中 \((x_b, y_b, \theta_b)\) 为平面基座位姿，\(q_L\)、\(q_R\) 为双臂关节配置。优化目标为：

\[
q^* = \arg\min_q \lambda_{pos} L_{pos} + \lambda_{rot} L_{rot} + \lambda_{base} L_{base} + \lambda_{reg} L_{reg}
\]

\(L_{pos}\) 对齐手与夹爪位置，\(L_{rot}\) 对齐方向，\(L_{base}\) 将基座平面运动与操作者骨盆位移和朝向耦合，\(L_{reg}\) 抑制关节越限。

- **关键设计——虚拟浮动基座**：将移动底盘建模为 3-DoF 平面虚拟浮动基座，与双臂关节优化联合求解。基座参与末端对齐目标，超出臂工作空间时优化器自动调整基座平移与偏航，减少末端重定向误差，使操作者能通过自然肢体运动协调底盘与双臂。
- **模式切换策略**：提出成本驱动的模式切换机制，在转向（spin）、阿克曼转向（ackermann）、斜移（diagonal translation）三种运动模式间根据实时重定向输出的匹配成本动态选择最优模式，生成底盘速度指令 \((v_x, v_y, \omega)\)。

### 2.2 数据集

- **规模**：4 个真实任务共 800 条成功示范轨迹，约 5.5 小时，约 50 万帧同步数据；每条轨迹 20–30 秒，采样率 25 Hz。
- **数据模态**：
  - 局部观察：前视 RGB 相机 + 两腕部 RGB 相机；
  - 全景观察：顶部 Insta X5 360 相机拍摄，以等距柱状投影（ERP）格式存储；
  - 本体感知状态：双臂绝对关节位置（12 维）+ 夹爪开合状态 + 基座平面位姿 \((x, y, θ)\)；
  - 全身动作：17 维向量 \(a_t \in \mathbb{R}^{17}\)，包括双臂与夹爪 14 维 + 基座平面速度 \((v_x, v_y)\) 与偏航角速度 \(\omega\)。

### 2.3 PanoVLA 模型

- **总体架构**：基于 **Mixture-of-Transformers（MoT）** 架构，包含三个专家模块：
  - **VLM 专家**：编码局部视图（SigLIP）、语言指令和本体状态；
  - **全景专家**：编码全景观察，输出任务条件化的全局空间上下文；
  - **动作专家**：基于联合上下文预测连续动作块。
- **全景编码器**：
  - 双鱼眼图像经球面重投影（spherical reprojection）映射到公共球面并栅格化为 ERP 图像；
  - 使用 **MTPano**（全景基础模型）提取分割分支和深度分支的中间特征，拼接形成统一的密集全景表示，兼顾语义与几何信息；
  - 通过自适应平均池化压缩为固定数量 token，再用轻量 MLP 适配到全景专家的隐藏维度。
- **全景专家**：
  - 采用块级因果注意力，VLM 专家生成 KV cache，全景专家在自身 token 与 VLM cache 之间进行联合自注意力（joint self-attention），生成全景 cache；
  - 动作专家同时利用 VLM cache 与全景 cache（沿 token 维度拼接），从而将局部细粒度操作线索与全局空间上下文统一用于动作生成。

\[
C^{\text{pano}}_t = \phi_{\text{pano}}(Z^{\text{pano}}_t \mid C^{\text{vlm}}_t, M^{\text{pano}})
\]

- **训练目标**：采用条件流匹配（Conditional Flow Matching），对于示范动作块 \(a\)、噪声样本 \(x_\tau\)、流匹配时间步 \(\tau\)，最小化：

\[
L = \mathbb{E}_{p(a|o_t,l), q(x_\tau|a)} \left[ \| v_\theta^{\text{act}}(x_\tau, \tau \mid C_t) - u(x_\tau \mid a) \|_2^2 \right]
\]

## 3. 实验设计

### 3.1 数据集与任务

自定义真实世界数据集，包含四个任务，覆盖不同的空间布局和任务复杂度：

| 任务 | 目标 | 空间设置 |
|---|---|---|
| Move Pen | 将笔放入笔桶 | 前方 / 左 / 右 |
| Move Block | 将积木搬到前方区域 | 左 / 右 / 两侧 |
| Open Curtain | 打开两侧窗帘 | 左 / 右 |
| Wipe Table | 擦拭长桌污渍并归回抹布 | 长桌（多阶段、大范围） |

任务设计的关键是：相关区域不能同时被局部相机覆盖，迫使策略进行跨视角空间推理和多阶段状态跟踪。

### 3.2 对比方法（Baselines）

- **π0.5**：仅使用局部相机视图（SigLIP 编码）的标准 π0.5 策略；
- **π0.5 w/ Pano**：将 ERP 全景图作为附加图像用 SigLIP 编码，无专用全景分支；
- **π0.5 w/ Stacked Pano**：将全景重投影为三个间隔 120° 的透视视角并拼接为一张复合图，作为附加输入；
- **PanoVLA**：本文方法，MTPano 编码 + 全景专家融合。

### 3.3 评估协议与指标

- **指标**：
  - **SCR（Stage Completion Rate）**：阶段完成率，衡量中间阶段（目标搜索、移动接近、物理操纵）的成功比例；
  - **SR（Success Rate）**：端到端成功率（整条轨迹完整成功与否的二元指标）。
- **规模**：每个任务 15 次连续闭环真实机器人试验，每项试验为不间断执行，无失败阶段手动重置。

### 充分性评估

**充分之处**：

- 采用真实机器人闭环评估，避免仿真到真实的域迁移偏差；
- 设置三种受控基线，隔离了“全景信息本身”和“全景建模方式”各自贡献；
- 消融覆盖了模型容量与编码器选择两个关键设计维度；
- 阶段级分析（SCR）有助于区分失败发生在哪个环节。

**不足/偏差风险**：

- 消融实验仅在 Move Pen 上测试，未验证专家规模/编码器选择在其他任务上的普适性；
- 四个任务均在同一机器人和相似室内环境，未验证跨环境、跨物体配置的泛化能力；
- 与基线的对比仅限 π0.5 体系内部变体，没有与其他移动操纵 VLA 方法（如 MoManipVLA、SG-VLA、AC-DiT 等）在统一 benchmark 上的横向对比；
- 未使用已有公开数据集或标准 benchmark（如 BEHAVIOR Robot Suite、RoboPanoptes 等）进行比较。

## 6. 主要结论与发现

1. **全景上下文显著提升移动操纵性能**：PanoVLA 平均 SCR 达 91.3%、SR 达 73.4%，显著超过局部视图基线 π0.5（SCR 58.6%、SR 30.0%），证明全景空间上下文有助于全局空间推理与闭环操作。
2. **有效全景建模比“看得更宽”更关键**：尽管 π0.5 w/ Pano（80.8% / 56.7%）优于局部基线，但与 PanoVLA 的差距表明：单纯扩大视野并不足够，需要使用全景专属编码器（MTPano）和专用的融合模块。
3. **透视重投影并非更优解**：将全景切分为三个透视视图（Stacked Pano）平均 SCR 70.4%、SR 38.3%，反而低于直接输入 ERP 的原始全景基线，且在不同任务上表现不稳定。
4. **多阶段任务中优势更明显**：对于要求持续状态跟踪和跨阶段空间一致性的任务（Open Curtain、Wipe Table），PanoVLA 的优势更突出，例如 Wipe Table 的最后阶段完成率 73.3% vs 基线 26.7%。
5. **专家规模存在最优平衡点**：100M 参数全景专家在效率与性能间达到最佳权衡，更小（50M）能力不足，更大（200M/300M）因微调数据有限而未见持续提升。
6. **全景专用视觉编码器优于通用视觉编码器**：MTPano（95.6% / 86.7%）显著优于 SigLIP（75.6% / 40.0%），说明通用透视图像预训练编码器难以有效处理全景图像的畸变与水平连续性。

## 7. 优点与亮点

- **系统完整性**：从数据采集（遥操作系统）→ 数据集建设 → 模型设计 → 真实世界验证形成完整闭环，不是单一算法贡献；
- **遥操作设计的创新性**：将移动底盘建模为虚拟浮动基座并入 GMR 联合优化，让基座运动参与末端对齐目标，降低操作者认知负担；成本驱动的模式切换策略将虚拟 3-DoF 指令映射到实际底盘运动模式，工程实现上有实际价值；
- **数据集具有独特性**：包含时间对齐的全景图 + 局部视图 + 本体状态 + 全身动作的多模态移动双臂操纵数据，且有任务分类学（目标布局、双边交互、空间尺度变化）；
- **模型设计具有针对性**：MTPano

## 7. 优点与亮点（续）

- **模型设计具有针对性**：MTPano 作为全景专用编码器同时提取语义（分割分支）与几何（深度分支）特征，缓解了通用透视预训练编码器对全景图像畸变和水平连续性的不适应问题；全景专家通过块级因果注意力实现全局上下文对动作预测的条件化，形成了"局部细粒度操作线索 + 全局空间上下文"的双通道动作生成管线。
- **训练效率友好**：训练时冻结语言骨干（Gemma-2B）与 MTPano 编码器，仅训练动作专家与全景专家，配合流匹配目标，在 4 张 A100 上即可完成训练，降低了大规模 VLA 微调的门槛。
- **工程实现完整性**：遥操作系统包含人体动捕、SMPL 重建、GMR 优化、模式切换、速度映射等多个模块，并开放虚拟浮动基座的联合优化策略，整个数据采集流程经过了真实环境的验证，具备较强的可复现性与实用价值。

## 8. 不足与局限性

尽管 PanoVLA 在四个任务上取得了明显优势，本文仍存在若干值得注意的局限：

- **泛化能力未充分验证**：实验仅在单一机器人平台（单臂/双臂规格固定）与相似室内环境中进行，没有验证跨机器人形态、跨环境布局、跨物体外观的泛化能力；任务中的物体位置虽有一定变化，但整体语义空间仍较封闭。
- **数据集规模有限**：800 条轨迹、四个任务的数据规模对于 VLA 训练而言相对较小，模型性能的上限可能受限于数据多样性；全景图像与局部视图的时间对齐和标定误差也未进行敏感性分析。
- **评估统计性偏弱**：每任务 15 次试验未报告方差、置信区间或逐次试验的详细信息，无法判断性能差异的统计显著性；考虑到机器人闭环执行的高随机性，15 次样本的结论稳健性有待加强。
- **缺乏与更广泛方法的横向对比**：基线均为 π0.5 体系内部的变体，未与 MoManipVLA、SG-VLA、AC-DiT 等其他移动操纵 VLA 方法，或 BEHAVIOR Robot Suite、RoboPanoptes 等公开基准进行统一评测，难以定位其在领域内的相对水平。
- **硬件依赖限制实用部署**：方法依赖顶部 360° 全景相机（Insta X5），在实际部署中可能面临相机重量、功耗、安装位置遮挡、实时拼接延迟等问题；全景图像的传输与预处理也会引入额外的计算开销。
- **长时程与跨区域任务未覆盖**：Wipe Table 已涉及约 20–30 秒的多阶段操作，但仍限于单房间内，未验证跨房间、跨楼层等更长时间跨度的空间记忆与状态跟踪能力。
- **可解释性分析缺失**：文章未对全景上下文具体在哪些阶段、哪些 token 上影响动作预测进行可视化或归因分析，全景专家与动作专家的融合机制仍是黑箱。

## 9. 综合总结与展望

PanoVLA 的贡献可以概括为三点：一套高效的全身遥操作数据采集方案、一个包含全景与局部多模态信息的移动双臂操纵数据集、以及一个面向全局空间推理的 VLA 模型架构。其核心洞察在于：**移动操纵失败的主要来源之一是局部视野受限导致的空间盲区，而全景感知结合专属编码器与融合机制能够有效弥补这一缺陷**。实验结果显示，PanoVLA 在阶段完成率与端到端成功率上均显著优于局部视图基线，且在多阶段、大范围任务中优势更为突出，验证了"全局空间上下文 + 局部操作细节"互补建模的有效性。

未来工作可以从以下方向展开：

1. **扩大数据规模与场景多样性**，将全景-局部多模态数据采集扩展到更多任务类型、更多环境布局，甚至结合仿真数据合成（如借助具身仿真平台生成全景渲染数据）以缓解真实数据采集瓶颈；
2. **探索轻量化全景感知方案**，例如基于多视角局部相机拼接或可学习的隐式空间表示替代专用全景相机，降低部署成本；
3. **引入更强的时间建模与记忆机制**，使策略在长时程任务中维持全局空间一致性；
4. **与开放词汇推理、场景图等高层语义模块结合**，提升对未见物体与未见布局的泛化能力；
5. **在统一公开基准上与更多主流方法进行横向对比**，建立更具说服力的评测体系。

总体而言，本文在"数据—模型—验证"三个层面均做出了扎实且有实用价值的贡献，为移动双臂 VLA 研究提供了一条值得借鉴的技术路线。
