## 摘要
视觉-语言-动作（VLA）模型的主流做法是将预训练的VLM与单独训练的流匹配动作专家相结合。这使得VLM成为上下文编码器而非决策者。我们引入G0.5，一种预训练的自回归VLA，其中单个Transformer解码器在单一目标下生成推理与动作标记。三个组件使其在基础模型规模下可行：一个可学习的跨具身动作分词器，将异构机器人动作映射到共享词汇表；一个原生思维链流，将任务分解、对象定位和动作提示与动作标记交错排列；以及一个视觉记忆模块，通过视觉编码器注入多秒历史信息。由于推理和动作共享同一组权重，预训练VLM的能力可迁移至物理行为：模型严格遵循指令，且提示可直接引导动作粒度、任务范围以及分布外场景处理，无需额外训练。G0.5在大量机器人数据集和VQA样本上预训练，在7个独立场景中均超越最先进模型：在R1lite和R1pro机器人上的真实世界微调（76.7%对比π₀.₅的53.3%和GR00T-N1.7的24.4%）；2025年BEHAVIOR挑战赛中使用通用策略完成50项长时程家庭移动操作任务（31.4%对比π₀.₅的26.3%和挑战赛冠军的26.1%）；DROID训练后零样本迁移至未见环境和物体（82.5%）；语言跟随抓取放置基准LIBERO（98.9%）；RoboTwin 2.0（93.3%）；以及SimplerEnv-Bridge（87.3%）。

## Abstract
The prevailing recipe for Vision-Language-Action (VLA) models couples a pretrained VLM with a separately trained flow-matching action expert. This makes the VLM a context encoder rather than a decision-maker. We introduce G0.5, a pretrained autoregressive VLA in which a single transformer decoder emits reasoning and action tokens under a single objective. Three components make this tractable at foundation-model scale: a learnable cross-embodiment action tokenizer that maps heterogeneous robot actions into a shared vocabulary; a native chain-of-thought stream interleaving task decomposition, object grounding, and action hints with action tokens; and a visual memory module that injects multi-second history through the vision encoder. Because reasoning and action share a single set of weights, the pretrained VLM's capabilities carry over to physical behavior: the model follows instructions closely, and prompts directly steer action granularity, task horizon, and out-of-distribution scene handling without further training. Pretrained on a large collection of robot datasets together with VQA samples, G0.5 surpasses state-of-the-art models across 7 independent regimes: real-world fine-tuning on R1lite and R1pro robots (76.7\% vs.\ 53.3\% for $π_{0.5}$ and 24.4\% for GR00T-N1.7), the 2025 BEHAVIOR Challenge on 50 long-horizon household mobile manipulation tasks using a generalist policy (31.4\% vs.\ 26.3\% for $π_{0.5}$ and 26.1\% for the challenge winner), DROID post-training followed by zero-shot transfer to an unseen environment and objects (82.5\%), a language-following Pick-and-Place benchmark, LIBERO (98.9\%), RoboTwin 2.0 (93.3\%), and SimplerEnv-Bridge (87.3\%).

## 1. 核心问题与研究动机

- **背景**：当前主流视觉-语言-动作（VLA）模型采用“预训练 VLM + 独立流匹配动作专家”的架构。
- **核心问题**：这种解耦设计使 VLM 仅充当**上下文编码器**，并未真正参与动作决策；推理（语言思维）与动作生成由不同模块、不同目标函数驱动，导致预训练 VLM 的语义理解、指令跟随和泛化能力无法直接迁移到物理行为。

## 2. 方法论

### 2.1 核心思想
- 训练一个**单自回归 Transformer 解码器**，输入视觉与语言上下文，输出交错排列的**推理词元**和**动作词元**，所有输出共享同一组权重、同一自回归目标（next-token prediction）。
- 推理不是“附加注释”，而是原生地参与动作生成：任务分解、物体定位、动作提示等思维链内容与动作标记交错产生，直接引导后续动作词元的预测。

### 2.2 关键技术组件

- **可学习的跨具身动作分词器（Learnable Cross-Embodiment Action Tokenizer）**
  - 将不同机器人（异构具身）的动作空间映射到**共享离散词汇表**。
  - 解决多数据集、多机器人动作维度、控制频率不一致的问题，使模型可在大规模异质机器人数据上统一预训练。

- **原生思维链流（Native Chain-of-Thought Stream）**
  - 推理文本与动作词元在序列中**交替排列**，形成一个统一的、逐步推进的决策序列。
  - 典型流程：任务分解 → 物体定位 → 动作提示 → 动作词元 → … → 最终动作完成。
  - 推理不是事后解释，而是动作生成的**因果先导**。

- **视觉记忆模块（Visual Memory Module）**
  - 通过视觉编码器将**多秒历史观测**注入当前上下文。
  - 为长时程任务提供时间一致性，弥补单帧观测的局限性。

### 2.3 训练流程
- 在**大量机器人数据集 + VQA 样本**上联合预训练，目标统一为自回归词元预测。
- 推理与动作在同一损失下优化，无需分离训练或两级微调。
- 预训练完成后，可通过提示词直接调控动作粒度、任务范围、分布外场景处理方式，**无需额外训练**（即具备零样本指令引导能力）。

## 6. 主要结论

- **单一自回归流可行且更优**：推理与动作可以共享同一组权重，在同一目标下联合生成，并在多个基准上超越“VLM + 动作专家”的解耦范式。
- **预训练 VLM 能力直接迁移到物理行为**：由于权重共享，VLM 的指令跟随、语义理解、分布外场景处理等能力不再是“旁路”，而能直接作用于动作生成。
- **提示词即控制器**：无需额外训练，通过改变提示即可控制动作粒度（如粗粒度/细粒度）、任务范围（单步/长时程）和分布外场景应对方式。
- **跨具身泛化**：可学习的动作分词器有效统一异构机器人动作空间，支撑大规模多机器人数据预训练。

## 7. 优点

- **架构简洁统一**：移除流匹配动作专家，仅用一个自回归 Transformer，简化了训练与推理流程。
- **推理与动作深度耦合**：思维链不是装饰，而是因果地参与动作词元生成，使模型可“边想边做”。
- **提示驱动零样本调控**：展示了语言提示直接控制行为特性，这是解耦架构难以实现的。

- **组件设计具有实用价值**：动作分词器解决跨具身问题，视觉记忆模块解决长时程依赖。
