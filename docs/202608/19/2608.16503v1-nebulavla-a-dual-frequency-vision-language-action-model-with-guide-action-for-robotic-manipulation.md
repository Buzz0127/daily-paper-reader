## 摘要
视觉-语言-动作（VLA）模型在现实世界中的部署通常受制于效率与性能之间的权衡、跨本体泛化以及执行平滑性。我们提出了NebulaVLA，一种异步双频架构，将高层语义推理与低层动作控制解耦，从而优化计算资源和模块性。为了弥合异构机器人之间的语义鸿沟，我们引入了GESTURE-7，一种统一的语言接地动作表示。此外，我们的引导动作算法通过基于掩码的平滑性约束来强制执行运动学连续性。综合评估表明，NebulaVLA显著优于同步基线，在LIBERO-Plus上实现了85.5%的平均成功率，并将动作生成加速约2.7倍。这种异步设计为实际机器人技术实现了高效且响应迅速的控制。

## Abstract
Real-world deployment of Vision-Language-Action (VLA) models is often bottlenecked by efficiency-performance trade-offs, cross-embodiment generalization, and execution smoothness. We present NebulaVLA, an asynchronous dual-frequency architecture that decouples high-level semantic reasoning from low-level action control, optimizing computational resources and modularity. To bridge semantic gaps across heterogeneous robots, we introduce GESTURE-7, a unified language-grounded action representation. Furthermore, our Guide Action algorithm enforces kinematic continuity via mask-based smoothness constraints. Comprehensive evaluations demonstrate that NebulaVLA significantly outperforms synchronous baselines, achieving an 85.5\% average success rate on LIBERO-Plus and accelerating action generation by \textasciitilde 2.7$\times$. This asynchronous design enables highly efficient and responsive control for practical robotics.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：机器人操作正从模块化流水线向端到端学习转变，视觉-语言-动作（VLA）模型通过统一感知、语言和控制，实现自然语言指令跟随与复杂任务执行。自 RT-1、OpenVLA 到 InternVLA 系列，该领域发展迅速。
- **核心痛点**：现有 VLA 模型在真实世界部署中面临三大瓶颈：
  1. **效率-性能权衡**：单体同步架构使用统一时间分辨率，无法同时支持低频语义推理与高频电机控制；
  2. **跨本体泛化不足**：将连续运动学映射为离散 Token 需要大规模词表与演示数据，难以统一异构平台的动作语义；
  3. **执行平滑性差**：异步实时推理与动作块生成之间的时间错配导致轨迹抖动和边界不连续。
- **论文意义**：提出 NebulaVLA，通过异步双频架构系统性地解决上述问题，为高效、平滑、跨本体的机器人部署提供了一条新路径。

### 2. 论文提出的方法论

**核心思想**：借鉴认知科学中的"快慢双系统"（fast-slow）范式，将高层语义推理与低层动作控制解耦为两个异构频率的子系统。

**关键技术细节**：

- **异构双频架构**：
  - System 2（10 Hz）：以 Qwen3-VL 为骨干，处理自然语言指令与稀疏视觉输入，输出抽象动作引导；
  - System 1（20 Hz）：以 DiT（Diffusion Transformer）为生成器，接收高频视觉输入、动作历史及 S2 的引导，输出执行动作。
  - 两系统通过异步通信解耦，支持分布式部署，最大限度降低交互延迟。

- **GESTURE-7 统一动作表示**：
  - 将末端执行器状态编码为 7 维向量 [x, y, z, r, p, w, gesture]，前 6 维为量化到整数厘米/度的笛卡尔位置与欧拉角；
  - 第 7 维 gesture 使用自然语言关键词（如 grasp、push、pinch）统一异构机器人（灵巧手、夹爪）的相同动作语义；
  - 该表示天然支持与语言条件强化学习结合，提升跨本体迁移能力。

- **Guide Action 机制**：受图像外推（Image Outpainting）启发，将块间拼接嵌入生成流程：
  - 下一动作块的生成以上一动作块中未执行的动作作为条件锚点（训练时随机采样 0~3 个引导点）；
  - 扩散去噪过程中通过二进制掩码 M 强制保留已知动作区域（M=1），仅对新增区域（M=0）进行生成，如下式：
    \[
    A^{t-1}_{full} = M \odot A^{(t-1)}_{prior} + (1 - M) \odot A^{t-1}_{noisy}
    \]
  - 该方法在生成过程内部强制执行运动学连续性，无需后处理平滑，有效消除块边界的硬切换抖动。

- **三阶段训练流程**：
  - **Stage 1（S2 SFT）**：基于 GESTURE-7 对 System 2 进行监督微调，涵盖姿态回归、关键点回归、2D/3D 轨迹预测及思维链生成等任务；
  - **Stage 2（S2 RL）**：采用 GRPO 强化学习进一步优化 System 2 的轨迹规划能力，设计多种奖励函数（GESTURE-7 距离、关键点定位、轨迹、格式等）；
  - **Stage 3（S1 SFT）**：利用加权流匹配损失联合优化 System 1（及 S2 部分权重），损失函数仅作用于掩码 M=0 的新生成区域，保证训练-推理频率严格对齐。

### 7. 优点

- **架构设计新颖**：异步双频架构直观地契合认知科学中 System 1/System 2 的范式，在计算效率与控制响应之间取得了实际可衡量的平衡，且天然支持分布式部署。
- **GESTURE-7 表示巧妙**：用 7D 连续向量 + 自然语言关键词的方式统一异构机器人动作语义，量化到整数单位简化学习难度，同时保持与语言模型和 RL 的天然兼容性。
- **Guide Action 机制有理论深度**：将图像外推思想迁移到动作块生成中，把平滑性约束内化到扩散去噪过程而非后处理，从原理上解决了块边界不连续问题。
- **训练流程设计严谨**：三阶段训练各司其职（感知建立 → 语义强化 → 动作对齐），并保留原始多模态模型通用能力，避免灾难性遗忘。
- **实验验证较全面**：仿真 + 真实世界双轨验证，消融实验覆盖训练策略和动作平滑机制，并提供了延迟、成功率、关节急动度等多维度量化指标。

### 8. 不足与局限

- **频率固定且经验设定**：10 Hz/20 Hz 的分配是静态且经验决定的，不同任务域的最优频率配置可能不同，动态自适应调度仍是未解挑战。
- **Guide Action 的响应延迟**：固定引导锚点机制在环境快速变化时可能引入轻微响应延迟，影响系统的即时反应能力。
