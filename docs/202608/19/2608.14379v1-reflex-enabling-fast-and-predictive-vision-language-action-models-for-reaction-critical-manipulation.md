## 摘要
视觉-语言-动作（VLA）模型近年来在机器人操作中取得了有前景的性能。然而，现有基准主要评估静态操作任务上的泛化能力，很大程度上忽略了动态交互场景。为解决这一缺口，我们提出了ReflexBench，一个用于反应关键型操作的基准。ReflexBench包含六个动态任务，并引入了一个评估框架，该框架将模拟器步进与机器人控制解耦，同时支持同步和异步推理下的可配置延迟。基于ReflexBench，我们提出了ReflexVLA，一种专为反应关键型操作设计的高效VLA模型，无需大规模机器人数据预训练。ReflexVLA通过潜在未来预测和视觉骨干网络内的多帧时间融合增强了时间推理能力，同时通过批量视觉编码和CUDA图重放降低了部署延迟。实验表明，ReflexVLA持续提升动态操作性能，同时在标准静态操作基准上保持具有竞争力的准确性，真实世界实验进一步证明了其在实际部署条件下的有效性。项目网站：https://reflexvla.github.io

## Abstract
Vision-Language-Action (VLA) models have recently achieved promising performance in robotic manipulation. However, existing benchmarks mainly evaluate generalization on static manipulation tasks and largely overlook dynamic interaction scenarios. To address this gap, we present ReflexBench, a benchmark for reaction-critical manipulation. ReflexBench contains six dynamic tasks and introduces an evaluation framework that decouples simulator stepping from robot control while supporting configurable latency under synchronous and asynchronous inference. Building upon ReflexBench, we propose ReflexVLA, an efficient VLA model designed for reaction-critical manipulation without large-scale robot-data pretraining. ReflexVLA enhances temporal reasoning through latent future prediction and multi-frame temporal fusion within the vision backbone, while reducing deployment latency through batched visual encoding and CUDA Graph replay. Experiments show that ReflexVLA consistently improves dynamic manipulation performance while maintaining competitive accuracy on standard static manipulation benchmarks, and real-world experiments further demonstrate its effectiveness under practical deployment conditions. Project website: https://reflexvla.github.io

  - 大多数方法仅基于当前观测生成动作，而推理延迟导致感知与执行之间存在时间差，在动态环境（移动物体、目标拦截、轨迹影响任务成功）中这一延迟尤为致命。

- **研究目标**：解决"同时实现强预见能力与快速推理"这一未被充分探索的问题，推动VLA模型在反应关键型操作场景中的应用。

- **延迟感知评估协议**（关键创新）：
  - 将仿真步进与机器人控制**解耦**，允许环境动力学独立于策略计算演变。
  - 支持**同步推理**（阻塞执行直至策略推理完成）与**异步推理**（动作执行与策略计算重叠）两种部署范式。
  - 通过延迟阻塞机制在仿真中忠实复现推理延迟效果；延迟值可手动指定，从而可控地分析不同延迟水平对性能的影响。
  - 支持从实际策略执行中测量的延迟，通过**实时因子（Real-Time Factor, RTF）** 将真实世界延迟转换为仿真延迟：

    RTF = t_sim / t_wall
    其中 t_sim 为仿真耗时，t_wall 为执行仿真所需的墙钟时间。

#### 2. ReflexVLA模型

基于紧凑的视觉-语言-动作架构（VLA-Adapter），视觉编码器为由DINOv2和SigLIP融合的ViT骨干（224×224分辨率），语言骨干为Qwen2.5-0.5B因果Transformer。三大核心设计：

**（1）潜在未来预测（Latent Future Prediction）**
- 直接在图像空间预测未来帧计算昂贵，且容易让模型关注与操作无关的低层外观细节。
- 改用**冻结的DINOv3编码器**提取未来观测的语义潜在特征：y_{t+i} = φ_DINOv3(o_{t+i})，维度为R_1024。
- 在输入序列中追加H个可学习的未来token（H等于动作块大小，使未来状态预测与动作生成的时序结构对齐），经过Transformer前向传播后，将第i个未来token的隐藏表示投影到DINOv3特征空间：ŷ_{t+i} = f_pred(h_future_i)。
- 使用**掩码余弦相似度损失**训练：

  L_future = Σ m_i [1 − cos(ŷ_{t+i}, y_{t+i})] / Σ m_i

- 总损失：L = L_act + λ_future · L_future（λ_future控制未来预测的贡献）。

**（2）多帧时间融合（Multi-Frame Temporal Fusion）**
- 直接从多帧图像拼接视觉token会导致V×T×P个token，带来二次注意力的高计算开销；且忽略显式时序结构。
- 在**视觉骨干内部**进行时间融合，仅将当前帧的融合表示暴露给语言模型：
  - 从ViT中间层和最终层提取特征 X_mid, X_final ∈ R^(B×V×T×P×D)。
  - 对中间层特征（保留更丰富的局部外观和运动线索），在每个相机视角和patch位置的T个历史帧特征上构建时间轨迹。
  - 先归一化并下投影降维：z = Down(LN(x_mid)) + e_1:T（e为时间位置编码），然后应用**因果时间注意力**（防止信息泄漏，保证在线部署一致性）：Δx = Up(MHA_causal(z)^T)。
  - 将时间表示整合进当前帧特征：x̃ = x_final + Δx。
- 关键优势：语言模型消费的视觉token数量与单帧设置完全相同，在不引入语言模型端大量开销的前提下利用短期运动信息。

**（3）推理延迟优化（Inference Latency Optimization）**
- 第一项优化：**批量视觉编码**，将所有视角和帧的图像合并为一次视觉编码器调用，减少逐帧执行的框架开销并提升GPU利用率。
- 第二项优化：**CUDA Graph重放**，将完整的推理流水线（视觉编码、时间融合、多模态投影、语言模型推理、动作预测）捕获为CUDA Graph，执行时通过预分配缓冲区和图重放消除反复的内核启动与运行时调度开销：

  â_{t:t+H−1} = G(x_text, x_vision, x_state)

- 这些优化不改变策略架构或学习目标，仅降低部署开销，适合延迟敏感的机器人操作任务。

### 六、论文的主要结论与发现

1. **推理范式与频率的权衡**：低频下异步推理因观测-动作错配而性能差；随推理频率增加，异步推理逐步优于同步推理。
