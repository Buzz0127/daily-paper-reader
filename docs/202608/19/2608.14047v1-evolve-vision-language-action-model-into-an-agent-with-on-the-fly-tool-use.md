## 摘要
本文整合了端到端的视觉-语言-行动（VLA）模型与智能体工具使用，提出了具身智能工具使用机器人（ART）。ART是一个工具注入框架，可调整任何VLA模型以利用现成的工具模块，用于低级视觉、高级可供性和具身增强。与具有连续动作解空间的普通VLA模型相比，ART通过工具使用降低了动作解空间的复杂度，不仅提高了跨不同任务的泛化能力，还减少了对数据的依赖。为了展示该框架的优势（高泛化性和低数据依赖性），我们首先构建了一个包含30K条工具使用轨迹和动作演示的数据集，该数据集远小于基线方法使用的数据量。然后，我们设计了一套在挑战性环境中进行长轨迹工具使用推理的训练方案。实验表明，ART在仿真和真实世界任务（如黑暗中的新视角抓取与放置）中比主流基线方法的成功率高出20%。实证结果凸显了基于智能体的方法的优势：模块化工具利用能够实现更高效训练、轻量级部署以及新工具的可扩展集成。这种设计增强了鲁棒性、适应性和可扩展性，为VLA系统在复杂现实场景中的实际部署铺平了道路。

## Abstract
This paper integrates end-to-end Visual-Language-Action (VLA) models with agentic tool-use to propose Agentic Robot with Tool-use (ART). ART is a tool-injection framework that tunes any VLA model to leverage off-the-shelf tool modules for low-level vision, high-level affordance, and embodiment enhancement. Compared to vanilla VLA models with a whole continuous action solution space, ART reduces the complexity of the action solution space through tool-use, which not only improves generalizability across different tasks but also reduces data dependency. To demonstrate the advantages (high generalizability and low data dependency) of this framework, we first built a dataset of 30K tool-use trajectories and action demonstrations, which is much smaller than those used by baseline methods. We then designed a training regimen for long-trajectory tool-use reasoning in challenging environments. Experiments show that ART achieves a 20% higher success rate than mainstream baselines on simulation and real-world tasks, such as pick-and-place in the dark at novel viewpoints. Empirical results highlight the benefits of an agent-based approach: modular tool utilization enables more efficient training, lightweight deployment, and scalable integration of new tools. This design fosters robustness, adaptability, and extensibility, paving the way for the practical deployment of VLA systems in complex real-world scenarios.

# 论文详细总结

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：视觉-语言-行动（VLA）模型在机器人操作领域主要有两条发展路径：
  - **模块化方法**（如 RoboTool、RoboScript、RoboCodeX）：将特定功能封装在工具模块中，通过调用预定义 API 完成任务。优点是功能解耦，但受限于固定工具集，难以应对复杂动作输出。
  - **端到端方法**（如 OpenVLA、ECoT、π0）：训练单一基础模型，在大规模多任务数据上直接输出连续动作，精度高，但面对新场景需要昂贵的后训练，且耦合性强、易发生灾难性遗忘。
- **核心问题**：如何同时获得端到端 VLA 模型的精确动作输出能力，又能让模型灵活、快速地集成外部工具以适配新场景和新任务？
- **研究动机**：现有 VLA 模型采用完整连续动作空间，导致跨任务泛化能力差、数据依赖强，限制了在复杂真实场景中的实际部署。

## 2. 论文提出的方法论

- **核心思想**：提出 ART（Agentic Robot with Tool-use）工具注入框架，通过将外部工具模块（视觉增强、可供性增强、具身增强）集成到 VLA 模型中，将连续动作空间离散化为"动作 + 推理 + 工具调用"的组合空间，从而降低动作解空间的复杂度，提升泛化能力并减少数据依赖。

- **关键技术细节**：
  - **动作空间扩展**：将模型动作空间从连续动作空间 A 扩展为 A\* = A × R × T，其中 R 为语言推理空间，T 为工具使用空间。
  - **优化目标分解**：将端到端目标分解为两部分——维持原始 VLA 的动作生成能力（Pθ₁）+ 工具推理与调用的微调目标（Pθ₂）。
  - **工具 Token 注入**：将工具使用动作表示为离散 token（每个工具状态是二元的：激活/未激活），映射到模型词表的末尾 N 个 token 中，融入标准 next-token prediction 训练。
  - **自适应 LoRA 微调（Adaptive LoRA Fine-tuning）**：冻结预训练 VLA 骨干，只微调 LoRA 模块用于工具推理；推理时，模型先启用 LoRA 生成推理和工具调用，激活外部工具后，再**屏蔽 LoRA 输出**，让模型基于增强后的观测恢复原始动作生成能力，有效避免灾难性遗忘。
  - **动作分块（Action Chunk）**：每 H 个时间步执行一次工具推理和选择，而非每一步调用工具，降低推理开销。
  - **数据生成流水线**（AT 数据集，30K 轨迹，远小于基线数据集）：
    1. **任务生成**：对现有 VLA 数据进行"降级处理"（引入视觉退化、可供性查询、具身扰动），生成需要工具使用的任务。
    2. **工具链生成**：为每个任务配对解决所需的工具序列。
    3. **轨迹生成**：用 GPT 将任务-工具对合成为详细的长轨迹推理过程。

## 6. 论文的主要结论与发现

- **工具使用显著提升性能**：ART-FAST 在 LIBERO 仿真环境平均成功率 75%，在真实 Astribot S1 上 62%，比最强基线 π0-FAST 分别高出约 36% 和 19%。
- **跨环境泛化能力强**：AT 数据集基于 LIBERO、Bridge v2、DROID 训练，工具推理能力可迁移至新的真实机器人环境，无需任务特定重训练。
- **工具推理优于纯推理**：与 ECoT 相比，在无视觉扰动时 ART 稍优；在有视觉扰动时，ECoT 性能大幅下降（36% 平均），而 ART 保持 67% 平均成功率，验证了外部视觉增强工具的价值。
- **工具注入优于端到端后训练**：用相同训练数据量，ART 在三类任务上全面优于纯端到端后训练的 FAST 模型，证明工具调用带来的中间表征有利于任务解决。
- **数据效率显著**：仅需 30K 工具轨迹即可实现上述性能，远小于传统端到端 VLA 模型所需的数据量。

## 7. 优点

- **低数据依赖**：通过工具使用缩小动作解空间，30K 轨迹即可达到优于大规模训练的基线效果。
- **模块化与可扩展性**：新工具可即插即用，不改变核心 VLA 结构，便于持续扩展工具库。
- **规避灾难性遗忘**：自适应 LoRA + 推理时屏蔽 LoRA 输出的设计，在保留原始动作能力的同时引入工具推理能力。
- **数据生成流水线创新**：通过"降级"现有 VLA 数据并借助 GPT 合成工具链轨迹，避免了昂贵的人工轨迹采集。
- **通用性强**：可与多种 VLA 架构集成（论文以 π-FAST 为例），不仅限于特定模型。
- **多模态工具覆盖**：视觉、可供性、具身三类工具覆盖了 VLA 输入的不同模态（图像、语言、本体感知），设计完整。
