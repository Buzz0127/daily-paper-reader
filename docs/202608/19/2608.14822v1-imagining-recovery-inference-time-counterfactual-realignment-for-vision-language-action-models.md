## Abstract
Vision-language-action (VLA) models have improved the flexibility and generality of robotic manipulation, yet they remain fragile to online disruptions, such as changes in task goal, scene configuration, or robot state. Existing recovery methods often require failure data, policy retraining, or external corrective agents, introducing additional data requirements and execution risks. We propose Counterfactual Realignment (CoRe), a training-free framework that recovers a frozen VLA at inference time without failure data. Upon detecting a deviation, CoRe imagines how the policy would continue toward the current goal from a recent viable state, using synthesized observations in place of physical execution, and then minimally realigns the robot and scene to rejoin this imagined continuation before returning control to the policy. Recovery is therefore planned without physical trial-and-error, preserves completed task progress, and handles both mid-episode instruction changes and physical perturbations in a unified manner. Extensive experiments across multiple simulators, VLA backbones, and real-world settings show that CoRe improves success rates by up to 85.0 percentage points to near-nominal levels while reducing physical restorations by 42.2%, without policy fine-tuning or failure-specific recovery training.

## 1. 核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）模型通过耦合大规模视觉-语言表示与机器人动作生成，在物体、任务和环境间展现出了较好的泛化能力。然而，VLA 几乎只在"成功、正向推进"的示范数据上训练，缺乏对分布外（OOD）执行状态的纠错能力。
- **核心问题**：VLA 在执行过程中对在线干扰非常脆弱，包括三类典型偏差：
  1. 任务目标改变（mid-episode instruction change）；
  2. 场景配置改变（物体被移动、推倒等环境扰动）；
  3. 机器人状态改变（机械臂受碰撞偏移、夹爪意外松开等）。
- **现有方法的不足**：
  - 第一类方法在示范数据中注入失败数据并重新训练策略（行为克隆、偏好优化等），代价高昂且新失败模式出现时需反复采集数据与重训；
  - 第二类方法将恢复委托给外部模块（LLM/VLM 智能体、残差策略等），增加推理开销，且恢复决策本身的可靠性无法保证；
  - 简单重置或回退到预定状态会丢弃已完成的任务进度，且无法真正逃离 OOD 状态。
- **本文意义**：提出一种**无需训练的推理时恢复框架 CoRe**，将"物理试错"替换为"虚拟规划"，统一处理语言切换与物理扰动，保留已完成的进度，且不依赖失败数据、策略微调或外部辅助模型。

## 2. 方法论

### 2.1 核心思想

CoRe 的核心是**反事实延续（counterfactual continuation）**：当检测到偏差时，从最近的可行（in-distribution）状态出发，在合成观测上闭环比对式地滚动执行冻结的 VLA 策略，得到"如果没被干扰，策略会如何继续"的短轨迹；然后据此确定一个安全的**重接状态 c\*** 和一组**最小恢复子集 S\***，最后才执行物理调整，将机器人/场景对齐到该状态后交还控制权。

整体优化目标：

```
c* = argmin |R(c)|   s.t.  π(·|c, ℓ') ∈ D,  P(c_now) ⊆ P(c)
```

即：最小化物理操作数，同时保证策略在新指令下的延续在分布内，且不丢失已完成的子目标进度。

### 2.2 关键技术流程（五个阶段）

1. **在线后缀 OOD 检测（Suffix OOD Detection）**
   - 监测动作头最后的隐藏状态（action-expert suffix latent），每次策略查询做 K 次随机前向，取均值池化后计算逐任务的马氏距离得分 st；
   - 阈值 τk 仅在成功 rollout 上离线校准，连续 n_consec 次查询超过阈值即触发恢复；
   - 与 SAFE 不同，CoRe 无需训练神经分类器，且触发后不是中止任务而是启动自主重对齐。

2. **阶段感知的恢复锚定（Phase-Aware Recovery Anchoring）**
   - 从最近一次恢复终点向前扫描轨迹，比较每个帧在两个指令下预测的动作块，计算归一化动作分歧 dt；
   - 指令不变时，改用干净 rollout 与记录配置间的末端 TCP 偏差；
   - 扫描是阶段感知的：跳过物体/关节未稳定、夹爪未离开可移动物体的帧；
   - 在块内进一步细化锚点位置（h*），通过正运动学积分推进夹爪位置。

3. **合成反事实延续（Synthesized Counterfactual Continuation）**
   - 从锚点出发，在完全合成的观测上闭环比对地滚动冻结策略：动作经 FK 积分得到新关节角，用体素存储（per-object voxel stores）重投影、z-buffer 体素喷溅、FK 渲染手臂、神经网络/经典 inpainting 修补空洞，生成第三人称（exocentric）与第一人称（egocentric）视图；
   - 滚动在 TCP 接近物体的阈值 d_prox 前终止（FK 无法建模接触动力学），最后一帧无接触状态即重接状态 c*；
   - 该过程完全虚拟，不产生物理运动，也不需要真实渲染器或环境状态访问。

4. **基于虚拟探针的最小恢复（Probe-Based Minimal Restoration）**
   - 计算偏差物体集合（相对 c* 超过位姿/旋转容差）；强制集 F 包含指令引用物体、任务实体附近物体、目标区域占用物体；
   - 按子集大小递增，对每个候选 S⊇F 做**虚拟探针**：从混合种子（S 中物体处于重接位姿，其余保持当前位姿）滚动策略，与"全恢复"参考轨迹比较关节轨迹距离 d_arm(S)，接受第一个小于阈值 ε 的子集；
   - 全部探针虚拟执行，无物理运动，失败时回退到恢复全部物体。

5. **物理重排与交还（Physical Rearrangement and Handoff）**
   - 仅此阶段产生物理运动：对 S* 中每个物体按"顶部优先"的顺序做运动规划的 pick-and-place，逐次验证；随后将手臂移动到重接姿态 q*；
   - 执行轨迹截断到恢复锚点，后续恢复从本次进度继续而非回退到更早状态；恢复策略的采样 RNG，保证交还后行为一致。
