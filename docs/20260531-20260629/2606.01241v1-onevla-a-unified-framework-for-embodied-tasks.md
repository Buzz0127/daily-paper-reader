## 摘要
导航和操作是具身智能的基本能力，使机器人能够解释自然语言指令并与周围环境进行物理交互。然而，当前的视觉-语言-动作（VLA）模型仍然受限于特定任务的架构，专门从事导航或操作任务，这阻碍了通用机器人的发展。为了弥合这一差距，我们提出了OneVLA，一个统一的架构，将这些不同的任务整合到一个连贯的框架中。具体来说，我们设计了一个统一的动作头，能够生成导航和操作动作，而不需要特定任务的变体。此外，我们提出了一种多阶段渐进训练策略——结合精心设计的数据构建和思维链（CoT）微调——促进了两个领域之间的强正迁移和相互增强。在模拟和真实环境中的大量实验表明，OneVLA实现了最先进的性能，显著优于专门的单任务和现有的跨任务模型。通过统一这些核心能力，OneVLA为真正的通用机器人系统铺平了道路。模型和源代码将公开发布。

## Abstract
Navigation and manipulation are fundamental capabilities of embodied intelligence, enabling robots to interpret natural language commands and interact physically with their surroundings. However, current Vision-Language-Action (VLA) models remain constrained by task-specific architectures, specializing in either navigation or manipulation, which hinders the development of general-purpose robotic agents. To bridge this gap, we introduce OneVLA, a unified architecture that integrates these distinct tasks into a single, cohesive framework. Specifically, we design a unified action head capable of generating both navigation and manipulation actions without requiring task-specific variants. Furthermore, we propose a multi stage progressive training strategy-incorporating curated data construction and Chain-of-Thought (CoT) fine-tuning that facilitates strong positive transfer and mutual reinforcement between the two domains. Extensive experiments in both simulated and real-world environments demonstrate that OneVLA achieves state-of-the-art performance, significantly outperforming both specialized single-task and existing cross-task models. By unifying these core capabilities, OneVLA paves the way for truly general-purpose robotic systems. The model and source code will be publicly released.

当前视觉-语言-动作（VLA）模型在具身智能任务（导航与操作）上取得了显著进展，但普遍存在一个根本性局限：**模型架构是任务特定的**——导航模型只能导航，操作模型只能操作，缺乏统一的通用能力。虽然存在跨任务模型（如UniVLA），但它们仍需要为不同任务保留专门的模型变体或不同的动作头，无法真正做到“一个模型完成所有任务”。

- （1）能否设计一个**统一的VLA架构**，在不使用任务特定变体的情况下，同时有效地执行导航和操作任务？
- （2）这两种基本具身智能任务是否能在联合训练中**相互受益**，从而提升整体性能？

OneVLA 的提出，打破了导航与操作之间的架构壁垒，为构建真正通用型的机器人基础模型铺平了道路。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
OneVLA 是一个统一的 VLA 框架，通过**统一的动作头**和**多阶段渐进训练策略**，在单一模型中同时支持导航（离散动作）和操作（连续动作）的生成，且不需要任何任务特定的模型变体。

### 关键技术细节
1. **统一的视觉语言编码器**：采用 Qwen2.5-VL-3B-Instruct 作为骨干，使用 32 层 Vision Transformer（patch size 14×14，隐藏维度 1280）提取多视图视觉特征，通过线性投影映射到语言模型隐藏维度 2048。语言模型为 36 层 Transformer（GQA，16 注意力头，2 KV 头），输出统一的跨模态表示 \( H \in \mathbb{R}^{(N_v+N_t) \times d_h} \)。

2. **输出生成机制**：引入特殊令牌 `<text>...</text><action>...</action>`，在单次前向传播中先通过语言生成解释（推理过程），再生成动作序列。序列形式为：
   ```
   <text> y_t </text><action> a_{t:t+T} </action>
   ```

3. **统一动作头（核心创新）**：将导航动作（4 维离散概率分布：前进/左转/右转/停止）和操作动作（7 维连续末端执行器控制：Δx, Δy, Δz, Δroll, Δpitch, Δyaw, gripper）拼接形成一个 **11 维统一动作空间**：
   \[
   a_{\text{unified}} = [a_{\text{navi}} | a_{\text{mani}}] \in \mathbb{R}^{11}
   \]
   动作头采用**流匹配扩散模型**（DiT-B，Peebles & Xie 2023）预测未来动作序列。训练时使用**任务特定权重掩码** \( w_{\tau_i} \)，对每个样本只计算相关维度的损失，其他维度的梯度被屏蔽：
   \[
   L_{\text{action}} = \frac{1}{N_{\text{task}}} \sum_{i} \text{mean}\left( w_{\tau_i} \odot (\hat{v}_i^\theta - v_i)^2 \right)
   \]
   其中 \( v_i = a_{\text{gt}} - \epsilon \)，\( \hat{v}_i^\theta \) 为模型预测的流速度场。

4. **多阶段渐进训练策略**（三个阶段）：
   - **阶段1**：只使用操作数据集和通用视觉问答数据，建立基础操作能力。损失函数：\( L_{\text{stage1}} = \lambda_{\text{vlm}} L_{\text{vlm}} + \lambda_{\text{action}} L_{\text{action}}^{\text{mani}} \).
   - **阶段2**：引入导航数据，进行联合训练。损失：\( L_{\text{stage2}} = \lambda_{\text{vlm}} L_{\text{vlm}} + \lambda_{\text{action}} (L_{\text{action}}^{\text{navi}} + L_{\text{action}}^{\text{mani}}) \).
   - **阶段3**：引入 Chain-of-Thought (CoT) 数据，强化推理能力和跨任务性能。损失：\( L_{\text{stage3}} = \lambda_{\text{vlm}} L_{\text{vlm}} + \lambda_{\text{text}} L_{\text{text}} + \lambda_{\text{action}} (L_{\text{action}}^{\text{navi}} + L_{\text{action}}^{\text{mani}}) \).

5. **总损失函数**：\( L_{\text{total}} = \lambda_{\text{vlm}} L_{\text{vlm}} + \lambda_{\text{text}} L_{\text{text}} + \lambda_{\text{action}} L_{\text{action}} \)，权重：\( \lambda_{\text{action}}=1, \lambda_{\text{text}}=\lambda_{\text{vlm}}=0.1 \).
