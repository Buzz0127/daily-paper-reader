## 摘要
机器人技术面临数据稀缺的根本性挑战。与语言或视觉研究不同，目前没有互联网规模的机器人操作数据集。一个有前景的前进方向是利用以自我为中心的人类数据，这类数据更容易收集，覆盖面更广，规模更大。为此，我们研究了跨人类和配备灵巧五指手的人形机器人本体的学习关键设计选择，以$π_{0.5}$模型为基础。我们的结果表明，在没有相应机器人数据的情况下，人类数据使机器人能够学习新的任务语义，并将现有技能组合成新颖的行为。论文网站见：https://egopipaper.github.io/

## Abstract
Robotics faces a fundamental challenge of data scarcity. Unlike language or vision research, there is no internet-scale dataset for robotic manipulation. A promising path forward is to leverage egocentric human data, which can be collected more easily, with greater breadth, and at a larger scale. Towards this end, we investigate key design choices for learning across human and humanoid embodiments equipped with dexterous five-finger hands, using the $π_{0.5}$ model as a foundation. Our results show that human data enables robots to learn new task semantics and compose existing skills into novel behaviors without corresponding robot data. ## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：基于π0.5 VLA模型进行跨本体（人类→人形机器人）的微调，同时适配人类和人形机器人的灵巧手动作空间，并通过多种技术手段实现任务语义的迁移。
- **关键技术细节**：
  - **动作空间对齐（robot-centric alignment）**：将人类手部关键点（MANO约定，20个关键点）先转换为每关节角度，再通过偏移量和缩放因子映射到机器人手部（如Tesollo手有20个主动关节，Inspire手有6个可控关节）的关节空间。机器人动作表示为：a = {p, r, q} ∈ ℝ²⁹，其中p为手腕位置(3维)，r为6D旋转表示(6维)，q为手部关节角(20维或6维)。
  - **动作Token交错（Interleaved Action Sequence）**：π0.5模型原始动作维度上限为32，而灵巧手双手共58维。为保留预训练权重，将左右手动作分别用一个独立的动作Token输出，从而将有效动作维度扩展至32×2=64，但有效时间步减半（H/2）。
  - **视觉对齐（Skeleton Overlay）**：在输入图像上绘制骨架线，每根手指用不同颜色标记，并采用深度感知的绘制顺序（近手指遮挡远手指），帮助模型理解人类手与机器人手之间的对应关系。
  - **子任务预测辅助损失（Subtask Prediction）**：在VLA的VLM部分增加子任务文本输出（作为中间预测），强制模型在动作前“思考”当前子任务，有助于复杂任务（如双手机器人装箱）中顺序技能链的组合。
