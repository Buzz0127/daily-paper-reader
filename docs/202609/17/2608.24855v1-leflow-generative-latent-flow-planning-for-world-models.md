## 摘要
潜在世界模型本质上是强大的编码器，可将图像像素转换为潜在嵌入，然而现有世界模型在动作规划时仍依赖在线轨迹优化：对于每个状态-目标对，都从头运行迭代优化器来搜索最优动作序列，将世界模型视为黑盒模拟器。这种做法在每个重规划步骤都要重新付出完整的迭代优化代价，且不在不同查询之间复用任何规划经验。在这项工作中，我们提出：一旦学习到潜在世界模型，规划本身能否被摊销？我们提出 LeFlow，它直接在世界模型的潜在动力学空间中学习一个可复用的潜在轨迹先验。LeFlow 将规划重构为条件潜在轨迹生成：一个 rectified-flow 模型想象当前与目标嵌入之间的未来潜在路径，一个逆动力学解码器将潜在转移转换为动作块，而冻结的世界模型通过自回归展开验证每个候选。在四个主要的目标条件像素控制基准上，LeFlow 用摊销式潜在规划和固定预算展开选择取代迭代动作空间优化，在规划时间减少一个数量级的同时取得了一致的成功率提升。我们的结果表明，潜在世界模型不仅应支持预测，还应支持可复用的规划先验。我们的代码见 https://github.com/hsiangwei0903/LeFlow。

## Abstract
Latent world models are inherently strong encoders that transform image pixel to latent embedding, yet existing world models still rely on online trajectory optimization for action planning: for every state-goal pair, an iterative optimizer is run from scratch to search for optimal action sequences, treating the world model as a black-box simulator. This approach pays the full iterative optimization cost anew at every replanning step and reuses no planning experience across queries. In this work, we ask whether planning itself can be amortized once a latent world model has been learned. We present LeFlow, which learns a reusable latent trajectory prior operating directly in the latent dynamics space from the world model. LeFlow recasts planning as conditional latent trajectory generation: a rectified-flow model imagines a future latent path between the current and goal embeddings, an inverse dynamics decoder turns latent transitions into action chunks, and the frozen world model verifies each candidate by autoregressive rollout. Across four major goal-conditioned pixel-control benchmarks, LeFlow replaces iterative action-space optimization with amortized latent planning and fixed-budget rollout selection, achieving consistent success-rate gains with an order-of-magnitude reduction in planning time. Our results argue that latent world models should support not only prediction but reusable planning priors. Our code is available at https://github.com/hsiangwei0903/LeFlow.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：潜在世界模型（latent world models）本质上是强编码器，将像素观测压缩为紧凑潜在嵌入，并可通过预测器（predictor）在动作条件下自回归地推演未来潜在状态。JEPA 系列（I-JEPA、V-JEPA）以及近期的 LeWorldModel（LeWM）已证明这类模型在 2D/3D 控制任务上具有很强的预测能力。
- **核心矛盾**：预测能力进步了，但**规划方式没有同步演进**。现有做法（如 LeWM 使用 CEM、MPPI 等）把世界模型当作**黑盒模拟器**：对每一个状态–目标对，在线从零开始迭代搜索动作序列，每个重规划步都要重新付出完整优化代价，且**不复用任何跨查询的规划经验**。
- **论文主张**：一旦潜在世界模型训练完成，**规划本身应当可以被"摊销"（amortize）**——离线学习一次可复用的潜在轨迹先验，直接在世界模型的潜在动力学空间中运行，而不是每次在线重解优化问题。
- **整体含义**：潜在世界模型不应只支持"预测"，还应支持"可复用的规划先验"；规划应利用编码器已组织的几何结构与预测器定义的动力学可达结构，而不是通过黑盒搜索重新发现它们。

## 2. 方法论

### 2.1 核心思想
- 将规划**重构为条件潜在轨迹生成**：不去搜索动作，而是生成一条潜在路径，之后再解码出实现该路径的动作。
- 动机：动作轨迹是低层、高度多模态的（多条动作序列可实现几乎相同的状态轨迹），而**潜在状态轨迹更平滑、几何结构更强**，可复用的规划结构存在于"潜在状态应如何演化"之中。
- 架构上分离**高层多步目标导向推理**（流规划器）与**低层控制**（逆动力学解码器），二者可独立训练与改进。
- 三个模块均构建在**冻结的 LeWM 主干**之上：流规划器、逆动力学解码器可训练；LeWM 编码器/预测器全程冻结。

### 2.2 关键技术细节

**(1) 条件 Rectified-Flow 潜在路径规划器**
- 给定起始与目标观测，编码得到 $z_{start}=\mathrm{enc}_\theta(o_{cur})$、$z_{goal}=\mathrm{enc}_\theta(o_{goal})$。
- 规划长度为 $H$ 的潜在路径 $z_{0:H}$，**端点被强制钳制**为 $z_0=z_{start}$、$z_H=z_{goal}$，模型只生成中间的 $H-1$ 个内部潜在状态。这一设计把目标条件直接注入路径几何结构，使模型容量全部用于学习"两个已知锚点之间的演化形状"。
- 采用 rectified flow 而非扩散：学习速度场 $v_\psi$，将高斯噪声 $u_0\sim\mathcal{N}(0,I)$ 沿直线插值 $u_\tau=(1-\tau)u_0+\tau u_1$ 输运到数据样本 $u_1$，回归常数速度目标 $u_1-u_0$。
- 训练目标（式 2）：$\mathcal{L}_{flow}=\mathbb{E}\|v_\psi(u_\tau,\tau\mid z_{start},z_{goal})-(u_1-u_0)\|_2^2$。
- 选择 rectified flow 的**效率理由**：其函数空间轨迹近似线性，可用极少的 Euler 步（本文 16 步）准确积分，且**与候选数 $N$ 无关**，适合每个重规划步并行生成 $N$ 条候选。

**(2) 逆动力学解码器**
- 局部地作用于每个潜在转移（式 3）：$a_t=g_\omega([z_t,z_{t+1},z_{t+1}-z_t])$，显式加入位移特征 $z_{t+1}-z_t$ 提供方向信息，改善回归条件性且不增加参数。
- 训练损失为对数据集归一化动作块的 MSE（式 4）：$\mathcal{L}_{inv}=\mathbb{E}\|g_\omega(\cdot)-a_t\|_2^2$。
- 关键论据：由于编码器把许多不同观测坍缩到同一潜在，**潜在空间中的逆动力学问题比观测空间良定得多**。

**(3) Rollout 重排序（投影回"可控潜在流形"）**
- 生成模型不天然尊重世界模型动力学：几何上平滑的路径可能经过**任何允许动作序列都无法到达**的潜在状态。论文称可被某动作序列到达的潜在轨迹集合为**可控潜在流形（controllable latent manifold）**。
- 推理时采样 $N$ 条候选路径，各自解码为动作序列，用冻结预测器自回归展开得到真实预测终端潜在 $\hat{z}_H^{(i)}$，按式 5 打分：$score^{(i)}=\|\hat{z}_H^{(i)}-z_{goal}\|_2^2$，选 $\arg\min_i score^{(i)}$ 执行其动作序列。
- 该步骤**仅在推理期做选择，不改变流模型的分布**。

**(4) 训练与总目标**
- 总损失（式 6）：$\mathcal{L}=\mathcal{L}_{flow}+\mathcal{L}_{inv}+\lambda_{cons}\mathcal{L}_{cons}$。
- **一致性损失**（式 7）：对每个生成转移解码动作 $\hat a_t$，经冻结预测器单步展开得 $\hat z_{t+1}$，惩罚 $\|\hat z_{t+1}-z_{t+1}\|_2^2$，把预测器动力学蒸馏进规划器，使生成分布朝可控流形靠拢。
- $\lambda_{cons}=0.1$ 为默认值；作者指出该损失与 rollout 重排序**互补而非冗余**（前者塑造训练分布，后者在推理期筛选），权重过大会把规划器分布坍缩到预测器的近视单步展开，牺牲多步规划结构。

**(5) 推理流程**
- 单次批处理计算：编码当前与目标 → 采样 $N=64$ 条潜在路径（16 步 Euler 积分）→ 逐条解码动作 → 冻结 LeWM rollout 重排序 → 执行最优动作块；运行在滚动时域 MPC 循环中。
- **完全不存在在线优化循环**：CEM 的数百次候选评估、多轮细化、每步重启被替换为一次流模型前向 + 一批 rollout 评估；计算量由 $N$ 个并行 rollout 主导，GPU 上高度可并行。

- **规划可以被摊销**：用离线学习的潜在轨迹先验替代在线动作空间迭代优化，是可行且更优的。
