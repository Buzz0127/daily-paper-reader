## 摘要
视觉-语言-动作策略是实现通用机器人控制的有前途的基础，但长时间跨度的类人移动操作要求机器人在移动、接触、遮挡和恢复过程中将任务对象视为持久的物理实体。我们将此问题作为对象状态发散来研究：用于调节全身动作的对象状态可能与用于判断动作是否达到预期物理关系的状态不同。我们提出了持久对象标记化（POT），它从RGB-D观测中维护角色索引的3D对象记录，并将其转换为全身动作专家的对象标记。实例化为POT-VLA，相同的对象记录调节动作生成并支持几何谓词检查，从而产生一个对象状态既可操作又可验证的闭环执行系统。在宇树G1机器人上，POT-VLA在八个真实世界任务族中将匹配的直接GR00T-N1.7基线从39/80成功提升到71/80成功。在与外部Being-0对齐的参考中，POT-VLA在对齐的服务任务上实现了44/50成功，而Being-0论文报告的成功率为37/50。最大的改进出现在需要维持3D关系的任务上，这表明持久以对象为中心的状态是可验证的人形VLA执行的一种有用抽象。

## Abstract
Vision-language-action policies are a promising foundation for general robot control, but long-horizon humanoid loco-manipulation requires the robot to treat task objects as persistent physical entities across movement, contact, occlusion, and recovery. We study this problem as object-state divergence: the object state used to condition a whole-body action can differ from the state used to decide whether the action achieved the intended physical relation. We propose \emph{Persistent Object Tokenization} (POT), which maintains role-indexed 3D object records from RGB-D observations and converts them into object tokens for a whole-body action expert. Instantiated as \emph{POT-VLA}, the same object records condition action generation and support geometric predicate checks, yielding a closed-loop execution system in which object state is both actionable and verifiable. On a Unitree G1, POT-VLA improves a matched direct GR00T-N1.7 baseline from 39/80 to 71/80 successes over eight real-world task families. In an external Being-0-aligned reference, POT-VLA achieves 44/50 successes on aligned service tasks, compared with the 37/50 success reported by the Being-0 paper. The largest gains occur on tasks requiring maintained 3D relations, suggesting that persistent object-centered state is a useful abstraction for verifiable humanoid VLA execution.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：人形机器人在长时程移动操作（loco-manipulation）中，用于条件化动作生成的物体状态与用于验证动作是否达到预期物理关系的物体状态之间存在**对象状态发散（object-state divergence）**。这种发散导致小误差（如抓取偏差、放置错位）会累积并引起过早的状态转移、错误操作或无效恢复。
- **研究动机**：现代VLA策略通常依赖当前观测的视觉-语言特征隐式编码对象状态，而任务进度检查则可能由独立的监控模块、谓词层或语言级状态完成。这种分离导致状态不一致。需要一种**持久的、以物体为中心的物理状态**，既能被策略用于动作生成，又能在执行后被验证。
- **整体含义**：提出持久对象令牌化（POT），构建一个闭环系统（POT-VLA），其中同一对象记忆同时服务于动作生成和几何谓词验证，从而提升人形机器人服务操作的鲁棒性和成功率。

## 2. 论文提出的方法论：核心思想、关键技术细节

**核心思想**：将RGB-D观测中的任务相关物体提升为**角色索引的3D物体记录**，序列化为**持久3D对象令牌**，驱动全身动作专家，并在每次动作块后刷新同一记录用于几何谓词验证，形成“维护-动作-观测-验证-恢复”闭环。

**关键技术细节**：

1. **持久对象令牌化（POT）**：
   - 从指令和VLM规划器得到类型化子任务计划，每个子任务定义角色、接地查询、成功谓词等。
   - 利用SAM3（或缓存）获取物体掩码，通过RGB-D反投影到机器人基坐标系，构建角色索引的物体记忆 \( M_t^{\tau_i} = \{ m_e^t \mid e \in E_i \} \)，记录实体角色、短语、2D框、3D质心/范围、置信度、可见性、关系特征等。
   - 序列化为固定槽位的特征张量 \( x_t^{obj} \in \mathbb{R}^{K \times F} \)（默认K=8槽，F=33特征），包括可见性、置信度、2D框、3D质心、3D范围、可选朝向、关系特征。未使用的槽位填PADDING并掩码。

2. **对象令牌条件化VLA执行**：
   - 动作专家基于GR00T-N1.7，保持相同骨干、躯体和运行环境。
   - 在动作头自注意力序列中插入对象令牌：序列布局为 \( S_t = [z_t^{state}, z_t^{obj}, z_t^{action}] \)，其中对象令牌通过投影层（LayerNorm → Linear → GELU → Dropout → Linear）映射到DiT隐藏维度。
   - 对象令牌包含角色嵌入和上下文嵌入，掩码槽位被忽略。动作头预测未来H步的全身动作块 \( \hat{a}_{t:t+H} \)。
   - 训练时，演示数据与对象令牌侧车配对，对动作头参数微调；不使用辅助对象记忆或谓词损失。

3. **谓词级验证与恢复**：
   - 几何谓词监督器读取同一对象记忆，检查子任务前提和完成条件。
   - 谓词类型包括：包含、支撑、末端执行器-目标接近、目标-目的地位移、双手分配、手外距离等。每个谓词定义为 \( p = \langle \kappa, \alpha, op, \nu, n \rangle \)。
   - 验证结果返回：in_progress, done, blocked, failed, uncertain。低置信度触发重新观测或重新接地。根据状态选择continue、retry、reobserve、reground、replan。
