## 摘要
视觉-语言-动作（VLA）策略提供了强大的通用操作先验知识，但在紧公差、接触密集的装配任务中，由于长时间跨度信用分配和子任务耦合问题，常常失败：对于当前技能在几何上成功的状态可能对后续技能是脆弱的。我们在冻结的VLA基策略上展示了残差强化学习（RL）中的这种失败模式：恒定的稀疏成功奖励可以单独改进每个子任务，但当技能链接时几乎没有增益，因为终端状态质量不可控。我们提出了前瞻残差强化学习，通过用离线估计的前瞻值（基于当前子任务终端状态的未来子任务成功的条件概率）增强每个子任务的稀疏成功奖励，来优化交接质量。具体来说，我们（i）从基策略的终端状态图像训练视觉前瞻预测器，使用下游回滚统计数据标注，（ii）通过后向前瞻归纳训练残差策略，将预测器输出作为奖励乘数。在Isaac Gym中的三阶段扳手拧螺母装配任务（抓取、移动-插入、旋转）上，我们的方法实现了85.6%的全任务成功率，优于标准子任务残差RL（54.5%）和VLA基线，同时保持每个子任务成功率不变。这些结果突出表明，提高长时间跨度性能需要塑造每个子任务产生的成功状态的质量，而不仅仅是是否成功。

## Abstract
Vision-Language-Action (VLA) policies offer strong general-purpose manipulation priors, but often fail on tight-tolerance, contact-rich assembly due to long-horizon credit assignment and subtask coupling: a state that is geometrically successful for the current skill can be brittle for downstream skills. We show this failure mode in residual reinforcement learning (RL) over a frozen VLA base policy: constant sparse success rewards improve each subtask in isolation yet yield little or no gain when skills are chained, because terminal state quality is uncontrolled. We propose Foresight Residual RL, which optimizes handoff quality by augmenting each subtask's sparse success reward with an offline-estimated foresight value -- the probability of future subtask success conditioned on the terminal state of the current subtask. Concretely, we (i) train a visual foresight predictor from images of terminal states of the base policy, labeled using downstream rollout statistics, and (ii) train residual policies via backward foresight induction, using the predictor output as a reward multiplier. On a three-phase wrench-based nut-tightening assembly task in Isaac Gym (grasp, move-insert, rotate), our method achieves 85.6% full-task success, outperforming standard subtask residual RL (54.5%) and VLA baselines, while leaving per-subtask success unchanged. These results highlight that improving long-horizon performance requires shaping which successful states are produced at each sub-task, not only whether success occurs.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：视觉-语言-动作（VLA）策略虽提供强大的通用操作先验，但在长时域、接触密集的装配任务（如扳手拧螺母）中，因子任务之间存在**因果耦合**（前一子任务的终端状态质量直接影响后一子任务的执行），现有方法（包括标准残差RL）仅用常数稀疏奖励优化各子任务独立成功率，导致链式执行时全任务性能增益甚微。
- **核心矛盾**：一个在几何上“成功”的终端状态可能对下游技能是脆弱的（如抓握角度偏差导致后续插入失败）。因此，**提升长时域性能的关键不是提升子任务成功率，而是控制子任务终端状态的质量**（即能使后续子任务成功的高概率状态）。

## 2. 方法论：核心思想、关键技术细节、算法流程

- **核心思想**：提出 **Foresight Residual RL**，通过离线训练一个**视觉前瞻预测器**，估计当前子任务终端状态下的未来子任务成功概率（前瞻值），并将该概率作为**奖励乘数**，引导残差策略朝向有利于下游成功的终端状态优化。
- **关键技术细节**：
  1. **Foresight Value Function**：定义前瞻值函数 \( V_{k+1:K}(s) \) 为从状态 \( s \) 开始执行后续子任务所获得的期望最终阶段成功折扣回报。将此值乘入子任务 \( k \) 的稀疏成功奖励中，得到局部前瞻目标。
  2. **后向前瞻训练**（Backward Foresight Induction，Alg.1）：从最后一个子任务 \( K \) 开始逆向训练残差策略。对 \( k=K \) 使用标准稀疏奖励；对 \( k<K \)，先训练好后续策略，再通过离线 rollouts 收集终端状态并训练 a a 前瞻预测器，随后训练残差策略时奖励为 \( r_t = \beta_k(s_{t+1}) \cdot p_\phi(o_{t+1}) \)。
  3. **离线预测器训练**（Alg.2）：收集基策略的 \( N \) 个成功终端状态，对每个状态执行 \( K_{\text{rep}} \) 次下游策略 rollout，记录成功次数 \( \kappa_i \)，以二项式负对数似然训练视觉预测器 \( p_\phi \)。使用 DINOv2 backbone + LoRA 微调。
- **算法流程**：
  - 阶段1：对各子任务边界（Grasp→Insert，Insert→Rotate），收集基 VLA 策略的终端状态图像。
  - 阶段2：用下游策略（已训练好的残差+基） rollout 标注每个状态的成功率。
  - 阶段3：训练前瞻预测器（二项式 NLL 损失）。
  - 阶段4：逆向训练残差策略，以预测器输出作为稀疏奖励乘数。

## 6. 论文的主要结论与发现

- **前瞻残差 RL 显著提升全任务成功率**：85.6% vs 标准残差 RL 54.5% vs π0 链式 41.4%，提升 +31.1%。
- **子任务独立成功率几乎不变**：各子任务在 oracle 初始化下均 >91%，说明增益来自终端状态分布优化而非子任务能力增强。
- **标准残差 RL 反而降低终端状态质量**：前瞻预测器得分在 Grasp 终端从 0.64 降为 0.32，说明常数奖励引导策略找到更差的下游状态。
- **结论**：长时域性能提升需要**控制子任务终端状态的质量**（使其有利于后续操作），而非仅追求当前子任务的成功率。

## 7. 优点

- **方法创新**：将前瞻值（completion function）从 MAXQ 框架中提取出来，以离线预测器形式融入残差 RL，避免了在线联合训练的非平稳性和高方差。
- **实用性强**：预测器仅需一次性离线收集数据，训练开销小（<5分钟），且与 VLA 模型（π0）兼容，残差策略改动小（α=0.1）。
- **任务设计有挑战性**：扳手-螺母装配具有因果耦合、子毫米精度、接触力交互等特点，能充分暴露子任务耦合问题。
- **实验与可视化清晰**：定量和定性分析充分证明了“状态质量优于成功率”的核心论点。

## 8. 不足与局限

- **仿真局限**：全部实验在 Isaac Gym 模拟中进行，未在真实机器人上验证。作者指出主要障碍是真实硬件上在线 RL 的成本，而非接触动力学差异。
- **任务单一**：仅一个复杂任务（三阶段拧螺母），缺少其他长时域接触密集型任务（如开抽屉、插入 peg、拧螺丝等）的验证。
- **近似局限**：仅采用“一步前瞻”（只预测下一个子任务的成功概率），对于更深层依赖链可能不够精确。作者承认当需要更深层前瞻时可扩展，但未实验。
- **分布偏移风险**：预测器基于基 VLA 策略的终端状态训练，残差策略可能访问未见过状态。作者认为小残差尺度（α=0.1）限制了偏移，但未给出定量分析。
- **阶段分解假设**：假设已知清晰的子任务边界和成功谓词，实际中可能需学习这些分解。
