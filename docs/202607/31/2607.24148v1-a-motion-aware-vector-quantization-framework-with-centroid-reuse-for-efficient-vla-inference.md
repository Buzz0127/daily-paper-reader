## 摘要
视觉-语言-动作（VLA）模型展现了在具身AI中的强大潜力，但其在GPU上的高推理延迟限制了实时部署。现有加速器（如Dadu-Corki）提高了效率，但将VLA模型视为全精度工作负载，留下了大量可进一步利用的内存和计算冗余。在本文中，我们提出了VQVLA，一种算法-硬件协同设计框架，通过利用权重相似性和执行动态来加速VLA推理。我们首先引入了MotionVQ，一种运动感知的向量量化方案，根据机器人的执行状态动态调整量化精度，在保持任务成功率的同时减少内存访问。随后，我们提出了一种基于码本索引表示的合并质心向量化GEMM范式，通过空间聚合和时间复用质心消除冗余乘法。为实现这些优化，我们设计了一种高效支持动态精度选择和质心复用计算的加速器。实验结果表明，VQVLA相比A100 GPU、Dadu-Corki、LUT-DLA、CodeGEMM和ShiftAddLLM分别实现了6.5倍、2.8倍、1.9倍、3.3倍和4.3倍的加速，且精度下降可以忽略不计。

## Abstract
Vision-Language-Action (VLA) models have demonstrated strong potential for embodied AI, yet their high inference latency on GPUs limits real-time deployment. Existing accelerators, such as Dadu-Corki, improve efficiency but treat VLA models as full-precision workloads, leaving substantial redundancy in both memory and computation underexploited.   In this paper, we propose VQVLA, an algorithm-hardware co-design framework that accelerates VLA inference by exploiting weight similarity and execution dynamics. We first introduce MotionVQ, a motion-aware vector quantization scheme that dynamically adjusts quantization precision based on the robot's execution state, reducing memory access while preserving task success rate. We then propose a merged-centroid vectorized GEMM paradigm that operates on the codebook-index representation, eliminating redundant multiplications through spatial aggregation and temporal reuse of centroids. To realize these optimizations, we design an accelerator that efficiently supports dynamic precision selection and centroid-reuse computation. Experimental results show that VQVLA achieves 6.5x, 2.8x, 1.9x, 3.3x, and 4.3x speedup over the A100 GPU, Dadu-Corki, LUT-DLA, CodeGEMM, and ShiftAddLLM, respectively, with negligible accuracy degradation.

## 二、论文提出的方法论

VQVLA框架包含三个层面的创新：

### 1. 关键洞察
- **状态相关的执行敏感性**：通过分析机器人运动行为，发现动作幅度与空间邻近性密切相关。当机器臂接近目标物体（执行状态，运动幅度小，需精细调整）时，系统对扰动高度敏感；而在物体间移动（过渡状态，运动幅度大）时，容错性更强。实验验证：相同噪声水平下，过渡状态的成功率始终高于执行状态。
- **质心访问的热度不均**：VQ后质心访问频率可视化显示少数热索引被频繁访问，存在大量冗余乘法。

### 2. MotionVQ：运动感知向量量化算法
- **状态预测**：以运动幅度 \( D = \sqrt{A_x^2 + A_y^2 + A_z^2} \) 为轻量级指标，与阈值 \( T_d \) 比较。\( D \leq T_d \) 判断为执行状态，否则为过渡状态。
- **精度适配**：离线准备两套VQ配置——高精度集（VQ[256, 2, 256]，平均4.125bit）和低精度集（VQ[128, 2, 64]，平均3.125bit）。运行时根据预测状态动态取用对应码本和索引矩阵，实现“按需取权”，减少内存访问。

### 3. 合并质心向量化GEMM范式
直接基于码本-索引表示在压缩域计算，无需反量化步骤，包含两种质心复用技术：

- **空间合并（Spatial Merging）**：利用同一列内重复质心，先对映射到同一质心的多个输入求和，再做一次乘法。数学表达为 \( \sum(I_i \times Centroid) \rightarrow \sum(I_i) \times Centroid \)。通过构建空间质心位置表（记录质心ID与其对应的权重向量ID），丢弃仅有一个关联向量的条目，进一步合并冗余。
- **时间复用（Temporal Reusing）**：利用跨列的质心重复，离线通过Top-k选出高频质心（不依赖具体输入），运行时初始化结果缓存（tag为质心ID与权重向量ID的元组），命中缓存时直接复用之前计算的乘积结果，跳过重复乘法。

### 4. 硬件架构
- **组成**：状态预测器（乘法器+加法器+阈值比较器）、矩阵乘法引擎（空间合并PE阵列、时间复用PE阵列、三级流水加法树、结果缓存1.5MB、缓存初始化单元、累加单元）、索引处理引擎（多个IPU并行构建质心位置表）。
- **关键设计**：三级流水加法树支持8输入、4输入、2输入三种归约模式，三周期输出7个部分和；PE阵列（空间：24×256，每PE含3乘法器+3加法器；时间：24×256，每PE含2乘法器+3加法器）与加法树流水配合；结果缓存大小经设计探索选定1.5MB；空间-时间PE比选1:1。
- **数据流**：三步流水——先MotionVQ取码本索引，再IPU构建质心位置表，最后矩阵乘法引擎执行空间合并与时间复用。

## 九、对未来研究的潜在启发与开放问题

1. **统一的多状态自适应量化框架**：论文仅区分“执行/过渡”二态，未来可探索更细粒度的连续状态感知（如速度、加速度、力矩等多维信号联合驱动），实现精度-延迟的动态帕累托最优控制，甚至通过强化学习在线自适应调整量化强度。
2. **非均匀敏感度的可解释性分析**：为什么空间邻近时量化敏感度更高？这一现象是否与视觉注意力、动作误差累积或内力控制相关？深入理解其机理有助于将VQ扩展到其他模态（如深度传感器、触觉）。
3. **面向更大规模模型的硬件扩展**：7B参数模型已占据1.5MB结果缓存和24×256 PE阵列，对于70B级或MoE结构的VLA，如何通过稀疏激活、分层存储、多芯粒互连扩展当前架构，是重要的开放问题。
4. **量化-记忆权衡的系统级建模**：VQ压缩比、质心复用收益与缓存容量之间存在三向折中，可进一步形式化为收益-成本模型，用于自动搜索最优硬件参数。
5. **通用压缩域GEMM生态**：合并质心向量化GEMM有望推广至其他具备码本结构的模型（如语音合成、推荐系统），构建统一的压缩域推理编译器与运行时。

## 十、总结性评价

VQVLA是一篇高质量的算法-硬件协同设计工作，其核心贡献在于将“机器人运动状态感知”这一领域知识引入VLA模型量化的动态决策，并结合质心热度统计提出了压缩域GEMM计算范式，实现了从算法洞察到硬件微架构的完整闭环。实验覆盖多模型、多任务、多基线，验证了其在精度、延迟、能耗与硬件利用率上的综合优势。尽管存在训练成本未报告、集成细节不完整、硬件评估停留于仿真等局限，但该工作为实时具身智能系统部署提供了一个极具启发性的设计范例，也为VLA推理加速开辟了“运动感知+计算复用”的新方向。
