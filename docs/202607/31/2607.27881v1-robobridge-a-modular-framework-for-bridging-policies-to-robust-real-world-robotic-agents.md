## 摘要
视觉-语言-动作（VLA）模型作为可扩展的机器人操控方法引起了广泛关注。尽管这些模型是有效的动作预测器，但将其部署为机器人代理时暴露了关键缺陷：缺乏故障恢复机制、长时程执行不一致，以及对观测、任务或本体变化的鲁棒性有限。现有解决方案通过模型重训练或环境特定模块单独解决这些局限性，但所需的是一种能够系统地将预训练VLA转化为机器人代理的通用框架。我们提出RoboBRIDGE，一种模块化框架，通过五个协调模块（即Monitor、Perceptor、Planner、Controller和Robot Interface）提供编排层，从现成组件（包括预训练VLA）中构建鲁棒机器人代理。Monitor将快速故障检测与分层恢复相结合，在错误级联前进行纠正。当环境偏离当前计划时，Planner触发重新规划，同时Perceptor异步更新场景理解，避免执行停滞。在Controller内部，原始技能微调将操作分解为具有专用LoRA适配器的域不变原语，降低使用VLA时对域偏移的敏感性。在跨越多个机器人平台和VLA主干的LIBERO、RoboCasa及真实世界案例研究中，RoboBRIDGE始终优于独立策略和先前增强型VLA部署。这些结果表明，可靠的机器人代理能力并非仅来自扩展动作预测器，而是来自围绕其进行的结构化编排。

## Abstract
Vision-Language-Action (VLA) models have attracted growing interest as a scalable approach to robotic manipulation. While these models are effective action predictors, deploying them as robotic agents exposes critical gaps: no mechanism for failure recovery, inconsistent execution over long horizons, and limited robustness to shifts in observations, tasks, or embodiments. Existing solutions address these limitations individually through model retraining or environment-specific modules, yet what is needed is a general framework that systematically transforms a pretrained VLA into a robotic agent. We present RoboBRIDGE, a modular framework that provides an orchestration layer over five coordinated modules, namely Monitor, Perceptor, Planner, Controller, and Robot Interface, to compose robust robotic agents from off-the-shelf components, including pretrained VLAs. The Monitor pairs rapid failure detection with hierarchical recovery to correct errors before they cascade. When the environment diverges from the current plan, the Planner triggers replanning while the Perceptor updates scene understanding asynchronously, avoiding execution stalls. Within the Controller, primitive skill fine-tuning factors manipulation into domain-invariant primitives with dedicated LoRA adapters, reducing sensitivity to domain shifts when a VLA is used. Across LIBERO, RoboCasa, and real-world case studies spanning multiple robot platforms and VLA backbones, RoboBRIDGE consistently outperforms both standalone policies and prior augmented VLA deployments. These results suggest that reliable robotic agency does not arise from scaling action predictors alone, but from structured orchestration around them.

## 1. 核心问题与整体含义
- **研究动机**：VLA 模型在机器人操控中展现出强大的动作预测能力，但作为“动作预测器”直接部署成机器人“代理”时存在三大关键缺口：
  - **无故障恢复机制**：一次抓取失败或碰撞无法被察觉，错误会逐级级联；
  - **长时程执行不一致**：每一步推理相互独立，缺乏任务进度跟踪，复合误差不断累积；
  - **域偏移鲁棒性差**：观测、任务或本体变化时性能退化严重，仿真到真实、跨机器人迁移脆弱。
- **现有方案局限**：已有研究分别处理失败检测、重规划、任务分解、域适应等，但均针对单一失败模式、绑定特定环境或模型，缺乏统一、通用的解决方案。
- **核心论点**：可靠机器人代理能力不能仅靠扩大动作预测模型规模获得，而需要围绕策略构建**结构化编排层**。类比 LLM 从裸生成器进化为 Agent 的路径，VLA 也需要一个通用的策略无关编排框架，将任意动作生成策略“包装”成完整智能体。

## 2. 方法论
- **总体框架**：RoboBRIDGE 由五个协调模块组成，包裹在任意动作生成策略外围，不修改预测器权重的条件下赋予其鲁棒性：
  - **Monitor（监控器）**：两阶段故障处理。
    - **阶段一：轻量成功检查**——用视觉语言模型 `D_check` 周期性对当前观测 `o_t` 与计划上下文 `c_t` 进行二元成功判断和置信度打分，格式受约束、不生成冗长推理，延迟低（约5Hz），不阻塞控制回路；
    - **阶段二：失败诊断与分层恢复**——高置信失败时停机，诊断模型 `D_diag` 推断根因并选择恢复动作，恢复层级由低到高为：`retry`（重试当前原语）→ `regenerate`（保留计划和感知，重生成轨迹）→ `replan`（基于最新异步感知重规划）→ `re-perceive`（强制重新感知再规划）。尽量选择成本最低且足够纠正错误的层级。
  - **Perceptor（感知器）**：将原始传感数据转换为对象中心状态（身份、3D 姿态、语义属性），以异步生产者-消费者模式在独立线程连续更新线程安全缓冲区 `B`，只保存最新结果，把感知延迟隐藏在执行之后。
  - **Planner（规划器）**：接收语言指令和感知状态，将任务分解为有序原始技能序列；每个原始技能执行完后，比较初始规划时的感知状态 `¯o_plan` 与缓冲区最新状态 `¯o_lat`，用发散度公式判断是否需要触发重规划。
    - 发散度：`∆(¯o_a, ¯o_b) = max_{i∈O_a∩O_b} ||p_a^(i) − p_b^(i)||₂ + λ·|O_a △ O_b|`（欧氏距离 + 物体出现/消失的集合差异加权）。当 `∆ ≥ τ` 时只重新生成当前及后续原语的空间参数，保留高层动作序列，避免冗余高层推理。
  - **Controller（控制器）**：策略占位槽，动作生成策略（如 VLA）通过低秩适配器（LoRA）按原语分解。
    - **原始技能微调**：将操控分解为域不变原语集合 P = {MOVE, GRIP, ROTATE, ...}，每个原语绑定一个独立 LoRA 适配器 `∆θ_k`，冻结基座 `f_θ` 上训练；
    - **控制器切换**：执行时根据当前原语解析适配器，若不存在则使用所有适配器的均值作为后备；
    - **动作生成**：7维增量动作 `a_t = (δx, δφ, g)`，其中 δx 为平移增量、δφ 为旋转增量、g 为夹爪命令；以笛卡尔速度命令发送，若有 IK 求解器则转换为关节位置。
  - **Robot Interface（机器人接口）**：抽象不同机器人的 API、时序、安全限制和坐标系变换，使上游逻辑可在不同平台间复用。
- **算法流程**：`RUN TASK` 并行启动感知线程，按计划顺序执行每个原语：每次动作后调用成功检查，若失败则停机→诊断→分层恢复；原语结束后检查发散度，超阈值则更新感知并重规划。整个流程无需重训基座模型。

## 6. 主要结论与发现
- **核心结论**：RoboBRIDGE 在 LIBERO、RoboCasa 和真实世界中一致提升三个 VLA 主干的成功率，而基线模型权重和训练数据完全不变。例如 RoboCasa 上平均成功率提升 +3.5% 至 +5.6%，并在长时程任务中尤为明显（LIBERO-Long +9.4%）。
- **监控与规划互补**：无监控时各 LLM 规划差距很小；启用监控后，足够推理能力的 LLM（Claude Opus 4.6、GPT-5 mini）带来显著增益，而小模型增益微弱，说明“规划+监控”缺一不可，且诊断能力依赖基座推理能力。
- **参数高效优势**：LoRA 微调 + RoboBRIDGE 达 27.1%，接近全微调独立部署的 31.9%；全微调放入框架后可进一步提升至 40.0%，说明即使强控制器也受益于外部编排。
- **模型内自纠错不如外部编排**：CycleVLA（带自回溯和自纠错解码的 VLA）独立运行仅 7.5%，低于 RoboBRIDGE + LoRA 的 27.1%。
- **主导失败模式**：感知错误（遮挡、相似物体导致的误定位）和不可恢复的接触丰富操控失败；后者需要验证控制器成功率预期及安全终止策略。

## 7. 优点
- **模块化与策略无关**：任何动作策略（VLA、经典 IK）都可插入 Controller 槽，Monitor/Perceptor/Planner/Robot Interface 与具体模型解耦，易于替换和扩展；
- **分层恢复设计合理**：按成本递增组织 retry→regenerate→replan→re-perceive，避免过度重规划，又能应对深层次错误；
- **异步感知提升效率**：感知与执行并行，用线程安全缓冲区避免阻塞；基于对象位姿差异的发散度量简单高效，重规划只更新空间参数而非重推理高层计划；
- **参数高效领域适配**：原始技能 + LoRA 适配器显著降低域迁移敏感性，同时保持基座权重冻结，节省训练资源；
- **实验验证兼顾广度和深度**：仿真、真实、多平台、多主干、多消融，验证框架通用性；并对失败模式进行了定性分析，提供改进方向。

## 8. 不足与局限
- **原语词汇有限**：当前只覆盖单臂桌面常见行为，接触丰富操作、可变形物体、双臂协作需要更丰富的原语和状态表示；
- **配置依赖人工**：监控阈值 τ、置信度阈值 γ、恢复规则均手动设定，未见自动化学习过程；
- **感知鲁棒性不足**：Perceptor 在遮挡、相似物体场景下出错率较高，会直接导致下游失败；框架未内置感知不确定性量化或校正机制；
- **不可恢复失败处理欠佳**：某些失败一旦发生即无解，现有分层恢复仍可能浪费步骤；需要显式可行性验证、失败可能性预测、备选控制器选择以及安全终止条件；
- **实验局限**：真实世界案例数量与量化成功率未公开、未与其他统一框架端到端对比、RoboCasa 独立基线成功率极低，可能低估基座能力；训练算力和耗时未披露，不利于复现和资源评估；
- **评估偏差潜在风险**：LLM 消融、监控消融等可能存在模型随机性未完全控制；重规划阈值 τ 和 λ 的敏感性未见分析。
