## 摘要
视觉-语言-动作策略是通用机器人控制的有前途基础，但长期人形移动操作要求机器人将任务对象视为在运动、接触、遮挡和恢复中持续的物理实体。我们将此问题研究为对象状态发散：用于调节全身动作的对象状态可能与用于判断动作是否达到预期物理关系的状态不同。我们提出持久对象令牌化（POT），该方法从RGB-D观测中维护角色索引的3D对象记录，并将其转换为全身动作专家的对象令牌。实例化为POT-VLA，相同的对象记录调节动作生成并支持几何谓词检查，产生一个闭环执行系统，其中对象状态既可操作又可验证。在宇树G1上，POT-VLA在八个真实世界任务族中将匹配的直接GR00T-N1.7基线从39/80成功提升至71/80。在外部Being-0对齐参考中，POT-VLA在对齐的服务任务上达到44/50成功，而Being-0论文报告为37/50成功。最大的提升出现在需要维持3D关系的任务上，表明持久以对象为中心的状态是可验证人形VLA执行的有用抽象。

## Abstract
Vision-language-action policies are a promising foundation for general robot control, but long-horizon humanoid loco-manipulation requires the robot to treat task objects as persistent physical entities across movement, contact, occlusion, and recovery. We study this problem as object-state divergence: the object state used to condition a whole-body action can differ from the state used to decide whether the action achieved the intended physical relation. We propose \emph{Persistent Object Tokenization} (POT), which maintains role-indexed 3D object records from RGB-D observations and converts them into object tokens for a whole-body action expert. Instantiated as \emph{POT-VLA}, the same object records condition action generation and support geometric predicate checks, yielding a closed-loop execution system in which object state is both actionable and verifiable. On a Unitree G1, POT-VLA improves a matched direct GR00T-N1.7 baseline from 39/80 to 71/80 successes over eight real-world task families. In an external Being-0-aligned reference, POT-VLA achieves 44/50 successes on aligned service tasks, compared with the 37/50 success reported by the Being-0 paper. The largest gains occur on tasks requiring maintained 3D relations, suggesting that persistent object-centered state is a useful abstraction for verifiable humanoid VLA execution.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究动机**：人形机器人执行长时程移动操作（如“整理桌子”“拿饮料”）时，需要将任务对象视为在移动、接触、遮挡和恢复过程中持续存在的物理实体。现有VLA（视觉-语言-动作）策略通常将物体状态隐式编码在视觉-语言特征中，导致**对象状态发散**：用于调节全身动作的物体状态与用于判断动作是否达到预期物理关系的状态可能不一致，从而引发抓取失败、放置偏差、错误提交子任务等故障。
- **核心问题**：如何在人形VLA中建立一种持久、可操作且可验证的物体中心状态表示，避免状态发散，实现闭环执行。
- **整体含义**：提出持久对象令牌化（POT），将RGB-D观测转换为角色索引的3D物体记录，并同时用于动作生成和几何谓词验证，形成闭环系统，显著提升真实世界人形机器人的任务成功率。

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：维护一个共享的、角色索引的对象记忆（object memory），该记忆由RGB-D实时刷新，并序列化为**持久3D对象令牌**（Persistent 3D Object Tokens），一方面输入到学习型动作专家（GR00T-N1.7）的DiT动作头，另一方面传递给几何谓词监督器进行物理一致性验证。
- **关键技术细节**：
  - **持久对象令牌化（POT）**：根据当前子任务的角色（TARGET、DESTINATION、SUPPORT、HANDOVER_PARTNER等），从RGB-D中提取物体记录（包括语义角色、2D框、3D质心、尺寸、可见性、置信度、关系特征等），并填充到固定数量（K=8）的槽位中，每个槽位33维特征。未使用的槽位用PADDING填充并掩码。
  - **对象令牌投影器**：将每个槽位的特征通过LayerNorm → Linear → GELU → Dropout → Linear投影成DiT隐藏维度，并加入角色嵌入和上下文嵌入。
  - **动作头插入**：将对象令牌插入DiT动作头的自注意力序列中，布局为 `[Z_state, Z_obj, Z_action]`，与视觉-语言骨干特征进行交叉注意力。动作专家预测全身动作块 `ˆa_{t:t+H}`。
  - **谓词级验证与恢复**：几何谓词监督器使用与动作专家相同的刷新后的对象记忆，检查子任务前提和完成条件（如包含、支撑、接近等）。每个谓词包含类型、参数、比较操作符、阈值和稳定窗口。验证结果决定继续、重试、重新观测、重新定标或重新规划。
  - **闭环流程**：维持对象记忆 → 预测动作块 → 执行并验证 → 刷新对象记忆 → 检查谓词 → 根据状态决定下一步。

## 7. 优点

- **方法创新**：提出在VLA中维持共享的对象级物理记忆，同时用于动作条件和验证，解决对象状态发散问题。将3D接地转化为可持久的执行记忆，而非仅用于初始规划。
- **实用性强**：不依赖仿真器、显式物理引擎或学习动力学模型，直接使用RGB-D测量，易于在实际机器人上部署。
- **实验设计完整**：包含主实验、消融、泛化、外部参考，对比公平，统计结果清晰。
