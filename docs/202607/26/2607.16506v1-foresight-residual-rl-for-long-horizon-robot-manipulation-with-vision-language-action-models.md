## 摘要
视觉-语言-动作（VLA）策略提供了强大的通用操作先验，但在高精度、接触密集的装配任务中常因长时程信用分配和子任务耦合而失败：一个在当前技能中几何上成功的状态可能对后续技能是脆弱的。我们展示了在冻结的VLA基础策略上进行残差强化学习（RL）时这种失败模式：恒定的稀疏成功奖励虽然分别提升了每个子任务，但当技能串联时几乎没有收益，因为终端状态质量不受控。我们提出远见残差强化学习（Foresight Residual RL），通过为每个子任务的稀疏成功奖励增加一个离线估计的远见值——即当前子任务终端状态下未来子任务成功的概率——来优化交接质量。具体而言，我们（i）从基础策略终端状态的图像训练一个视觉远见预测器，使用下游 rollout 统计信息进行标注，以及（ii）通过反向远见归纳训练残差策略，将预测器输出作为奖励乘数。在Isaac Gym中的三相扳手螺母拧紧装配任务（抓取、移动插入、旋转）上，我们的方法达到了85.6%的全任务成功率，优于标准子任务残差RL（54.5%）和VLA基线，同时保持每个子任务的成功率不变。这些结果强调，提升长时程性能需要塑造每个子任务产生哪些成功状态，而不仅仅是是否成功。

## Abstract
Vision-Language-Action (VLA) policies offer strong general-purpose manipulation priors, but often fail on tight-tolerance, contact-rich assembly due to long-horizon credit assignment and subtask coupling: a state that is geometrically successful for the current skill can be brittle for downstream skills. We show this failure mode in residual reinforcement learning (RL) over a frozen VLA base policy: constant sparse success rewards improve each subtask in isolation yet yield little or no gain when skills are chained, because terminal state quality is uncontrolled. We propose Foresight Residual RL, which optimizes handoff quality by augmenting each subtask's sparse success reward with an offline-estimated foresight value -- the probability of future subtask success conditioned on the terminal state of the current subtask. Concretely, we (i) train a visual foresight predictor from images of terminal states of the base policy, labeled using downstream rollout statistics, and (ii) train residual policies via backward foresight induction, using the predictor output as a reward multiplier. On a three-phase wrench-based nut-tightening assembly task in Isaac Gym (grasp, move-insert, rotate), our method achieves 85.6% full-task success, outperforming standard subtask residual RL (54.5%) and VLA baselines, while leaving per-subtask success unchanged. These results highlight that improving long-horizon performance requires shaping which successful states are produced at each sub-task, not only whether success occurs.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：长时程、接触密集的机器人装配任务（如扳手拧螺母）需要顺序执行多个子任务（抓取、插入、旋转）。标准方法为每个子任务独立训练策略并链式执行，但子任务间存在**因果耦合**：前一子任务的终端状态质量直接影响后续子任务成功率。例如，一个在几何上成功的抓取可能因姿态不佳导致插入失败。
- **现有局限**：
  - 独立子任务训练（包括标准VLA微调、残差RL）仅优化子任务内成功，忽略终端状态对下游的影响。
  - 分布匹配方法（如对抗技能链）优化的是分布重叠这一替代指标，而非全局任务成功。
  - 层次RL中的完成函数理论上正确，但需联合在线训练，不适用于冻结的预训练VLA基础策略。
- **核心含义**：**长时程性能提升的关键在于控制每个子任务产生何种成功状态（质量），而非仅追求“是否成功”**。

## 2. 方法论：核心思想、关键技术细节、公式/算法流程

### 核心思想
- 引入**远见值函数**（Foresight Value Function）：衡量当前子任务终端状态下后续所有子任务成功的期望回报。
- 通过离线训练的视觉远见预测器估计该值，并将其作为奖励乘子，指导残差策略向利于下游成功的终端状态偏移。

### 关键技术细节
1. **残差策略**：在冻结的VLA基础策略（π⁰_k）上叠加一个轻量残差策略（π^res_k），输出小幅度动作修正：  
   `a_t = π⁰_k(o_t) + α · π^res_k(o_t)`，α<<1。

2. **远见值估计**：
   - 使用**一步远见近似**：近似为下一子任务的成功概率（当剩余子任务为单个时精确；否则可扩展）。
   - **离线收集**：滚动基础策略（π⁰_k）收集N个成功终端状态，对每个状态执行K_rep次下游策略π_{k+1}的rollout，记录成功次数κ_i。
   - **训练预测器**：用一个视觉神经网络p_φ: O→[0,1]（基于DINOv2骨干）以二项负对数似然损失从这些标签学习：  
     `L(φ) = - Σ [κ_i log p_φ(o_i) + (K_rep - κ_i) log(1 - p_φ(o_i))]`

3. **后向远见归纳（Backward Foresight Induction）**：
   - 从最后一个子任务（k=K）开始向前训练。对k=K使用标准稀疏奖励；对k<K使用远见调节奖励：  
     `r_t = β_k(s_{t+1}) · p_φ(o_{t+1})`
   - 训练顺序确保下游策略固定后，远见估计稳定。

### 算法流程
- 算法1：Backward Foresight-driven Learning：从K到1循环，对每个k：若k=K则用标准PPO训练；否则先训练/固定下游策略，调用Foresight Predictor（算法2）获得预测器，再用调节奖励训练残差策略。
- 算法2：Foresight Predictor：收集终端状态→下游rollout标定→训练预测器。

## 6. 主要结论与发现

1. **标准残差RL无法提升链式性能**：尽管子任务成功率大幅提升（如插入从45.7%→92.2%），但全任务成功率仅54.5%，与端到端π0（54.9%）相当。原因在于终端状态质量恶化（远见评分从0.64降至0.32）。
2. **远见残差RL显著改善链式组合**：全任务成功率85.6%，比标准残差RL提高31.1%，且主要增益来自Grasp→Insert边界（+31.8%）。子任务独立成功率并未下降。
3. **远见预测器有效区分高质量与低质量终端**：在Grasp→Insert边界预测准确率86.2%远超基线73.9%，说明能捕捉微小姿态差异对下游的影响。
4. **优化终端状态质量是关键**：长时程接触密集型任务中，成功状态空间内存在巨大性能差异；仅控制“是否成功”而不控制“哪种成功”会导致链式失败。

## 7. 优点

- **方法创新性**：将层次RL中的完成函数思想与现代VLA+残差RL结合，通过离线远见预测器避免了联合训练的非平稳性和样本效率问题，兼容冻结的预训练基础策略。
- **实用性与可扩展性**：只修改终端奖励，保留子任务内部优化过程；不需要所有子任务同时训练；预测器训练成本低（<5分钟），可集成到现有残差RL框架。
- **实验设计清晰**：验证了“标准残差RL虽提升子任务却恶化链式性能”的反直觉现象，并通过终端质量量化（表III）和可视化（图3）提供了深刻解释。
- **对比全面**：包括端到端、链式、标准残差和本文方法，覆盖了不同策略组合。

## 8. 不足与局限

- **实验场景单一**：仅在模拟中的单一装配任务（扳手-螺母）上验证。虽任务复杂，但缺乏多任务、多场景的泛化验证（如其他装配任务、非装配长时程操作）。
- **模拟与现实差距**：所有实验在Isaac Gym模拟中进行，未涉及真实机器人部署。作者指出主要障碍是真实环境在线RL成本，但接触动力学差异可能影响预测器迁移。
- **一步远见近似**：仅使用下一子任务成功概率近似完整远见值，当剩余多个子任务且耦合复杂时可能不够准确。作者提到可扩展但未实验。
