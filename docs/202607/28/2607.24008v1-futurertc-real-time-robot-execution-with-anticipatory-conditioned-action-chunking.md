## 摘要
视觉-语言-动作（VLA）策略的实时部署需要异步执行，即后续动作分块与当前分块执行同时计算，导致预测-执行错位并表现为分块间的不连续性。现有方法要么仅表面平滑分块边界、需要昂贵的策略优化，要么仅前向预测本体感受状态而忽视关键的视觉观测。在本文中，我们提出FutureRTC，一种即插即用的自适应框架，通过预测执行时刻的观测和状态实现异步VLA控制，而无需修改底层策略。具体而言，FutureRTC包含一个状态校正模块，用于补偿前向传播与实际执行时刻本体感受状态之间的差异；以及一个观测预测模块，通过利用机器人运动作为显式物理先验，基于运动感知的特征传递和重构来预测执行时刻的视觉表示。此外，我们引入策略一致性损失，使从预测上下文生成的动作分块与VLA策略在预期执行时刻输入下产生的动作分块对齐。在模拟和真实环境中的大量实验表明，FutureRTC对推理延迟具有卓越的鲁棒性，从而实现更平滑的轨迹、更快的执行和持续更高的任务成功率。

## Abstract
Real-time deployment of Vision-Language-Action (VLA) policies necessitates asynchronous execution, wherein subsequent action chunks are computed concurrently with the execution of the current chunk, leading to prediction-execution misalignment and manifesting as inter-chunk discontinuities. Existing methods either superficially smooth chunk boundaries, require costly policy optimization, or exclusively forward-predict proprioceptive states yet neglect critical visual observations. In this paper, we propose \textbf{FutureRTC}, a plug-and-play adaptation framework that predicts execution-time observations and states for asynchronous VLA control without modifying the underlying policy. Specifically, FutureRTC features a state correction module to compensate for the discrepancy between rolled-forward and actual execution-time proprioceptive states and an observation prediction module that forecasts execution-time visual representations by leveraging robot motion as an explicit physical prior through motion-aware feature transport and reconstruction. Furthermore, we introduce a policy consistency loss to align the action chunks generated from predicted contexts with those produced under the expected execution-time inputs of the VLA policy. Extensive experiments across simulated and real-world environments demonstrate that FutureRTC achieves superior robustness to inference delays, resulting in smoother trajectories, faster execution, and consistently higher task success rates.

## 1. 核心问题与整体含义（研究动机和背景）

- **背景**：VLA（视觉-语言-动作）模型在机器人学习中的部署面临推理延迟与高频控制之间的矛盾。动作分块（Action Chunking）通过生成多步动作序列缓解计算瓶颈，但同步执行中机器人会停顿等待推理，导致“启停”行为。异步执行允许在执行当前分块的同时计算下一个分块，提高了计算效率，但引入了**预测-执行错位（Prediction-Execution Misalignment）**：后续分块基于过时的观测和状态生成，执行时场景已演变，导致分块间不连续、误差累积和任务失败。

- **现有方法的不足**：
  - 推理时方法（如Temporal Ensembling, BID, RTC）仅在后处理层面平滑边界，未从根本上解决原始错位，且可能增加计算开销。
  - 训练时方法（如T-RTC, VLASH, REMAC）需要昂贵的重训练或微调VLA模型，且VLASH虽能前向预测本体感受状态，但仍依赖过时的视觉观测，忽略了环境变化。

- **研究目标**：在不修改底层VLA策略的前提下，预测执行时刻的观测和状态，使异步执行能像实时同步一样准确、平滑、快速。

## 2. 方法论

### 2.1 核心思想
FutureRTC是一个即插即用的适配器 ϕ(·)，部署在VLA策略之前。它从过时的观测-状态对（o_{t+K-d}, s_{t+K-d}）和已提交的动作序列中，预测出执行时刻（t+K）的观测潜特征 ẑ_{t+K} 和校正后的状态 ŝ_{t+K}，然后将该预测上下文作为VLA策略的条件输入，生成与执行时间对齐的动作分块。

### 2.2 关键技术细节

1. **状态校正模块（State Correction Module, SCM）**：
   - 通过将过时状态 s_{t+K-d} 与已提交动作（a_{t+K-d} ... a_{t+K-1}）的前向积分得到粗略估计 ~s_{t+K}。
   - 使用一个小型MLP预测补偿残差 ~s_Δ = ϕ_SCM(~s_{t+K}, d/d_max)，最终状态 ŝ_{t+K} = ~s_{t+K} ⊕ ~s_Δ。
   - 训练损失 L_state = ||(s_{t+K} ⊖ ~s_{t+K}) - ~s_Δ||²。

2. **观测预测模块（Observation Prediction Module, OPM）**：
   - 在VLA视觉编码器的潜空间操作（z = E(o)），避免重建高维像素。
   - **运动先验提取**：将延迟窗口内的动作序列映射为物理特征向量 u_i（包含瞬时指令、累积位移、增量、路径长度、时间进度），通过时间自注意力生成运动先验 c_motion。
   - **特征传输**：将运动先验、过时潜特征 z_{t+K-d}、相机嵌入 e_cam、位置嵌入 e_pos、校正状态 ŝ_{t+K} 融合为条件特征 F。通过线性+卷积层预测2D位移场 Δp 和传输门控 α ∈ [0,1]，利用可微双线性网格采样执行特征扭曲（warp），生成 z_trans = (1-α)·z_{t+K-d} + α·W(z_{t+K-d}, p - Δp)。
   - **门控残差合成**：对于传输无法解释的内容（如变形、新暴露区域），使用另一分支预测合成特征 r 和合成门控 β ∈ [0,1]；最终潜特征 ẑ_{t+K} = z_trans + β·r。
   - 训练损失 L_obs = ||z_{t+K} - ẑ_{t+K}||²。

3. **策略一致性损失（Policy Consistency Loss）**：
   - 使从预测上下文生成的第一个动作分块与从真实执行时刻上下文生成的动作分块对齐（使用单步流近似）：L_policy = ||π_θ(z_{t+K}, s_{t+K}) - π_θ(ẑ_{t+K}, ŝ_{t+K})||²。

4. **训练**：优化总损失 L_total = L_state + L_obs + λL_policy（λ=10），延迟 d 在 [1, d_max] 中均匀采样以支持多延迟泛化；VLA策略全程冻结。

### 2.3 推断流程
- 异步执行中，在时刻 t+K-d 启动下一个分块 Am+1 的生成，而机器人继续执行当前分块。
- Adapter ϕ 根据当前过时观测状态和已提交动作序列（a_{t+K-d}...a_{t+K-1}）计算出 ẑ_{t+K} 和 ŝ_{t+K}。
- VLA策略以 (ẑ_{t+K}, ŝ_{t+K}) 为条件生成动作分块 Am+1，并直接提取前 K 个动作执行（无需丢弃前 d 个动作）。

## 6. 主要结论与发现

- FutureRTC在所有实验中**显著提升对异步延迟的鲁棒性**，成功率下降幅度远小于对比方法（如Kinetix中d=0→4仅降3.0%）。
- 执行步数和执行时间**最少**，表明轨迹更平滑、决策更果断，减少了抖动和犹豫。
- **观测预测比状态校正更重要**：仅校正状态（VLASH）在较大延迟下性能有限，而同时预测观测可恢复大部分延迟-free性能。
- 预测执行时刻上下文使异步执行**性能接近同步执行（延迟为0）**，验证了该方法的有效性。
- 计算开销极低（<5.2M参数，<4ms延迟），适合实时部署。

## 7. 优点

- **即插即用**：无需修改或重新训练VLA策略，兼容多种骨干（π0.5, SmolVLA）。
- **同时预测观测和状态**，解决完整错位问题，而VLASH仅处理状态。
- **基于运动先验的潜空间特征传输**：通过物理约束（动作流）引导特征演化，比直接回归更稳定且可解释。
- **门控机制（传输门+合成门）**：自适应区分可传输区域和需合成区域，避免过度扭曲。
- **策略一致性损失**：使预测上下文被VLA策略自然接受，提升生成质量。
- **实验充分**：覆盖模拟和真实、多种骨干、多延迟、多种对比方法，并附有详细分析和消融。

## 8. 不足与局限

- **对高度动态外界场景的鲁棒性**：观测预测模块假设主要变化由机器人运动引起，若存在其他独立移动物体（如人、移动工件），特征传输可能失效。
- **仅适用于流匹配VLA**：当前框架基于流匹配生成动作；无法直接应用于自回归模型或离散扩散策略（如DiscreteRTC的骨干），论文未讨论扩展方案。
- **延迟范围有限**：在LIBERO中最大仅测试d=20（约660ms），实际边缘部署或跨网络推理可能更大（如d>50），未验证极端情况下的表现。
- **真实环境仅测试两个延迟水平**（d≈5, 10），且任务均为结构化双机械臂操纵；未涉及自由移动、避碰等需要更高频反馈的场景。
- **训练依赖仿真或离线数据**：潜空间观测预测需要真实执行时刻的潜特征作为监督，这要求训练时能记录延迟后的实际观测，在真实世界中收集较为繁琐（论文通过回放演示数据解决）。
- **偏差风险**：对比的训练时方法（如REMAC、T-RTC）可能需要较多超参数调优，论文未提供其调优细节，可能存在不公平对比（但总体趋势合理）。
