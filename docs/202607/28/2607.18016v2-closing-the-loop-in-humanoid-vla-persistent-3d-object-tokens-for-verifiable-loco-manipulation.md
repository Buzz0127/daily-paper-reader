## 摘要
视觉-语言-行动策略是一般机器人控制的有前景基础，但长时间跨度的类人移动操作要求机器人在运动、接触、遮挡和恢复过程中将任务物体视为持久的物理实体。我们将此问题研究为物体状态分歧：用于条件化全身动作的物体状态可能不同于用于判断该动作是否达到预期物理关系的状态。我们提出持久物体标记化（POT），该方法从RGB-D观测中维护索引化的3D物体记录，并将其转换为用于全身行动专家的物体标记。实例化为POT-VLA，相同的物体记录条件化动作生成并支持几何谓词检查，从而形成一个闭环执行系统，其中物体状态既可操作又可验证。在Unitree G1上，POT-VLA在八个真实世界任务族中将匹配的直接GR00T-N1.7基线从39/80提升至71/80成功。在外部与Being-0对齐的参考中，POT-VLA在对齐的服务任务上取得了44/50成功，而Being-0论文报告的成功为37/50。最大的收益出现在需要维持3D关系的任务上，表明以物体为中心的持久状态是可验证的类人VLA执行的有用抽象。

## Abstract
Vision-language-action policies are a promising foundation for general robot control, but long-horizon humanoid loco-manipulation requires the robot to treat task objects as persistent physical entities across movement, contact, occlusion, and recovery. We study this problem as object-state divergence: the object state used to condition a whole-body action can differ from the state used to decide whether the action achieved the intended physical relation. We propose \emph{Persistent Object Tokenization} (POT), which maintains role-indexed 3D object records from RGB-D observations and converts them into object tokens for a whole-body action expert. Instantiated as \emph{POT-VLA}, the same object records condition action generation and support geometric predicate checks, yielding a closed-loop execution system in which object state is both actionable and verifiable. On a Unitree G1, POT-VLA improves a matched direct GR00T-N1.7 baseline from 39/80 to 71/80 successes over eight real-world task families. In an external Being-0-aligned reference, POT-VLA achieves 44/50 successes on aligned service tasks, compared with the 37/50 success reported by the Being-0 paper. The largest gains occur on tasks requiring maintained 3D relations, suggesting that persistent object-centered state is a useful abstraction for verifiable humanoid VLA execution.

### 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：人形机器人在长时间序列的移动操作（loco-manipulation）中，需要把任务物体当作持久的物理实体来处理，但现有视觉-语言-行动（VLA）策略存在 **物体状态发散** 问题——用于条件化动作的物体状态与用于验证该动作是否达到预期物理关系的状态不一致。  
- **动机**：这种发散会导致物体抓取、放置错误，过早子任务切换，无效恢复等失败模式。因此需要一种 **以物体为中心的持久状态**，既能指导动作生成，又能事后验证物理后果。

### 2. 方法论：核心思想、关键技术细节、算法流程

- **核心思想**：提出 **持久物体标记化（Persistent Object Tokenization, POT）**，从RGB-D观测中维护角色索引的3D物体记录，并将其序列化为“持久3D物体令牌”，同时作为动作专家的条件和验证器的输入，形成**共享物体记忆的闭环**（感知-动作-验证循环）。  
- **关键技术细节**：  
  - **任务角色物体记录**：基于VLM规划器或人工任务文件生成类型化子任务计划，每个子任务有实体集，POT为其构造角色索引的物体记忆 \( M_t^{\tau_i} = \{ m_e^t \mid e \in E_i \} \)，存储角色名称、短语、图像框、3D质心/范围、置信度、可见性、关系特征等。  
  - **持久令牌模式**：将物体记录映射为固定槽位的特征张量 \( x_t^{obj} \in \mathbb{R}^{K \times F} \)（默认K=8, F=33）。每个槽包含可见性、置信度、2D框、3D质心/范围、可选朝向、关系特征。角色ID如TARGET, DESTINATION等。未用槽被遮蔽。  
  - **与VLA动作专家集成**：采用GR00T-N1.7作为基础动作专家。POT-VLA保持相同骨干，但在动作头序列中插入物体令牌，形成 \( S_t = [Z_t^{state}, Z_t^{obj}, Z_t^{action}] \)，并额外与视觉-语言隐藏状态交叉注意。  
  - **闭环执行**：执行一个短水平动作块后，RGB-D观测刷新同一物体记忆，然后由**几何谓词监督器**基于相同记忆验证物理关系（如包含、支撑、抓取接近度等）。验证结果决定继续、重试、重观测、重接地或重规划。  
- **算法流程（文字说明）**：  
  1. 接收指令，通过VLM或人工文件得到子任务计划。  
  2. 对于当前子任务，从RGB-D观测构建角色索引的物体记忆。  
  3. 序列化为持久3D物体令牌，嵌入动作头。  
  4. 动作专家预测全身动作块，执行后刷新物体记忆。  
  5. 几何谓词检查刷新后的记忆，判断子任务是否完成。  
  6. 根据状态（进行中、完成、阻塞、失败、不确定）选择后续动作。
