## 摘要
视觉-语言-动作（VLA）策略提供了强大的通用操作先验，但在紧公差、接触密集的装配任务中往往失败，原因是长程信用分配和子任务耦合：对于当前技能几何上成功的状态可能对后续技能脆弱。我们展示了在冻结的VLA基策略上的残差强化学习（RL）中的这种失败模式：恒定的稀疏成功奖励在孤立情境下改善每个子任务，但当技能链式连接时几乎没有增益，因为终端状态质量不受控制。我们提出远见残差强化学习，该方法通过用离线估计的远见值——当前子任务终端状态下未来子任务成功的概率——来增强每个子任务的稀疏成功奖励，从而优化交接质量。具体来说，我们(i)从基策略终端状态的图像中训练视觉远见预测器，使用下游滚动统计数据进行标注，以及(ii)通过反向远见归纳训练残差策略，将预测器输出作为奖励乘数。在Isaac Gym中的三相扳手式螺母紧固装配任务（抓取、移动插入、旋转）上，我们的方法实现了85.6%的全任务成功率，优于标准子任务残差RL（54.5%）和VLA基线，同时保持每个子任务成功率不变。这些结果强调，提高长程性能需要对每个子任务产生哪些成功状态进行塑造，而不仅仅是是否发生成功。

## Abstract
Vision-Language-Action (VLA) policies offer strong general-purpose manipulation priors, but often fail on tight-tolerance, contact-rich assembly due to long-horizon credit assignment and subtask coupling: a state that is geometrically successful for the current skill can be brittle for downstream skills. We show this failure mode in residual reinforcement learning (RL) over a frozen VLA base policy: constant sparse success rewards improve each subtask in isolation yet yield little or no gain when skills are chained, because terminal state quality is uncontrolled. We propose Foresight Residual RL, which optimizes handoff quality by augmenting each subtask's sparse success reward with an offline-estimated foresight value -- the probability of future subtask success conditioned on the terminal state of the current subtask. Concretely, we (i) train a visual foresight predictor from images of terminal states of the base policy, labeled using downstream rollout statistics, and (ii) train residual policies via backward foresight induction, using the predictor output as a reward multiplier. On a three-phase wrench-based nut-tightening assembly task in Isaac Gym (grasp, move-insert, rotate), our method achieves 85.6% full-task success, outperforming standard subtask residual RL (54.5%) and VLA baselines, while leaving per-subtask success unchanged. These results highlight that improving long-horizon performance requires shaping which successful states are produced at each sub-task, not only whether success occurs.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题背景**：长程机器人操作任务（如工业装配、工具使用）通常分解为多个子任务并依次执行。Vision-Language-Action (VLA) 模型提供了强大的通用操作先验，但在紧公差、接触密集的装配任务中表现不佳。
- **核心挑战**：子任务之间存在因果耦合——前序子任务的终止状态质量会显著影响后续子任务的成功概率。标准做法（如为每个子任务独立训练策略并使用恒定的稀疏成功奖励）忽略了这种依赖：所有满足当前子任务成功谓词的终止状态被视为等值，但实际上只有部分状态能良好地衔接下游任务。
- **论文揭示的失败模式**：在冻结的 VLA 基策略上应用标准残差 RL，虽然能提升孤立子任务的成功率（如插入从 45.7% 提升到 92.2%），但当子任务链式执行时，全任务成功率几乎没有提升（54.5% vs 端到端 π0 的 54.9%），原因在于终端状态质量不受控制。
- **整体含义**：提升长程操作性能的关键不是“是否”让每个子任务成功，而是“怎样”产生成功的终端状态——即优化子任务终止状态的质量，而非仅仅提升子任务成功率。

## 2. 方法论

### 核心思想
- 定义**远见值函数（Foresight Value Function）**：当前子任务终止状态下，未来子任务成功概率的期望。用该值作为奖励乘数，引导残差策略产生对下游有利的终止状态。
- 采用**反向远见归纳（Backward Foresight Induction）**：从最后一个子任务开始反向训练每个子任务，保证下游策略固定后可估计远见值。

### 关键技术细节

1. **视觉远见预测器（Visual Foresight Predictor）**
   - 输入：子任务 k 终止时刻的观测图像（使用 DINOv2-S/14 特征，通过 LoRA 微调）。
   - 输出：子任务 k+1 成功概率 p_ϕ(o) ∈ [0,1]。
   - 训练数据：收集 N=2560 个基策略 (π0_k) 成功终止状态；对每个状态执行 Krep=5 次下游策略 (π_{k+1}) 的独立 rollout，记录成功次数 κ_i，获得标签 y_i = κ_i / Krep。
   - 损失函数：二项式负对数似然（Binomial NLL），尊重计数结构。

2. **残差策略（Residual Policy）**
   - 动作公式：a_t = π0_k(o_t) + α · π_res_k(o_t)，α = 0.1。
   - 残差网络：基于冻结的 DINOv2-S/14 提取 wrist 图像特征，经 CNN → LSTM → MLP（actor/critic 头），actor 输出层零初始化以保持基策略行为。
   - 训练算法：PPO，128 个并行环境，先进行 10 次 critic-only 热身，再 300 次 joint actor-critic 训练。

3. **反向远见归纳流程（Algorithm 1）**
   - 从最后一个子任务 (k=K) 开始，使用标准成功奖励训练残差策略。
   - 对 k < K：先固定训练好的下游策略 π_{k+1}，调用 FORESIGHT PREDICTOR（Algorithm 2）获得当前边界上的远见预测器 p_ϕ；然后训练 π_res_k，奖励函数为 r_t = β_k(s_{t+1}) · p_ϕ(o_{t+1})。

### 公式（用文字说明）
- 局部远见值函数 V°_k(s) = E[∑γ^t β_k(s_{t+1}) V_{k+1:K}(s_{t+1})]，其中 V_{k+1:K} 是未来所有子任务的折扣累积成功概率。
- 实际采用一步近似：V_{k+1}(s) ≈ Pr(子任务 k+1 成功 | s, π_{k+1})。

## 6. 主要结论与发现

1. **标准残差 RL 的失败模式**：虽然提高了子任务成功率，但链式后全任务成功率与端到端基线持平（54.5% vs 54.9%），证明了优化终端状态质量的重要性。
2. **远见残差 RL 显著提升链路性能**：全任务成功率从 54.5% 提升到 85.6%（提升 31.1%），主要是 Grasp→Insert 边界的改善（+31.8%）。
3. **预测器有效性**：远见预测器在两个边界上的分类准确率（86.2%、93.9%）均超过多数类基线（73.9%、90.4%），说明能够区分终端状态的质量差异。
4. **终端状态质量改变**：标准残差 RL 反而降低了平均远见分（Grasp 终端从 0.64→0.32），而远见残差 RL 提升了它（0.64→0.73）。这表明恒定量奖励激励策略去找到更多“便捷”的成功状态但牺牲了下游性能。
5. **子任务成功率本身不变**：远见残差 RL 并没有显著改变单个子任务的成功率（与标准残差 RL 相近），但通过重塑终止状态分布提升了组合性能。

## 7. 优点

- **方法新颖性**：明确指出现有残差 RL、分布匹配等方法忽略的关键问题——终端状态质量 vs 子任务成功概率，并提出了基于远见值的直接优化方法。
- **实践可行性**：离线训练预测器避免了在线蒙特卡洛的高方差和高计算成本，且仅需一次收集；预测器输出为确定值，稳定了 RL 训练。

- **实验验证清晰**：通过控制子任务成功率不变而全任务成功率大幅提升，直接证明终端状态质量是主导因素；通过表 3 的预测分变化进一步强化结论。

## 8. 不足与局限

- **仅限仿真环境**：实验完全在 Isaac Gym 中进行，未考虑 sim-to-real 转移。作者指出主要障碍是真实机器人上的在线 RL 成本，而非接触动力学差异，但未验证。
- **单一任务**：只在一个扳手-螺母装配任务上验证，任务特性和阶段分解固定。需要更多元化的长程操作任务来证明泛化性。
- **未与同类方法对比**：未与 T-STAR、SCaR、Sequential Dexterity 等分布匹配方法进行定量比较，削弱了相对于现有工作的竞争力证明。
- **假设已知阶段分解**：方法要求人工定义子任务边界和成功谓词，在更复杂或不明确的任务中可能不适用。
- **分布偏移风险**：预测器基于基策略终端状态训练，残差策略改进后可能访问超出训练覆盖的状态，尽管 α 较小限制了偏移，但仍存在风险。
- **计算成本隐忧**：收集 2560 个终端状态并每个执行 5 次下游 rollout（涉及完整子任务）需要较多仿真资源，但属于一次性成本。
- **未探讨更深层远见**：使用一步近似，当子任务数多于 2 时精度会下降。论文仅在最后阶段之前应用（共 3 阶段），但未测试更多阶段的情况。
