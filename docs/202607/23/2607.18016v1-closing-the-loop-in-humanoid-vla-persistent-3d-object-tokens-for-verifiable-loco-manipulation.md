## 摘要
视觉-语言-动作策略是通用机器人控制的一个有前景的基础，但长期任务的人形移动操作要求机器人将任务对象视为跨越运动、接触、遮挡和恢复的持久物理实体。我们将此问题研究为对象状态发散：用于调节全身动作的对象状态与用于判断动作是否实现预期物理关系的状态可能不同。我们提出了"持久对象令牌化"（POT），该方法从RGB-D观测中维护角色索引的三维对象记录，并将其转换为面向全身动作专家的对象令牌。实例化为POT-VLA，相同的对象记录既调节动作生成，又支持几何谓词检查，从而产生一个对象状态既可操作又可验证的闭环执行系统。在Unitree G1上，POT-VLA在八个真实世界任务族中将匹配的直接GR00T-N1.7基线从39/80成功率提高到71/80。在与外部Being-0对齐的参考中，POT-VLA在对齐的服务任务上实现了44/50的成功率，而Being-0论文报告的成功率为37/50。最大的改进出现在需要维持三维关系的任务上，这表明以对象为中心的持久状态是用于可验证的人形VLA执行的一个有用抽象。

## Abstract
Vision-language-action policies are a promising foundation for general robot control, but long-horizon humanoid loco-manipulation requires the robot to treat task objects as persistent physical entities across movement, contact, occlusion, and recovery. We study this problem as object-state divergence: the object state used to condition a whole-body action can differ from the state used to decide whether the action achieved the intended physical relation. We propose \emph{Persistent Object Tokenization} (POT), which maintains role-indexed 3D object records from RGB-D observations and converts them into object tokens for a whole-body action expert. Instantiated as \emph{POT-VLA}, the same object records condition action generation and support geometric predicate checks, yielding a closed-loop execution system in which object state is both actionable and verifiable. On a Unitree G1, POT-VLA improves a matched direct GR00T-N1.7 baseline from 39/80 to 71/80 successes over eight real-world task families. In an external Being-0-aligned reference, POT-VLA achieves 44/50 successes on aligned service tasks, compared with the 37/50 success reported by the Being-0 paper. The largest gains occur on tasks requiring maintained 3D relations, suggesting that persistent object-centered state is a useful abstraction for verifiable humanoid VLA execution.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究动机**：人形机器人执行长期移动操作任务（如“整理桌面”“拿饮料”）时，需要将任务物体视为跨越移动、接触、遮挡和恢复的持久物理实体。现有VLA策略通常将物体状态隐式编码在视觉语言特征中，导致动作条件所依据的物体状态与验证动作是否达成预期物理关系所使用的状态可能不一致，称为**物体状态发散**（object-state divergence）。这种发散会造成细小的抓取、放置误差累积，导致任务过早转换、操作错误物体或无效恢复。
- **整体含义**：为了在长期操作中实现闭环执行，需要一种以物体为中心的持久状态表示，既能为动作生成提供条件，又能在执行后用于验证物理关系，从而弥合动作与验证之间的状态鸿沟。

## 2. 论文提出的方法论：核心思想、关键技术细节、流程

### 核心思想
- **Persistent Object Tokenization (POT)**：从RGB-D观测中提取角色索引的3D物体记录，并将其序列化为持久3D物体令牌（Persistent 3D Object Tokens），供全身动作专家使用。
- **POT-VLA**：基于POT构建的完整VLA系统，共享同一物体记忆，实现“感知-动作-验证”闭环。动作专家在每次动作块前消费物体令牌，执行后使用相同记录进行几何谓词验证。

### 关键技术细节
- **角色索引物体记忆**：对于每个类型子任务τᵢ，构造角色索引物体记忆Mₜ^{τᵢ}，包含实体角色、短语、图像框、3D质心/范围、置信度、可见性、关系特征。使用SAM3（Segment Anything Model 3）提供掩码，通过深度反投影和基座坐标变换得到3D记录。
- **持久令牌模式**：将Mₜ^{τᵢ}映射到固定大小的特征张量x_obj_t ∈ ℝ^{K×F}（默认K=8槽，F=33特征/槽）。每个槽包含可见性、置信度、2D框、3D质心/范围、可选朝向、关系特征。角色包括TARGET、DESTINATION、SUPPORT、HANDOVER_PARTNER等，未用槽为PADDING并掩码。
- **动作头插入**：对象令牌投影为Z_obj_t ∈ ℝ^{K×d}（LayerNorm→Linear→GELU→Dropout→Linear），与状态令牌Z_state_t和动作令牌Z_action_t拼接，作为DiT动作头的自注意力输入。视觉语言骨干特征通过交叉注意力参与。预测的全身动作块ˆa_{t:t+H}经过运行时校验后执行。
- **闭环执行与验证**：每个动作块执行后，RGB-D刷新相同物体记录到M_{t+H}^{τᵢ}，几何谓词监督器读取同一记忆，检查物理关系谓词（包含、支撑、接近度等），返回状态（in_progress/done/blocked/failed/uncertain）和诊断，触发继续、重试、重新观察、重新接地或重新规划。

- **创新性**：提出POT概念，将3D接地转化为可共享的执行记忆，同时用于动作条件和验证，有效解决物体状态发散。
