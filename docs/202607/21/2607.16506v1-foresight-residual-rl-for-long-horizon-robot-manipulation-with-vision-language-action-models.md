## 摘要
视觉-语言-动作（VLA）策略提供了强大的通用操纵先验，但在高精度、接触密集的装配任务中常常失败，原因是长时域信用分配和子任务耦合：当前技能在几何上成功的状态可能对下游技能是脆弱的。我们在冻结的VLA基础策略上的残差强化学习（RL）中展示了这种失败模式：恒定的稀疏成功奖励单独改善了每个子任务，但当技能链式组合时却几乎没有收益，因为末端状态质量不受控制。我们提出预见性残差强化学习，通过用离线估计的预见值增强每个子任务的稀疏成功奖励来优化交接质量——该预见值是在当前子任务末端状态下未来子任务成功的概率。具体而言，我们（i）从基础策略的末端状态图像中训练一个视觉预见预测器，使用下游轨迹统计数据进行标注，以及（ii）通过反向预见归纳训练残差策略，将预测器输出作为奖励乘数。在Isaac Gym中基于扳手的三阶段螺母拧紧装配任务（抓取、移动插入、旋转）上，我们的方法实现了85.6%的全任务成功率，优于标准子任务残差RL（54.5%）和VLA基线，同时保持每个子任务的成功率不变。这些结果强调，提升长时域性能需要塑造每个子任务产生的成功状态类型，而不仅仅是是否成功。

## Abstract
Vision-Language-Action (VLA) policies offer strong general-purpose manipulation priors, but often fail on tight-tolerance, contact-rich assembly due to long-horizon credit assignment and subtask coupling: a state that is geometrically successful for the current skill can be brittle for downstream skills. We show this failure mode in residual reinforcement learning (RL) over a frozen VLA base policy: constant sparse success rewards improve each subtask in isolation yet yield little or no gain when skills are chained, because terminal state quality is uncontrolled. We propose Foresight Residual RL, which optimizes handoff quality by augmenting each subtask's sparse success reward with an offline-estimated foresight value -- the probability of future subtask success conditioned on the terminal state of the current subtask. Concretely, we (i) train a visual foresight predictor from images of terminal states of the base policy, labeled using downstream rollout statistics, and (ii) train residual policies via backward foresight induction, using the predictor output as a reward multiplier. On a three-phase wrench-based nut-tightening assembly task in Isaac Gym (grasp, move-insert, rotate), our method achieves 85.6% full-task success, outperforming standard subtask residual RL (54.5%) and VLA baselines, while leaving per-subtask success unchanged. These results highlight that improving long-horizon performance requires shaping which successful states are produced at each sub-task, not only whether success occurs.

### 论文总结：Foresight Residual RL for Long-Horizon Robot Manipulation

#### 1. 核心问题与整体含义
- **研究动机**：视觉-语言-动作（VLA）模型在通用操纵任务中表现出色，但在高精度、接触密集的长时程装配任务（如扳手拧螺母）中常失败。根本原因是**子任务耦合**：每个子任务独立训练时只追求几何成功，忽略了终端状态对下游任务的影响。一个几何上成功的状态（如抓取姿态）可能因稳定性差导致后续插入或旋转失败。
- **关键失败模式**：在冻结VLA基础策略上做标准残差强化学习（RL），用常值稀疏成功奖励训练每个子任务策略，单独测试成功率可大幅提升，但链式组合后全任务成功率几乎无增益，因为终端状态质量未被优化。
- **整体含义**：长时程操纵性能提升的关键不是让每个子任务更频繁地成功，而是**塑造成功状态的类型**——使终端状态更有利于后续子任务成功。

#### 2. 方法论
- **核心思想**：提出**Foresight Residual RL**，通过离线学习一个视觉预见预测器，估计当前子任务终端状态导致下一子任务成功的概率，然后将该概率作为奖励乘子与稀疏成功奖励相乘，指导残差策略优化终端状态质量。
- **关键技术细节**：
  - **一阶预见近似**：将未来多步回报近似为下一子任务的成功概率（`V_{k+1}(s)` ≈ `Pr(子任务k+1成功 | 起始状态s)`）。
  - **离线预见预测器（Foresight Predictor）**：
    1. 用基础VLA策略收集当前子任务的N个成功终端状态（图像+机器人状态）。
    2. 对每个终端状态，运行下游策略Krep次独立rollout，记录成功次数，得到标签 `κ_i / Krep`。
    3. 训练一个视觉预测器 `p_ϕ(o)`，输入终端状态图像（DINOv2特征+LoRA微调），输出成功概率。损失函数采用**二项负对数似然**（Binomial NLL），保证概率校准。
  - **反向预见归纳（Backward Foresight Induction）**：
    1. 从最后一个子任务（k=K）开始训练，其预见值视为1，使用标准成功奖励。
    2. 依次向前训练：k = K-1,...,1。对于每个k，固定下游策略（已训练好的基础+残差），利用预见预测器生成奖励 `r_t = β_k(s_{t+1}) * p_ϕ(o_{t+1})`，并用PPO训练当前子任务的残差策略。
  - **残差策略结构**：基础VLA策略（π0）输出动作，残差策略输出小幅度修正（`a_t = π0_k(o_t) + α·πres_k(o_t)`，α=0.1）。残差策略仅使用腕部相机图像，通过DINOv2+CNN+LSTM+MLP输出。

#### 3. 实验设计
- **任务与场景**：在NVIDIA Isaac Gym仿真中实现三阶段扳手-螺母拧紧任务（抓取→移动插入→旋转），使用7-DoF Kuka IIWA臂和11-DoF Robotiq三指爪。包含5种不同尺寸的扳手/螺母（间隙<2mm），初始位姿随机化。最大步数560步，控制频率20Hz。
- **基线与对比方法**：
  - **π0端到端（end-to-end）**：直接训练整个任务的π0策略。
  - **π0链式（chained）**：每个子任务独立训练π0，链式执行（未做残差优化）。
  - **π0+残差（无预见）**：每个子任务用标准稀疏成功奖励训练残差策略（对应本文标准残差RL）。
  - **π0+残差+预见（本文方法）**：使用预见奖励乘子训练残差策略。
- **评估指标**：子任务成功率（从专家oracle状态初始化）、连续两阶段成功率、全任务成功率。

#### 8. 不足与局限
- **仅在仿真中验证**：未在真实机器人上实验，虽然作者认为主要障碍是on-hardware在线RL的成本，但仿真到现实的域迁移（尤其是接触动力学）仍需验证。
- **单一任务泛化性不足**：仅在扳手拧螺母装配任务上测试，其他类型的长时程操纵任务（如多物体组装、可变形体操作）未能覆盖。
- **依赖已知阶段分解**：方法要求任务预先分为清晰的阶段和成功谓词，对于阶段边界不明确的任务不适用。
- **一阶预见近似假设**：只考虑下一子任务的即时成功概率，更深层（如越过多个子任务）的依赖可能被忽略。若后续子任务的成功条件高度依赖于更多历史状态，可能产生偏差。
