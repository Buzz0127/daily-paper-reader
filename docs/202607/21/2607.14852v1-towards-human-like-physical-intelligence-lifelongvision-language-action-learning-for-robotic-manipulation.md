## 摘要
与人类顺序学习新任务的自然能力类似，配备视觉-语言-动作（VLA）模型的机器人在开放世界环境中部署时应具备终身学习能力以学习新任务。然而，最近提出的大多数终身学习模型旨在有效学习当前任务（可塑性）或保持先前任务的高精度（稳定性），而可塑性-稳定性权衡在机器人操作模型中仍未得到充分解决。为应对这一根本性挑战，我们提出了一种面向机器人操作的缓存高效终身视觉-语言-动作学习框架（即LifelongVLA），该框架通过双时间尺度自适应机制缓解可塑性-稳定性权衡，同时通过缓存高效的重放策略实现低成本的机器人部署。更具体地，我们提出了一种双时间尺度LoRA门控模块，将VLA自适应分解为两个轻量级路径：用于可塑性的短期适配器和用于稳定巩固的长期适配器。这些路径通过任务感知门控集成，实现可塑性-稳定性权衡的显式控制。在技能重放阶段，我们提出了一种缓存高效的随机重放策略，无需存储完整轨迹即可保留更均衡的保留信号。最后，实验表明，LifelongVLA优于现有基线，在xArm机器人上的实际部署中展示了高效的技能扩展、对已学习操作行为的鲁棒保留以及减少对重新训练的依赖。

## Abstract
Similar to the natural capabilities of humans to sequentially learn new tasks, robots with Vision-Language-Action (VLA) models should possess lifelong learning ability to learn a new task when deployed in open-world environments. However, most recently proposed lifelong learning models aim to effectively learn the current task (plasticity) or maintain high accuracy on previous tasks (stability), while the plasticity-stability trade-off remains largely unsolved in robotic manipulation models. To address this fundamental challenge, we propose a cache-efficient lifelong Vision-Language-Action learning framework for robotic manipulation (i.e., LifelongVLA), which alleviates the plasticity-stability trade-off with a dual-timescale adaptation mechanism while achieving low-cost robotic deployment with a cache-efficient replay strategy. More concretely, we propose a dual-timescale LoRA gating module to decompose VLA adaptation into two lightweight pathways: a short-term adapter for plasticity and a long-term adapter for stable consolidation. These pathways are integrated via a task-aware gate, enabling explicit control of the plasticity-stability trade-off. In the skill replay phase, a cache-efficient stochastic replay strategy is proposed to preserve more balanced retention signals without full-trajectory storage. Finally, experiments show that LifelongVLA outperforms existing baselines, demonstrating efficient skill expansion, robust retention of learned manipulation behaviors, and reduced reliance on retraining for real-world deployment on an xArm robot.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究动机**：现有 Vision-Language-Action (VLA) 模型多采用静态离线训练范式，即在固定技能集上训练一次后部署，无法在开放世界中持续学习新操作技能。然而，机器人应像人类一样具备顺序学习新任务的能力，这要求 VLA 模型拥有终身学习能力。
- **核心挑战**：终身学习面临“可塑性-稳定性权衡”（plasticity-stability trade-off）：高可塑性有助于快速学习新任务，但可能覆盖已有知识；强稳定性保留过去技能，但限制未来学习。现有方法（如经验重放、架构扩展）未能充分解决此问题，且全轨迹重放对 VLA 大模型计算与存储开销高昂。
- **整体目标**：提出一种缓存高效的终身 VLA 学习方法，使机器人在有限重放下实现新技能高效获取与旧技能稳健保留，同时降低部署成本。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 核心思想

- **LifelongVLA 框架**：基于冻结的 VLA 骨干网络（PaliGemma + Gemma 2B），通过两个核心模块——**双时间尺度 LoRA 门控**和**缓存高效随机重放**——显式平衡可塑性与稳定性，并减少重放存储与计算开销。

### 2.2 关键技术细节

#### (a) 双时间尺度 LoRA 门控（Dual-Timescale LoRA Gating）

- **设计**：为每个适配层 ℓ 定义两条 LoRA 路径：
  - **短期适配器**（`∆W_sh,t`）：由当前任务损失 `L_new` 更新，学习率 `η_sh` 较大，负责快速适应新任务（高可塑性）。
  - **长期适配器**（`∆W_lg,t`）：仅由重放损失 `L_rep` 和蒸馏损失 `L_dist` 更新，学习率 `η_lg` 较小（`η_lg < η_sh`），负责巩固之前技能（高稳定性）。
- **任务感知门控**：基于冻结的视觉-语言前缀特征计算门控上下文 `c`，通过轻量网络生成门控值 `α∈[0,1]`，动态组合两条路径的权重：  
  `∆W_composed = (1-α)∆W_sh + α∆W_lg`  
  当 `α→0` 时强调可塑性，`α→1` 时强调稳定性。门控参数共享，但上下文 `c` 与样本相关。
- **优势**：在单次前向传播中实现权重级组合，不修改骨干网络，不增加二次推理。

#### (b) 缓存高效随机重放（Cache-Efficient Stochastic Replay）

- **存储**：每个技能只随机选取 `ct=50` 个样本，仅存储**停止梯度的前缀令牌**（`stop-gradient prefix tokens`）和紧凑状态-动作监督，不存储原始图像、语言令牌、后缀令牌、扩散时间步或噪声。相比全轨迹重放，大幅减少存储开销。
- **重放**：重放时重新采样扩散变量 `τ'` 和噪声 `ϵ'`，利用当前模型重新计算后缀令牌，使得同一前缀可生成多样化的随机去噪实例，缓解缓存特征过时问题。
- **损失函数**：混合批次中当前样本与重放样本分开归一化，并加入蒸馏损失 `L_dist`（使用任务 t-1 的模型快照作为教师），总损失为：  
  `L_t = L_new + λ L_rep + β L_dist`  
  其中 `λ=1.0, β=0.1`。

### 2.3 算法流程（文字说明）

1. 初始化：冻结 VLA 骨干 `Θ0`，初始化短期与长期 LoRA 参数，缓存缓冲区 `B` 为空。
2. 对于每个新任务 t：
   - 用当前任务数据训练，短期适配器通过 `L_new` 更新。
   - 从之前任务缓存中采样，重放样本通过重新构造后缀与教师蒸馏更新长期适配器。
   - 训练后，从当前任务随机选取 `ct` 个样本，仅存储其前缀令牌与状态-动作对到缓存 `B`。
   - 任务门控根据前缀特征动态组合两条 LoRA 路径，用于推理。
