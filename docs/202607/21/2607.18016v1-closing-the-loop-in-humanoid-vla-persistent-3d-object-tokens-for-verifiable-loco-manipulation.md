## 摘要
视觉-语言-动作策略是通用机器人控制的有前景的基础，但长时间跨度的人形全身操作要求机器人将任务对象视为在运动、接触、遮挡和恢复过程中持续存在的物理实体。我们将此问题研究为对象状态发散：用于调节全身动作的对象状态可能与用于判断动作是否达到预期物理关系的状态不同。我们提出可持久化对象令牌化（POT），该方法从RGB-D观测中维护角色索引的3D对象记录，并将其转换为对象令牌，以供全身动作专家使用。实例化为POT-VLA，相同的对象记录用于条件化动作生成并支持几何谓词检查，从而形成一个闭环执行系统，在该系统中对象状态既可行又可验证。在Unitree G1上，POT-VLA在八个真实世界任务族中将匹配的直接GR00T-N1.7基线从39/80成功率提升至71/80。在一个外部的Being-0对齐参考中，POT-VLA在对齐的服务任务上实现了44/50的成功率，而Being-0论文报告的成功率为37/50。最大的提升出现在需要维护3D关系的任务上，这表明以对象为中心的持久状态是可验证的人形VLA执行的有用抽象。

## Abstract
Vision-language-action policies are a promising foundation for general robot control, but long-horizon humanoid loco-manipulation requires the robot to treat task objects as persistent physical entities across movement, contact, occlusion, and recovery. We study this problem as object-state divergence: the object state used to condition a whole-body action can differ from the state used to decide whether the action achieved the intended physical relation. We propose \emph{Persistent Object Tokenization} (POT), which maintains role-indexed 3D object records from RGB-D observations and converts them into object tokens for a whole-body action expert. Instantiated as \emph{POT-VLA}, the same object records condition action generation and support geometric predicate checks, yielding a closed-loop execution system in which object state is both actionable and verifiable. On a Unitree G1, POT-VLA improves a matched direct GR00T-N1.7 baseline from 39/80 to 71/80 successes over eight real-world task families. In an external Being-0-aligned reference, POT-VLA achieves 44/50 successes on aligned service tasks, compared with the 37/50 success reported by the Being-0 paper. The largest gains occur on tasks requiring maintained 3D relations, suggesting that persistent object-centered state is a useful abstraction for verifiable humanoid VLA execution.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：人形机器人在长时程全身操作（locomotion + manipulation）中，存在“对象状态发散（object-state divergence）”现象。即：用于**调节动作生成**的对象状态与用于**验证动作是否达到预期物理关系**的对象状态不一致。这导致抓取偏移、放置错误、过早的子任务转换等失败模式。
- **背景**：现有VLA策略通常从当前观测的视觉-语言特征隐式编码对象状态，但任务进度检查可能使用独立的符号层或谓词层，两者脱节。人形机器人在行走、抓取、放置、遮挡、恢复过程中，物体在度量3D空间中移动，需要持久、可行动、可验证的对象中心状态。
- **整体含义**：论文提出**持久对象标记化（POT）**，将RGB-D观测转化为角色索引的3D对象记录，并生成**持久3D对象令牌**，同时用于动作生成和几何谓词验证，从而在共享对象记忆上闭环执行，避免状态发散。

## 2. 方法论

### 2.1 核心思想

- 构建并维护一个**角色索引的对象记忆** $M_{t}^{\tau_i}$（$\tau_i$为当前类型化子任务），记录每个任务实体的角色、3D位置、几何、可见性、置信度及关系特征。
- 将此记忆序列化为**持久3D对象令牌**（Persistent 3D Object Tokens） $x_{t}^{obj} = \mathcal{T}(M_{t}^{\tau_i})$，**插入到全身动作专家的自注意力序列中**，使动作生成条件化于显式3D对象状态。
- 执行一个动作块后，刷新同一对象记忆，利用**几何谓词**验证物理关系是否达成，判断是否完成、需要重试或重新观察。

### 2.2 关键技术细节

- **对象记录构建**：基于类型化子任务定义实体角色（TARGET, DESTINATION, SUPPORT, HANDOVER_PARTNER等），利用SAM3在线掩码、深度反投影、相机到基座的变换，在机器人基座坐标系中构造记录，包含质心、范围、可见性、置信度、以及关系特征（如物体-容器距离、支持高度、端效应器偏移等）。
- **令牌架构**：固定 $K=8$ 个槽位，每个槽位 $F=33$ 维特征。有效槽包含角色ID，未用槽为PADDING并掩码。特征包括可见性、置信度、归一化2D框、3D质心/范围、可选方向、关系特征。持久性在于：每次动作块后刷新度量证据，但角色槽保持绑定。
- **动作头部插入**：将对象令牌投影到DiT隐藏维度，并与状态令牌、动作令牌构成序列 $S_t = [Z_{t}^{state}, Z_{t}^{obj}, Z_{t}^{action}]$。视觉-语言编码器的隐状态用于交叉注意力。通过角色嵌入和情境嵌入区分槽位语义。
- **验证与恢复**：每个子任务定义一组物理谓词 $p = \langle \kappa, \alpha, op, \nu, n \rangle$，用于检查包含、支持、距离、位移等。验证函数 $\phi(\kappa, \alpha, M_{\xi}^{\tau_i})$ 返回标量证据。运行状态包括 in_progress, done, blocked, failed, uncertain。根据诊断触发 continue, retry, reobserve, reground, replan。

### 2.3 算法流程（文字描述）

1. 输入指令 $I$ 和当前观测，VLM规划器生成类型化子任务计划 $\Pi$。
2. 对于当前活跃子任务 $\tau_i$，从RGB-D观测 $o_t$ 和 proprioception $s_t$ 构建对象记忆 $M_{t}^{\tau_i}$。
3. 将记忆转化为对象令牌 $x_{t}^{obj}$，插入动作专家，预测整条动作块 $\hat{a}_{t:t+H}$。
4. 经过运行时检查和命令平滑后执行 $a_{t:t+H}$。
5. 刷新对象记忆到 $M_{t+H}^{\tau_i}$，运行几何谓词验证。
6. 如果满足目标谓词（done），进入下一子任务；否则根据状态（blocked/failed/uncertain）选择恢复策略。

## 6. 主要结论与发现

- POT-VLA将人形机器人全身操作成功率从**48.8%（39/80）提升至88.8%（71/80）**，提升40个百分点。
- 在对齐的Being-0服务任务上，POT-VLA达到**44/50（88%）**，优于Being-0报告的37/50（74%）。
- **最大提升在需要维持3D关系的任务**（杯堆叠、两球放置、衣物运输、抽屉/托盘操作），这些任务中直接基线容易因物体状态发散而失败。
- 消融表明：**对象令牌条件化是主要贡献者**（从15/40提升至31/40），验证进一步提供残余增益（至34/40）。两者分工明确：令牌解决多数接地失败，验证捕捉残留假完成。
- 持久物体中心状态（Persistent object-centered state）是人形VLA可验证执行的有效抽象。

## 7. 优点

- **核心创新**：提出角色感知的持久对象记忆，使动作生成和验证共享同一个3D对象状态，从根本上避免状态发散。
- **模块化设计**：不依赖模拟器或物理模型，仅用RGB-D测量驱动，易于集成到现有VLA框架。
- **令牌插入方式**：将对象令牌直接插入动作专家头部自注意力序列，而非修改视觉-语言骨干，保持主干参数不变，微调轻量。
- **验证层设计**：几何谓词具有可解释性，提供细粒度诊断（如缺失可见性、抓取失败、支持不稳定等），支持本地恢复而非全局重规划。
- **实验扎实**：真实世界实验涵盖多种操作类型，消融和泛化测试设计严谨，分离条件化与验证的贡献。
- **对比公平**：与直接基线在相同硬件、骨干、运行时下对比；与外部文献（Being-0）对比任务对齐。
- **实际效果显著**：在需要长时间维持3D关系的复杂任务上提升巨大，验证了方法的必要性。

## 8. 不足与局限

- **依赖感知质量**：系统性能受限于SAM3/RGB-D可靠性、相机标定精度、对象记录质量；低光照、强反射或运动模糊可能导致记录失败。
- **令牌槽位固定**：默认8个槽位，对于包含更多角色（如多个目标/多个容器）的任务可能不足，需扩展槽位或动态分配。
- **单机器人验证**：所有实验仅在Unitree G1上执行，泛化到其他型号人形机器人（不同自由度、传感器配置、控制器）尚未验证。
- **缺乏仿真实验**：完全依赖真实世界实验，环境不可控因素较多（照明、背景运动、人为干扰），可能引入变量但未量化。仿真可提供更大规模系统化评估。
- **几何谓词阈值手动设定**：谓词中用到的距离、稳定窗口等阈值由子任务规格和机器人标定给出，未学习或自适应，可能在不同场景下不够鲁棒。
- **计算资源未公开**：训练和推理的计算开销（GPU型号、训练时长、能耗）未提供，影响复现性和可扩展性评估。
- **动作专家限制**：基于GR00T-N1.7，其本身的能力（如对不同物体、接触的泛化）构成上限；POT-VLA无法克服动作专家本身的局限性。
- **长期稳定性未验证**：更大时间尺度（如清理整个房间）或多步重规划场景下的表现未知。
- **人工标注/先验知识**：角色定义、接地查询、谓词规范需要一定程度的人工设计，自动化程度可进一步提高。
