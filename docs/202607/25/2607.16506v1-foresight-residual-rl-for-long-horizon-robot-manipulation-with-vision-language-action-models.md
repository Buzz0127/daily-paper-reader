## 摘要
视觉-语言-动作（VLA）策略提供了强大的通用操作先验，但由于长时域信用分配和子任务耦合（一个在当前技能上几何上成功的状态可能对后续技能很脆弱），在公差严格、接触密集的装配任务中常常失败。我们展示了冻结VLA基策略上的残差强化学习（RL）的这种失败模式：恒定的稀疏成功奖励在孤立情况下改善每个子任务，但当技能链式连接时几乎无增益，因为终端状态质量不受控。我们提出前瞻性残差RL，通过用离线估计的前瞻值（基于当前子任务终端状态下未来子任务成功的概率）增强每个子任务的稀疏成功奖励，来优化交接质量。具体来说，我们（i）从基策略终端状态的图像训练视觉前瞻预测器，使用下游回滚统计数据标记，以及（ii）通过后向前瞻归纳训练残差策略，使用预测器输出作为奖励乘数。在Isaac Gym的三阶段基于扳手的螺母拧紧装配任务（抓取、移动-插入、旋转）中，我们的方法实现了85.6%的全任务成功率，优于标准子任务残差RL（54.5%）和VLA基线，同时保持各子任务成功率不变。这些结果强调，提升长时域性能需要塑造每个子任务产生哪些成功状态，而不仅仅是是否成功。

## Abstract
Vision-Language-Action (VLA) policies offer strong general-purpose manipulation priors, but often fail on tight-tolerance, contact-rich assembly due to long-horizon credit assignment and subtask coupling: a state that is geometrically successful for the current skill can be brittle for downstream skills. We show this failure mode in residual reinforcement learning (RL) over a frozen VLA base policy: constant sparse success rewards improve each subtask in isolation yet yield little or no gain when skills are chained, because terminal state quality is uncontrolled. We propose Foresight Residual RL, which optimizes handoff quality by augmenting each subtask's sparse success reward with an offline-estimated foresight value -- the probability of future subtask success conditioned on the terminal state of the current subtask. Concretely, we (i) train a visual foresight predictor from images of terminal states of the base policy, labeled using downstream rollout statistics, and (ii) train residual policies via backward foresight induction, using the predictor output as a reward multiplier. On a three-phase wrench-based nut-tightening assembly task in Isaac Gym (grasp, move-insert, rotate), our method achieves 85.6% full-task success, outperforming standard subtask residual RL (54.5%) and VLA baselines, while leaving per-subtask success unchanged. These results highlight that improving long-horizon performance requires shaping which successful states are produced at each sub-task, not only whether success occurs.

## 2. 论文提出的方法论：核心思想、关键技术细节与算法流程

### 核心思想
- **前瞻值函数**（Foresight Value Function）：定义为给定当前子任务终端状态 \( s \) 后，后续子任务策略获得的期望最终阶段成功回报。用这个值来加权当前子任务的稀疏成功奖励，从而引导子任务策略产生更有利于后续成功的终端状态。
- **前向预测 + 后向归纳**：离线训练一个**视觉前瞻预测器**，从当前子任务终端状态的图像估计下一个子任务的成功概率；然后按照**后向前瞻归纳**（从最后一个子任务开始，逆向训练每个子任务的残差策略），使用预测器输出作为奖励乘数。

### 关键技术细节
1. **残差策略框架**：在冻结的基 VLA 策略 \(\pi_k^0\) 上添加一个小权重残差策略 \(\pi_k^{\text{res}}\)（\(\alpha=0.1\)），最终动作 \(a_t = \pi_k^0(o_t) + \alpha \cdot \pi_k^{\text{res}}(o_t)\)。残差策略仅输入腕部相机图像，通过 DINOv2 + LSTM 实现。
2. **前瞻预测器训练**（Algorithm 2）：
   - 对于每个子任务边界 \(k \to k+1\)，使用基策略 \(\pi_k^0\) 收集 \(N=2560\) 个成功终端状态。
   - 对每个终端状态，执行 \(K_{\text{rep}}=5\) 次下游策略 \(\pi_{k+1}\) 的 rollout，记录成功次数 \(\kappa_i\)，得到标签 \(y_i = \kappa_i / K_{\text{rep}}\)。
   - 训练一个基于 DINOv2（LoRA 微调）的预测器 \(p_\phi: \mathcal{O} \to [0,1]\)，使用二项负对数似然损失 \(\mathcal{L}(\phi) = -\sum_i [\kappa_i \log p_\phi(o_i) + (K_{\text{rep}}-\kappa_i)\log(1-p_\phi(o_i))]\)。
3. **后向前瞻归纳**（Algorithm 1）：
   - 从最后阶段 \(K\) 开始训练，使用标准稀疏奖励 \(r_t = \beta_K(s_{t+1})\)。
   - 对于阶段 \(k < K\)，先训练好下游策略 \(\pi_{k+1}\)，然后用前瞻预测器 \(p_\phi\) 为当前阶段提供奖励 \(r_t = \beta_k(s_{t+1}) \cdot p_\phi(o_{t+1})\)，再通过 PPO 训练残差策略。
4. **近似**：使用单步前瞻（只预测下一个子任务的成功概率）近似完整多步前瞻值。

1. **标准残差RL无法提升链式任务性能**：尽管标准残差RL显著提高了各子任务的孤立成功率（如插入从45.7%提升至92.2%），但全任务成功率仅54.5%，与端到端π0持平（54.9%），说明孤立优化不能解决交接问题。

4. **子任务成功率的提升不是关键**：本文方法并不显著提高子任务孤立成功率（甚至略有下降），但通过引导策略产生更利于下游的终端状态，实现了链式任务的飞跃。
5. **后向前瞻归纳的稳定性**：由于下游策略固定后才训练上游，避免了联合优化中的非平稳性问题。
