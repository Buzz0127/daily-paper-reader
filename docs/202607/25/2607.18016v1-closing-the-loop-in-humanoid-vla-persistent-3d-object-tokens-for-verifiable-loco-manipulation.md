## 摘要
视觉-语言-动作策略是通用机器人控制的一个有前景的基础，但长时域的人形行走操作要求机器人将任务物体视为在运动、接触、遮挡和恢复过程中持续存在的物理实体。我们将此问题研究为物体状态散度：用于调节全身动作的物体状态可能与用于判断动作是否达到预期物理关系的状态不同。我们提出可持久化物体标记化（POT），该方法从RGB-D观测中维护角色索引的3D物体记录，并将其转换为全身动作专家的物体标记。实例化为POT-VLA，相同的物体记录既用于条件化动作生成，又支持几何谓词检查，从而形成一个闭环执行系统，其中物体状态既可操作又可验证。在Unitree G1上，POT-VLA在八个真实世界任务族中将匹配的直接GR00T-N1.7基线从39/80成功次数提升至71/80。在外部与Being-0对齐的参考中，POT-VLA在对齐的服务任务上达到44/50成功次数，而Being-0论文报告的成功次数为37/50。最大的提升出现在需要维持3D关系的任务上，这表明以物体为中心的持久化状态是可验证人形VLA执行的一个有用抽象。

## Abstract
Vision-language-action policies are a promising foundation for general robot control, but long-horizon humanoid loco-manipulation requires the robot to treat task objects as persistent physical entities across movement, contact, occlusion, and recovery. We study this problem as object-state divergence: the object state used to condition a whole-body action can differ from the state used to decide whether the action achieved the intended physical relation. We propose \emph{Persistent Object Tokenization} (POT), which maintains role-indexed 3D object records from RGB-D observations and converts them into object tokens for a whole-body action expert. Instantiated as \emph{POT-VLA}, the same object records condition action generation and support geometric predicate checks, yielding a closed-loop execution system in which object state is both actionable and verifiable. On a Unitree G1, POT-VLA improves a matched direct GR00T-N1.7 baseline from 39/80 to 71/80 successes over eight real-world task families. In an external Being-0-aligned reference, POT-VLA achieves 44/50 successes on aligned service tasks, compared with the 37/50 success reported by the Being-0 paper. The largest gains occur on tasks requiring maintained 3D relations, suggesting that persistent object-centered state is a useful abstraction for verifiable humanoid VLA execution.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：人形机器人在长时程行走-操作任务中，存在“物体状态发散”（object-state divergence）问题——用于条件化全身动作的物体状态，与用于判断动作是否实现预期物理关系的状态不一致。这导致抓取、放置、恢复等环节的失败，例如抓取目标不精确、放置位置偏移、子任务过早切换等。
- **研究动机**：现有VLA策略通常隐式地将物体编码在视觉-语言特征中，难以在接触、遮挡、移动后刷新和共享；任务进展监控常使用分离的符号层或语言级状态，造成动作生成与效果验证使用不同的物体表示。
- **整体含义**：提出可持久化物体标记化（POT），构建基于角色索引的3D物体记忆，使其同时服务于动作生成和几何谓词验证，从而形成闭环执行系统，提升人形机器人长时间操作的可靠性和可验证性。

## 2. 论文提出的方法论

### 核心思想
- **持久化物体标记化（POT）**：从RGB-D观测中提取任务相关物体的角色、3D位姿、置信度、关系特征等，构建角色索引的物体记忆，并序列化为“持久3D物体令牌”（Persistent 3D Object Tokens），供全身动作专家使用。
- **闭环系统（POT-VLA）**：共享同一物体记忆：动作生成前，动作专家接收物体令牌；执行后，RGB-D刷新记忆，几何谓词验证物理关系，实现“维持→执行→观测→验证→恢复”循环。

### 关键技术细节
- **物体记忆构建**：给定子任务 \( \tau_i \) 和实体集 \( E_i \)，从RGB-D观测 \( o_t \) 和本体感知 \( s_t \) 构建角色索引记录 \( \mathcal{M}^{\tau_i}_t = \{ m^e_t \mid e \in E_i \} \)，包含语义角色、短语、2D框、3D质心/尺寸、置信度、可见性、关系特征等。使用SAM3获取掩码，深度反投影到机器人基座坐标系。
- **持久物体令牌模式**：默认8个槽位（K=8），每个槽位33维特征（F=33），包括可见性、置信度、归一化2D框、3D质心/尺寸/朝向、关系特征等。未使用槽位填充为PADDING并屏蔽。令牌经LayerNorm→Linear→GELU→Dropout→Linear投影到DiT隐空间。
- **动作头插入**：物体令牌插入DiT自注意力序列中（\( S_t = [Z^{state}_t, Z^{obj}_t, Z^{action}_t] \)），与状态令牌、动作令牌并列，视觉-语言特征通过交叉注意力接入。预测全身动作块 \( \hat{a}_{t:t+H} \)。
- **谓词验证与恢复**：几何谓词集 \( \Psi_i \) 包括包含、支撑、末端-目标接近、目标-目的地位移等。每个谓词用 \( \langle \kappa, \alpha, op, \nu, n \rangle \) 表示。执行后刷新记忆，计算证据 \( \phi(\kappa, \alpha, \mathcal{M}^{\tau_i}_\xi) \)，判断谓词是否满足。返回状态：in_progress, done, blocked, failed, uncertain，并附带诊断信息（如目标不可见、抓取失败、支撑不稳）。根据状态选择继续、重试、重新观测、重新定位或重新规划。
- **训练**：使用与基座动作专家相同的动作块预测目标，无辅助物体记忆或谓词损失。演示数据配对物体令牌侧车，微调时更新物体令牌分支。
