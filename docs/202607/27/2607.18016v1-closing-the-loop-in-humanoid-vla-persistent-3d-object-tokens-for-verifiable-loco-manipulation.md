## 摘要
视觉-语言-动作策略是通用机器人控制的有前景基础，但长时程的类人移动操控要求机器人将任务物体视为跨越运动、接触、遮挡和恢复的持久物理实体。我们将此问题研究为物体状态发散：用于调节全身动作的物体状态可能与用于判断动作是否达到预期物理关系的状态不同。我们提出持久物体令牌化（POT），该方法从RGB-D观测中维护角色索引的3D物体记录，并将其转换为用于全身动作专家的物体令牌。实例化为POT-VLA后，相同的物体记录条件化动作生成并支持几何谓词检查，形成物体状态既可操作又可验证的闭环执行系统。在Unitree G1上，POT-VLA在八个真实世界任务族中将匹配的直接GR00T-N1.7基线的成功率从39/80提升至71/80。在外部Being-0对齐参考中，POT-VLA在对齐的服务任务上实现了44/50的成功率，而Being-0论文报告的成功率为37/50。最大的提升出现在需要维持3D关系的任务上，这表明以物体为中心的持久状态是可验证类人VLA执行的有用抽象。

## Abstract
Vision-language-action policies are a promising foundation for general robot control, but long-horizon humanoid loco-manipulation requires the robot to treat task objects as persistent physical entities across movement, contact, occlusion, and recovery. We study this problem as object-state divergence: the object state used to condition a whole-body action can differ from the state used to decide whether the action achieved the intended physical relation. We propose \emph{Persistent Object Tokenization} (POT), which maintains role-indexed 3D object records from RGB-D observations and converts them into object tokens for a whole-body action expert. Instantiated as \emph{POT-VLA}, the same object records condition action generation and support geometric predicate checks, yielding a closed-loop execution system in which object state is both actionable and verifiable. On a Unitree G1, POT-VLA improves a matched direct GR00T-N1.7 baseline from 39/80 to 71/80 successes over eight real-world task families. In an external Being-0-aligned reference, POT-VLA achieves 44/50 successes on aligned service tasks, compared with the 37/50 success reported by the Being-0 paper. The largest gains occur on tasks requiring maintained 3D relations, suggesting that persistent object-centered state is a useful abstraction for verifiable humanoid VLA execution.

# 论文总结

## 1. 核心问题与整体含义
- **研究动机**：人形机器人在长时程移动操控中存在“物体状态发散”问题——用于条件化动作的物体状态与用于判断动作是否达到预期物理关系的状态不一致。这导致小的抓取、放置误差积累，引起过早任务转移、错误物体操控或无效恢复。
- **整体含义**：提出持久物体令牌化（POT），将任务物体视为持续存在的物理实体，通过共享的物体内存同时服务于动作生成和效果验证，形成闭环执行系统，大幅提升人形机器人在真实世界多步操作中的成功率。

## 2. 方法论
- **核心思想**：POT从RGB-D观测中维护角色索引的3D物体记录（持久物体内存），将其序列化为持久3D物体令牌，送入全身动作专家的自注意力序列；执行动作块后，刷新相同物体记录，并用几何谓词检查物理关系是否达成，形成“维护→动作→观察→验证→恢复”闭环。
- **关键技术细节**：
  - **任务角色物体记录**：每个活跃子任务定义实体集，POT为每个实体构建记录`met`，包含：角色（TARGET、DESTINATION等）、短语、2D框、3D质心/范围、置信度、可见性、关系特征（物体-容器距离、末端执行器偏移等）。使用SAM3获取掩码，深度像素反投影到机器人基座坐标系。
  - **持久3D物体令牌模式**：默认K=8个槽，每个槽F=33个特征，包括语义角色、可见性、置信度、2D框、3D质心、3D范围、可选方向、关系特征。空槽用PADDING并掩码。令牌通过LayerNorm→线性→GELU→Dropout→线性投影为DiT隐层维度。
  - **动作头插入**：令牌插入DiT自注意力序列中（布局：`[状态令牌，物体令牌，动作令牌]`），视觉-语言编码器隐藏状态用于交叉注意力。动作专家预测完整的全身动作块`ˆa_{t:t+H}`。
  - **训练与微调**：使用相同动作块预测目标，无额外辅助损失。演示数据配合同步物体令牌侧车，更新物体令牌分支和动作头参数。禁用时回退到基线路径。
  - **谓语级验证与恢复**：几何谓语检查器读取相同物体内存，评估前提条件和完成条件，返回in_progress/done/blocked/failed/uncertain状态及诊断信息（如可见性缺失、抓取失败、放置错误等）。根据状态选择continue、retry、reobserve、reground、replan。

## 6. 主要结论与发现
- **POT-VLA显著提升成功率**：在8任务套件中从39/80（48.75%）提升至71/80（88.75%）；外部基准上44/50 vs 37/50。

## 7. 优点
- **新颖的共享物体内存抽象**：将动作生成和效果验证建立在同一物体状态上，从根本上解决物体状态发散问题。
- **实用性强**：不依赖仿真、物理引擎或动力学模型，仅用RGB-D观测和机械度量，可直接部署在真实人形机器人上。
- **实验充分且客观**：8个多样化真实世界任务、消融、泛化测试，控制变量，结果显著。
- **模块化设计**：可插入现有VLA策略（如GR00T-N1.7），无需从头训练，便于复现和推广。
- **结构化恢复机制**：谓语验证提供细粒度诊断（抓取失败、放置错误等），支持局部重试而非全局重规划。

## 8. 不足与局限
