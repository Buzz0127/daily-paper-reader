## 摘要
视觉-语言-动作策略是通用机器人控制的一个有前景的基础，但长时间跨度的类人移动操作要求机器人将任务对象视为跨运动、接触、遮挡和恢复的持久物理实体。我们将此问题研究为对象状态发散：用于调节全身动作的对象状态可能与用于决定动作是否达到预期物理关系的状态不同。我们提出可持久对象令牌化（POT），该方法从RGB-D观测中维护角色索引的3D对象记录，并将其转换为用于全身动作专家的对象令牌。实例化为POT-VLA，相同的对象记录调节动作生成并支持几何谓词检查，从而产生一个闭环执行系统，其中对象状态既可行又可验证。在Unitree G1上，POT-VLA在八个真实世界任务系列上将匹配的直接GR00T-N1.7基线从39/80成功提高到71/80成功。在一个外部的Being-0对齐参考中，POT-VLA在对其服务任务上实现了44/50成功，而Being-0论文报告的成功率为37/50。最大的改进出现在需要维持3D关系的任务上，这表明以对象为中心的持久状态是可验证的类人VLA执行的一个有用抽象。

## Abstract
Vision-language-action policies are a promising foundation for general robot control, but long-horizon humanoid loco-manipulation requires the robot to treat task objects as persistent physical entities across movement, contact, occlusion, and recovery. We study this problem as object-state divergence: the object state used to condition a whole-body action can differ from the state used to decide whether the action achieved the intended physical relation. We propose \emph{Persistent Object Tokenization} (POT), which maintains role-indexed 3D object records from RGB-D observations and converts them into object tokens for a whole-body action expert. Instantiated as \emph{POT-VLA}, the same object records condition action generation and support geometric predicate checks, yielding a closed-loop execution system in which object state is both actionable and verifiable. On a Unitree G1, POT-VLA improves a matched direct GR00T-N1.7 baseline from 39/80 to 71/80 successes over eight real-world task families. In an external Being-0-aligned reference, POT-VLA achieves 44/50 successes on aligned service tasks, compared with the 37/50 success reported by the Being-0 paper. The largest gains occur on tasks requiring maintained 3D relations, suggesting that persistent object-centered state is a useful abstraction for verifiable humanoid VLA execution.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究对象**：人形机器人（humanoid）的长时程移动操作（loco-manipulation），即结合行走、抓取、放置、交接等动作的连续任务。
- **核心问题**：现有VLA（视觉-语言-动作）策略在长时程任务中面临**物体状态发散**（object-state divergence）问题——用于条件化动作生成的物体状态与用于验证动作是否达成预期物理关系的状态可能不一致，导致动作执行在语义上正确但实际物理关系错误（如抓空、放偏、误判完成）。
- **研究动机**：人形机器人在行走、接触、遮挡和恢复过程中，任务物体必须被视为**持久物理实体**，其3D状态需持续可访问、可动作、可验证。
- **整体含义**：提出**持久物体令牌化**（Persistent Object Tokenization, POT）作为共享抽象，通过维护角色索引的3D物体记录并转化为物体令牌，同时用于动作生成和几何谓词验证，从而在VLA中实现闭环执行。

## 2. 方法论

### 核心思想
- 构建一个**角色索引的物体内存**（role-indexed object memory），以机器人基座坐标系维护任务相关物体的3D几何及关系信息。
- 该内存被序列化为**可持久3D物体令牌**（Persistent 3D Object Tokens），插入到动作专家（GR00T-N1.7）的DiT（扩散Transformer）动作头序列中，条件化动作生成。
- 每次执行一个短时域动作块后，通过RGB-D观测刷新同一物体内存，并利用**几何谓词**（geometric predicates）验证动作是否达成预期物理关系，形成“条件化 → 执行 → 刷新 → 验证 → 恢复”的闭环。

### 关键技术细节

1. **持久物体令牌化（POT）**：
   - 从RGB-D观测中提取SAM3（Segment Anything Model 3）掩码，反投影得到3D质心、范围、可见性、置信度等。
   - 构建固定槽位（K=8）的令牌张量，每个槽位包含：语义角色ID（TARGET、DESTINATION、SUPPORT、HANDOVER_PARTNER等）、可见性、置信度、2D边界框、3D质心、3D范围、方向（可选）、关系特征（如末端执行器偏移、目标-目的地位移、包含关系等）。
   - 未使用的槽位填充为PADDING并掩码；低置信度或遮挡时保留槽位但标记为不确定。

2. **令牌注入动作专家**：
   - 保持GR00T-N1.7的视觉-语言骨干不变，仅在DiT动作头序列中插入物体令牌：序列布局为 `[状态令牌, 物体令牌, 动作令牌]`。
   - 物体令牌通过一个轻量MLP（LayerNorm → Linear → GELU → Dropout → Linear）投影到DiT隐藏维度，并与角色嵌入、上下文嵌入相加。
   - 训练时使用与部署相同的角色感知RGB-D方案生成令牌侧车，仅微调动作头参数，不添加额外损失。

3. **谓词级验证与恢复**：
   - 几何谓词覆盖：包含、支撑、靠近、位移、双手分配、交接距离等。
   - 每个谓词形式化为 `<κ, α, op, ν, n>`，即类型、参数、比较操作符、阈值、稳定窗口。
   - 验证状态包括：in_progress（继续）、done（完成）、blocked（前提失败）、failed（超时/安全）、uncertain（低置信度触发重新观测）。
   - 根据诊断选择继续、重试、重新观测、重新接地或重规划。

## 6. 主要结论与发现

- **核心结论**：持久物体中心状态（persistent object-centered state）是可验证人形VLA执行的有效抽象。
- **定量结果**：
  - POT-VLA在8个任务族上成功71/80，直接基线仅39/80，提升近一倍。
  - 在Being-0对齐服务任务上实现44/50，高于原报告37/50。
  - 最大改进出现在需维持3D关系的任务（堆杯：1/10→8/10；两球放置：5/10→9/10；衣物运输：3/10→9/10）。
- **消融贡献**：
  - “仅令牌”提升最大（15/40→31/40），说明显式3D物体条件化解决大部分接地错误。
  - “仅验证器”提升至22/40，主要消除假完成和部分失败。
  - 完整POT-VLA达到34/40，表明验证提供残留增益。
- **泛化表现**：POT-VLA在新物体实例、布局偏移、扰动下均优于基线（如新实例：6/10→9/10）。
- **故障模式分析**：直接基线错误多数不是语义误解，而是度量级物体状态错误（抓不准、放偏、漏小物体）；POT-VLA通过重观测、重尝试避免静默推进。

## 7. 优点

- **方法创新性**：首次在VLA中引入**共享物体内存**，将物体令牌同时用于动作条件化与验证，解决“状态发散”核心问题。
- **系统闭环设计**：形成“维持-动作-观测-验证-恢复”闭环，无需模拟器或显式物理引擎。
- **与现有框架兼容**：仅修改动作头输入，不改变骨干网络或动作空间，便于集成到GR00T等开源VLA中。
- **消融实验设计严谨**：分别评估令牌和验证器的独立贡献，论证清晰。
- **真实机器人验证**：在复杂办公室环境、灵巧手、多种任务下进行大量实机实验，结果可信。
- **与SOTA外部基准比较**：提供Being-0对齐参考，尽管并非复现，但仍展示可比性能。

## 8. 不足与局限

- **依赖感知质量**：POT依赖SAM3掩码、RGB-D深度、相机标定质量；低纹理、透明物体或极端遮挡下性能可能下降。
- **动作专家瓶颈**：POT-VLA的动作头仍基于GR00T-N1.7，其当前人体覆盖（embodiment coverage）有限，难以直接迁移到其他机器人。
- **验证范围有限**：几何谓词仅覆盖空间关系，缺乏对接触力、变形、交互完成度的精细判断；复杂语义条件需依赖VLM辅助。
- **计算开销未报告**：未量化物体令牌化、几何推理和循环验证的实时延迟，是否满足人形机器人实时控制需求存疑。
- **实验局限**：仅单机器人平台（Unitree G1），未在更大人形机器人（如Fourier GR-2、Tesla Optimus）或不同机械臂形态上验证。
- **训练数据要求**：物体令牌侧车需在训练时与演示数据配对，可能增加数据采集复杂度。
- **恢复策略朴素**：当前恢复主要依赖重试或重新观测，缺乏基于物理模型或学习的更智能重规划。
