## 摘要
具身智能通常通过针对操纵或导航等单个任务的专用模型进行研究，导致能力碎片化，且跨任务、环境和机器人本体的泛化能力有限。在这项工作中，我们研究了异构的具身决策问题是否可以在单个视觉-语言-动作模型中得到统一。我们提出了Qwen-VLA，一个统一的具身基础模型，它将Qwen的视觉-语言建模栈从感知、理解和推理扩展到连续动作和轨迹生成，通过一个基于DiT的动作解码器。Qwen-VLA通过大规模联合预训练方案在多样化的数据源上进行训练，包括机器人操纵轨迹、人类自我中心演示、合成模拟数据、视觉与语言导航数据、轨迹中心监督以及辅助的视觉-语言数据。为了支持多种机器人平台，我们引入了具身感知提示调节，其中机器人特定的文本描述指定了当前的具身和控制约定。我们进一步将操纵、导航和轨迹预测统一到一个动作与轨迹预测框架中，使得视觉定位、空间推理和连续动作生成能够在不同机器人形态、任务族和环境之间迁移。在操纵、导航和轨迹中心基准上的实验表明，Qwen-VLA在场景布局、背景、光照、物体配置和机器人本体变化下具有一致的多任务性能和分布外泛化能力。Qwen-VLA-Instruct在LIBERO上达到97.9%，在Simpler-WidowX上达到73.7%，在RoboTwin-Easy/Hard上达到86.1%/87.2%，在R2R上达到69.0%的OSR，在RxR上达到59.6%的SR，在真实世界的ALOHA实验中平均OOD成功率为76.9%，在DOMINO动态操纵任务中零样本成功率为26.6%。

## Abstract
Embodied intelligence is often studied through specialized models for individual tasks such as manipulation or navigation, resulting in fragmented capabilities and limited generalization across tasks, environments, and robot embodiments. In this work, we study whether heterogeneous embodied decision-making problems can be unified within a single vision-language-action model. We present Qwen-VLA, a unified embodied foundation model that extends Qwen's vision-language modeling stack from perception, understanding, and reasoning to continuous action and trajectory generation through a DiT-based action decoder. Qwen-VLA is trained with a large-scale joint pretraining recipe over diverse data sources, including robotics manipulation trajectories, human egocentric demonstrations, synthetic simulation data, vision-and-language navigation data, trajectory-centric supervision, and auxiliary vision-language data. To support multiple robot platforms, we introduce embodiment-aware prompt conditioning, where robot-specific textual descriptions specify the current embodiment and control convention. We further cast manipulation, navigation, and trajectory prediction into a unified action-and-trajectory prediction framework, enabling transferable visual grounding, spatial reasoning, and continuous action generation across robot morphologies, task families, and environments. Experiments on manipulation, navigation, and trajectory-centric benchmarks show consistent multi-task performance and out-of-distribution generalization under variations in scene layout, background, lighting, object configuration, and robot embodiment. Qwen-VLA-Instruct achieves 97.9% on LIBERO, 73.7% on Simpler-WidowX, 86.1%/87.2% on RoboTwin-Easy/Hard, 69.0% OSR on R2R, 59.6% SR on RxR, 76.9% average OOD success in real-world ALOHA experiments, and 26.6% zero-shot success on DOMINO dynamic manipulation.

# Qwen-VLA: 统一跨任务、环境和机器人本体的视觉-语言-动作建模 —— 论文总结

## 1. 核心问题与整体含义（研究动机和背景）

- **现状碎片化**：现有的具身智能模型通常针对单一任务（如桌面操作、导航）或单一机器人平台单独设计，导致能力碎片化，难以跨任务、环境和机器人形态进行泛化。
- **核心挑战**：虽然操作、导航、人机交互等任务在输出格式、控制频率和动作维度上存在显著差异，但它们共享共同的计算结构：代理必须基于视觉观察、语言指令和具身约束来预测未来动作或轨迹。
- **研究目标**：验证能否将这些异构的具身决策问题统一在**单个视觉-语言-动作（VLA）模型**中，从而构建一个通用的具身基础模型，实现跨任务、跨环境、跨本体的迁移。

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想

将操作、导航、轨迹预测和人类自我中心动作建模统一到一个**共享的动作-轨迹预测空间**中，并利用**具身感知提示**（embodiment-aware prompt conditioning）区分不同机器人平台的硬件特性与控制约定，从而让单一模型学习跨本体的视觉定位、空间推理和连续动作生成能力。

### 2.2 模型架构

- **视觉语言骨干**：基于 Qwen3.5-4B，一个原生多模态模型，支持文字、图像和视频的联合处理，具备精细视觉感知、指代理解和结构化推理能力。
- **动作解码器**：采用 **DiT（扩散Transformer）** 实现的流匹配策略（flow-matching policy），输入是 VLM 隐藏状态与噪声动作块的拼接，通过联合自注意力与 AdaIN 时间步条件生成连续动作。该解码器参数量约为 1.15B。
- **具身感知提示**：在每个训练样本前添加机器人特定文本描述，包括机器人名称、单/双臂配置、控制频率、预测块大小等，作为唯一区分不同本体的接口。

### 2.3 统一动作表示

- 所有本体共享一个固定通道数 K 的预测张量，每个动作模式（如末端执行器位姿、关节角、导航路径点）占据前 c 个通道，剩余通道零填充，并使用**二元掩码**确保梯度只作用于有效通道。
- 动作类型涵盖：增量/绝对末端执行器位姿、关节角、夹爪开度、灵巧手关节、导航路径点等。

### 2.4 训练目标

- **动作损失**：条件流匹配（conditional flow matching），计算带掩码的均方误差，分通道均匀平均，防止填充区域影响梯度。
- **视觉语言损失**：保留标准的下一个词元预测损失，用于维持骨干模型的感知和推理能力。
- **联合目标**：加权和，权重 λₐct 和 λ_vl 平衡两部分梯度。

### 2.5 四阶段训练策略

- **Stage I: T2A（文本到动作预训练）**：冻结 VLM，仅训练 DiT，输入为文本+具身提示，无图像。目的是构建语言索引的动作先验，让解码器学会将紧凑的描述解压缩为完整动作分布。
- **Stage II: CPT（继续预训练）**：解冻两个模块，在混合数据（模拟+真实）上训练，将动作先验锚定到视觉观察中。
- **Stage III: SFT（监督微调）**：分为两条并行分支——多任务SFT（涵盖VQA、空间定位、操作、导航）和真实机器人SFT（基于国内遥操作数据）。
- **Stage IV: RL（强化学习）**：在多任务SFT检查点基础上，在 SimplEnv 环境中用 PPO 和稀疏二进制奖励优化闭环任务成功率，产生最终模型 Qwen-VLA-Instruct。

### 2.6 关键技术细节

- **文本到动作预训练（T2A）的消融设计**：数据组成、全序列 vs 分块预测、是否引入图像、流匹配时间步分布、训练时长等均有详细实验。
- **RL 中的重要性采样**：将概率流 ODE 转换为 SDE 以计算 log-probability，实现流解码策略的 PPO 更新。
- **具身感知提示模板**：`The robot is {robot_tag} with {single arm / dual arms}[, waist][, and mobile base]. The control frequency is {FPS} Hz. Please predict the next {chunk_size} control actions to execute the following task: {ori_instruction}.`

## 6. 主要结论与发现

1. **统一模型可以超越专用模型**：Qwen-VLA-Instruct 在 LIBERO（97.9%）、Simpler-WidowX（73.7%）、RoboTwin-Hard（87.2%）上均超过所有对比的专用模型；在 RoboCasa-GR1 和 RoboTwin-Easy 上也达到最佳或次佳。
2. **预训练提供强基础，SFT 与 RL 带来显著提升**：从 Base 到 Instruct，各基准提升 7-21 个百分点，RL 在训练环境（SimplerEnv）上额外提升 2.9%，且对其他基准无伤害。
3. **跨本体泛化有效**：通过具身感知提示，单一模型可部署在 WidowX、ALOHA、GR1、Franka 等多种机器人上，零样本或微调后均能达到可用性能。
4. **OOD 泛化能力强**：在颜色、实例、位置、背景、指令变化下，实际 ALOHA 实验平均 OOD 成功率 76.9%，大幅超越 π0.5（41.5%）；在 DOMINO 动态操作上零样本 SR 26.6%，超过所有微调过的动态专用方法。
5. **视觉-语言数据对动作学习有益**：在需要精细物体识别和组合指令解析的任务中（如 RoboCasa-GR1），混合 VL 数据带来 4.9% 的提升，而简单任务不受影响。
6. **T2A 最佳实践**：使用 ~20% 合成+80% 真实数据、全序列预测、不含图像、Sigmoid-Normal 时间步分布、2000 步训练。

## 7. 优点

- **高度统一性**：首次将操作、导航、人类自我中心动作、轨迹预测统一在单个 VLA 模型中，且支持多种机器人形态。
- **训练策略创新**：四阶段渐进式训练（T2A→CPT→SFT→RL）逻辑清晰，有效解决了 VLM 骨干与动作解码器初始化不对称的问题。
- **具身感知提示机制**：轻量有效，无需修改架构即可处理不同机器人，是可扩展的关键设计。
- **实验验证全面**：从模拟到真实世界、从域内到 OOD、从静态到动态，覆盖了广泛的具身场景。
- **开源意识**：论文提到项目开源（GitHub 链接），有利于社区复现与推动。

## 8. 不足与局限

1. **算力资源未公开**：未提供 GPU 型号、数量和总训练时长，影响可复现性。
2. **数据规模仍有限**：尽管收集了多种数据，但动作训练数据相比视觉-语言预训练数据仍少几个数量级，导致长尾物体和接触丰富场景的泛化不够。
3. **优化权衡**：联合训练导致部分纯 VLM 和导航任务有轻微性能回退，需要更好的目标平衡或课程学习。
4. **评估仍偏短视**：当前基准多为短视任务（episode 较短），缺乏长时间尺度、易出错的实际部署验证。
5. **RL 环境单一**：RL 仅在 SimplEnv 中训练，尽管有正迁移，但可能在未涵盖的物理环境中引入偏差。
6. **状态信息利用不足**：论文显示显式状态条件对性能提升有限，但未来或许需更强的状态融合来处理更复杂的机器人（如全自由度人形）。
