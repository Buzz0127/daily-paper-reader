## 摘要
导航与操作是具身智能的基本能力，使机器人能够解析自然语言命令并与周围环境进行物理交互。然而，当前的视觉-语言-动作（VLA）模型仍受限于特定任务的架构，专注于导航或操作，这阻碍了通用机器人代理的开发。为了弥合这一差距，我们提出了OneVLA，一个统一的架构，将这些不同的任务整合到单个一致的框架中。具体来说，我们设计了一个统一的动作头，能够生成导航和操作动作，而无需特定任务的变体。此外，我们提出了一种多阶段渐进训练策略——包括精心设计的数据构建和思维链（CoT）微调——促进了两个领域之间的强正迁移和相互增强。在模拟和真实环境中的大量实验表明，OneVLA实现了最先进的性能，显著优于专门的单任务和现有的跨任务模型。通过统一这些核心能力，OneVLA为真正通用的机器人系统铺平了道路。模型和源代码将公开发布。

## Abstract
Navigation and manipulation are fundamental capabilities of embodied intelligence, enabling robots to interpret natural language commands and interact physically with their surroundings. However, current Vision-Language-Action (VLA) models remain constrained by task-specific architectures, specializing in either navigation or manipulation, which hinders the development of general-purpose robotic agents. To bridge this gap, we introduce OneVLA, a unified architecture that integrates these distinct tasks into a single, cohesive framework. Specifically, we design a unified action head capable of generating both navigation and manipulation actions without requiring task-specific variants. Furthermore, we propose a multi stage progressive training strategy-incorporating curated data construction and Chain-of-Thought (CoT) fine-tuning that facilitates strong positive transfer and mutual reinforcement between the two domains. Extensive experiments in both simulated and real-world environments demonstrate that OneVLA achieves state-of-the-art performance, significantly outperforming both specialized single-task and existing cross-task models. By unifying these core capabilities, OneVLA paves the way for truly general-purpose robotic systems. The model and source code will be publicly released.

- **背景**：视觉-语言-动作（VLA）模型在具身智能领域取得显著进展，但现有模型存在根本性的架构限制——它们通常被设计为**任务特定**的，要么专精于导航（如NaVid、MapNav），要么专精于操作（如OpenVLA、π0），缺乏统一的通用性。即便是一些跨任务模型（如UniVLA）仍需为不同任务保留不同的动作头或模型变体。
- **核心问题**：能否设计一个**统一的VLA架构**，在不依赖任务特定变体的前提下，同时高效地执行导航和操作任务？并且，这两种基础具身能力能否在联合训练中相互受益，提升整体性能？
- **整体含义**：OneVLA通过提出一个统一的动作头和渐进式多阶段训练策略，首次将导航和操作整合到单一模型中，实现了跨任务的**正迁移和相互增强**，为迈向通用机器人系统奠定了基础。论文验证了统一框架不仅在架构上更优雅，在性能上也显著优于分离的单任务或浅层跨任务模型。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- **统一动作头（Unified Action Head）**：将导航的离散动作（4维：前进、左转、右转、停止）和操作的连续动作（7维：6D位姿增量+夹爪开合）拼接成一个**11维统一动作空间**。训练时通过**任务特定权重掩码**（weight mask）分别计算各任务维度的损失，确保梯度只更新相关维度，而无关维度被屏蔽。
- **多阶段渐进训练（Multi-Stage Progressive Training）**：分三个阶段逐步引入任务复杂性：
  1. **阶段1**：仅使用操作数据集和通用视觉问答（VQA）数据，建立基础操作能力。
  2. **阶段2**：加入导航数据集，进行联合训练（导航+操作+VQA），通过共享视觉语言编码器实现跨任务知识迁移。
  3. **阶段3**：引入思维链（Chain-of-Thought, CoT）数据，增强模型的推理能力和决策质量，进一步提升跨任务性能。
- **输出生成机制**：使用特殊令牌 `<text>...</text><action>...</action>` 在同一前向传播中先后生成文本推理和动作序列。语言模型先输出解释性文本，再生成动作。

### 关键技术细节
- **视觉语言骨干**：基于 Qwen2.5-VL-3B-Instruct，包含32层视觉Transformer（patch size 14×14，hidden dim 1280）和36层语言Transformer（hidden dim 2048，GQA，16注意力头），通过线性投影对齐视觉和文本特征。
- **动作预测**：采用**流匹配扩散模型（Flow-Matching Diffusion）**。训练时从噪声向真实动作插值，学习速度场 \(v_\theta\)；推理时通过Euler积分逐步去噪生成未来动作序列。动作头包含动作编码器、交叉注意力DiT骨干和解码器。
- **损失函数**：总损失 \(L_{\text{total}} = \lambda_{\text{vlm}} L_{\text{vlm}} + \lambda_{\text{text}} L_{\text{text}} + \lambda_{\text{action}} L_{\text{action}}\)。其中 \(L_{\text{vlm}}\) 为通用VQA的交叉熵，\(L_{\text{text}}\) 为推理文本的交叉熵，\(L_{\text{action}}\) 为带权重掩码的流匹配均方误差。超参数 \(\lambda_{\text{action}}=1, \lambda_{\text{text}}=\lambda_{\text{vlm}}=0.1\)。

## 3. 实验设计：数据集、场景、基准与对比方法

### 数据集与基准
