## 摘要
视觉-语言-动作（VLA）模型已成为通用机器人操作的一种有前景的范式。当前架构中的常见设计是将语言指令和视觉观测映射到单次前向传播中的动作。虽然概念上简单，但这种表述将指令理解、空间场景感知和运动控制纠缠在单一学习目标中。因此，动作专家必须隐式地重新学习预训练VLM中已经存在的认知和感知能力，这可能会限制学习效率和泛化能力。我们引入了AVP（基于视觉基元的动作），这是一种端到端架构，实现了这种以视觉基元为中心的接口：VLM推断下一阶段目标并发出视觉基元标记，这些标记条件化一个流匹配动作专家，其监督来自末端执行器运动学。在通用拾取-放置任务上的真实机器人实验表明，AVP相比pi_0.5将成功率提高了27.61%，并优于其他近期方法，在数据效率、空间组合泛化和物体级迁移方面均有持续改进。

## Abstract
Vision-Language-Action (VLA) models have emerged as a promising paradigm for generalist robotic manipulation. A common design in current architectures maps language instructions and visual observations to actions in a single forward pass. While conceptually simple, this formulation entangles instruction comprehension, spatial scene understanding, and motor control within a single learning objective. As a result, the action expert must implicitly relearn cognitive and perceptual capabilities already present in the pretrained VLM, which can limit both learning efficiency and generalization. We introduce AVP (Action with Visual Primitives), an end-to-end architecture that implements this visual-primitive-centric interface: the VLM infers the next-stage target and emits visual-primitive tokens that condition a flow-matching action expert, with supervision derived from end-effector kinematics. Real-robot experiments on general pick-and-place tasks show that AVP improves the success rate by 27.61% over pi_0.5 and outperforms other recent methods, with consistent gains in data efficiency, spatial-compositional generalization, and object-level transfer.

## 1. 核心问题与整体含义（研究动机和背景）

当前 Vision-Language-Action（VLA）模型通常将语言指令、视觉观察和动作预测映射到单一前向传播中，这种设计虽然概念简单，但将指令理解、空间场景感知和运动控制三大任务捆绑在同一个学习目标里。其后果是：动作专家必须隐式地重新学习 VLM 已经具备的认知与感知能力，导致**学习效率低下**、**泛化能力受限**，尤其在对象、布局或环境变化时表现脆弱。

现有改进思路包括：
- **规划中心型（如 π0.5）**：将指令拆分为子任务描述，但接口仍是纯语言，难以传递细粒度空间信息。
- **子目标图像型（如 π0.7）**：提供预测的未来帧作为视觉目标，但密集像素预测仍要求动作专家自行筛选关键信息。
- **视觉提示型（如 Point-VLA、VP-VLA）**：利用外部模型（如 SAM、通用 VLM）在输入图像上绘制空间标记，但形成级联管道，引入推理延迟和误差累积。

AVP 提出重思 VLM 与动作专家的职责划分：VLM 负责“做什么、在哪做”，动作专家专注“如何执行”，并通过**视觉基元**作为两者之间的显式通信接口，实现端到端协同优化。

## 2. 方法论

### 2.1 核心思想

将 VLM 与动作专家之间的隐式连接替换为**视觉基元（Visual Primitives）** 这一显式、空间可定位的中间表示。视觉基元可以是点、边界框、掩码等，由 VLM 自动生成，并直接条件化下游的流匹配（flow-matching）动作专家。

### 2.2 关键技术细节

- **三组件架构**：预训练 VLM → 视觉基元解码器（自回归生成离散基元） → 流匹配动作专家。
- **流程**：
  1. VLM 根据语言指令 `l` 和观测 `o_t` 产生多模态上下文 token。
  2. 视觉基元解码器自回归预测下一阶段执行所需的离散视觉基元 `p_t`。
  3. 将 `p_t` 投影到视觉 token 空间得到 `z_t^(vp)`，与原始多模态 token 融合为增强表示 `z_t^(aug)`。
  4. 动作专家（流匹配策略）以 `z_t^(aug)` 和本体状态 `s_t` 为条件，生成动作序列 `a_{t:t+h}`。
- **监督信号**：来自末端执行器运动学，不依赖外部标注或视觉检测器。具体步骤：
  - 关键帧提取（通过夹爪状态变化检测交互时刻）；
  - 从机器人本体感知获取 3D 末端位置；
  - 通过相机内参和外参投影到图像平面，得到 2D 空间锚点；
  - 锚点离散化为网格标签，用于训练解码器。
- **训练目标**：`L = L_act + λ * L_vp`，其中 `L_vp` 为基元预测交叉熵损失，`L_act` 为动作预测损失。

### 2.3 算法流程（文字说明）

1. 输入语言指令和当前多视角图像。
2. VLM 编码获得上下文特征。
3. 自回归解码器逐 token 生成视觉基元（如“box: [x, y, w, h], color: red, mask: True, memory: True”）。
4. 基元投影到图像 token 空间，与原始特征拼接。
5. 流匹配动作专家基于增强特征和本体状态，通过扩散/流匹配生成连续动作序列。

## 6. 主要结论与发现

1. **主任务性能**：AVP 在三个任务的平均成功率上均优于所有基线，相比于 π0.5 提升 27.61%（中国象棋 90.28% vs 62.67%，通用物体 86.18% vs 64.96%，多米诺 88.19% vs 81.94%）。
2. **空间组合泛化**：π0.5 在未见过的直接过渡上完全失败（0/8），而 AVP 成功执行 8/8，表明视觉基元帮助动作专家复用已学习运动模式以适应新空间配置。
3. **跨域零样本泛化**：虽然仅在象棋数据上训练，AVP 能直接泛化到多种未见过的物体（日常物品、塑料玩具等），在不同背景和指令模式下保持高成功率；π0.5 在分布偏移下显著退化。
4. **消融分析**：视觉基元（尤其是框+掩码+记忆）对性能贡献最大；掩码和记忆组件进一步提升放置精度与稳定性。
5. **推理延迟**：AVP 平均 0.27 秒，远低于 Point-VLA（37.32 秒，因调用外部 API），略高于 π0.5（0.16 秒），但仍可接受。

## 7. 优点

- **责任分离清晰**：VLM 负责“做什么、在哪做”，动作专家专注“如何做”，避免了认知与控制的纠缠。
- **端到端训练，无外部依赖**：视觉基元的监督来自末端执行器运动学，无需手动标注或调用外部感知模型，降低部署复杂度和错误传播风险。
- **表现优异**：在真实机器人上多任务验证，显著超过强基线 π0.5，且泛化能力突出。
- **泛化实验设计巧妙**：通过间接/直接过渡设置，直接测试了组合泛化能力，而不是仅测试同分布样本。
- **消融完整**：系统探索了基元类型、掩码透明度、记忆增强等设计选择，有量化对比。

## 8. 不足与局限

- **推理延迟增加**：两阶段推理（基元预测 + 动作生成）比单次通过策略（如 π0.5）额外增加约 0.11 秒，在高速任务中可能成为瓶颈。
- **依赖精确手眼标定**：监督投影需要准确的相机内参和外参，对硬件标定误差敏感；实际部署中若标定漂移，基元定位可能不准。
- **训练数据量有限**：总共约 14.6 小时演示数据，且中国象棋任务占主体（11.2 小时），可能不足以充分验证在更复杂、更视觉多样的场景中的泛化。
- **对比基线覆盖不全**：未与最近的其他 VLA 架构（如 Octo、GR-2）在同一条件下比较，且 DM0/LDA 仅在 20 指令子集上评估，削弱了对比公平性。
- **缺乏失败案例分析**：论文未详细分析失败原因（如基元预测错误 vs 动作执行错误），也未提供视觉基元的输出示例（如可视化生成的框/掩码）。
- **环境限定桌面操作**：实验中物体均位于固定工作台，未涉及移动操作、动态障碍或非结构化环境，限制了结论向更通用场景的外推。
