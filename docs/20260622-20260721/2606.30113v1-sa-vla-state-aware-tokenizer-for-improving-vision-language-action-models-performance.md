## 摘要
离散动作分词为自回归VLA策略提供了紧凑的接口，但从离散码中准确恢复连续机器人动作仍然具有挑战性。现有分词器通常将每个离散码映射到一个固定的连续动作原型，忽略了机器人当前的本体感知状态。这一限制在操作任务中尤为明显，因为相同的动作标记在不同的关节配置、物体姿态和接触条件下可能需要不同的连续控制。因此，我们提出SA-VLA，一种基于机器人状态对动作解码进行条件化的状态感知动作分词器。我们研究了两种基于VQ的动作分词的状态注入机制：状态特征与动作特征之间的交叉注意力，以及一个轻量级状态适配器，该适配器预测动作调制的因子，用于状态条件化的动作调制和重建。适配器公式允许每个离散标记表示一族状态依赖的连续动作，从而扩展了有限码本的有效支持范围，同时保持了离散动作建模的效率和兼容性。集成到基于LLM的VLA策略中后，SA-VLA支持自回归和并行动作标记解码，且对模型接口的改动最小。在12个RoboTwin操作任务上，SA-VLA将平均成功率从最强分词器基线的0.29提升到0.56。在三个真实世界任务的零样本模拟到现实实验中，它进一步将平均成功率从最强分词器基线的0.15提升到0.33。这些结果表明，状态条件化的动作解码是缩小离散VLA策略压缩差距的一种简单有效的机制。

## Abstract
Discrete action tokenization provides a compact interface for autoregressive VLA policies, but accurately recovering continuous robot actions from discrete codes remains challenging. Existing tokenizers typically map each discrete code to a fixed continuous action prototype, ignoring the robot's current proprioceptive state. This limitation is particularly pronounced in manipulation, where the same action token may require different continuous controls under different joint configurations, object poses, and contact conditions. We therefore propose SA-VLA, a state-aware action tokenizer that conditions action decoding on robot state. We study two state-injection mechanisms for VQ-based action tokenization: cross-attention between state and action features, and a lightweight state adapter that predicts action-wise modulation factors for state-conditioned action modulation and reconstruction. The adapter formulation expands the effective support of a finite codebook by allowing each discrete token to represent a family of state-dependent continuous actions, while preserving the efficiency and compatibility of discrete action modeling. Integrated into an LLM-based VLA policy, SA-VLA supports both autoregressive and parallel action-token decoding with minimal changes to the model interface. On 12 RoboTwin manipulation tasks, SA-VLA improves the average success rate from 0.29 to 0.56 over the strongest tokenizer baseline. In zero-shot sim-to-real experiments on three real-world tasks, it further improves average success from 0.15 to 0.33 over the strongest tokenizer baseline. These results demonstrate that state-conditioned action decoding is a simple and effective mechanism for reducing the compression gap in discrete VLA policies.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：现有离散动作 tokenizer（如 OpenVLA 的 binning、FAST 的 DCT+BPE、VQ-VLA 的残差 VQ-VAE）将每个离散码映射到一个固定的连续动作原型，**忽略了机器人当前的本体感知状态**（关节角度、物体位姿、接触状态等）。这导致同一动作 token 在不同情境下可能需要不同的连续控制值，限制了 VLA 模型的动作解码精度和泛化能力。
- **背景**：VLA 模型是具身智能领域的基础模型，通过预训练 VLM 从图像和语言指令中提取动作 token，再由 tokenizer 解码为连续动作。离散动作 token 化提供了与自回归 LLM 兼容的接口，但“离散码→连续动作”的压缩误差成为性能瓶颈。现有方法未能利用机器人状态来指导解码，因此本文提出 **状态感知分词器（State-Aware Action Tokenizer）**，使解码过程依赖于当前状态。

## 2. 论文提出的方法论

### 2.1 核心思想
- 在标准 VQ-VAE 基础上引入机器人状态信息，使每个离散 token 不再是固定动作原型，而是代表一族状态依赖的连续动作，从而扩展有限码本的有效支持范围。
- 研究了两种状态注入机制：**Method A（交叉注意力）** 和 **Method B（轻量适配器）**。最终采用 Method B 作为主要方案。

### 2.2 关键技术细节
- **Method A**：编码器和解码器的 Transformer 层中，key 和 value 均来自状态输入，通过 cross-attention 融合状态与动作特征。
- **Method B**：
  - 状态通过一个轻量适配器（MLP + sigmoid）预测每个动作维度的缩放因子 **w**。
  - 对输入动作进行调制：`a_trans = a ÷ w`。
  - 将调制后的动作送入标准 VQ-VAE（编码器、码本、解码器），得到重建的 `a_trans_hat`。
  - 最终动作重建：`a_hat = a_trans_hat × w`。
  - 优势：状态缩放因子使同一 token 能对应不同幅度的连续动作，本质上是将离散码本问题转化为回归问题，而无需改变码本结构。

### 2.3 公式与损失
- 量化过程：`q_i = arg min ||z_i - e_k||`，其中 z_i 为编码特征，e_k 为码本向量。
- 总损失：`L = ||a_hat - a||² + λ1 * ||sg(x) - q(x)||² + λ2 * ||x - sg(q(x))||²` （重建损失 + VQ 损失 + 提交损失）。

### 2.4 集成到 VLA
- 输入序列：语言 token → 状态 token（256 bin 离散化） → 图像 token（SigLIP-SO400M-patch14-224） → 动作 token（SA-VLA tokenizer） → 特殊分隔符。
- 支持两种解码策略：
  - **自回归解码（AR）**：逐 token 预测，使用因果注意力。
  - **并行解码（PD）**：固定长度动作块一次性生成，使用双向注意力和占位嵌入。

## 6. 论文的主要结论与发现

1. **SA-VLA 显著优于现有 tokenizer**：在 RoboTwin 上，Method B（AR）平均成功率 0.56，对比最强基线 VQ-BET（0.29）提升 27 个百分点；真实世界零样本从 0.15 提升至 0.33。

4. 并行解码性能与自回归相当（Method B 均为 0.56），推理效率更高。
