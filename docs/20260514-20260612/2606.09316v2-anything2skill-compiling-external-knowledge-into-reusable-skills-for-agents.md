## 摘要
检索增强生成（RAG）使得智能体在推理时能够访问外部知识，但它主要检索碎片化的陈述性证据，迫使智能体反复从段落、手册、示例、日志或轨迹中推断任务流程。这引发了一个基本问题：能否将从外部知识库中提取的技能安装到智能体中，使其能够快速逼近领域专业知识？在本文中，我们提出了Anything2Skill，这是一个基于分类法引导的框架，能够将异构外部知识编译为智能体的可复用、可检索和可执行的技能。给定一个知识记录语料库，Anything2Skill首先将每条记录分解为证据窗口，并在技能树先验下执行“规划-扩展”技能提取。随后，提取的候选技能被转换为结构化的技能契约，其中指定了调用条件、禁忌、动作步骤、工作流步骤、约束、输出规范、支持证据和置信度分数。为了构建可部署的程序性记忆，Anything2Skill通过分类法感知的编译、注册表级协调、生命周期跟踪、版本化更新和可视化的技能树投影，将提取的技能持久化存储在SkillBank中。在推理时，智能体从原始知识库中检索任务相关的段落，并从SkillBank中检索相关的程序性技能，使得RAG提供陈述性证据，而编译的技能提供可复用的程序性指导。在qsv和GitHub-CLI上的实验表明，Anything2Skill结合RAG分别达到了98.85%和94.10%的成功率，显著优于仅使用RAG的智能体。这些结果表明，将潜在的程序性知识编译为显式技能，是从知识访问扩展到能力复用的有效方法。

## Abstract
Retrieval-augmented generation (RAG) enables agents to access external knowledge at inference time, but it primarily retrieves fragmented declarative evidence, leaving agents to repeatedly infer task procedures from passages, manuals, examples, logs, or trajectories. This raises a fundamental question: can skills extracted from external knowledge bases be installed into an agent, enabling it to rapidly approximate domain expertise? In this paper, we propose Anything2Skill, a taxonomy-guided framework that compiles heterogeneous external knowledge into reusable, retrievable, and executable skills for agents. Given a corpus of knowledge records, \textsc{Anything2Skill} first decomposes each record into evidence windows and performs plan-and-expand skill extraction under a skill-tree prior. The extracted candidates are then converted into structured skill contracts that specify invocation conditions, contraindications, action moves, workflow steps, constraints, output specifications, supporting evidence, and confidence scores. To construct a deployable procedural memory, Anything2Skill manages the extracted skills in a persistent SkillBank through taxonomy-aware compilation, registry-level reconciliation, lifecycle tracking, versioned updates, and visible skill-tree projection. At inference time, agents retrieve both task-specific passages from the original knowledge base and relevant procedural skills from the SkillBank, allowing RAG to provide declarative evidence while compiled skills provide reusable procedural guidance. Experiments on qsv and GitHub-CLI show that Anything2Skill combined with RAG achieves 98.85\% and 94.10\% success rates, respectively, substantially outperforming RAG-only agents. These results suggest that compiling latent procedural knowledge into explicit skills is an effective way to extend retrieval-augmented agents from knowledge access toward capability reuse.

### 论文结构化总结：Anything2Skill

#### 1. 核心问题与整体含义（研究动机和背景）

- **研究背景**：大语言模型（LLM）作为智能体已被广泛应用于推理、调用工具和执行多步骤任务。检索增强生成（RAG）是让智能体获取外部知识的主流方法，但它主要提供**陈述性知识**（Declarative Knowledge），即事实性信息。
- **核心问题**：现有的RAG系统主要提供碎片化的证据，如文档片段或API描述，但并未直接告诉智能体 **“如何做”** （How to do）。因此，智能体必须每次重新从这些片段中推断任务流程、动作序列和约束条件。这种“每次从头推理”的方式效率低下且容易出错。
- **论文核心思想**：论文提出，是否可以自动从已有的、异构的外部知识库（如文档、手册、日志、对话历史等）中提取并编译出**可复用的程序性知识**（Procedural Knowledge），并将其打包成“技能”直接安装到智能体中，从而将智能体从“知识访问”扩展到“能力复用”。

#### 2. 论文提出的方法论

- **核心思想**：提出一个名为 **Anything2Skill** 的框架，该框架是一个由分类法（Taxonomy）引导的编译流水线，能够将异构的知识记录编译成结构化、可检索、可执行的技能合约，并存入一个持久的 **SkillBank** 中。
- **关键技术细节**：
    1.  **技能合约 (Skill Contract)**：技能被表示为一个结构化合约，包含技能名称、描述、资产类型、分类法节点、调用条件、禁忌、动作步骤、工作流步骤、约束、输出规范、支持证据和置信度分数。
    2.  **技能提取 (Skill Extraction)**：
        - **证据窗口 (Evidence Windows)**：将输入的每条知识记录分解为有边界的文本窗口，以确保每个技能都能追溯到原始证据。
        - **规划-扩展提取 (Plan-and-Expand Extraction)**：
            - **规划阶段**：使用LLM规划器，在每个证据窗口中识别出技能候选，包括目标、资产类型、调用线索等轻量级信息。
            - **扩展阶段**：独立地将每个候选技能扩展成一个完整的结构化技能草稿。该步骤是保守的，如果证据不支持，则返回空草稿，避免幻觉。
        - **程序性有效性过滤器**：只保留包含至少一个程序性组件（如工作流步骤、动作或约束）且能映射到分类法的候选技能。
    3.  **技能管理 (Skill Management in the SkillBank)**：
        - **文档级编译**：将来自同一文档的、描述同一能力的多个草稿进行分组，并合成为一个规范的、精简的、引用完整证据的技能规格。
        - **注册表级协调 (Registry-level Reconciliation)**：将新编译的技能与SkillBank中的现有技能进行比对。通过混合检索（结合稠密向量、稀疏文本和分类法兼容性）找到相关技能，然后由一个管理模型预测生命周期动作：创建、增强、修订、合并、拆分、无变化或丢弃。
        - **可见技能树投影**：将协调后的活跃技能组织成一个**分层的领域/族**层次结构（根据技能树先验）。这允许进行导航、检查和分类法感知的检索。
    4.  **技能增强检索 (Skill-Augmented Retrieval)**：在推理时，智能体不仅从原始知识库中检索相关的事实段落（RAG），还会从SkillBank中检索相关的程序性技能。两者结合，RAG提供声明性证据，SkillBank提供可复用的程序性指导。
